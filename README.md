# 책쓰기 AI 코칭 시스템

> 황준연(작가의 집 대표)의 100명+ 작가 배출 경험을 AI로 구현한 책쓰기 코칭 도구

## 📖 소개

이 시스템은 **11개의 AI 프롬프트**로 책쓰기 코칭의 모든 과정을 자동화합니다:

### 책쓰기 핵심 기능 (3개)
1. **제목/목차 개발**: 독자를 사로잡는 제목과 논리적인 목차 설계
2. **초안 작성**: 작가의 목소리를 살린 글쓰기 지원
3. **글 검토**: 오탈자, 비문, 문장 개선 제안

### 코칭 업무 자동화 (8개) ⭐ NEW!
4. **원고 진단**: 수강생 원고를 받으면 즉시 완성도/강점/약점 분석
5. **맞춤형 과제**: 수강생 진도별 과제 자동 생성, 난이도 조절
6. **격려 메시지**: 상황별(잘할 때/막힐 때/완성) 따뜻한 격려
7. **FAQ 답변**: 50개 자주 묻는 질문, 복붙만 하면 되는 답변
8. **상세페이지 카피**: 강의 홍보 문구 3가지 버전 자동 생성
9. **강의 커리큘럼**: 주제/대상/시간 입력하면 회차별 커리큘럼 생성
10. **블로그/뉴스레터**: 주간 콘텐츠 자동 생성 (블로그 2개, 뉴스레터 1개, SNS 10개)
11. **수강생 모집 문구**: 메타광고, 블로그, 인스타그램 각 3가지 버전

황준연 대표의 43명 이상 실제 코칭 사례와 박일섭 작가의 베스트셀러 성공 사례를 바탕으로 만들어진 검증된 방법론입니다.

**업무 시간 85% 절감, 주당 15-20시간 절약!**

## 🚀 사용 방법

### 방법 1: Claude Code / ChatGPT / 기타 AI 챗봇 사용

가장 간단한 방법입니다. 별도의 설치 없이 바로 사용할 수 있습니다.

#### Step 1: 프롬프트 파일 복사
원하는 기능에 맞는 프롬프트 파일을 엽니다:
- 제목/목차 개발: `prompts/01-title-outline.md`
- 초안 작성: `prompts/02-draft-writing.md`
- 글 검토: `prompts/03-proofreading.md`

#### Step 2: AI에게 지시
1. AI 챗봇 (Claude, ChatGPT 등)에 접속
2. 프롬프트 파일 내용 전체를 복사하여 붙여넣기
3. "위 역할을 수행해줘"라고 요청
4. 이후 작가로서 필요한 정보를 제공

#### 예시 대화 흐름

**제목/목차 개발:**
```
You: [01-title-outline.md 전체 내용 붙여넣기]
     위 역할을 수행해줘.

AI: 네, 제목/목차 개발 전문가로 작업하겠습니다!
    먼저 작가님에 대해 알려주시겠어요?
    - 책의 핵심 주제는 무엇인가요?
    - 타겟 독자는 누구인가요?
    ...

You: 저는 기질이 다른 두 아이를 키우는 엄마입니다.
     큰아이는 예민하고, 둘째는 활발해서...
```

**초안 작성:**
```
You: [02-draft-writing.md 전체 내용 붙여넣기]
     위 역할을 수행해줘.

AI: 초안 작성 전문가로 도와드리겠습니다!
    어떤 챕터를 쓰시나요?

You: "1장. 완벽하지 않아도 괜찮습니다" 초안을 쓰고 싶어요.
     핵심 메시지는 엄마도 실수할 수 있다는 것이에요.
```

**글 검토:**
```
You: [03-proofreading.md 전체 내용 붙여넣기]
     위 역할을 수행해줘. 아래 글을 검토해줘.

     [검토받을 원고 붙여넣기]

AI: 글 검토를 시작하겠습니다!
    [검토 결과 제공]
```

### 방법 2: Claude API 활용 (고급 사용자용)

프로그래밍을 할 줄 안다면, Claude API를 사용해 자동화된 도구를 만들 수 있습니다.

#### 필요 사항
- Python 3.8 이상
- Claude API 키 (https://console.anthropic.com/)

#### 간단한 Python 스크립트 예시

```python
import anthropic
import os

# API 키 설정
client = anthropic.Anthropic(api_key="your-api-key")

# 프롬프트 파일 읽기
with open("prompts/01-title-outline.md", "r", encoding="utf-8") as f:
    system_prompt = f.read()

# AI에게 요청
message = client.messages.create(
    model="claude-sonnet-4-5-20250929",
    max_tokens=4096,
    system=system_prompt,
    messages=[
        {"role": "user", "content": "육아서 제목을 개발하고 싶어요. 기질이 다른 두 아이를 키우는 엄마의 이야기입니다."}
    ]
)

print(message.content[0].text)
```

## 💡 활용 팁

### 1. 제목/목차 개발 시

**준비하면 좋은 정보:**
- 책의 핵심 주제 (한 문장으로)
- 타겟 독자 (나이, 성별, 상황)
- 당신만의 독특한 경험/관점
- 전하고 싶은 핵심 메시지
- 참고할 만한 비슷한 책

**활용 예:**
- 제목 5-10개 받아서 주변 사람들에게 반응 테스트
- 목차를 처음부터 끝까지 읽어보며 스토리 흐름 확인
- 각 장의 핵심 메시지를 뽑아 일관성 체크

### 2. 초안 작성 시

**준비하면 좋은 정보:**
- 해당 챕터의 핵심 메시지 (한 문장)
- 전하고 싶은 구체적 경험/에피소드
- 참고할 키워드나 간단한 개요
- (있다면) 이미 작성한 샘플 텍스트 (문체 분석용)

**활용 팁:**
- 처음부터 완벽한 초안을 기대하지 마세요
- AI 초안을 받아서 당신의 목소리로 다시 다듬으세요
- "이 부분은 내가 쓴 느낌이 안 나" 싶으면 피드백하세요
- 구체적인 에피소드와 감정을 추가로 제공할수록 좋아집니다

### 3. 글 검토 시

**검토 레벨 선택:**
- **Level 1 (기본)**: 빠른 오탈자 체크만 필요할 때
- **Level 2 (표준)**: 일반적인 원고 검토 (추천)
- **Level 3 (심화)**: 출판 전 최종 점검

**활용 팁:**
- 한 번에 전체 원고를 넣기보다 챕터별로 검토
- AI의 수정 제안을 무조건 따르지 마세요 (작가의 의도가 우선)
- 반복되는 실수 패턴을 기록해두고 다음부터 주의

## ❓ FAQ

### Q1. AI가 쓴 티가 나지 않나요?
A: 이 시스템의 최우선 원칙이 "작가의 목소리 유지"입니다. 특히 초안 작성 AI는 10가지 "AI 티 제거 원칙"을 적용하며, 작가의 샘플 텍스트를 분석해 문체를 맞춥니다.

### Q2. 어떤 AI 서비스를 사용해야 하나요?
A: Claude (Sonnet 3.5 이상), ChatGPT (GPT-4 이상) 모두 사용 가능합니다. Claude를 추천합니다.

### Q3. 프로그래밍을 모르는데 사용할 수 있나요?
A: 네! 방법 1(AI 챗봇 사용)은 프로그래밍 지식이 전혀 필요 없습니다. 복사-붙여넣기만 하시면 됩니다.

### Q4. 비용이 드나요?
A:
- Claude Code: 무료 플랜으로도 충분히 사용 가능
- ChatGPT: GPT-4 사용 시 Plus 구독 필요 ($20/월)
- Claude API: 사용한 만큼 과금 (보통 원고 하나당 몇 백원 수준)

### Q5. 제 책 장르도 지원하나요?
A: 육아서, 자기계발, 에세이, 전문서, 신앙서, 기업 홍보서 등 모든 장르를 지원합니다. 각 프롬프트에 장르별 전략이 포함되어 있습니다.

### Q6. AI가 제 아이디어를 학습하나요?
A:
- Claude/ChatGPT 웹 버전: 설정에서 학습 비활성화 가능
- Claude API: 기본적으로 학습하지 않음
- 민감한 내용은 사용 전 확인 권장

### Q7. 완전히 AI에게만 맡길 수 있나요?
A: 아니요. 이 도구는 "코칭 파트너"이지 "대필 작가"가 아닙니다. 작가의 경험, 스토리, 통찰이 핵심이고, AI는 그것을 더 잘 표현하도록 돕는 역할입니다.

### Q8. 결과물이 마음에 안 들면?
A: 피드백을 주세요! "이 부분은 제 느낌이 아니에요", "더 감정적으로 써주세요", "이 에피소드를 추가해주세요" 등 구체적으로 요청하면 AI가 수정합니다.
