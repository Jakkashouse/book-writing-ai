# 책 쓰기 워크플로우 UI

## 개요
책 쓰기 프로세스를 체계적으로 지원하는 웹 애플리케이션으로, AI 기반 글쓰기 도우미와 자동화된 워크플로우를 제공합니다.

## 워크플로우 흐름도

```
랜딩 페이지 (/)
    ↓
대시보드 (/dashboard)
    ↓
새 프로젝트 생성 (/projects/new)
    ↓
제목 생성 (/projects/[id]/title)
    ↓
목차 작성 (/projects/[id]/toc)
    ↓
초안 작성 (/projects/[id]/draft)
    ↓
과제 제출 (/assignments)
    ↓
피드백 확인 (/feedback)
```

## 주요 페이지 및 기능

### 1. 대시보드 (`/dashboard`)
**목적**: 프로젝트 관리 및 진행 상황 추적

**주요 기능**:
- 프로젝트 목록 표시 (카드 형식)
- 진행률 시각화 (Progress Bar)
- 통계 대시보드 (전체 프로젝트 수, 진행 중, 완료, 총 단어 수)
- 빠른 액션 버튼
  - 새 프로젝트 만들기
  - 과제 제출
  - 피드백 확인

**사용자 경험**:
- 직관적인 프로젝트 카드 디자인
- 프로젝트 상태별 색상 구분
- 클릭으로 바로 프로젝트 진입

---

### 2. 프로젝트 생성 플로우 (`/projects/new`)
**목적**: 단계별 프로젝트 초기화

**5단계 위저드**:
1. **기본 정보**: 제목(임시), 설명, 장르, 타겟 독자, 키워드
2. **제목 생성**: AI 기반 제목 추천 페이지로 이동 안내
3. **목차 작성**: 목차 작성 페이지로 이동 안내
4. **초안 작성**: 초안 작성 페이지로 이동 안내
5. **교정**: 교정 및 피드백 페이지로 이동 안내

**사용자 경험**:
- 상단 진행률 표시
- 단계별 인디케이터 (숫자 + 체크마크)
- 이전/다음 버튼으로 네비게이션
- 각 단계 완료 시 자동 저장

---

### 3. 제목 생성 페이지 (`/projects/[id]/title`)
**목적**: AI를 활용한 매력적인 제목 생성

**제목 공식 10가지**:
1. **How to 공식**: 실용적인 가이드 제목
2. **숫자 활용**: 구체적인 숫자로 신뢰도 향상
3. **질문형**: 독자의 호기심 자극
4. **Before/After**: 변화와 성장 강조
5. **비밀/공개**: 독점 정보 암시
6. **시간 제한**: 긴급성 부여
7. **대상 명시**: 타겟 독자 직접 지정
8. **역설/반전**: 의외성으로 주목도 향상
9. **스토리텔링**: 개인적 경험 강조
10. **권위/전문성**: 전문성 어필

**워크플로우**:
1. 원하는 공식 선택 (복수 선택 가능)
2. "AI 제목 생성" 버튼 클릭
3. AI가 각 공식별로 제목 생성
4. 생성된 제목 중 선택 또는 직접 입력
5. 저장 후 다음 단계로 이동

**사용자 경험**:
- 공식별 예시 표시로 이해도 향상
- 실시간 AI 생성 (로딩 인디케이터)
- 생성된 제목 선택 시 하이라이트
- 직접 입력 옵션 제공

---

### 4. 목차 작성 페이지 (`/projects/[id]/toc`)
**목적**: 5부 구조의 체계적인 목차 구성

**5부 구조 템플릿**:
- **1부**: 도입 (독자의 관심 유도)
- **2부**: 전개 (핵심 메시지 전달)
- **3부**: 심화 (구체적인 방법론)
- **4부**: 적용 (실제 사례)
- **5부**: 마무리 (요약 및 메시지)

**주요 기능**:
- 드래그 앤 드롭으로 순서 변경
- 각 부별 제목, 부제목, 설명 입력
- AI 도움받기 (자동 목차 생성)
- 실시간 자동 저장 (3초 딜레이)
- 부 추가/삭제 기능

**사용자 경험**:
- 직관적인 드래그 앤 드롭 UI
- 자동 저장 상태 표시 (저장 중/저장됨)
- 목차 작성 팁 제공
- 각 부의 역할 설명

---

### 5. 초안 작성 페이지 (`/projects/[id]/draft`)
**목적**: 챕터별 초안 작성 및 관리

**레이아웃**:
- **좌측 사이드바**: 챕터 목록 (진행 상황 표시)
- **중앙 메인**: 에디터 영역
- **상단**: 통계 (단어 수, 진도율)

**주요 기능**:
- 챕터별 텍스트 에디터
- AI 글쓰기 도우미
  - 컨텍스트 기반 자동 생성
  - 이전 챕터 참조
- 자동 저장 (3초 딜레이)
- 실시간 단어 수 카운터
- 챕터별 진행 상태 관리

**사용자 경험**:
- 큰 텍스트 영역 (20줄)
- 세리프 폰트로 가독성 향상
- 챕터 간 쉬운 이동
- 자동 저장으로 작업 손실 방지
- 글쓰기 팁 제공

---

### 6. 과제 제출 페이지 (`/assignments`)
**목적**: 주차별 과제 제출 및 관리

**과제 목록** (예시):
- **1주차**: 책 주제 및 타겟 독자 정의
- **2주차**: 제목 및 부제목 작성
- **3주차**: 5부 구조 목차 작성
- **4주차**: 1부 초안 작성
- **5주차**: 2-3부 초안 작성

**주요 기능**:
- 과제 상태 표시 (시작 전, 진행 중, 제출 완료, 채점 완료)
- 마감일 표시 및 마감 경과 알림
- 과제 제출 다이얼로그
- 제출 내역 확인
- 통계 대시보드 (전체, 제출 완료, 평균 점수)

**사용자 경험**:
- 과제 카드 형식으로 한눈에 파악
- 마감일 임박 시 시각적 경고
- 모달 창으로 간편한 제출
- 과제 요구사항 명확히 표시

---

### 7. 피드백 확인 페이지 (`/feedback`)
**목적**: AI 분석 결과 및 개선 제안 확인

**피드백 구성**:
- **점수**: 100점 만점 기준
- **세부 평가 항목**:
  - 명확성 (Clarity)
  - 구조 (Structure)
  - 창의성 (Creativity)
  - 문법 (Grammar)
  - 몰입도 (Engagement)
- **잘한 점**: 긍정적 피드백 목록
- **개선할 점**: 구체적인 개선 제안
- **상세 피드백**: 종합 분석 및 조언

**주요 기능**:
- 피드백 목록 (날짜, 과제명, 점수)
- 상세 피드백 뷰
- 평가 항목별 진행률 그래프
- PDF 다운로드 (추후 구현)
- 다음 단계 제안

**사용자 경험**:
- 시각적 점수 표시 (큰 숫자)
- 색상 코드 (우수: 녹색, 양호: 파랑, 보통: 노랑)
- 긍정/부정 피드백 구분
- 실용적인 개선 제안

## API 엔드포인트

### 프로젝트 관리
- `GET /api/projects` - 프로젝트 목록 조회
- `POST /api/projects` - 새 프로젝트 생성
- `GET /api/projects/[id]` - 프로젝트 상세 조회
- `PATCH /api/projects/[id]` - 프로젝트 수정
- `DELETE /api/projects/[id]` - 프로젝트 삭제

### 목차
- `GET /api/projects/[id]/toc` - 목차 조회
- `PUT /api/projects/[id]/toc` - 목차 저장 (전체 교체)

### 챕터
- `GET /api/projects/[id]/chapters` - 챕터 목록 조회
- `POST /api/projects/[id]/chapters` - 챕터 생성
- `GET /api/projects/[id]/chapters/[chapterId]` - 챕터 조회
- `PUT /api/projects/[id]/chapters/[chapterId]` - 챕터 수정
- `DELETE /api/projects/[id]/chapters/[chapterId]` - 챕터 삭제

### AI 생성
- `POST /api/title/generate` - AI 제목 생성
- `POST /api/toc/generate` - AI 목차 생성
- `POST /api/draft/generate` - AI 초안 생성

### 과제 및 피드백
- `POST /api/assignments/submit` - 과제 제출
- `GET /api/feedback/[id]/pdf` - 피드백 PDF 다운로드

## UX 원칙

### 1. 직관적인 네비게이션
- 상단 네비게이션 바 (홈, 대시보드, 과제, 피드백)
- 브레드크럼 (breadcrumb) 없이 명확한 페이지 타이틀
- 일관된 버튼 위치 (이전/다음, 저장)

### 2. 진행 상황 시각화
- 프로젝트 진행률 (Progress Bar)
- 챕터별 완료 상태 (아이콘)
- 단계별 인디케이터 (숫자, 체크마크)

### 3. 자동 저장
- 3초 딜레이 후 자동 저장
- 저장 상태 표시 (저장 중/저장됨)
- 네트워크 오류 시 재시도 로직

### 4. 오프라인 작업 지원 (향후 구현)
- Service Worker 활용
- IndexedDB에 로컬 저장
- 온라인 복구 시 동기화

## 사용 예시

### 1. 새 프로젝트 시작하기
```
1. 대시보드 접속
2. "새 프로젝트" 버튼 클릭
3. 기본 정보 입력 (제목, 설명, 장르 등)
4. "프로젝트 생성" 클릭
5. 제목 생성 페이지로 자동 이동
```

### 2. AI로 제목 생성하기
```
1. 원하는 공식 선택 (예: How to, 숫자 활용, 질문형)
2. "AI 제목 생성" 버튼 클릭
3. 생성된 제목 중 마음에 드는 것 선택
4. 또는 직접 입력
5. "저장하고 다음 단계로" 클릭
```

### 3. 목차 작성하기
```
1. 5부 구조 템플릿 기본 제공
2. 각 부의 제목과 설명 입력
3. 드래그 앤 드롭으로 순서 조정
4. "AI 도움받기"로 자동 생성 가능
5. 자동 저장됨
6. "저장하고 초안 작성하기" 클릭
```

### 4. 초안 작성하기
```
1. 왼쪽에서 챕터 선택
2. 에디터에서 내용 작성
3. "AI 도움받기"로 자동 생성 가능
4. 실시간 단어 수 확인
5. 자동 저장됨
6. "저장하고 다음" 또는 "저장하고 완료" 클릭
```

## 결론

이 책 쓰기 워크플로우 UI는 사용자가 체계적으로 책을 쓸 수 있도록 설계되었습니다. 각 단계마다 AI 도움을 받을 수 있으며, 자동 저장 기능으로 작업 손실을 방지합니다. 직관적인 UI와 명확한 네비게이션으로 누구나 쉽게 사용할 수 있습니다.
