## 개요

이 프롬프트 관리 시스템은 책 쓰기 과정을 지원하는 30개 이상의 전문 AI 프롬프트 템플릿을 제공합니다. 각 프롬프트는 황준연(작가의 집 대표)의 100명 이상 작가 배출 경험을 바탕으로 설계되었습니다.

### 주요 기능

- **30+ 전문 프롬프트 템플릿**: 책 기획부터 마케팅까지 전 과정 커버
- **8개 카테고리**: 체계적인 분류로 쉬운 탐색
- **변수 시스템**: 맞춤형 프롬프트 생성
- **사용 기록 추적**: 사용 이력 및 통계
- **즐겨찾기**: 자주 사용하는 프롬프트 관리
- **검색 및 필터**: 키워드, 카테고리, 태그 기반 검색

## 프롬프트 카테고리

### 1. 제목/목차 기획 (TITLE_TOC)

**목적**: 베스트셀러 수준의 책 제목과 목차 개발

**주요 프롬프트**:
- **01-제목목차기획**: 제목 10대 원칙, 목차 10대 원칙 기반 전문 가이드

**사용 시나리오**:
- 책 기획 초기 단계
- 제목이 마음에 들지 않을 때
- 목차 구조를 잡을 때

**핵심 원칙**:
- 문장형 제목의 힘
- 감정적 호소력
- MECE 원칙 (목차)
- 장르별 맞춤 전략

---

### 2. 초안 작성 (DRAFT)

**목적**: 작가의 목소리를 살린 고품질 초안 작성

**주요 프롬프트**:
- **02-초안작성**: 스토리텔링 기반 초안 작성
- **41-스타일반영초안작성**: 작가 스타일 학습 후 반영

**사용 시나리오**:
- 챕터 작성 시작
- 글쓰기가 막힐 때
- AI 도움으로 초안 빠르게 작성

**핵심 원칙**:
- Show, Don't Tell
- 구체적 디테일
- 5감 활용
- AI 티 제거

---

### 3. 원고 교정/진단 (EDITING)

**목적**: 출판사 편집자 수준의 교정 및 피드백

**주요 프롬프트**:
- **03-원고교정**: 맞춤법, 띄어쓰기, 비문 교정
- **04-원고진단**: 전체적인 품질 진단

**사용 시나리오**:
- 초안 완성 후
- 출판 전 최종 검토
- 원고 품질 개선

**핵심 기능**:
- 오탈자 검출
- 비문 수정
- 가독성 개선
- 작가 스타일 유지

---

### 4. 출판 제안서 (PROPOSAL)

**목적**: 잠재 작가 발굴 및 출간 제안

**주요 프롬프트**:
- **24-출간제안서**: 감성형/비즈니스형/하이브리드형 제안서

**사용 시나리오**:
- 유튜버/인플루언서 출간 제안
- 방송 출연자 섭외
- 전문가 책 출간 제안

**제안서 유형**:
- **Type A (감성형)**: 방송 출연자, 선교사, 감동 스토리 보유자
- **Type B (비즈니스형)**: 유튜버, 인플루언서, 전문가
- **Type C (하이브리드형)**: 범용적 사용

---

### 5. 마케팅/홍보 (MARKETING)

**목적**: 책 출간 후 효과적인 마케팅 및 홍보

**주요 프롬프트**:
- **08-상세페이지카피**: 책 소개 페이지 작성
- **10-블로그뉴스레터생성**: 콘텐츠 마케팅
- **18-책홍보투두리스트**: 체계적 홍보 계획
- **19-작가인터뷰질문생성**: 인터뷰 질문 세트
- **20-독자타겟팅채널전략**: 채널 전략 수립
- **21-책리뷰요청문구**: 리뷰 요청 문구
- **22-SNS콘텐츠캘린더**: SNS 콘텐츠 계획
- **23-강연북토크제안서**: 강연/북토크 제안서
- **26-도서상세페이지카피**: 온라인 서점용 카피
- **27-도서영상대본생성**: 홍보 영상 대본
- **43-도서보도자료작성**: 언론 보도자료

**사용 시나리오**:
- 출간 준비 단계
- 출간 후 홍보 기간
- 강연/북토크 섭외

**마케팅 타임라인**:
1. 출간 3개월 전: 보도자료, SNS 콘텐츠 캘린더
2. 출간 1개월 전: 상세페이지, 영상 대본
3. 출간 직후: 리뷰 요청, 인터뷰
4. 출간 후 1-3개월: 강연/북토크, 블로그 마케팅

---

### 6. 코칭/피드백 (COACHING)

**목적**: 작가 성장 지원 및 동기부여

**주요 프롬프트**:
- **05-맞춤과제생성**: 맞춤형 글쓰기 과제
- **06-격려메시지생성**: 동기부여 메시지
- **07-FAQ답변생성**: 자주 묻는 질문 답변
- **09-강의커리큘럼설계**: 강의 커리큘럼
- **11-수강생모집문구**: 프로그램 모집
- **12-설문지진단**: 작가 설문 분석
- **13-진도트래커**: 진행 상황 추적
- **14-챕터별피드백**: 챕터 피드백
- **15-작가셀프체크리스트**: 셀프 점검
- **16-완주동기부여시스템**: 완주 지원
- **17-베타리더피드백분석**: 베타리더 피드백 분석
- **25-필체분석스타일학습**: 작가 스타일 분석
- **28-상담분석**: 상담 내용 분석
- **42-초안피드백생성**: 초안 피드백

**사용 시나리오**:
- 책쓰기 강의 운영
- 작가 코칭 세션
- 작가 커뮤니티 운영

**코칭 프로세스**:
1. 설문지 진단 → 2. 맞춤 과제 → 3. 진도 추적 → 4. 피드백 → 5. 격려 메시지

## API 사용법

### 1. 전체 프롬프트 목록 조회

```typescript
// GET /api/prompts
const response = await fetch('/api/prompts');
const data = await response.json();

console.log(data.prompts);
console.log(data.pagination);
```

**쿼리 파라미터**:
- `category`: 카테고리 필터 (예: TITLE_TOC, DRAFT)
- `search`: 검색어 (제목, 설명, 템플릿 내용)
- `tag`: 태그 필터
- `page`: 페이지 번호 (기본값: 1)
- `limit`: 페이지당 항목 수 (기본값: 20)

**예시**:
```typescript
// 초안 작성 카테고리만 조회
const response = await fetch('/api/prompts?category=DRAFT');

// '마케팅' 검색
const response = await fetch('/api/prompts?search=마케팅');

// '제목' 태그 필터
const response = await fetch('/api/prompts?tag=제목');
```

```typescript
  method: 'POST',

// DELETE /api/prompts/[id]/favorite - 제거

  method: 'DELETE',

```

```typescript

  body: JSON.stringify({

    },

  }),
});
```

## UI 사용법

### 1. 프롬프트 목록 페이지

**URL**: `/prompts`

**기능**:
- 전체 프롬프트 카드 형태로 표시
- 카테고리 필터
- 검색 기능
- 사용 횟수 표시
- 태그 표시

**사용법**:
1. 원하는 카테고리 선택
2. 검색어 입력 (선택)
3. 프롬프트 카드 클릭

---

### 2. 프롬프트 상세 페이지

**URL**: `/prompts/[id]`

**기능**:
- 프롬프트 템플릿 전체 보기
- 변수 입력 폼
- 프롬프트 생성
- 클립보드 복사
- 즐겨찾기 토글

**사용법**:
1. 변수 입력 (필요한 경우)
2. "프롬프트 생성" 버튼 클릭
3. 생성된 프롬프트 확인
4. "복사" 버튼으로 클립보드 복사
5. Claude 또는 다른 AI에 붙여넣기

## 사용 예시

### 예시 1: 책 제목 정하기

1. `/prompts` 접속
2. "제목/목차 기획" 카테고리 선택
3. "제목/목차 기획" 프롬프트 클릭
4. 변수 입력:
   - 작가정보: "육아 블로거, 두 아이 엄마, 10년 육아 경험"
   - 책주제: "완벽하지 않아도 괜찮은 육아"
   - 타겟독자: "초보 엄마, 육아 스트레스를 받는 부모"
   - 장르: "육아서"
5. "프롬프트 생성" 클릭
6. 생성된 프롬프트 복사
7. Claude에 붙여넣기
8. 결과: 5-10개 제목 후보 + 평가

---

### 예시 2: 책 홍보 계획 수립

1. `/prompts` 접속
2. "책 홍보 투두리스트" 검색
3. 프롬프트 클릭
4. 변수 입력:
   - 책정보: "제목: 엄마의 성장기, 장르: 육아 에세이"
   - 출간일: "2024년 3월 15일"
   - 마케팅예산: "300만원"
5. 프롬프트 생성 및 복사
6. Claude에 붙여넣기
7. 결과: 출간 전후 3개월 홍보 계획

---

### 예시 3: 작가 스타일 학습 후 초안 작성

1. "필체 분석 및 스타일 학습" 프롬프트 사용
   - 작가의 샘플 텍스트 입력
   - 스타일 분석 결과 받기
