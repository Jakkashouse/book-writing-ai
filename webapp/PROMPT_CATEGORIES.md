# 프롬프트 카테고리 및 사용법 요약

## 전체 프롬프트 개요

총 **30개 이상**의 전문 AI 프롬프트가 **8개 카테고리**로 분류되어 있습니다.

---

## 8개 카테고리 상세

### 1. 제목/목차 기획 (TITLE_TOC) - 1개

**목적**: 베스트셀러 수준의 제목과 목차 개발

**프롬프트**:
- 제목/목차 기획

**사용 시기**:
- 책 기획 초기
- 제목/목차 개선 필요 시

**변수**:
- 작가정보
- 책주제
- 타겟독자
- 장르

**기대 효과**:
- 호기심을 자극하는 제목 5-10개
- 논리적이고 매력적인 목차 구조
- 장르별 맞춤 전략 적용

---

### 2. 초안 작성 (DRAFT) - 2개

**목적**: 작가 목소리를 살린 고품질 초안 작성

**프롬프트**:
- 초안 작성
- 스타일 반영 초안 작성

**사용 시기**:
- 챕터 작성 시작
- 글쓰기가 막힐 때

**변수**:
- 챕터제목
- 핵심메시지
- 작가샘플텍스트
- 참고자료

**기대 효과**:
- AI 티 없는 자연스러운 글
- 작가만의 목소리 유지
- 스토리텔링 기반 초안

---

### 3. 원고 교정/진단 (EDITING) - 2개

**목적**: 출판사 편집자 수준의 품질 관리

**프롬프트**:
- 원고 교정
- 원고 진단

**사용 시기**:
- 초안 완성 후
- 출판 전 최종 검토

**변수**:
- 원고내용
- 검토레벨 (기본/표준/심화)

**기대 효과**:
- 오탈자/비문 0개
- 가독성 향상
- 전체 품질 진단 및 개선안

---

### 4. 출판 제안서 (PROPOSAL) - 1개

**목적**: 잠재 작가 섭외 및 출간 제안

**프롬프트**:
- 출간 제안서

**사용 시기**:
- 잠재 작가 발굴
- 유튜버/인플루언서 섭외

**변수**:
- 대상자정보
- 콘텐츠링크
- 감동포인트
- 제안유형 (감성형/비즈니스형/하이브리드형)

**기대 효과**:
- 진심 어린 제안서
- 맞춤형 접근
- 높은 섭외 성공률

---

### 5. 마케팅/홍보 (MARKETING) - 11개

**목적**: 책 출간 후 효과적인 마케팅

**프롬프트**:
1. 상세페이지 카피
2. 블로그/뉴스레터 생성
3. 책 홍보 투두리스트
4. 작가 인터뷰 질문 생성
5. 독자 타겟팅 채널 전략
6. 책 리뷰 요청 문구
7. SNS 콘텐츠 캘린더
8. 강연/북토크 제안서
9. 도서 상세페이지 카피
10. 도서 영상 대본 생성
11. 도서 보도자료 작성

**사용 시기**:
- 출간 3개월 전 ~ 출간 후 3개월

**주요 변수**:
- 책정보
- 타겟독자
- 마케팅예산
- 출간일

**기대 효과**:
- 체계적 마케팅 계획
- 다양한 채널 콘텐츠
- 효과적인 독자 리치

**마케팅 타임라인**:
```
출간 3개월 전
  ├─ 보도자료 준비
  ├─ SNS 콘텐츠 캘린더 작성
  └─ 상세페이지 카피 작성

출간 1개월 전
  ├─ 영상 대본 제작
  ├─ 인터뷰 질문 준비
  └─ 강연 제안서 발송

출간 직후
  ├─ 리뷰 요청 발송
  ├─ 블로그/뉴스레터 발행
  └─ SNS 콘텐츠 발행 시작

출간 1-3개월 후
  ├─ 강연/북토크 진행
  ├─ 추가 콘텐츠 마케팅
  └─ 독자 타겟팅 최적화
```

---

### 6. 코칭/피드백 (COACHING) - 14개

**목적**: 작가 성장 지원 및 완주율 향상

**프롬프트**:
1. 맞춤 과제 생성
2. 격려 메시지 생성
3. FAQ 답변 생성
4. 강의 커리큘럼 설계
5. 수강생 모집 문구
6. 설문지 진단
7. 진도 트래커
8. 챕터별 피드백
9. 작가 셀프 체크리스트
10. 완주 동기부여 시스템
11. 베타리더 피드백 분석
12. 필체 분석 및 스타일 학습
13. 상담 분석
14. 초안 피드백 생성

**사용 시기**:
- 책쓰기 강의 운영
- 작가 코칭 세션
- 커뮤니티 운영

**주요 변수**:
- 작가상황
- 진행상황
- 목표
- 어려움

**기대 효과**:
- 작가 완주율 100%
- 체계적 코칭 시스템
- 효과적인 동기부여

**코칭 프로세스**:
```
1단계: 진단
  └─ 설문지 진단
  └─ 필체 분석

2단계: 계획
  └─ 맞춤 과제 생성
  └─ 진도 트래커 설정

3단계: 실행
  └─ 챕터별 피드백
  └─ 초안 피드백

4단계: 지원
  └─ 격려 메시지
  └─ 완주 동기부여

5단계: 개선
  └─ 베타리더 피드백 분석
  └─ 상담 분석
```

### 7. 워크플로우/템플릿 (WORKFLOW) - 1개

**목적**: 효율적인 작업 프로세스

**프롬프트**:
- 녹음본 목차 배열

**사용 시기**:
- 인터뷰 녹음 정리
- 강의 녹음 책 변환

**변수**:
- 녹음텍스트
- 주제

**기대 효과**:
- 음성 → 텍스트 → 목차 자동화
- 시간 절약

## 프롬프트 선택 가이드

### 책 쓰기 단계별 프롬프트

#### 1단계: 기획 (1-2주)
```
제목/목차 기획
  ↓
설문지 진단
  ↓
맞춤 과제 생성
```

#### 2단계: 초안 작성 (2-3개월)
```
필체 분석 및 스타일 학습
  ↓
스타일 반영 초안 작성 / 초안 작성
  ↓
챕터별 피드백
  ↓
진도 트래커 + 격려 메시지
```

#### 3단계: 교정 (2-4주)
```
초안 피드백 생성
  ↓
원고 교정
  ↓
원고 진단
  ↓
베타리더 피드백 분석
  ↓
최종 원고 교정
```

#### 4단계: 출판 준비 (1-2개월)
```
출간 제안서 (필요시)
  ↓
상세페이지 카피
  ↓
도서 영상 대본 생성
  ↓
보도자료 작성
```

#### 5단계: 마케팅 (출간 전후 6개월)
```
출간 3개월 전:
  - 책 홍보 투두리스트
  - SNS 콘텐츠 캘린더
  - 독자 타겟팅 채널 전략

출간 1개월 전:
  - 작가 인터뷰 질문 생성
  - 강연/북토크 제안서

출간 직후:
  - 책 리뷰 요청 문구
  - 블로그/뉴스레터 생성
```
