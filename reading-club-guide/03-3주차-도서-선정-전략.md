# 3주차: 도서 선정 전략

---

## 학습 목표

이번 주차를 마치면 다음을 할 수 있습니다:

- 독서모임의 목적에 맞는 도서 선정 기준을 수립할 수 있다
- 다양한 장르와 주제의 균형을 고려한 도서 선정 방법을 이해한다
- 구성원 특성을 고려한 맞춤형 도서 선정 전략을 실행할 수 있다
- 효과적인 도서 선정 프로세스를 설계할 수 있다
- 피해야 할 도서 선정의 함정을 인식한다

---

## 도서 선정이 중요한 이유

독서모임의 성패는 **어떤 책을 읽느냐**에 크게 좌우됩니다. 좋은 도서 선정은:

- 참여자들의 흥미와 참여도를 높입니다
- 풍부한 토론거리를 제공합니다
- 모임의 정체성을 형성합니다
- 구성원들의 성장을 돕습니다

하지만 걱정하지 마세요. **완벽한 책은 없습니다.** 중요한 것은 모임의 목적과 구성원에게 맞는 책을 찾는 것입니다.

---

## 1. 목적에 맞는 도서 선정 기준

### 주요 선정 기준 5가지

| 기준 | 질문 | 설명 |
|------|------|------|
| **적합성** | 모임의 주제와 목표에 부합하는가? | 모임이 추구하는 방향과 일치하는 책 |
| **접근성** | 참여자들이 읽을 수 있는 수준인가? | 난이도, 분량, 구하기 쉬운 책 |
| **토론 가능성** | 다양한 의견을 이끌어낼 수 있는가? | 해석의 여지가 있는 책 |
| **현재성** | 지금 우리에게 의미가 있는가? | 현재 관심사와 연결되는 책 |
| **가용성** | 쉽게 구할 수 있는가? | 절판되지 않고 접근 가능한 책 |

### 선정 기준 우선순위 정하기

모임의 성격에 따라 기준의 우선순위가 달라집니다:

**성장형 모임**: 적합성 > 토론 가능성 > 접근성
**사교형 모임**: 접근성 > 토론 가능성 > 현재성
**전문형 모임**: 적합성 > 토론 가능성 > 현재성

> **TIP**: 처음 시작하는 모임이라면 **접근성**을 최우선으로 두세요. 너무 어려운 책은 참여자들의 부담이 됩니다.

## 2. 다양성과 균형 잡기

### 장르 다양화 전략

한 가지 장르만 고집하면 모임이 단조로워질 수 있습니다. 다음과 같은 균형을 고려해보세요:

```
[장르 균형의 예시]

6개월 독서 계획:
├── 1월: 소설 (한국 현대소설)
├── 2월: 에세이 (삶과 성찰)
├── 3월: 비소설 (과학/사회)
├── 4월: 소설 (번역소설)
├── 5월: 자기계발/실용서
└── 6월: 고전 또는 시집
```

### 주제 다양화 전략

| 분기 | 주제 | 예시 도서 |
|------|------|-----------|
| 1분기 | 개인과 성장 | 자기계발, 심리, 에세이 |
| 2분기 | 사회와 관계 | 사회학, 인간관계, 커뮤니티 |
| 3분기 | 지식과 탐구 | 과학, 역사, 철학 |
| 4분기 | 예술과 감성 | 문학, 시, 예술 |

### 균형 잡기의 원칙

- **소설과 비소설의 균형**: 감성과 지식의 조화
- **고전과 현대 작품의 조화**: 시대를 넘나드는 통찰
- **국내 작품과 번역 작품의 균형**: 다양한 문화적 관점
- **가벼운 주제와 무거운 주제의 교차**: 지속 가능한 독서

> **주의**: 다양성을 추구하되, 모임의 정체성을 흐리지 않도록 하세요. "우리 모임은 이런 책을 읽는다"는 일관성도 중요합니다.

## 3. 테마 중심 독서모임 운영

테마를 중심으로 운영하면 일관성과 깊이를 동시에 확보할 수 있습니다.

### 테마 유형별 예시

**작가 중심 테마**
- 한 작가의 작품을 시간순으로 읽기
- 예: 무라카미 하루키의 초기작부터 최신작까지

**장르 중심 테마**
- 특정 장르에 집중
- 예: 한국 SF 소설 탐험, 북유럽 추리소설 여행

**주제 중심 테마**
- 특정 주제와 관련된 다양한 장르의 책
- 예: "일과 삶의 균형" - 소설, 에세이, 경영서 포함

**시대/지역 중심 테마**
- 특정 시대나 지역의 문학
- 예: 1920년대 경성의 문학, 라틴아메리카 문학

### 테마 기획 예시: "디지털 시대의 인간"

```
[3개월 테마 기획서]

테마: 디지털 시대의 인간
기간: 3개월 (6회 모임)

1회차: 《1984》 조지 오웰
       - 감시 사회와 개인의 자유

2회차: 《블랙 미러》 관련 에세이
       - 기술이 바꾸는 일상

3회차: 《호모 데우스》 유발 하라리
       - 기술과 인류의 미래

4회차: 《82년생 김지영》 조남주
       - 디지털 세대의 삶과 정체성

5회차: 《디지털 미니멀리즘》 칼 뉴포트
       - 기술과의 건강한 관계

6회차: 참여자 추천 도서
       - 테마 마무리 및 종합 토론
```

## 4. 구성원 특성을 고려한 선정

### 참여자 분석 체크리스트

도서 선정 전 참여자들의 특성을 파악하세요:

- [ ] 평균 연령대와 세대적 특성
- [ ] 주요 직업군과 전문 분야
- [ ] 독서 취향과 경험 수준
- [ ] 가용한 독서 시간
- [ ] 이전 모임에서의 반응과 피드백

### 상황별 맞춤 선정 예시

| 구성원 특성 | 고려사항 | 추천 접근법 |
|-------------|----------|-------------|
| 바쁜 직장인 | 시간 부족 | 300페이지 이하, 읽기 쉬운 문체 |
| 육아 중인 부모 | 집중 시간 짧음 | 짧은 챕터, 에세이집 |
| 독서 초보자 | 부담감 | 베스트셀러, 화제작 |
| 다양한 전공자 | 배경지식 차이 | 학제간 주제, 교양서 |
| 독서 고수 | 도전 욕구 | 고전, 전문서적 |

### 독서 편식 극복하기

참가자들이 평소 읽지 않는 장르에 도전하도록 장려하는 방법:

1. **점진적 접근**: 익숙한 장르에서 조금씩 확장
2. **연결고리 만들기**: 관심사와 연결되는 새로운 장르 소개
3. **짧은 도전**: 처음에는 짧은 분량으로 시도
4. **함께 도전**: "이번에는 다 같이 처음 읽어보는 장르"

## 5. 효과적인 도서 선정 프로세스

체계적인 프로세스는 공정성을 높이고 갈등을 예방합니다.

### 방식 1: 투표제

```
[투표제 진행 방법]

1단계: 후보 수집 (1주일)
       - 각 참여자가 1-2권씩 추천
       - 간단한 추천 이유 작성

2단계: 후보 목록 공유 (3일)
       - 전체 후보 목록 정리
       - 각 책의 기본 정보 제공

3단계: 투표 (3일)
       - 1인 3표 또는 순위 투표
       - 온라인 투표 도구 활용

4단계: 결과 발표
       - 최다 득표 도서 선정
       - 차점자는 다음 후보로
```

**장점**: 민주적, 참여도 높음
**단점**: 소수 의견 반영 어려움

### 방식 2: 순환제

```
[순환제 진행 방법]

1단계: 순서 정하기
       - 가나다순, 가입순, 추첨 등

2단계: 담당자가 1-3권 제안
       - 선정 이유와 함께 제안
       - 간단한 책 소개

3단계: 모임에서 최종 결정
       - 담당자 제안 중 1권 선택
       - 또는 담당자가 최종 결정

4단계: 다음 담당자로 순환
```

**장점**: 다양한 취향 반영, 책임감 분산
**단점**: 일관성 부족 가능성

### 방식 3: 테마 기반 선정

```
[테마 기반 선정 방법]

1단계: 분기별 테마 설정
       - 전체 합의로 테마 결정

2단계: 테마에 맞는 후보 수집
       - 리더 또는 담당자가 5-10권 제안

3단계: 투표 또는 합의로 선정
       - 테마 내에서 구체적 도서 결정
```

**장점**: 학습의 연속성, 깊이 있는 탐구
**단점**: 유연성 제한

### 방식 4: 챌린지 방식

```
[챌린지 예시]

- 노벨문학상 수상작 읽기
- 각자 다른 나라의 작품 읽기
- 출판된 지 50년 이상 된 책 읽기
- 100페이지 이하의 책 읽기
- 참여자 전원이 처음 접하는 작가
```

**장점**: 새로운 발견, 독서 영역 확장
**단점**: 진입장벽, 부담감

### 추천: 혼합 방식

처음 시작하는 모임에 추천하는 방식:

```
[혼합 방식 예시]

- 기본: 투표제로 운영
- 변형 1: 분기별 1회는 리더 추천작
- 변형 2: 연 2회는 챌린지 도서
- 변형 3: 순환제로 후보 제안, 투표로 결정
```

## 6. 피해야 할 도서 선정의 함정

### 함정 1: 과도한 난이도

**문제**: 지나치게 어려운 책 → 좌절과 중도 포기

**해결책**:
- 점진적으로 난이도 높이기
- 배경지식 자료 함께 제공
- 어려운 책은 여러 회차로 나누기

### 함정 2: 유행에만 치중

**문제**: 베스트셀러만 선정 → 깊이 부족, 정체성 약화

**해결책**:
- 베스트셀러와 숨은 명작의 균형
- 모임의 목적에 맞는 선택 우선
- "왜 이 책인가?"에 대한 명확한 이유

### 함정 3: 지나친 분량

**문제**: 현실적인 독서 시간 무시 → 미완독 참여자 증가

**해결책**:
- 참여자들의 가용 시간 파악
- 월 1회 모임이면 300-400페이지 이하 권장
- 긴 책은 2회에 나눠 읽기

### 함정 4: 특정 취향 편중

**문제**: 리더나 일부 참여자의 취향만 반영 → 다른 참여자 이탈

**해결책**:
- 도서 선정 과정의 민주화
- 모든 참여자의 추천 기회 보장
- 정기적으로 선호도 설문

### 함정 5: 균형 없는 다양성

**문제**: 너무 산만한 주제 변경 → 정체성 상실

**해결책**:
- 테마 기반 운영으로 일관성 유지
- "우리 모임의 색깔" 정의하기
- 다양성은 범위 내에서 추구

## 7. 실용적인 도서 찾기 방법

### 도서 발굴 채널

| 채널 | 활용법 | 장점 |
|------|--------|------|
| 서점 | 신간 코너, 직원 추천 | 트렌드 파악 |
| 도서관 | 대출 순위, 사서 추천 | 무료, 다양한 장르 |
| 온라인 서점 | 리뷰, 연관 도서 | 상세 정보, 편의성 |
| 북팟캐스트/북튜브 | 깊이 있는 리뷰 | 실제 독서 경험 공유 |
| 문학상 수상작 | 검증된 작품 | 품질 보장 |
| 다른 독서모임 | 후기와 추천 | 토론 가능성 검증 |

### 도서 사전 검토 체크리스트

새로운 책을 선정하기 전 확인하세요:

- [ ] 분량은 적절한가? (페이지 수)
- [ ] 구하기 쉬운가? (절판 여부, 전자책 유무)
- [ ] 번역 품질은 괜찮은가? (번역서의 경우)
- [ ] 토론거리가 있는가? (리뷰 확인)
- [ ] 우리 모임에 적합한가? (목적과 부합)

### 성공 사례: 테마 중심 접근법

- 2월: 《게으름에 대한 찬양》 - 에세이
- 3월: 《일의 기쁨과 슬픔》 - 르포

- 일관성과 다양성의 균형
- 하나의 주제를 다양한 각도에서 탐구
- 참여자들의 관심사와 연결

### 실패 사례: 베스트셀러 중심 선정

**방식**: 매번 현재 베스트셀러 목록에서만 선정

**문제점**:
- 베스트셀러가 유사한 주제에 집중되어 다양성 부족

**결과**: 6개월 만에 해체

**교훈**:
- 일시적 유행보다 모임의 목적에 부합하는 선정이 중요
- 다양성과 일관성의 균형 필요
