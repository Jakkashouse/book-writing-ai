# 6주차: 참여자 관리와 창의적 독서활동

---

## 학습 목표

이번 주차를 마치면 다음을 할 수 있습니다:

- 효과적인 참여 독려와 동기부여 전략을 실행할 수 있다
- 다양한 의견 수용과 균형 있는 발언 관리 방법을 적용할 수 있다
- 어려운 참가자 유형별 대처법을 활용할 수 있다
- 갈등을 건설적으로 관리할 수 있다
- 다양한 창의적 독서활동을 기획하고 진행할 수 있다

---

## 참여자 관리가 중요한 이유

독서모임의 성공은 **사람**에 달려 있습니다. 아무리 좋은 책을 선정하고 완벽한 운영 체계를 갖춰도, 참여자들이 적극적으로 참여하지 않으면 모임은 살아 있지 않습니다.

참여자 관리는:
- 모든 구성원이 가치를 느끼게 합니다
- 지속적인 참여를 이끌어냅니다
- 건강한 커뮤니티 문화를 형성합니다
- 갈등을 예방하고 해결합니다

## 1. 참여 독려와 동기부여 전략

### 동기의 두 가지 유형

**내재적 동기** (내면에서 오는 동기)
- 책에 대한 순수한 관심
- 성장하고 싶은 욕구
- 의미 있는 대화에 대한 갈망

**외재적 동기** (외부에서 오는 동기)
- 소속감과 친목
- 독서 목표 달성
- 인정과 보상

### 내재적 동기 강화 전략

| 전략 | 방법 |
|------|------|
| **관심사 연결** | 참여자들의 관심사와 연결된 도서 선정 |
| **성장 경험** | 토론 후 "오늘 새롭게 알게 된 것" 공유 시간 |
| **자율성 부여** | 역할 선택, 토론 주제 제안 기회 제공 |
| **성취감 제공** | 완독 축하, 통찰 공유 인정 |

### 외재적 동기 활용 전략

| 전략 | 방법 |
|------|------|
| **독서 챌린지** | 연간 독서 목표 설정, 진행 상황 공유 |
| **소속감 강화** | 모임 이름, 로고, 공유 경험 |
| **특별 이벤트** | 작가와의 만남, 북콘서트, 출판사 투어 |
| **작은 인정** | 우수 참여자 선정, 책 관련 선물 |

### 참여 장벽 낮추기

참여를 어렵게 만드는 요소들을 제거하세요:

```
[참여 장벽과 해결책]

장벽: 책을 다 읽지 못했다
→ 해결: "일부만 읽어도 참여 환영" 분위기 조성

장벽: 발언이 부담스럽다
→ 해결: 소그룹 토론, 글로 쓰는 방식 제공

장벽: 시간이 없다
→ 해결: 적절한 분량의 책, 요약 자료 제공

장벽: 처음이라 어색하다
→ 해결: 신규 참여자 환영 시간, 버디 시스템
```

## 2. 균형 있는 발언 관리

### 발언 기회 균등화 방법

**라운드 로빈 방식**
- 모든 사람이 차례대로 발언
- 장점: 공평함, 침묵하는 사람도 참여
- 활용: "한 분씩 돌아가며 첫인상을 나눠볼까요?"

**발언권 토큰**
- 각자 3개의 토큰 보유
- 발언할 때마다 1개 사용
- 장점: 발언량 자연스럽게 조절

**침묵자 초대**
- "아직 말씀 안 하신 분의 생각이 궁금합니다"
- 강요가 아닌 초대의 느낌으로

**다양한 참여 방식**
- 말하기 외에 글쓰기, 포스트잇, 채팅 등 활용
- 내향적인 참여자에게 대안 제공

### 다양한 관점 장려하기

```
[관점 확장을 위한 질문들]

"다른 시각에서 보면 어떨까요?"
"반대 입장에서 생각해보면?"
"저자가 이 비판을 듣는다면 뭐라고 할까요?"
"이 상황에서 다른 선택지는 없었을까요?"
```

## 3. 어려운 참가자 유형별 대처법

### 유형 1: 대화를 독점하는 사람

**특징**: 열정적이지만 다른 사람의 발언 기회를 줄임

**대처 전략**:
- "좋은 의견이네요. 다른 분들 생각도 들어볼까요?"
- 시간 제한 안내: "1분 정도로 요약해주시겠어요?"
- 발언권 토큰 시스템 도입
- 모임 후 개인적으로 대화: "열정에 감사드려요. 다른 분들도 참여하면 더 좋을 것 같아요"

### 유형 2: 항상 침묵하는 사람

**특징**: 참석은 하지만 거의 발언하지 않음

**대처 전략**:
- 부담 없는 질문으로 초대: "○○님은 어떤 장면이 기억에 남으세요?"
- 사전에 질문 공유하여 준비 시간 제공
- 소그룹/짝 활동 먼저 진행
- 글로 쓰는 방식 제공 (포스트잇, 채팅)
- 1:1 대화로 참여 방법 논의

### 유형 3: 지나치게 논쟁적인 사람

**특징**: 모든 의견에 반박, 논쟁을 즐김

**대처 전략**:
- 개인이 아닌 아이디어에 집중하도록 유도
- "흥미로운 관점이네요. 다른 시각도 함께 살펴보죠"
- 필요시 휴식 제안
- 토론 규칙 상기: "다양한 의견을 존중합니다"
- 모임 후 개별 대화

### 유형 4: 책을 읽지 않고 오는 사람

**특징**: 준비 없이 참석, 반복됨

**대처 전략**:
- 비난하지 않고 참여 기회 제공
- 모임 시작 시 간단한 요약 제공
- "책 소개를 보고 어떤 기대를 하셨나요?" 같은 질문
- 반복될 경우 개인적으로 대화
- 모임 규칙에 준비에 대한 기대치 명시

### 유형 5: 부정적인 사람

**특징**: 책, 모임, 다른 참여자에 대해 부정적

**대처 전략**:
- 건설적인 피드백으로 전환 유도: "어떻게 하면 더 좋았을까요?"
- 긍정적인 면도 함께 이야기하도록 요청
- 개인적인 어려움이 있는지 확인
- 지속되면 개인적으로 대화

### 대처의 기본 원칙

```
[어려운 상황 대처 원칙]

1. 공개적으로 비난하지 않기
2. 개인이 아닌 행동에 초점
3. 가능하면 개인적으로 대화
4. 모임 규칙을 근거로 이야기
5. 상대방의 입장도 이해하려 노력
```

## 4. 갈등 관리

### 갈등 예방

**사전에 할 수 있는 것들**:
- 모임 초기에 상호 존중의 규칙 설정
- "나" 메시지 사용 독려 ("내 생각에는..." vs "너는 틀렸어")
- 의견과 개인을 분리하는 문화 조성
- 토론의 목적이 승패가 아님을 강조

### 갈등 발생 시 대응

```
[갈등 대응 단계]

1단계: 즉각 개입
   - 감정적 고조 방지
   - "잠깐, 양쪽 의견을 정리해볼까요?"

2단계: 객관적 요약
   - "A님은 ~라고 하셨고, B님은 ~라고 하셨네요"
   - 공통점 찾기

3단계: 전환
   - 제3의 관점이나 중립적 질문으로 전환
   - "텍스트에서 이 부분을 다시 볼까요?"

4단계: 필요시 휴식
   - "잠깐 5분 쉬었다가 계속할까요?"
```

### 갈등 이후 관리

- 토론 종료 전 화해와 이해의 기회 제공
- "오늘 다양한 관점을 경험할 수 있었습니다"로 긍정적 재구성
- 개인적 후속 대화로 관계 회복
- 모임 규칙이나 문화 개선점 파악

## 5. 피드백 문화 만들기

### 피드백 제공 방법

**좋은 피드백의 특징**:
- 구체적이고 관찰 가능한 행동에 초점
- 긍정적 측면과 개선점 균형 있게
- 개인이 아닌 아이디어나 행동에 대해
- 실행 가능한 제안 포함

### 피드백 수집 방법

| 방법 | 특징 | 활용 시점 |
|------|------|-----------|
| 모임 마무리 소감 | 즉각적, 간단 | 매 모임 |
| 익명 설문 | 솔직한 의견 | 분기별 |
| 1:1 대화 | 깊이 있는 피드백 | 필요시 |
| 온라인 설문 | 편리, 기록 남음 | 시즌 종료 시 |

### 간단한 피드백 질문

```
[모임 마무리 피드백 질문]

"오늘 모임에서 가장 좋았던 점은?"
"다음에 이렇게 해보면 어떨까요?"
"이 책에서 가장 기억에 남는 것은?"
```

## 6. 창의적 독서활동

토론만으로 모임을 운영할 수도 있지만, 다양한 활동을 추가하면 독서 경험이 더 풍부해집니다.

### 활동 유형 1: 시각화 활동

**마인드맵 만들기**
- 책의 핵심 개념을 중심에 두고 가지치기
- 개인별 또는 그룹별로 작성 후 비교
- 준비물: 큰 종이, 색연필/마커

**캐릭터 프로파일**
- 등장인물의 특징, 동기, 변화를 시각화
- 관계도 그리기
- 준비물: A4 용지, 필기구

**컨셉 콜라주**
- 책의 분위기나 주제를 이미지로 표현
- 잡지에서 이미지 오려붙이기 또는 온라인 이미지 수집
- 준비물: 잡지, 가위, 풀 또는 디지털 도구

### 활동 유형 2: 글쓰기 활동

**관점 바꾸기**
- 다른 인물의 시점에서 특정 장면 다시 쓰기
- 예: 조연의 시점에서 주요 사건 서술

**편지 쓰기**
- 등장인물에게 편지 쓰기
- 또는 등장인물이 되어 다른 인물에게 편지 쓰기

**결말 바꾸기**
- 다른 결말을 상상해서 쓰기
- 책 이후의 이야기 상상하기

**한 줄 리뷰**
- 이 책을 한 문장으로 표현한다면?
- 모두의 한 줄 리뷰 모아서 공유

### 활동 유형 3: 대화형 활동

**핫시팅 (Hot Seating)**
- 한 참여자가 등장인물 역할
- 다른 참여자들이 질문
- 등장인물의 입장에서 답변

**북 데이트**
- 짧은 시간 동안 여러 사람과 1:1로 특정 질문 토론
- 5분마다 파트너 교체
- 네트워킹과 다양한 관점 경험

**모의 인터뷰**
- 저자 인터뷰 형식으로 진행
- 한 명이 저자 역할, 나머지가 인터뷰어
- 책의 의도와 배경 탐구

### 활동 유형 4: 연극/역할극 활동

**장면 재연**
- 책의 중요한 장면을 연기로 재현
- 대본 없이 즉흥으로 진행해도 좋음

**결정의 순간**
- 등장인물의 중요한 결정 순간을 재현
- 다른 선택을 했다면 어땠을지 탐구

**재판 형식**
- 등장인물의 행동에 대해 재판 진행
- 검사, 변호사, 판사, 배심원 역할 분담

### 활동 선택 가이드

| 상황 | 추천 활동 |
|------|-----------|
| 처음 해보는 활동 | 한 줄 리뷰, 마인드맵 |
| 소설 읽을 때 | 관점 바꾸기, 핫시팅, 장면 재연 |
| 비소설 읽을 때 | 마인드맵, 적용 계획 세우기 |
| 참여도 높이고 싶을 때 | 북 데이트, 소그룹 활동 |
| 깊이 있는 탐구 원할 때 | 편지 쓰기, 모의 인터뷰 |

### 활동 진행 팁

```
[창의적 활동 진행 팁]

1. 목적 설명하기
   - "이 활동을 통해 ~를 경험해봐요"

2. 명확한 지시
   - 시간, 방법, 결과물 명확히

3. 예시 제공
   - 리더가 먼저 시범 보이기

4. 충분한 시간
   - 서두르지 않기

5. 공유 시간
   - 결과물 나누고 피드백
```

## 사례 연구: 참여 불균형 해결

### 모임: 부산 직장인 독서모임

**문제**: 15명 중 3-4명만 적극 발언, 나머지는 침묵

**적용한 해결책**:

1. **구조적 변화**
   - 전체 토론 전 4명씩 소그룹 토론 15분 진행
   - 소그룹에서 나온 내용을 전체에 공유

2. **역할 부여**
   - 매 모임 다른 사람에게 토론 일부 진행 역할
   - 요약, 질문 제시 등 작은 역할 분담

3. **다양한 표현 방식**
   - 포스트잇에 의견 적기
   - 그림으로 표현하기
   - 짧은 글쓰기

4. **사전 질문 공유**
   - 모임 3일 전 주요 질문 공유
   - 미리 생각할 시간 제공

**결과** (6주 후):
- 침묵하던 회원 80%가 적극 참여
- 토론의 다양성과 깊이 향상
- 참여자 만족도 3.2점 → 4.5점 (5점 만점)

**교훈**:
- 참여 불균형은 개인 문제가 아니라 구조의 문제일 수 있습니다
- 다양한 참여 방식과 안전한 환경이 중요합니다
