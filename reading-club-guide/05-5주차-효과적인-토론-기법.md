# 5주차: 효과적인 토론 기법

---

## 학습 목표

이번 주차를 마치면 다음을 할 수 있습니다:

- 토론 리더의 역할과 책임을 이해한다
- 효과적인 토론 질문을 설계할 수 있다
- 체계적인 토론 흐름을 설계할 수 있다
- 다양한 토론 형식을 상황에 맞게 적용할 수 있다
- 토론 중 발생하는 어려움에 대처할 수 있다

---

## 토론이 독서모임의 핵심인 이유

책을 읽는 것만으로는 독서모임이 완성되지 않습니다. **함께 이야기를 나누는 토론**이 있어야 진정한 독서모임입니다.

좋은 토론은:
- 혼자서는 발견하지 못한 관점을 열어줍니다
- 책의 내용을 더 깊이 이해하게 합니다
- 참여자들 간의 연결을 만들어줍니다
- 독서의 가치를 배가시킵니다

토론 진행이 어렵게 느껴질 수 있지만, **몇 가지 기본 원칙**만 알면 누구나 할 수 있습니다.

## 1. 토론 리더의 역할과 책임

### 토론 리더는 전문가가 아닙니다

토론 리더는 **촉진자(facilitator)**입니다. 책에 대한 정답을 알려주는 사람이 아니라, 대화가 잘 흐르도록 돕는 사람입니다.

**토론 리더가 해야 할 것**
- 질문을 던지고 대화를 이끌기
- 모든 사람이 발언할 기회 갖도록 돕기
- 시간을 관리하기
- 핵심 내용을 요약하기

**토론 리더가 하지 않아도 되는 것**
- 책에 대한 모든 것을 알기
- 정답을 제시하기
- 가장 많이 말하기

### 토론 전 준비

| 준비 항목 | 내용 |
|-----------|------|
| 책 읽기 | 꼼꼼히 읽고 표시하기 |
| 질문 준비 | 5-10개의 토론 질문 준비 |
| 배경 조사 | 저자, 출판 배경 등 기본 정보 |
| 시간 계획 | 토론 흐름과 시간 배분 |

### 토론 중 역할

```
[토론 중 리더의 역할]

1. 시작하기
   - 분위기 조성
   - 첫 질문으로 대화 열기

2. 진행하기
   - 대화의 흐름 조절
   - 모든 참여자 발언 기회 보장
   - 깊이 있는 추가 질문

3. 마무리하기
   - 주요 내용 요약
   - 다음 모임 안내
```

### 토론 후 역할

- 토론 내용 정리 및 공유 (서기에게 위임 가능)
- 다음 모임 안내
- 피드백 수집

## 2. 효과적인 토론 질문 설계

좋은 질문이 좋은 토론을 만듭니다. 질문 설계는 토론 준비의 핵심입니다.

### 블룸의 분류체계를 활용한 질문

다양한 수준의 질문을 준비하면 토론이 풍부해집니다:

| 수준 | 유형 | 예시 질문 |
|------|------|-----------|
| 1단계 | **기억** | "주인공의 직업은 무엇인가요?" |
| 2단계 | **이해** | "주인공이 그런 결정을 내린 이유는 무엇일까요?" |
| 3단계 | **적용** | "비슷한 상황에서 여러분은 어떻게 했을까요?" |
| 4단계 | **분석** | "이 책의 구조적 특징은 무엇인가요?" |
| 5단계 | **평가** | "저자의 주장에 동의하시나요? 왜 그런가요?" |
| 6단계 | **창조** | "다른 결말이었다면 어땠을까요?" |

> **TIP**: 1-2단계 질문으로 시작해서 워밍업 후, 3-6단계 질문으로 심화하세요.

### 열린 질문 vs 닫힌 질문

**닫힌 질문** (예/아니오, 단답형)
- 사용 시점: 토론 시작, 사실 확인
- 예: "이 책을 재미있게 읽으셨나요?"

**열린 질문** (다양한 답변 가능)
- 사용 시점: 본격적인 토론
- 예: "이 책에서 가장 인상 깊었던 장면은 무엇이고, 왜 그런가요?"

**권장 비율**: 열린 질문 80% + 닫힌 질문 20%

### 좋은 토론 질문의 특징

```
[좋은 질문 체크리스트]

✓ 다양한 의견이 나올 수 있는가?
✓ 책의 내용과 연결되어 있는가?
✓ 개인의 경험과 연결할 수 있는가?
✓ 너무 쉽거나 너무 어렵지 않은가?
✓ 대화를 확장시킬 수 있는가?
```

### 질문 예시: 소설의 경우

```
[소설 토론 질문 예시]

1. 첫인상 (워밍업)
   - 책을 덮고 가장 먼저 떠오른 감정이나 생각은?
   - 한 문장으로 이 책을 표현한다면?

2. 인물 탐구
   - 가장 공감되는 인물은 누구이고, 왜 그런가요?
   - 주인공의 선택 중 이해하기 어려웠던 것은?

3. 주제 탐구
   - 이 책이 던지는 가장 중요한 질문은 무엇인가요?
   - 작가가 독자에게 전하고 싶은 메시지는?

4. 개인적 연결
   - 나의 삶에서 비슷한 경험이나 감정은?
   - 이 책을 읽고 달라진 생각이 있다면?

5. 확장
   - 이 책을 누구에게 추천하고 싶나요?
   - 결말 이후의 이야기를 상상해본다면?
```

### 질문 예시: 비소설의 경우

```
[비소설 토론 질문 예시]

1. 핵심 내용
   - 저자의 핵심 주장은 무엇인가요?
   - 가장 설득력 있었던 부분은?

2. 비판적 검토
   - 저자의 주장에 동의하나요? 왜/왜 아닌가요?
   - 부족하거나 아쉬운 부분은?

3. 적용
   - 이 책의 내용을 내 삶에 어떻게 적용할 수 있을까요?
   - 우리 사회에 주는 시사점은?

4. 연결
   - 이 주제에 대해 더 알고 싶은 것은?
   - 관련해서 읽어볼 만한 다른 책은?
```

## 3. 토론 흐름 설계

### 4단계 토론 흐름

체계적인 흐름이 있으면 토론이 자연스럽게 깊어집니다.

```
┌─────────────────────────────────────────┐
│         토론의 4단계 흐름                 │
├─────────────────────────────────────────┤
│                                         │
│   1. 도입 (15-20분)                      │
│      ↓                                  │
│   2. 전개 (30-40분)                      │
│      ↓                                  │
│   3. 심화 (20-30분)                      │
│      ↓                                  │
│   4. 마무리 (10-15분)                    │
│                                         │
└─────────────────────────────────────────┘
```

### 단계별 상세 가이드

**1단계: 도입 (15-20분)**

| 활동 | 시간 | 방법 |
|------|------|------|
| 인사와 분위기 조성 | 5분 | 근황 나누기, 가벼운 대화 |
| 첫인상 공유 | 10분 | "책을 읽고 첫 느낌은?" |
| 기본 내용 확인 | 5분 | 줄거리, 주요 인물 간단 확인 |

**2단계: 전개 (30-40분)**

| 활동 | 시간 | 방법 |
|------|------|------|
| 핵심 주제 토론 | 20분 | 준비한 주요 질문 중심 |
| 텍스트 분석 | 10분 | 인상적인 구절 함께 읽기 |
| 다양한 관점 탐색 | 10분 | 서로 다른 의견 교환 |

**3단계: 심화 (20-30분)**

| 활동 | 시간 | 방법 |
|------|------|------|
| 개인 경험 연결 | 15분 | "나의 삶에서 비슷한 경험은?" |
| 현실 적용 | 10분 | "우리 삶/사회에 주는 의미는?" |
| 확장 토론 | 5분 | 관련 주제로 대화 확장 |

**4단계: 마무리 (10-15분)**

| 활동 | 시간 | 방법 |
|------|------|------|
| 핵심 요약 | 5분 | 오늘 토론의 주요 포인트 정리 |
| 새로운 통찰 공유 | 5분 | "오늘 새롭게 알게 된 것은?" |
| 다음 모임 안내 | 5분 | 일정, 도서, 담당자 확인 |

## 4. 다양한 토론 형식

상황에 따라 다양한 토론 형식을 활용하면 모임에 신선함을 더할 수 있습니다.

### 형식 1: 일반 토론 (기본)

- **방식**: 전체가 함께 자유롭게 토론
- **적합한 상황**: 소규모 모임 (4-8명)
- **장점**: 간단하고 자연스러움
- **주의점**: 발언 기회 균등하게 배분

### 형식 2: 하브루타 (짝 토론)

- **방식**: 2인 1조로 짝을 이뤄 질문과 답변 주고받기
- **적합한 상황**: 깊이 있는 탐구, 참여도 높이기
- **진행 방법**:
  1. 짝 구성 (15분)
  2. 서로 질문하고 답하기
  3. 전체 모임에서 핵심 내용 공유 (15분)
- **장점**: 모든 사람이 적극 참여

### 형식 3: 월드카페

- **방식**: 여러 테이블에서 주제별 토론 후 순환
- **적합한 상황**: 대규모 모임 (12명 이상), 다양한 주제 탐색
- **진행 방법**:
  1. 3-4개 테이블 설정, 각 테이블에 주제 배정
  2. 20분 토론 후 테이블 이동 (호스트 1명 잔류)
  3. 3라운드 진행 후 전체 공유
- **장점**: 다양한 관점 경험, 네트워킹

### 형식 4: 소크라테스식 세미나

- **방식**: 텍스트 기반의 깊이 있는 질의응답
- **적합한 상황**: 철학적 주제, 심층 분석
- **진행 방법**:
  1. 특정 구절 선택
  2. "왜?", "어떻게?" 질문으로 깊이 탐구
  3. 리더는 답을 주지 않고 질문으로 사고 촉진
- **장점**: 비판적 사고력 향상

### 형식 5: 찬반 토론

- **방식**: 책의 쟁점에 대해 찬반으로 나눠 토론
- **적합한 상황**: 논쟁적 주제, 다양한 입장이 있는 책
- **진행 방법**:
  1. 쟁점 선정 (예: "주인공의 선택은 옳았는가?")
  2. 찬성팀, 반대팀 구성
  3. 각 팀 입장 발표 → 반론 → 요약
- **장점**: 다양한 관점 경험, 논리적 사고

### 형식 선택 가이드

| 상황 | 추천 형식 |
|------|-----------|
| 처음 시작하는 모임 | 일반 토론 |
| 참여도가 낮을 때 | 하브루타 |
| 인원이 많을 때 | 월드카페 |
| 깊이 있는 분석 원할 때 | 소크라테스식 |
| 논쟁적인 책일 때 | 찬반 토론 |

## 5. 토론 중 어려움 대처하기

### 상황 1: 한 사람이 대화를 독점할 때

**대처 방법**:
- "흥미로운 관점이네요. 다른 분들의 생각도 들어볼까요?"
- 발언권 토큰 사용 (각자 3개씩, 발언할 때마다 1개 사용)
- 시간 제한 안내 ("1분 정도로 요약해주시겠어요?")
- 모임 후 개인적으로 대화

### 상황 2: 침묵이 길어질 때

**대처 방법**:
- 소그룹/짝 토론으로 전환
- 더 쉬운 질문으로 변경 ("가장 인상적인 장면은 어디였나요?")
- 리더가 먼저 자신의 생각 공유
- 포스트잇에 적어서 공유하는 방식 활용

### 상황 3: 주제에서 벗어날 때

**대처 방법**:
- "흥미로운 이야기인데, 잠시 원래 주제로 돌아가볼까요?"
- 화이트보드에 핵심 주제 적어두기
- 벗어난 주제는 메모해두고 "나중에 이야기하기"로 분류

### 상황 4: 의견 충돌이 심해질 때

**대처 방법**:
- 양측 의견 객관적으로 요약하기
- "텍스트로 돌아가서 확인해볼까요?"
- 제3의 관점 소개하기
- 필요시 짧은 휴식 제안
- "다양한 의견이 있다는 것 자체가 의미 있네요"

### 상황 5: 책을 읽지 않은 사람이 있을 때

**대처 방법**:
- 비난하지 않기
- 참여할 수 있는 질문 제공 ("책 소개를 보고 어떤 기대를 했나요?")
- 모임 시작 시 간단한 요약 제공
- 반복될 경우 개인적으로 대화

## 6. 한국 문화를 고려한 토론 진행

### 한국적 맥락에서의 토론

한국 사회의 문화적 특성을 이해하고 반영하면 더 효과적인 토론이 가능합니다.

**고려할 문화적 특성**:
- 나이, 직위에 따른 계층 의식
- 직접적인 반대 의견 표현의 어려움
- 침묵이 갖는 다양한 의미
- "눈치" 문화

### 대응 전략

| 특성 | 대응 전략 |
|------|-----------|
| 계층 의식 | 모임 내에서는 호칭 통일 (예: "~님"), 나이순 아닌 가나다순 발언 |
| 의견 표현 어려움 | "틀린 답은 없다" 강조, 익명 의견 수집 방식 활용 |
| 침묵의 의미 | 충분한 생각 시간 제공, 침묵을 급하게 채우지 않기 |
| 눈치 문화 | 안전한 분위기 조성, 소그룹부터 시작 |

### 실제 적용 사례

**서울 "세대공감 독서모임"**
- 구성: 20대~60대 다양한 연령
- 문제: 연령에 따른 발언 격차
- 해결책:
  - 호칭 통일 ("~님")
  - 가나다순 발언
  - 익명 의견 카드 활용
- 결과: 젊은 참여자 발언률 40% 증가

## 사례 연구: 질문의 힘

### 모임: 대전 "생각의 숲"

**특징**: 질문 설계에 특별히 집중하는 모임

**운영 방식**:
1. 매 책마다 핵심 질문 3개 + 하위 질문 각 3-4개 준비
2. 토론 3일 전 질문 목록 공유
3. 모든 참여자가 최소 1개 질문 제출
4. 개인 성찰 → 소그룹 토론 → 전체 공유 순서

**결과**:
- 모든 참여자의 적극적 참여
- 토론의 깊이와 폭 확대
- 참여자 만족도 크게 향상

**교훈**:
- 잘 설계된 질문은 토론의 질을 결정합니다
- 질문을 미리 공유하면 준비된 토론이 가능합니다
- 참여자들이 질문 형성에 참여하면 주인의식이 높아집니다
