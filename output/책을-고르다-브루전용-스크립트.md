## 🖼️ 2단계: 이미지 프롬프트 (브루에 순서대로 입력)

### 장면 1
```
50대 한국 여성 간호사, 병원 복도를 걸으며 지친 표정, 유니폼 착용, 저녁 무렵, 따뜻한 조명
```

### 장면 2
```
50대 여성이 공원 벤치에 앉아 눈물을 흘리며, 콧물까지 닦는 모습, 감정적인 순간, 자연광
```

### 장면 3
```
50대 여성이 서점에서 책을 고르며 망설이는 모습, 따뜻한 조명, 희망적 분위기
```

### 장면 4
```
책 표지 클로즈업: 책을 고르다 숨을 고르다, 따뜻하고 희망적인 배경, 부드러운 톤
```

### 장면 5
```
새벽, 마이크 앞에서 책을 낭독하는 50대 여성, 집중된 표정, 따뜻한 실내 조명
```

### 장면 6
```
독서 모임에서 책에 대해 이야기 나누는 사람들, 웃으며 대화, 따뜻한 카페 분위기
```

### 장면 7
```
헤드폰을 끼고 오디오북 녹음하는 50대 여성, 전문적인 모습, 녹음실 분위기
```

### 장면 8
```
시각장애인과 함께 점자 책을 만지고 있는 손, 따뜻한 연대의 순간, 클로즈업
```

### 장면 9
```
따뜻한 조명의 서재에서 책을 읽으며 미소 짓는 50대 여성, 평화롭고 행복한 표정
```

### 장면 10
```
책 표지와 함께 "지금 바로 만나보세요" 텍스트, 따뜻한 배경, 구매 유도 이미지
```

## ⚙️ 4단계: 브루 설정

### 나레이션 음성
- 성별: **여성**
- 나이: **중년 (40-50대)**
- 톤: **따뜻하고 공감적인**
- 속도: **보통**

### 배경음악
- 분위기: **따뜻하고 희망적인**
- 장르: **어쿠스틱 기타 또는 피아노**
- 볼륨: **나레이션의 30%**

### 자막 스타일
- 폰트: **깔끔한 고딕**
- 색상: **흰색 + 부드러운 그림자**
- 위치: **화면 하단**
- 크기: **크게 (모바일 가독성)**

### 영상 비율
- 유튜브 쇼츠/인스타 릴스: **9:16 (세로)**
- 유튜브 일반: **16:9 (가로)**

## 🎯 브루 사용 순서 요약

1. **브루 앱 열기** → 새 프로젝트
2. **나레이션 붙여넣기** → 위의 "1단계" 전체 복사
3. **AI 음성 선택** → 여성, 중년, 따뜻한 톤
4. **이미지 생성** → "2단계" 10개 프롬프트 순서대로 입력
5. **자막 추가** → "3단계" 키워드 강조
6. **배경음악 추가** → 따뜻한 어쿠스틱
7. **미리보기** → 조정
8. **렌더링** → 완성!
