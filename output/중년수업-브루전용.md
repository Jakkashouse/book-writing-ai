## ⚙️ 4단계: 브루 설정

### 나레이션 음성
- 성별: **남성**
- 나이: **중년 (40-50대)**
- 톤: **진지하고 단단한, 하지만 희망적인**
- 속도: **보통-약간 느림** (무게감)

### 배경음악
- 분위기: **시련 → 극복 → 희망**
- 장르: **드라마틱 피아노 → 희망적 오케스트라**
- 볼륨: **나레이션의 30%**

### 자막 스타일
- 폰트: **굵은 고딕 (힘있는 느낌)**
- 색상: **흰색 + 주황색 강조 (희망)**
- 위치: **화면 하단**
- 크기: **크게**
- 특수효과: 중요 부분 **주황색 하이라이트**

### 영상 비율
- 유튜브 쇼츠/인스타 릴스: **9:16 (세로)**
- 유튜브 일반: **16:9 (가로)**

## 💡 꿀팁

### 나레이션 연기 포인트
- "15만 원 일당 봉투" → **씁쓸하게**
- "일에 귀천이 없더라고" → **깨달음의 톤**
- "가족의 얼굴이 떠올랐습니다" → **감정 실어서**
- "무대가 바뀌었을 뿐" → **확신 있게**

### 이미지 전환
- 과거(롯데) → 추락(건설현장) → 회복(독서) → 재기(온라인)
- 감정 변화에 맞춰 색감도 변화 (어두움 → 밝음)

### 음악 변화
- 전반부: 무겁고 긴장감
- 중반부: 조용한 성찰
- 후반부: 밝고 희망적

## 🎯 차별화 포인트

### 기존 북트레일러와 다른 점
1. **15만 원 일당 봉투**로 시작 (강렬한 후킹)
2. **롯데 18년 → 건설현장** (극적 대비)
3. **구체적 직업명** (카이/위원 - 온라인 재기)
4. **30일 실전 가이드** (실용성 강조)

### 타겟
- 40-50대 중년 남성
- 퇴직/이직 고민하는 직장인
- 사업 실패 경험자
- 온라인 비즈니스 관심 중년
