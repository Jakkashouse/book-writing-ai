# 열다섯 걸음, 울릉도 독도 이야기 - 브루(Vrew) AI 전용 스크립트

## 🎬 차별화 각도
**기존 북트레일러**: 책 전체 소개
**이 영상**: 14명 청소년의 진짜 목소리 - 불평, 땀, 감동, 성장의 순간

---

```
"목사님, 여길 왜 가요?"
"배고파요, 더워요, 힘들어요!"

2025년 여름, 14명의 청소년과 한 명의 목사님이
울릉도와 독도로 떠났습니다.

봉래폭포 오르막길에서는

관음도 계단 앞에서는
"이건 그냥 천국의 계단이잖아!" 하며 후들거렸습니다.

하지만 독도 땅을 밟는 순간,
"나는 독도를 위해 뭘 했지?"
묵직한 반성이 밀려왔습니다.

에메랄드빛 바다 앞에서
"예쁘다"밖에 나오지 않던 어휘력의 한계.

그래도 괜찮았습니다.

힘든 등반 속에서 서로를 격려하는 우정,
자연 앞에서 겸손해지는 마음,

교실에서는 배울 수 없는

동탄기독학교 학생 14명이 직접 쓴

"열다섯 걸음, 울릉도 독도 이야기"

완벽하게 다듬어진 글이 아닙니다.
투박하지만 진실한,
10대 청소년들의 있는 그대로의 목소리입니다.
```

## 🖼️ 2단계: 이미지 프롬프트 (브루에 순서대로 입력)

### 장면 1
```
청소년들이 버스 안에서 불평하는 모습, 더워하며 땀 흘리는 표정, 여름 여행 분위기
```

### 장면 2
```
14명의 중학생들이 배에 타고 바다를 바라보는 뒷모습, 기대와 설렘, 푸른 바다
```

### 장면 3
```
가파른 오르막길을 힘들게 오르는 청소년들, 땀 흘리며 지친 표정, 울릉도 숲길
```

### 장면 4
```
관음도 가파른 계단, 끝이 보이지 않는 계단, 후들거리는 다리, 힘든 등반
```

### 장면 5
```
독도 표지석 앞에 선 청소년들, 벅찬 감동의 표정, 독도의용수비대 기념관
```

### 장면 6
```
울릉도 에메랄드빛 바다, 행남해안산책로, 청소년들이 감탄하며 바라보는 모습
```

### 장면 7
```
친구들끼리 서로 격려하며 등산하는 모습, 손 잡아주기, 우정, 따뜻한 분위기
```

### 장면 8
```
청소년들이 노트에 여행 기록을 쓰는 모습, 진지한 표정, 펜과 노트
```

### 장면 9
```
책 표지: 열다섯 걸음 울릉도 독도 이야기, 청소년들의 여행 사진 콜라주 배경
```

### 장면 10
```
청소년들이 함께 웃으며 단체 사진 찍는 모습, 우정과 성장, 따뜻한 마무리
```

## ⚙️ 4단계: 브루 설정

### 나레이션 음성
- 성별: **남성** (목사님 시점이지만 청소년 느낌도 섞어서)
- 나이: **젊은 성인 (30대)**
- 톤: **따뜻하고 유머러스한, 공감적인**
- 속도: **보통-약간 빠름** (청소년 에너지)

### 배경음악
- 분위기: **활기차고 청춘스러운**
- 장르: **어쿠스틱 팝, 경쾌한 기타**
- 볼륨: **나레이션의 35%**

### 자막 스타일
- 폰트: **둥근 고딕 (친근한 느낌)**
- 색상: **흰색 + 노란색 강조 (청소년 감성)**
- 위치: **화면 하단**
- 크기: **크게 (모바일 가독성)**
- 특수효과: 중요 부분은 **노란색 하이라이트**

### 영상 비율
- 유튜브 쇼츠/인스타 릴스: **9:16 (세로)**
- 유튜브 일반: **16:9 (가로)**

## 🎯 브루 사용 순서 요약

1. **브루 앱 열기** → 새 프로젝트
2. **나레이션 붙여넣기** → "1단계" 전체 복사
3. **AI 음성 선택** → 남성, 젊은 톤, 따뜻하고 유머러스
4. **이미지 생성** → "2단계" 10개 프롬프트 순서대로 입력
5. **자막 추가** → "3단계" 키워드 강조, 중요 부분 노란색
6. **배경음악 추가** → 경쾌한 어쿠스틱 팝
7. **미리보기** → 청소년 에너지 느껴지는지 확인
8. **렌더링** → 완성!

## 💡 꿀팁

### 나레이션 연기 포인트
- "목사님, 여길 왜 가요?" → **짜증 섞인 톤** (청소년 목소리 흉내)
- "천국의 계단" → **웃으면서** 읽기
- "나는 독도를 위해 뭘 했지?" → **진지하게** 천천히
- "이것도 한때야" → **따뜻하게** 위로하듯

### 이미지 전환
- 불평하는 장면 → 힘든 등반 → 감동의 순간 (감정 변화)
- 빠른 전환 (청소년 에너지)
- 마지막은 천천히 (감동)

### 자막 타이밍
- "배고파요, 더워요!" → **빨간색 강조** (불평)
- "나는 독도를 위해 뭘 했지?" → **화면 중앙, 크게**
- "있는 그대로의 목소리" → **노란색 하이라이트**

## 🎨 차별화 포인트

### 기존 북트레일러와 다른 점
1. **청소년 목소리 중심** (불평부터 감동까지)
2. **유머러스한 톤** ("속았다", "천국의 계단")
3. **진짜 성장 스토리** (완벽하지 않은 투박함의 가치)
4. **20년 후의 추억** (시간 확장)

### 타겟
- 청소년 자녀를 둔 부모
- 교회학교 교사
- 수학여행 기획하는 선생님
