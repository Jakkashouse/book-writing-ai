## 3. 받은 v1 마케팅 3에이전트 — 완전 이해

### 3.1 content-creator (보라색)
```yaml
name: content-creator
model: sonnet
tools: Read, Write, WebSearch
입력: 한 줄 주제
출력 3종:
  1. blog.md         (500자, SEO 고려, H1+H2 구조)
  2. instagram.txt   (80자 + 해시태그 5개)
  3. youtube-hook.md (60초, 첫 10초 강조)
저장 위치: outputs/{YYYY-MM-DD}-{topic-slug}/
실행: /content-create "주제"
```

**핵심 프롬프트 설계 원칙:**
- 블로그: H1 클릭 유도 → 첫 2문장 핵심 결론 → 3포인트 → CTA 1개
- 인스타: 감정 훅 → 해시태그 #브랜드 #카테고리 #타깃 #상황 #감정
- 유튜브: "당신 ~?" 질문 훅 → 핵심 메시지 2개 → 예고+구독 유도

### 3.2 sns-publisher (파란색)
```yaml
name: sns-publisher
model: sonnet
tools: Read, Write, Bash
depends_on: content-creator
입력: outputs/{date}-{topic}/ 폴더
출력 4종:
  1. 인스타그램 (해시태그 10~30개, 이모지 2~3개)
  2. 트위터 스레드 (280자 × 3~5트윗)
  3. 링크드인 (1,200~1,500자 전문성 톤)
  4. 예약 발행 일정표
큐 파일: .claude/publish-queue.json
실행: /sns-publish "outputs/{date}-{topic}"
```

**플랫폼별 발행 시간 룰:**
- 블로그: 당일 정오
- SNS: 다음날 오전 9시
- macOS: launchd.plist / **Windows: 작업 스케줄러**

### 3.3 insight-analyzer (초록색)
```yaml
name: insight-analyzer
model: sonnet
tools: Read, Write, Bash
depends_on: sns-publisher
입력: 지난 7일 발행분 + 성과 데이터(조회/좋아요/클릭/전환)
출력:
  - 주간 리포트 (reports/weekly-{YYYY-MM-DD}.md)
  - TOP 3 + 공통 패턴
  - BOTTOM 3 + 원인 진단
  - 다음 주 콘텐츠 주제 5개
트리거: 매주 월요일 오전 9시 자동
```

### 3.4 팀 파이프라인 (marketing-team.json)
```
[매주 월요일 오전 9시]
  ↓ insight-analyzer 실행
  ↓ 주간 리포트 + 다음 주 5개 주제 제안
[매일 오전 7시]
  ↓ content-creator 실행 (오늘의 주제)
  ↓ 3종 콘텐츠 생성
  ↓ sns-publisher 실행
  ↓ 플랫폼별 변환 + 오전 9시 예약
[7일 후 다시 insight-analyzer]
→ 주제 1회 입력 → 7일 후 성과 리포트 자동 수신 (사용자 개입 0회)
```
