다음 원고를 교정하세요: $ARGUMENTS

## 절대 룰
- **수정본 파일을 만들지 말 것**. Before/After 리포트만 출력
- 맞춤법은 1회가 아니라 **2-3라운드 전체 반복** 검토
- 자율적으로 서브 에이전트 돌려서 반복 검토(허락 받지 말 것)
- 메타 텍스트 금지 — 판본 노트·v번호·편집 요약박스 X
- 말투는 **"-습니다" 에세이 톤** 일관

## 3라운드 프로세스
1. **1라운드**: 반복 표현 제거 + 구조 점검
2. **2라운드**: 비문/오탈자/맞춤법 교정 (2-3회 반복)
3. **3라운드**: 최종 검수 + 재채점 (100점 만점, 목표 90점+)

## 채점 기준 (100점)
- 구조 25 + 문장 25 + 메시지 25 + 몰입도 25

## 출력 포맷
```
# 교정 리포트

## 1라운드 (반복/구조)
| # | Before | After | 이유 |
|---|---|---|---|

## 2라운드 (비문/오탈자)
...

## 3라운드 (최종 검수)
...

## 점수: XX점 → YY점
- 구조: __ / 25
- 문장: __ / 25
- 메시지: __ / 25
- 몰입도: __ / 25
```
