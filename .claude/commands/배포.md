배포 대상: $ARGUMENTS

## 자동 판별 규칙
- `book-coaching-next/` 또는 `webapp/` 등 Next.js → **Vercel** (`npx vercel --prod`)
- `deploy/`, `thankyou-deploy/`, 정적 HTML 폴더 → **Netlify** (`npx netlify-cli deploy --prod --dir=<폴더>`)
- 어느 것도 아니면 사용자에게 묻기

## 절차
1. 대상 폴더 확인 → 빌드 필요한지 점검
2. 빌드 실패 시 즉시 중단·원인 보고
3. 배포 후 라이브 URL 출력 + `Invoke-WebRequest`로 200 응답 확인
4. expert-workbook이면 ESLint 빌드 우회 적용 (이미 설정됨)

## 절대 룰
- `git push --force`, `git reset --hard` 금지 (이미 deny됨)
- 배포 전 현재 브랜치·리포 경로 명시 후 시작
- 배포 후 메모리에 URL 기록할지 묻지 말고 그냥 보고만
