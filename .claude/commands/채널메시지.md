같은 공지를 채널별 3버전으로 만드세요: $ARGUMENTS

## 하는 일

`scripts/channel_split.py`를 실행합니다. 손으로 세 번 고쳐 쓰지 마십시오.

```
python scripts/channel_split.py --file "C:/Users/JUN/Downloads/공지.md"
python scripts/channel_split.py --text "공지 내용" --title "8월 라이브"
```

원문이 길거나 파일이면 `--file`, 짧으면 `--text`를 쓰십시오.

## 채널별로 다른 규칙

| 채널 | 특수기호 | 처리 |
|---|---|---|
| 단톡방(카톡) | **허용** | 마크다운 표식(`**`, `#`, `-`)만 제거 |
| 문자(SMS/LMS) | **금지** | 룰10 강제 — 한글·숫자·영문·쉼표·마침표·괄호·하이픈만 |
| 이메일(스티비) | **허용** | 원문 그대로 |

문자에서 자동 변환되는 것: `·`→쉼표, `~`→"부터 까지", `1:1`→`1대1`,
`:)` `^^` `ㅠㅠ` 이모티콘·이모지 제거, `※` `→` `"` 제거.
**URL은 살립니다** — 링크에서 `:` `/`를 지우면 접속이 안 되기 때문입니다.

## 실행 후 반드시 보고할 것

1. **`[안전]`이 떴는지** — `[위험]`이면 발송하지 마시라고 명확히 알리기
2. 문자 SMS/LMS 구분과 바이트 수
3. 파일 절대경로
4. 세 버전 중 **문자 버전만 채팅에도 보여드리기** (가장 사고가 잦은 채널이라서)

2,000바이트를 넘으면 LMS 한도를 넘으니 줄이시라고 알리십시오.

## 발송 전 체크 (파일에 포함됨)

- 문자에 `[안전]`이 떴는가
- 링크가 살아 있는가
- 날짜·시간이 세 버전 모두 같은가
- 수료증 관련 내용이 없는가

## 나오는 파일

`C:\Users\JUN\Downloads\채널메시지_<제목>_YYYYMMDD.md`

## 하지 않는 것

- **발송하지 않습니다.** 문안만 만듭니다.
- 내용을 새로 쓰지 않습니다. 주신 원문을 채널에 맞게 변환만 합니다.
  (내용까지 새로 쓰시려면 `/마케팅`을 쓰십시오.)
