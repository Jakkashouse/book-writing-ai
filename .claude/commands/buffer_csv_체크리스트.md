# Buffer CSV 작성 체크리스트 (인스타 자동 발행)

## 배경
2026-05-22 제주 1박 2일 시리즈 발행 시 카드 2~9번이 모두 실패함. 원인 분석 결과 — Instagram 안티스팸 트리거(반복 URL + 13개 해시태그 매 카드 반복 + 본문 과다). 다시는 동일 실수를 하지 않기 위한 체크리스트.

## 절대 금지 (위반 시 차단 거의 확정)

1. **캡션 본문 URL 금지** — `https://...` 형태의 외부 링크를 본문에 넣지 말 것. 인스타는 캡션 URL을 클릭 불가 텍스트로 처리하면서 동시에 스팸 의심을 강하게 함. Buffer 공식 에러 라이브러리에도 명시.
   - 대신: "프로필 링크 →" / "프로필 링크 참조" / "DM 주세요"
2. **동일 해시태그 묶음 10회 반복 금지** — 10장 카드뉴스에 똑같은 해시태그 13개가 매번 들어가면 안티스팸 발동. 카드마다 주제에 맞춰 다르게.
3. **동일 CTA 문구 매 카드 반복 금지** — "정원 4명. 1기 1회. 1기 특가 330만원" 같은 라인을 10번 그대로 반복하지 말 것.

## 안전 가이드라인 (성공 사례 「그날에」 패턴)

| 항목 | 안전선 |
|------|--------|
| 본문 길이 | 120~250자 (인스타 평균에 맞춤) |
| 해시태그 수 | 카드당 3~8개 |
| 해시태그 다양성 | 카드별 70% 이상 다른 태그 |
| 본문 내 URL | 0개 |
| CTA | 마지막 카드 1장에만 집중 |

## CSV 포맷 (Buffer 공식)

```
Text,Image URL,Tags,Posting Time
"본문...",이미지URL,,"YYYY-MM-DD HH:MM"
```

- **컬럼명 대소문자 정확히**: `Text`, `Image URL`, `Tags`, `Posting Time`
- **인코딩**: UTF-8 with BOM (`utf-8-sig`)
- **따옴표**: 본문 안 따옴표는 곡선("/")으로. 직선 따옴표는 CSV 이스케이프 충돌
- **줄바꿈**: 셀 안 줄바꿈은 그대로 OK (Buffer 정상 해석)
- **시간대**: Buffer Posting Schedule에 설정된 타임존 기준. KST면 KST 그대로

## 사전 검증 스크립트

새 CSV 만들 때마다 다음을 실행:

```bash
python C:/Users/JUN/Downloads/buffer_csv_검증.py <CSV경로>
```

검증 항목:
- [ ] 컬럼명 정확
- [ ] UTF-8 BOM 인코딩
- [ ] 본문 URL 0개
- [ ] 해시태그 8개 이하
- [ ] 본문 250자 이하
- [ ] 카드 간 해시태그 중복률 70% 이하
- [ ] 곡선 따옴표 사용
- [ ] Image URL 200 OK 응답

하나라도 빨간불이면 발송 금지.

## 발행 후 모니터링

1. 첫 카드 발행 직후 인스타 계정 확인
2. 정상이면 1시간 기다림
3. 두 번째 카드 발행 후 또 확인
4. 둘 다 정상이면 나머지 진행
5. 한 건이라도 실패 → 즉시 일정 일시정지하고 원인 분석

## 「그날에」 vs 「제주」 사후 비교 (학습 기록)

| 항목 | 그날에 (성공) | 제주 1-9 (실패) |
|------|---------------|-----------------|
| 카드당 본문 | 123~202자 | 436~624자 |
| 카드당 해시태그 | 2~13개 (평균 5) | 13개 매번 |
| 본문 URL | 0개 | 1~2개 |
| 카드 1만 성공? | (해당없음) | 첫 발행만 통과 |

→ Instagram 안티스팸은 *반복 패턴*에 가장 민감. 1회는 통과해도 동일 패턴 9연속은 막힘.
