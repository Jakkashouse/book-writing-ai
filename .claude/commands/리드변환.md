메타 리드 CSV를 스티비 업로드용으로 변환하세요: $ARGUMENTS

경로가 비어 있으면 `C:\Users\JUN\Downloads\` 에서 가장 최근 `leads*.csv` 를 찾아
그 파일을 쓰겠다고 먼저 알리고 진행합니다.

## 실행

```
python "C:\Users\JUN\my-first-project\book-writing-ai\scripts\meta_to_stibee.py" "<CSV 경로>"
```

## 이 변환이 필요한 이유
메타는 12개 컬럼으로 내보내는데, 스티비 주소록에 정의되지 않은 필드
(제출된 날짜·소스·양식·채널·단계·소유자·레이블·보조 전화번호·WhatsApp 번호)가
섞여 있으면 스티비가 파일 전체를 **"잘못된 파일"** 로 거부합니다.
컬럼명 자체는 문제가 없습니다 — `이메일 주소`는 스티비 표준과 일치합니다.

## 절대 룰
- 결과물은 항상 `C:\Users\JUN\Downloads\` 에 저장 (스크립트가 처리)
- **원본 CSV는 절대 수정하지 말 것**
- 개인정보 파일이므로 **개별 리드 정보를 대화에 나열하지 말 것**.
  건수·형식·통계만 보고합니다
- 메타 CSV를 **엑셀로 열지 말 것**. 전화번호가 지수 표기(`8.21048E+12`)로
  뭉개져 뒷자리가 영구 소실됩니다. 확인이 필요하면 메모장이나 구글 시트로

## 출력 2종
1. `스티비_업로드_메타리드_<날짜>.csv` — 이메일 주소, 이름 (기본, 바로 업로드)
2. `스티비_업로드_전화포함_<날짜>.csv` — + 전화번호
   (주소록에 `전화번호` 사용자 정의 필드를 먼저 만들어야 통과)

## 보고 포맷
```
| 항목 | 건수 |
|---|---|
| 원본 | __건 |
| 이메일 없음·무효 제외 | -__건 |
| 중복 이메일 제외 | -__건 |
| **최종** | **__건** |

전화번호 있는 건: __건
저장 위치: (절대경로 2개)
```

깨진 전화번호가 감지되면 엑셀 손상 가능성을 함께 경고합니다.
