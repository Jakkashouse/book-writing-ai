결제하신 분께 보낼 안내 문안을 만드세요: $ARGUMENTS

## 하는 일

`scripts/payment_notice.py`를 실행합니다. 문안을 직접 작성하지 말고 반드시 스크립트를 쓰세요.
문자 특수기호 제거(룰10)가 코드에 들어 있어서, 손으로 쓰면 2026-08-11 발송 실패가 재발합니다.

## 실행

**한 명일 때**
```
python scripts/payment_notice.py --name 홍길동 --amount 100000
```

**여러 명일 때** (이름·금액 컬럼이 있는 CSV)
```
python scripts/payment_notice.py --csv "C:/Users/JUN/Downloads/명단.csv"
```

**아무 문장의 기호만 정리할 때**
```
python scripts/payment_notice.py --text "정리할 문장"
```

인자 해석:
- 이름만 주어지면 금액은 100000원으로 봅니다 (유료 컨설팅 기본가).
- `.csv` 경로가 보이면 `--csv`로 넘깁니다.
- 이름과 숫자가 함께 있으면 숫자를 금액으로 봅니다.

## 나오는 파일

- `C:\Users\JUN\Downloads\결제확인_문자_YYYYMMDD.csv` — 발송 시스템에 올리는 파일
- `C:\Users\JUN\Downloads\결제확인_문안_YYYYMMDD.md` — 눈으로 보고 복사하는 문서

## 실행 후 반드시 보고할 것

1. 대상 몇 명인지
2. **금지문자 검사 결과** — `[안전]`이 떴는지, 아니면 `[위험]`인지
3. 각 사람의 SMS/LMS 구분과 바이트 수
4. 파일 두 개의 절대경로

`[위험]`이 뜨면 **발송하지 마시라고 명확히 알리세요.**

## 알아둘 것

- **URL은 일부러 살려둡니다.** 룰10은 `:`와 `/`를 금지하지만, 링크에서 그걸 지우면
  캘린들리 주소가 죽어 상담 예약 자체가 막힙니다. 그래서 URL만 예외로 통과시킵니다.
  링크 밖의 `:` `/`는 여전히 전부 제거됩니다.

## 하지 않는 것

- 문자·이메일을 **대신 발송하지 않습니다.** 문안만 만들고 발송은 대표님이 하십니다.
- 누구에게 보냈는지 **기록하지 않습니다.**
- 결제선생·지메일에 **접속하지 않습니다.** 명단은 받아서 씁니다.
