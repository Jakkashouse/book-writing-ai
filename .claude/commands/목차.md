입력값: $ARGUMENTS

## 1단계 — 원고 또는 키워드 수령

- **파일 경로가 입력된 경우**: Read 도구로 원고를 읽어 장·절 구조를 추출하십시오.
- **키워드·콘셉트가 입력된 경우**: 입력값 그대로 사용하십시오.

## 2단계 — 목차 초안 작성

8-12장 구조로 작성하십시오. 각 장마다 3-5절을 포함하십시오.

```
# <책 제목>

## 1장. <장 제목>
- 한 줄 요약: (이 장에서 독자가 얻는 것)
- 예상 분량: (예: 약 12쪽, 4,000자)
- 핵심 메시지: (이 장의 한 문장 결론)
  - 1절. <절 제목>
  - 2절. <절 제목>
  - 3절. <절 제목>

## 2장. ...
```

프롤로그 / 에필로그 / 부록 필요 여부도 판단하여 포함하십시오.

## 3단계 — 균형 진단

목차 초안 작성 후 아래 항목을 진단하십시오.

```
## 균형 진단

### 분량 불균형
- 너무 긴 장: (장 번호 + 이유)
- 너무 짧은 장: (장 번호 + 이유)

### 흐름 점검
- 흐름이 끊기는 구간: (XX장 → XX장, 이유)
- 전환이 자연스러운 구간: (XX장 → XX장)

### 누락 의심 주제
- (독자가 기대하지만 빠진 내용 1-3개)

### 총평
- 출간 가능 목차 구조인가: 예 / 수정 필요
- 주요 수정 제안 (3개 이내, 우선순위순)
```

## 절대 룰
- 수료증 관련 내용 **절대 금지**
- 메타 텍스트(v번호·판본 노트) **금지**
- 결과물은 `C:\Users\JUN\Downloads\<책제목>_목차안.md` 저장
- 한국어 "-습니다" 에세이 톤 유지
- 원고 파일 경로는 반드시 **절대경로**로 처리

- [ ] 균형 진단 3개 항목 모두 작성됐는가
