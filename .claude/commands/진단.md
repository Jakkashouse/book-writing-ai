다음 원고를 진단하세요: $ARGUMENTS

## 채점 기준 (100점 만점)
- **구조** 25점: 목차 흐름, 장 균형, 도입-전개-마무리
- **문장** 25점: 비문, 군더더기, 가독성, 톤 일관성
- **메시지** 25점: 핵심 주장 명확성, 차별점, 독자 효용
- **몰입도** 25점: 에피소드, 첫 문단 흡인력, 페이지 터너 요소

## 목표
- 90점 이상이면 출간 가능
- 그 미만이면 보강 포인트 제시

## 출력 포맷
```
# 진단 리포트: <책 제목>

| 메시지 | __/25 | ... |
| 몰입도 | __/25 | ... |

## 강점
- ...

1. ...
2. ...
3. ...

- [ ] 가능 (90점+)
- [ ] 보강 후 가능

```
