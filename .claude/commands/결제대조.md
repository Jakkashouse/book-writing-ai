결제하신 분 중 아직 안내를 못 받은 분을 찾아내세요: $ARGUMENTS

## 하는 일

`scripts/payment_reconcile.py`를 실행합니다. 눈으로 대조하지 마세요.

기준은 **결제선생 결제내역**입니다. 돈이 들어온 사실이 진실이고,
안내를 보냈는지는 그 뒤의 일입니다.

## 실행

**기본** (발송이력 없이 — 전원이 미발송으로 잡힙니다)
```
python scripts/payment_reconcile.py "C:/Users/JUN/Downloads/결제내역.csv"
```

**이미 보낸 분을 알고 있을 때**
```
python scripts/payment_reconcile.py "결제내역.csv" --sent "홍길동,김철수"
python scripts/payment_reconcile.py "결제내역.csv" --sent-file "발송이력.csv"
```

**기간·금액으로 좁힐 때**
```
python scripts/payment_reconcile.py "결제내역.csv" --days 30 --min-amount 100000
```

## 자동으로 걸러지는 것

- 취소·환불·실패 건
- 같은 사람 같은 금액 중복 행
- `--days` 밖의 오래된 건
- `--min-amount` 미만 소액 (배송비 5천원 등)

컬럼명은 결제선생 내보내기 설정에 따라 달라지므로 스크립트가 알아서 찾습니다.
`이름 컬럼을 찾지 못했습니다`가 뜨면 헤더 행이 첫 줄이 맞는지 확인하세요.

## 나오는 파일

## 실행 후 반드시 할 것

1. 안내 필요 몇 건인지, 합계 금액이 얼마인지 보고
2. **그 CSV를 그대로 `/결제확인`에 넘겨** 문안까지 만들어 드릴지 여쭙기
3. 발송이력을 안 주셨으면 "전원 미발송으로 처리했다"고 명확히 알리기

## 하지 않는 것

- 결제선생·지메일에 **접속하지 않습니다.** 파일을 받아서 씁니다.
- 문자·이메일을 **발송하지 않습니다.**
- 보낸 기록을 **저장하지 않습니다.** 발송이력은 매번 넘겨주셔야 합니다.
