강의 하나에서 전 채널 콘텐츠를 뽑으세요: $ARGUMENTS

## 입력

Vrew에서 내보낸 `.srt` 파일 경로 또는 강의 자막 텍스트.
`/자막교정`을 먼저 돌린 파일을 쓰면 품질이 올라갑니다.

## 원칙 — 하나의 강의, 다섯 갈래

2시간 강의는 콘텐츠 광맥입니다. 숏폼만 뽑고 버리면 90%를 버리는 겁니다.
같은 자막에서 채널별로 형태만 바꿔 전부 뽑습니다.

| 산출물 | 분량 | 용도 |
|---|---|---|
| 숏폼 10편 | 30~60초 | 유튜브 쇼츠·릴스 (신규 유입) |
| 블로그 글 3편 | 각 1,500자 | 검색 유입·체류 |
| 카드뉴스 1세트 | 10장 이상 | 인스타 (저장·공유) |
| 뉴스레터 1통 | 1,000자 | 기존 명단 재활성화 |
| 원고 꼭지 2개 | 각 800자 | 대표님 책 재료 축적 |

**다섯 갈래가 전부 같은 곳으로 보냅니다.** 그게 아래 깔때기입니다.

## 깔때기 설계 (모든 CTA가 이 순서를 탑니다)

```
콘텐츠 (숏폼·블로그·카드뉴스·뉴스레터)
   ↓  [1단] 무료 설문 = mokcha 목차 진단
설문 응답 (이름·연락처·원고 상태 확보)
   ↓  [2단] 진단 결과 발송 + 만족 확인
"목차 잘 나왔다" 확인된 사람만
   ↓  [3단] 유료 1대1 컨설팅 10만원
컨설팅 결제자
   ↓  [4단] 캘린들리 일정 예약
통화·대면 상담
   ↓  [5단] 고가 책쓰기 과정 제안
```

### 단계별 CTA 규칙

**1단 (콘텐츠 → 설문)**
- 모든 콘텐츠의 CTA는 **여기로만** 보냅니다
- 결제 링크·고가 과정을 콘텐츠에서 직접 언급하지 않습니다
- 링크에 채널 추적 파라미터 필수
  - 숏폼 `?from=shorts` / 블로그 `?from=blog`
  - 인스타 `?from=insta` / 뉴스레터 `?from=news`

**2단 (설문 → 결과)**
- 진단 결과를 먼저 드립니다. 판매 문구를 섞지 않습니다
- 결과 발송 후 **만족 확인 질문**을 겁니다
- 만족 확인 전에 결제 링크를 보내지 않습니다

**3단 (결과 → 유료 컨설팅)**
- 만족 확인된 사람에게만 10만원 컨설팅을 제안합니다
- 제안 문구는 "더 파는 것"이 아니라 "목차 다음 단계"로 씁니다

**4단 (컨설팅 → 캘린들리)**
- 결제 즉시 캘린들리 링크를 보냅니다
- 예약 안 하면 3일 뒤 리마인드

**5단 (상담 → 고가)**
- 통화·대면에서만 꺼냅니다. 문자·메일로 먼저 던지지 않습니다
- `/상담준비`로 브리프를 먼저 만듭니다

### 넘지 말아야 할 선

**단계를 건너뛰지 마십시오.** 설문 응답자에게 결제 링크를 바로 보내는 것이
과거 리드 방치의 원인이었습니다. 한 칸씩만 올립니다.

## 출력 형식

### 1. 숏폼 10편
`/숏폼선별`과 동일한 형식. 타임코드 + 4축 점수 + 훅 문장 + Vrew 편집 지시 + 캡션.
CTA는 전부 1단(설문)으로.

### 2. 블로그 3편
- 제목 (검색 키워드 포함)
- 도입 3문장 (강의 중 실제 발언 인용으로 시작)
- 본문 소제목 3~4개
- 마무리 + CTA
- 어느 타임코드에서 나온 내용인지 표시

### 3. 카드뉴스 1세트 (10장 이상)
- 표지 1장 + 본문 8장 이상 + CTA 1장
- 에피소드·명문장·스토리 3요소 필수
- 장당 카피 + 이미지 지시
- "프로필 링크" 표현 금지

### 4. 뉴스레터 1통
- 제목 (열어볼 이유)
- 본문 1,000자
- 표준 링크 3종 배치 (캘린들리·설문지·랜딩)
- 이메일은 특수기호 허용

### 5. 원고 꼭지 2개
- 대표님 책 재료로 쓸 수 있는 형태
- "-습니다" 에세이 톤
- 메타 텍스트 금지
- 어느 책·어느 장에 들어갈지 배치 제안

### 6. 배포 캘린더
2주치 발행 일정표. 같은 날 같은 내용이 여러 채널에 겹치지 않게.

## 반드시 지킬 것

- 수료증 관련 내용 금지
- 제3자 실명은 지역명·관계호칭으로 익명화 (작가 본인 이름은 유지)
- 문자로 나갈 것이 있으면 룰10 적용 (한글·숫자·영문·쉼표·마침표·괄호·하이픈만)
- 강의에서 하지 않은 말을 지어내지 않습니다. 자막 원문 근거를 답니다
