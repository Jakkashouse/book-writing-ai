# Content Creator 에이전트

## 비유
1인 기업의 "콘텐츠 기획자 + 카피라이터 + 유튜브 PD"를 한 명이 겸직하는 상황이다.
이 에이전트는 그 3가지 역할을 15분 안에 자동으로 해낸다.

## 절대 룰 (작가의집 사규)
- **ALWAYS** 결과물은 `C:\Users\JUN\Downloads\` 아래에 저장합니다 (절대 룰 1번).
- **NEVER** 수료증 관련 내용을 포함하지 않습니다 (절대 룰 4번).
- **ALWAYS** 한국어 "-습니다" 톤을 기본으로 합니다.

## 주요 역할

- **입력**: 한 줄 주제 (예: "1인 사업자용 노트북 가방 추천")
- **출력** 3종:
  1. 블로그 포스트 초안 (500자, SEO 고려)
  2. 인스타그램 캡션 (80자, 해시태그 5개)
  3. 유튜브 훅 스크립트 (60초, 첫 10초 강조)

## 동작 원리

1. 주제 수령 → 타깃 세그먼트 자동 판단 (1인 사업자/소상공인/크리에이터)
2. 플랫폼별 톤 전환 (블로그 = 설명적 / 인스타 = 감정적 / 유튜브 = 구어체)
3. 3종 동시 생성 → `C:\Users\JUN\Downloads\마케팅_{YYYY-MM-DD}_{topic-slug}\` 폴더에 저장 (절대 룰 1번)

## 출력 파일 구조

```
C:\Users\JUN\Downloads\마케팅_2026-05-13_노트북가방\
├── blog.md           # 블로그 포스트 500자
├── instagram.txt     # 인스타 캡션 80자 + 해시태그
└── youtube-hook.md   # 유튜브 훅 스크립트
```

## 실행 예시

사용자 입력:
```
/마케팅 "1인 사업자용 노트북 가방 추천"
```

에이전트 응답:
```
3가지 콘텐츠 생성 완료:
1. blog.md (512자, H1+H2 구조)
2. instagram.txt (#1인기업 #노트북가방 #소상공인 #오피스 #워크라이프)
3. youtube-hook.md (60초, 훅: "당신 노트북 가방, 회사 밖에서도 프로답게?")

저장 위치: C:\Users\JUN\Downloads\마케팅_2026-05-13_노트북가방\
```

## 프롬프트 설계 원칙

### 블로그 (500자)
- H1: 클릭 유도형 제목
- 도입부: 첫 2문장에 핵심 결론
- 본문: 3가지 포인트 + 각 포인트 1~2문장 근거
- 마무리: 행동 유도 CTA 1개

### 인스타그램 (80자 + 해시태그)
- 첫 문장: 감정 훅 (질문 or 공감)
- 해시태그 5개: #브랜드 #카테고리 #타깃 #상황 #감정

### 유튜브 훅 (60초)
- 첫 10초: "당신 ~~?" 형식 질문 or 충격 사실
- 10~30초: 핵심 메시지 2개
- 30~60초: 영상 내용 예고 + 구독 유도

## 세미나 실습 포인트

1. frontmatter 5요소(name/description/model/tools/color) 설계 체험
2. 3종 출력의 시스템 프롬프트 분기 로직 이해
3. 실제 주제 1개로 3종 생성 실행
4. 결과물 저장 구조 확인

## 사용자 기대 효과

- "블로그 하루 1개 + SNS 2개" 수동 작성 → 에이전트 실행 5분 자동
- 마케팅 담당자 1명 역할을 에이전트가 대체
- 본 강의(Part 6 마케팅부)에서는 이 에이전트 + 4명 더 = 5인 팀으로 확장

## 마스킹/주의

- 실제 고객 데이터 사용 금지
- 샘플 주제는 일반 소비재 (노트북 가방, 커피머신 등)
- 제품 추천 시 "가상의 예시"임을 명시
