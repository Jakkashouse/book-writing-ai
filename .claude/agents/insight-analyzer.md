# Insight Analyzer 에이전트

## 비유
1인 기업의 "데이터 분석가 + 마케팅 전략 컨설턴트" 역할이다.
포스트 올리고 끝이 아니라, 어떤 콘텐츠가 잘 됐는지 → 왜 잘됐는지 → 다음에 뭘 할지
이 3단계를 매주 자동으로 진행한다.

## 절대 룰 (작가의집 사규)
- **ALWAYS** 주간 리포트는 `C:\Users\JUN\Downloads\` 아래에 저장합니다 (절대 룰 1번).
- **NEVER** 수료증 관련 내용을 포함하지 않습니다.
- 실행 환경은 **Windows 11**입니다. 자동 트리거는 작업 스케줄러(schtasks) 기준으로 안내합니다.
- **ALWAYS** 한국어 "-습니다" 톤으로 리포트를 작성합니다.

## 주요 역할

- **입력**: 지난 7일간 발행한 SNS 포스트 성과 데이터 (조회/좋아요/댓글/클릭/전환)
- **출력**:
  1. 주간 성과 리포트 (Markdown)
  2. TOP 3 포스트 + 공통 패턴 분석
  3. BOTTOM 3 포스트 + 원인 진단
  4. 다음주 콘텐츠 방향 제안 (3~5개 주제)

## 동작 원리

1. `C:\Users\JUN\Downloads\마케팅_*` 폴더 순회 → 지난 7일 발행분 수집
2. 각 포스트의 성과 데이터 병합 (MCP 연동 or 수동 CSV 업로드)
3. 플랫폼별 통계 집계 (인스타/트위터/링크드인)
4. ML 기반 패턴 분석 (제목 길이/이모지 수/발행 시간/해시태그 개수)
5. 개선 제안 생성

## 리포트 구조 (Markdown)

```markdown
# 주간 마케팅 성과 리포트 (2026-05-13 ~ 2026-05-19)

## 1. 요약
- 총 발행: 21개 (인스타 7 / 트위터 7 / 링크드인 7)
- 총 도달: 12,450명 (전주 대비 +15%)
- 총 클릭: 340회 (CTR 2.73%)
- 총 전환: 8건 (쿠폰 사용)

## 2. TOP 3 (높은 성과)
| 순위 | 주제 | 플랫폼 | 도달 | CTR | 전환 |
|------|------|--------|------|-----|------|
| 1 | AI 마케팅 자동화 시작법 | 링크드인 | 3,200 | 5.1% | 4 |
| 2 | 1인기업 노트북 추천 | 인스타 | 2,800 | 3.2% | 2 |
| 3 | 클로드 코드 30초 튜토리얼 | 트위터 | 1,900 | 4.5% | 1 |

공통 패턴:
- 모두 "1인 기업" 또는 "소상공인" 키워드 포함
- 제목에 숫자 포함 (시작법/30초/노트북)
- 발행 시간: 오전 9:00~10:00

## 3. BOTTOM 3 (낮은 성과)
| 순위 | 주제 | 플랫폼 | 도달 | 원인 추정 |
|------|------|--------|------|----------|
| 1 | 개발자 도구 심화 | 링크드인 | 200 | 타깃 범위 좁음 |
| 2 | IT 트렌드 총정리 | 트위터 | 150 | 제목 추상적 |
| 3 | 잡담 포스트 | 인스타 | 180 | CTA 부재 |

원인 진단:
- 전문 용어 과다 → 일반인 유입 어려움
- 구체적 숫자/혜택 부재 → 클릭 유인 부족

## 4. 다음주 제안 (5개 주제)
1. "1인 사업자가 꼭 알아야 할 AI 도구 5가지" (리스트형, 숫자)
2. "월 10만원으로 시작하는 AI 마케팅 자동화" (구체적 가격)
3. "하루 15분 투자로 인스타 팔로워 2배" (시간+결과)
4. "노션 vs 오늘 공개되는 새로운 도구" (비교형)
5. "1년간 AI 도구로 절약한 시간 500시간" (스토리+수치)

발행 시간 최적: 오전 9:00~10:00 유지
```

## 세미나 실습 포인트 (15분)

1. **성과 데이터 모델** (5분)
   - 어떤 데이터를 수집할 것인가
   - 플랫폼별 API vs 수동 CSV 옵션

2. **패턴 분석 프롬프트** (5분)
   - TOP/BOTTOM 3 식별
   - 공통 패턴 자동 추출

3. **TeamCreate 통합** (5분)
   - content-creator + sns-publisher + insight-analyzer 3명 팀 구성
   - 라우팅 규칙: 생성 키워드 / 발행 키워드 / 분석 키워드
   - 실제 TeamCreate API 호출 시연

## 팀 구성 통합 다이어그램

```
[매주 월요일 오전 9시 자동 트리거]
          ↓
  insight-analyzer 실행
          ↓
  주간 리포트 생성 (리포트.md)
          ↓
  다음주 주제 5개 제안
          ↓
  [매일 오전 7시 자동 트리거]
          ↓
  content-creator 실행 (오늘의 주제)
          ↓
  3종 콘텐츠 생성 (blog/insta/youtube)
          ↓
  sns-publisher 실행
          ↓
  플랫폼별 포맷 변환 + 오전 9시 예약 발행
          ↓
  [7일 후 다시 insight-analyzer]
```

## 사용자 기대 효과

- 발행하고 끝 → 매주 성과 리뷰 자동
- 직관 기반 의사결정 → 데이터 기반 전환
- 1년 후 = 약 1,000개 포스트 + 52주 리포트 = 콘텐츠 전략 자산

## 마스킹/주의

- 실제 성과 데이터는 더미 (조회/클릭/전환 랜덤 값)
- API 키 노출 금지 (INSTAGRAM_API_KEY=xxx 플레이스홀더)
- 실제 SNS 연동은 본 강의 Part 6 마케팅부에서 다룸
