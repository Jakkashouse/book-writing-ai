# 📍 1주차

## 🎯 주제: "당신이 3년째 책을 못 쓰는 이유는 **'제목과 목차'** 때문이다"

Part.1 이론+노하우
- 책쓰기 실패의 진짜 원인은 재능이 아니라 '제목과 목차'입니다
	- 99%가 모르는 진실: 제목과 목차가 80%다
- 출판사가 숨기는 비밀: 제목 하나로 운명이 갈립니다
	- 제목 공식 10가지 상세 설명
- 목차가 없으면 3개월 후 거절됩니다
	- 5부 구조 시스템 (Why-What-How-Do-Future)
- 29년 실패한 사람도 목차 시스템으로 3주 만에 초고 완성
	- 박○○님 사례: 27년째 책쓰기 포기 → 2달 만에 출간

Part.2 실습
**🎯 제목 자동 생성 엑셀로 30분 만에 10개 완성**
**🎯 5부 구조 템플릿으로 1일 만에 40꼭지 완성**

[과제]

- 책 쓰는 이유 작성 (6주 후 / 1년 후 내가 얻고 싶은 것)

# 📍 2주차

## 🎯 주제: 완벽하게 쓰려다 3년째 한 글자도 못 썼다면, **'AI 80% + 나 20%'** 공식을 몰랐기 때문이다

Part.1 이론+노하우
- 완벽주의가 책쓰기를 망칩니다
	- 100% 완벽 목표 → 완성률 3%, 80% 완성 목표 → 완성률 87%
- 2025년 책쓰기는 "AI 80% + 나 20%"입니다
	- 황금 프롬프트 7종 공개
	- 실제 시간 단축 데이터: 13.5시간 → 1.5시간 (9배 단축)
- 글쓰기 5+5 시스템: 말하듯 쓰면 됩니다
	- 70대도 30분 만에 주제 3개 찾은 비밀
- 초고 완성률 87%의 비밀
	- 작가의집 수강생 초고 완성률 87% vs 일반인 5% (17배 차이)

Part.2 실습
**🎯 황금 프롬프트 7종으로 작업 시간 9배 단축**
**🎯 5+5 시스템으로 말하듯 글쓰기 (첫 챕터 완성)**

[과제]
- 황금 프롬프트 7종으로 Part 1 초고 작성하기 (AI 80% + 나 20%)
- 5+5 시스템으로 내 경험 스토리 5개 작성
- 완벽주의 탈출 선언문 작성

# 📍 3주차

## 🎯 주제: 원고만 보내면 3개월 후 거절됩니다. 출판사가 원하는 것은 **'기획서'**입니다

Part.1 이론+노하우
- 출판사는 원고가 아니라 기획서를 본다
	- 원고만 제출 → 답장률 5%, 기획서 제출 → 답장률 85% (17배 차이)
- 계약률 100%의 비밀: 5분 기획서 템플릿
	- 7가지 구성 요소 (제목, 타겟 독자, 시장 분석, 목차, 저자 소개, 마케팅 계획, 예상 판매 부수)
- 계약서 함정: 이것 모르면 500만원 손해
	- 인세율, 선인세, 저작권, 2차 저작물 권리 체크리스트
- 출판사 100곳 명단 공개
	- 장르별 / 타겟별 출판사 분류
	- 동시 제안 전략 (3~5곳)

Part.2 실습
**🎯 5분 기획서로 계약률 300배 상승**
**🎯 계약서 체크리스트로 500만원 손해 방지**

[과제]
- 5분 기획서 완성하기 (7가지 요소)
- 출판사 3~5곳 선정 후 기획서 제안 발송
- 계약서 체크리스트 작성 (7가지 질문)

# 📍 4주차

## 🎯 주제: 출간하면 자동으로 팔릴 거라 생각하면 평균 30부 팔고 끝입니다. **'출간 전 30일 마케팅'**이 베스트셀러를 만듭니다

Part.1 이론+노하우
- 출간 후 홍보하면 이미 늦습니다
	- 출간 후 홍보 시작 → 평균 30부, 출간 전 30일 마케팅 → 평균 120부 (4배 차이)
	- 출간일 100부만 팔아도 = 베스트셀러 (예스24 기준)
- 출간 전 30일 마케팅 타임라인
	- D-30: 출간 예고 SNS 포스팅
	- D-15: 지인 50명 동원
	- D-Day: 100부 판매 → 베스트셀러 달성
- 책은 명함입니다. 진짜 수익은 강의와 컨설팅입니다
	- 책 100부 × 3,000원 = 30만원 vs 강의 1회 = 30만원 (같은 시간 37배 차이)
- 책→강의→컨설팅 파이프라인 설계
	- 90일 플랜: 출간 → 강의 10건 → 컨설팅 5건

Part.2 실습
**🎯 출간일 100부 판매로 베스트셀러 만들기**
**🎯 책→강의→컨설팅 파이프라인 (연 1,920만원)**

[과제]
- D-30부터 D-Day 마케팅 타임라인 작성
- 지인 리스트 100명 작성 (A/B/C급 분류)
- 강의 제안서 3종 작성 (기업/공공기관/커뮤니티)

# 📍5주차

## 🎯 주제: 책 1권으로 끝내면 손해입니다. **'콘텐츠 7번 재활용'**으로 연 3,000만원 만드는 법

Part.1 이론+노하우
- 책 1권 = 콘텐츠 100개

	- 같은 콘텐츠로 7번 돈 버는 법
- 웨비나 1회 = 3,000만원 (전환율 10% 기준)
	- 웨비나 수익 계산: 참석 100명 × 전환율 10% × 상품가 300만원 = 3,000만원
	- 최○○님 사례: "첫 회에서 1.65억. 10배 벌었어요"
- 웨비나 시스템 전체 공개 (복붙 가능)
	- 90분 웨비나 스크립트 (복붙 가능)
	- PPT 62페이지 (복붙 가능)
- 책쓰기 코치 상품 설계 (월 230만원)
	- 1:1 코칭 vs 그룹 코칭 vs 디지털 상품

Part.2 실습
**🎯 웨비나 시스템 전체 확보 (스크립트+PPT 62페이지 복붙 가능)**
**🎯 책쓰기 코치 상품 설계로 월 900만원 수익 구조**

[과제]
- 웨비나 스크립트 커스터마이징 (내 책 내용으로)

# 📍 6주차

## 🎯 주제: 더 이상 출판사에 의존하지 마라. **'1인 출판사'**로 100% 수익 가져가는 법

Part.1 이론+노하우
- 출판사 계약하면 인세 10%. 1인 출판사 하면 100%
	- 출판사: 15,000원 × 인세 10% = 1,500원
	- 1인 출판사: 15,000원 × 순수익 60% = 9,000원 (6배 차이)
- 실제 사례 4가지 (작가의집 수강생)
	- 사례 1: 6개월 만에 600부 판매 → 순수익 500만원
	- 사례 2: 내 책 1,100부 판매 → 총 수익 3,950만원
	- 사례 3: 1년 만에 350부 판매 → 손해 안 봄
	- 사례 4: 코칭비 모델 → 손해 가능성 0%
- 예비창업패키지 (실제 수혜 사례)
	- 내가 받은 지원금: 4,500만원
	- 어떻게 받았나? (신청 방법 상세)
- 6주 총정리: 당신은 이제 '작가'입니다
	- 제목 → 목차 → 초고 → 기획서 → 마케팅 → 수익화 전체 프로세스

Part.2 실습
**🎯 1인 출판사로 수익 6배 상승**
**🎯 예비창업패키지 4,500만원 지원금 신청 방법**

[과제]
- 1인 출판사 사업 계획서 작성
- 예비창업패키지 신청서 작성 (템플릿 활용)
- 수료 후 액션 플랜 (3개월 / 6개월 / 1년 목표)
