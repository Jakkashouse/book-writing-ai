# ♻️ 콘텐츠 재활용 자동화 템플릿

> **"책 1권 (40꼭지) = 블로그 40개 + 유튜브 40개 + 인스타 120개"**

---

## 🎯 콘텐츠 재활용 공식

```
책 1꼭지 (1,500자)
  ↓
├─ 블로그 1편 (1,500자) ← 그대로 복붙
├─ 유튜브 1편 (3-5분) ← 읽어주기
├─ 인스타그램 피드 3개 ← 핵심만 발췌
├─ 인스타그램 릴스 1개 ← 명언 1개
├─ 유튜브 쇼츠 1개 ← 15초 요약
└─ 뉴스레터 1편 (매주 월요일)
```

**1꼭지 = 7개 콘텐츠 = 1주일 분량**

## 📝 Step 1: 블로그 (그대로 복붙)

### 방법:
1. 책 1꼭지를 그대로 복사
2. 블로그에 붙여넣기
3. 제목만 SEO 최적화

### 제목 최적화 예시:
- 책: "아이와의 대화법"
- 블로그: "[육아 팁] 아이와 대화 잘하는 법 3가지 (워킹맘 필독)"

### 추가 요소:
- 서론 (2줄): "안녕하세요, [저자명]입니다. 오늘은..."
- 결론 (2줄): "이 내용은 제 책 [책 제목]에서 더 자세히 다룹니다."
- CTA: "▶ 책 구매하기: [링크]"

---

## 🎥 Step 2: 유튜브 (3-5분)

### A. 스크립트 = 책 내용 그대로 읽기
```
[인트로 10초]
안녕하세요, [저자명]입니다.
오늘은 [꼭지 제목]에 대해 이야기해볼게요.

[본론 3분]
(책 내용을 그대로 읽기)

[아웃트로 20초]
오늘 내용은 제 책 [책 제목]에서 더 자세히 보실 수 있어요.
구매 링크는 설명란에 있습니다. 좋아요와 구독 부탁드려요!
```

### B. 촬영 방법:
1. **책상 앞 앉아서 촬영** (얼굴 정면)
   - 조명: 링라이트 or 창문 앞
   - 배경: 깔끔한 책장 or 흰 벽
   - 카메라: 스마트폰 세로 or 가로

2. **화면 녹화** (PPT + 목소리)
   - PPT 5-7장 준비
   - 파워포인트 화면 녹화 기능 사용
   - 목소리만 녹음

### C. 편집:
- CapCut (무료 앱) 사용
- 자막 자동 생성
- 썸네일 제작 (Canva)

---

## 📷 Step 3: 인스타그램 피드 3개

### 피드 1: 도입부 (문제 제기)
```
[이미지: 책 표지 + 꼭지 제목]

[본문]
당신도 이런 고민 있나요? 🤔

[책 내용 중 문제 제기 부분 발췌 - 3줄]

→ 다음 게시물에서 해결법 공개합니다!

#책추천 #[책주제] #[타겟독자]
```

### 피드 2: 해결법 (본론)
```
[이미지: 핵심 내용 텍스트]

[본문]
✅ [꼭지 제목] 핵심 3가지

1. [핵심 1 - 1줄]
2. [핵심 2 - 1줄]
3. [핵심 3 - 1줄]

자세한 내용은 프로필 링크에서 확인하세요 📚

#[책제목] #[주제] #[타겟]
```

### 피드 3: CTA (행동 유도)
```
[이미지: 책 전체 표지]

[본문]
💡 더 알고 싶다면?

제 책 「[책 제목]」에서
이 내용을 10배 더 자세히 다룹니다.

👉 프로필 링크에서 구매 가능
👉 서점 방문 시 제목 검색!

여러분의 후기가 궁금해요 💬

#신간 #책스타그램 #[주제]
```

---

## 🎬 Step 4: 인스타그램 릴스 (15초)

### 스크립트:
```
[0-3초] 후킹
화면: "[문제 상황]" 텍스트
음성: X

[3-10초] 솔루션
화면: "[해결법 1줄]" 텍스트
음성: "이렇게 하세요"

[10-15초] CTA
화면: 책 표지 + "자세한 내용은 프로필 링크"
음성: 트렌디한 BGM
```

### 제작 방법:
1. CapCut 앱 실행
2. 템플릿 검색 → "책 추천" or "명언"
3. 텍스트만 교체
4. 내보내기 → 인스타그램 릴스 업로드

---

## 📺 Step 5: 유튜브 쇼츠 (15초)

### 인스타그램 릴스 그대로 재활용
1. 인스타그램 릴스 다운로드 (SnapTube 앱)
2. 유튜브 쇼츠 업로드
3. 제목: "[꼭지 제목] #shorts"
4. 설명: 책 구매 링크

---

## 📧 Step 6: 뉴스레터 (주간)

### 구성:
```
제목: [책 제목] 뉴스레터 #[주차] - [이번 주 주제]

---

안녕하세요, [저자명]입니다.

이번 주는 [꼭지 제목]에 대해 이야기합니다.

[책 내용 발췌 - 300자]

더 자세한 내용은 이번 주 블로그에서 확인하세요:
👉 [블로그 링크]

---

📚 이번 주 콘텐츠:
• 블로그: [링크]
• 유튜브: [링크]
• 인스타그램: @[계정명]

---

다음 주에 만나요!
[저자명]
```

### 발송 도구:
- Mailchimp (무료 2,000명)
- Stibee (한국 서비스)
- 네이버 폼 (간단)

## 💰 수익화 전략

### 블로그 (애드센스)
- 40개 포스팅 × 월 1,000 방문자
- 월 10-30만원 수익

### 유튜브 (광고)
- 40개 영상 × 평균 500 조회
- 월 20-50만원 수익
- 구독자 1,000명 넘으면 가속

### 인스타그램 (제휴 마케팅)
- 120개 피드 → 팔로워 증가
- 책 판매 링크 클릭 → 수수료

### 뉴스레터 (유료 전환)
- 무료 뉴스레터 40주
- 이후 유료 전환 (월 9,900원)
- 구독자 100명 = 월 99만원
