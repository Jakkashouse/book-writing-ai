# 마음이 자라는 책방 - 20일 인스타그램 홍보 플랜

## 목표
- 일일 판매 10-15권 달성
- 인스타그램 팔로워 증가 및 참여율 향상
- 독자 커뮤니티 형성

---

## 1단계: 기반 구축 (1-5일차)

### 1일차 - 계정 최적화
- [ ] 프로필 최적화
  - 프로필 사진: 책 표지 또는 브랜드 로고
  - 소개글: "자녀의 마음을 이해하는 부모가 되고 싶다면 | 예스24 자녀교육 분야 | 구매링크 ↓"
  - 링크: 예스24 구매링크 (또는 링크트리로 여러 서점 통합)
- [ ] 하이라이트 정리
  - 책소개
  - 독자후기
  - 저자소개
  - 육아팁

### 2일차 - 콘텐츠 뱅크 준비
**포스팅 소재 10가지 준비**
1. 책 핵심 내용 요약 (챕터별)
2. 실전 육아 팁
3. 공감 콘텐츠 (육아맘 고민)
4. 독자 후기 리뷰
5. 저자 인터뷰/메시지
6. 책 구절 명언 카드뉴스
7. 비포/애프터 사례
8. Q&A
9. 이벤트/프로모션
10. 일상 비하인드

### 3일차 - 초기 콘텐츠 발행
- [ ] 오전 9시: 책 소개 릴스 (30-60초)
  - "자녀의 떼쓰기, 어떻게 대응하시나요?"
  - 책의 핵심 솔루션 3가지 제시
  - 해시태그: #육아 #자녀교육 #육아서 #육아맘 #육아스타그램

- [ ] 오후 3시: 피드 포스팅
  - 책 표지와 핵심 메시지
  - 구매 링크 바이오에 표시

### 4일차 - 타겟 커뮤니티 참여
- [ ] 육아 관련 해시태그 팔로우 및 댓글 활동
  - #육아맘 #육아일기 #육아스타그램 #자녀교육 #육아고민
  - 하루 30개 게시물에 진심 어린 댓글
- [ ] 릴스 발행: 공감 콘텐츠
  - "아이가 말을 안 들을 때 당신의 반응은?"
  - 잘못된 반응 vs 올바른 반응 비교

### 5일차 - 첫 이벤트 기획
- [ ] 서평단 모집 이벤트 공지
  - "마음이 자라는 책방 서평단 10명 모집"
  - 참여방법: 팔로우 + 이 게시물 스토리 공유 + 댓글
  - 선정자에게 책 무료 증정 (대신 상세 후기 필수)

---

## 2단계: 성장 가속화 (6-12일차)

### 6일차 - 서평단 선정 및 발표
- [ ] 오전: 서평단 10명 선정 발표
- [ ] 오후: 감사 스토리 + 책 발송 인증

### 7일차 - 릴스 집중 공략
- [ ] 릴스 2개 발행
  - 오전: 책 핵심 내용 (예: "아이의 자존감을 높이는 3가지 말")
  - 오후: 릴레이션 콘텐츠 (트렌디한 음악 + 육아 상황극)
- [ ] 인스타 스토리 4-5개
  - 일상 + 육아팁 + 투표 스티커

### 8일차 - 협업 시작
- [ ] 육아 인플루언서 10명에게 DM
  - 소규모 인플루언서 (팔로워 5천-3만)
  - 책 무료 증정 + 솔직한 후기 요청
- [ ] 피드: 책 명언 카드뉴스

### 9일차 - 라이브 방송 예고
- [ ] 스토리 + 피드: 라이브 예고
  - "육아 고민 실시간 상담 라이브"
  - 날짜: 11일차 저녁 8시
  - 사전 질문 받기 (댓글로)

### 10일차 - UGC 활용
- [ ] 서평단 후기 리포스팅 시작
  - 스토리에 태그하며 재공유
  - "감사합니다! 더 많은 후기가 기다려집니다"
- [ ] 릴스: 독자 후기 모음 영상

### 11일차 - 첫 인스타 라이브
- [ ] 저녁 8시 라이브 진행 (30-40분)
  - 자기소개 및 책 소개
  - 사전 질문 답변
  - 실시간 질문 받기
- [ ] 라이브 특별 혜택: 지금 구매 시 저자 사인본 or PDF 특별부록
- [ ] 라이브 후 하이라이트 저장

### 12일차 - 라이브 복기
- [ ] 라이브 하이라이트 릴스로 편집
- [ ] 피드: 라이브 요약 + 감사 인사
- [ ] 스토리: 라이브 구매자 감사 메시지

---

## 3단계: 바이럴 확산 (13-20일차)

### 13일차 - 챌린지 시작
- [ ] 해시태그 챌린지 런칭
  - #마음이자라는육아챌린지
  - "오늘 아이에게 한 따뜻한 말 한마디 공유하기"
  - 참여자 중 추첨 5명 책 증정
- [ ] 릴스로 챌린지 참여 방법 안내

### 14일차 - 협업 콘텐츠 발행
- [ ] 육아 인플루언서 후기 리포스팅
- [ ] 협업 릴스 (인플루언서와 함께)
- [ ] 스토리: 챌린지 참여자 소개

### 15일차 - 감정 자극 콘텐츠
- [ ] 릴스: "엄마도 처음이라서..." (공감 영상)
  - 육아의 어려움 공감
  - 책이 주는 위로 메시지
- [ ] 피드: 독자 실제 변화 사례 스토리

### 16일차 - 2차 이벤트
- [ ] 구매 인증 이벤트
  - "책 구매 후 인증샷 올리면 스타벅스 기프티콘"
  - 참여방법: 구매 인증 + 스토리 태그
  - 하루 선착순 3명

### 17일차 - 콜라보 확대
- [ ] 육아 관련 계정과 맞팔 이벤트
  - 유아교육 업체
  - 육아용품 브랜드
  - 상호 홍보

### 18일차 - 긴급성 강조
- [ ] 스토리: "베스트셀러까지 D-3! 함께 만들어요"
- [ ] 릴스: 지금까지의 여정 요약 (판매량, 후기 등)
- [ ] 피드: 구매 독려 메시지

### 19일차 - 2차 라이브
- [ ] 저녁 8시 라이브
  - 그동안의 감사 인사
  - 베스트셀러 도전 현황 공유
  - Q&A 세션
  - 특별 할인 or 굿즈 증정 이벤트

### 20일차 - 마무리 및 재정비
- [ ] 오전: 최종 감사 메시지
- [ ] 오후: 향후 커뮤니티 운영 계획 공유
- [ ] 저녁: 결산 포스팅
  - 20일간의 성과
  - 독자들의 후기 모음
  - 다음 프로젝트 예고

## 일일 루틴

### 매일 해야 할 것
1. **콘텐츠 발행**
   - 피드 1개 (오전 9시 or 오후 3시)
   - 릴스 1-2개 (오후 12시, 저녁 7시)
   - 스토리 5-7개 (수시로)

2. **커뮤니티 활동**
   - 댓글 응답 (모든 댓글에 답변)
   - 육아 해시태그 탐색 및 댓글 30개
   - DM 응답 (24시간 내)

3. **분석**
   - 인사이트 확인 (도달, 참여율)
   - 가장 반응 좋은 콘텐츠 파악
   - 다음 날 콘텐츠 조정

## 릴스 제작 팁

### 효과적인 릴스 구조
1. **첫 3초가 생명**
   - 강렬한 질문 or 공감 멘트
   - 예: "아이가 떼쓸 때 이렇게 하시나요?"

2. **중간 전개**
   - 문제 상황 제시
   - 잘못된 대응 vs 올바른 대응
   - 책의 솔루션 간단히 소개

3. **마무리**
   - CTA: "자세한 내용은 프로필 링크에서"
   - 좋아요, 저장 유도

### 추천 릴스 주제
- "아이 떼쓰기 대처법 3단계"
- "자존감 높이는 부모의 말 vs 낮추는 말"
- "출근 전 5분, 아이와 관계 개선하는 법"
- "화낼 뻔했지만 참았던 순간 (feat. 이 책)"

## 스토리 활용법

### 스토리 콘텐츠 아이디어
1. **일상 공유** (친근함 형성)
   - 저자의 육아 일상
   - 책 쓰는 과정 비하인드

2. **인터랙션**
   - 투표 스티커: "이럴 땐 어떻게 하세요?"
   - 질문 스티커: "육아 고민 보내주세요"
   - 퀴즈: "이 상황에서 아이는 뭐라고 말할까요?"

3. **긴급성**
   - "지금 주문하면 내일 도착"
   - "이벤트 마감 3시간 전"
   - "베스트셀러까지 OO권 남았어요"

## 인플루언서 협업 가이드

### 타겟 인플루언서
- **팔로워 규모**: 5천-5만 (참여율이 높은 중소 인플루언서)
- **분야**: 육아맘, 육아일기, 책육아, 홈스쿨링
- **스타일**: 진솔하고 솔직한 후기를 쓰는 계정

### 협업 제안 멘트
```
안녕하세요! [계정명]님
평소 [계정명]님의 진솔한 육아 이야기를 재미있게 보고 있습니다.

저희 '마음이 자라는 책방'이라는 자녀교육서를 출간했는데,
[계정명]님께 책을 보내드리고 싶어 연락드립니다.

솔직한 후기를 부탁드리며, 부담 없이 읽어주시면 감사하겠습니다.
관심 있으시면 주소를 DM으로 보내주세요!
```

## 추가 팁

### 콘텐츠 제작 도구
- **디자인**: Canva (무료 템플릿)
- **릴스 편집**: CapCut, InShot
- **스케줄링**: Meta Business Suite

### 효과 극대화 전략
1. **일관성**: 매일 같은 시간대 포스팅
2. **진정성**: 과장된 홍보보다 진솔한 경험 공유
3. **상호작용**: 댓글, DM에 빠른 응답
4. **테스트**: A/B 테스트로 효과적인 콘텐츠 찾기
5. **재활용**: 반응 좋은 콘텐츠는 다시 포맷 변경해서 재발행

### 주의사항
- 과도한 판매 멘트 자제 (가치 제공 80%, 판매 20%)
- 팔로우/언팔 반복 금지 (계정 제재)
- 봇이나 가짜 팔로워 구매 절대 금지
- 저작권 주의 (음악, 이미지)

## 20일 후 전략

이 플랜이 끝난 후:
- 월 1-2회 라이브 정기화
- 독자 커뮤니티 형성 (오픈채팅방 or 밴드)
- 시즌별 이벤트 (어린이날, 방학 등)
- 후속 콘텐츠 (전자책, 강연 등) 준비
