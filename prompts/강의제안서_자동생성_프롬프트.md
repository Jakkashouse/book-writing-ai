# 📧 강의 제안서 자동 생성 AI 프롬프트

> **책 내용만 입력하면 → 기업/기관 맞춤 강의 제안서 완성**

---

## 🎯 사용법

1. 아래 프롬프트를 ChatGPT/Claude에 복사
2. [책 정보] 부분에 당신의 책 내용 입력
3. 타겟 기업/기관 선택
4. **5분 만에 강의 제안서 완성!**

---

## 📝 프롬프트 1: 기본 강의 제안서

```
당신은 강연 기획 전문가입니다.
아래 책 정보를 바탕으로 기업/기관에 보낼 강의 제안서를 작성해주세요.

[책 정보]
- 책 제목: 「_______________」
- 저자: _______________
- 핵심 주제: _______________
- 타겟 독자: _______________
- 주요 내용 (3-5문장):
_______________

[타겟 기관]
- 종류: 기업 / 학교 / 공공기관 / 도서관 (택 1)
- 규모: 대기업 / 중소기업 / 스타트업 (기업일 경우)

[강의 형식]
- 시간: 1시간 / 2시간 / 반일 / 1일 (택 1)
- 방식: 오프라인 / 온라인 / 하이브리드

---

다음 형식으로 작성해주세요:

**제목:** [기관 니즈를 반영한 매력적인 제목]

**1. 제안 배경 (3줄)**
- 현재 [타겟 기관]이 겪는 문제
- 이 강의가 필요한 이유

**2. 강의 목표 (3가지)**
1. [구체적 목표 1]
2. [구체적 목표 2]
3. [구체적 목표 3]

**3. 강의 개요**
| 시간 | 내용 | 방법 |
|------|------|------|
| 00:00-00:20 | [세션 1] | 강의/토론/워크숍 |
| 00:20-00:40 | [세션 2] | 강의/토론/워크숍 |
| 00:40-01:00 | [세션 3] | 강의/토론/워크숍 |

**4. 기대 효과 (3가지)**
1. [즉시 효과]
2. [중기 효과]
3. [장기 효과]

**5. 강사 소개**
- 저자: [이름]
- 대표 도서: 「[책 제목]」
- 주요 이력 (책 내용 기반으로 추정)
- 강의 경력 (있다면)

**6. 제안 조건**
- 강의료: [00만원] (협의 가능)
- 준비물: 빔프로젝터, 마이크 등
- 참가 인원: 최소 [00명] ~ 최대 [00명]

**7. 문의**
- 이메일: _______________
- 연락처: _______________

---

[중요]
- 기관의 니즈를 정확히 파악한 제안서
- 책 내용을 강의로 자연스럽게 연결
- 구체적인 숫자와 예시 포함
- 읽는 즉시 "이거다!" 싶게 작성
```

## 📝 프롬프트 2: 타겟별 맞춤 강의 제안서

### A. 기업 대상

```
당신은 기업 교육 전문가입니다.
아래 책 정보를 바탕으로 기업 HRD 담당자에게 보낼 강의 제안서를 작성해주세요.

[책 정보]
- 책 제목: 「_______________」
- 저자: _______________
- 핵심 키워드 3개: ___, ___, ___

[타겟 기업]
- 업종: IT / 제조 / 서비스 / 금융 / 유통 (택 1)
- 직급: 신입사원 / 대리급 / 팀장급 / 임원급
- 니즈: 리더십 / 커뮤니케이션 / 생산성 / 자기계발 / 조직문화

---

제안서 작성 시 반드시 포함:
1. **ROI 명확화**: "이 강의 후 [구체적 변화] 발생"
2. **사내 문제 해결**: 현재 [타겟 기업]이 겪는 문제 언급
3. **액션 플랜**: 강의 후 즉시 적용 가능한 3가지 실행안
4. **강의료 정당화**: "1인당 [00원] 투자로 [00배] 효과"

형식:
- 제목: [기업 니즈] 해결을 위한 [책 주제] 강의 제안
- A4 2페이지 이내
- 표, 도표 활용
- 담당자가 임원에게 보고하기 쉽게
```

### B. 학교 대상

```
당신은 교육 강연 전문가입니다.
학교(초/중/고/대학) 대상 강의 제안서를 작성해주세요.

[책 정보]
- 책 제목: 「_______________」
- 저자: _______________
- 학생들에게 전하고 싶은 메시지 (3줄):
_______________

[타겟 학교]
- 유형: 초등학교 / 중학교 / 고등학교 / 대학교
- 대상: 전체 학생 / 특정 학년 / 동아리

---

제안서 작성 시 반드시 포함:
1. **학생 눈높이**: 지루하지 않고 재미있게
2. **교육적 가치**: 진로/인성/학습 등 교육 목표와 연결
3. **상호작용**: 강의 중 학생 참여 활동 포함
4. **학부모 만족**: "우리 아이가 이 강의를 들으면..."

형식:
- 제목: [학생들의 관심사]와 연결된 제목
- 재미 + 교훈
- 50분 수업 or 2시간 특강
```

### C. 도서관 대상

```
당신은 독서 문화 프로그램 기획자입니다.
도서관 대상 저자 강연 제안서를 작성해주세요.

[책 정보]
- 책 제목: 「_______________」
- 저자: _______________
- 책의 핵심 메시지:
_______________

[타겟 도서관]
- 유형: 공공도서관 / 대학도서관 / 전문도서관
- 대상: 일반 시민 / 학생 / 직장인

---

제안서 작성 시 반드시 포함:
1. **독서 연계**: 강의 전/후 책 읽기 권장
2. **지역 사회 기여**: 지역 주민에게 주는 가치
3. **참여 유도**: 북토크, Q&A 세션
4. **예산 친화적**: 도서관 예산 고려한 합리적 강의료

형식:
- 제목: [책 제목] 저자와 함께하는 북토크
- 90분 (강의 60분 + Q&A 30분)
- 책 증정 이벤트 포함
```

## 📝 프롬프트 3: 강의 제목 10개 뽑기

```
당신은 강의 제목 전문가입니다.
아래 책 정보를 바탕으로 강의 제목 10개를 뽑아주세요.

[책 정보]
- 책 제목: 「_______________」
- 핵심 주제: _______________
- 타겟: _______________

---

제목 작성 원칙:
1. **후킹**: 첫 1초에 시선 사로잡기
2. **구체성**: "누가, 무엇을, 어떻게" 명확히
3. **숫자 활용**: "3가지", "7단계", "30일" 등
4. **문제 해결**: "[문제] 해결하는 [방법]"

10개 제목을 다음 형식으로:
1. [기업용] _______________
2. [기업용] _______________
3. [학교용] _______________
4. [학교용] _______________
5. [도서관용] _______________
6. [도서관용] _______________
7. [공공기관용] _______________
8. [공공기관용] _______________
9. [일반 대중용] _______________
10. [일반 대중용] _______________

각 제목 옆에 [타겟 니즈]를 간단히 설명해주세요.

## 📝 프롬프트 4: 강의 PPT 목차 자동 생성

1. _______________
2. _______________
3. _______________
4. _______________
5. _______________

[강의 시간]
- 선택: 1시간 / 2시간 / 3시간

---

다음 형식으로 PPT 목차를 만들어주세요:

**[강의 제목]**

**슬라이드 구성 (총 [00장])**

1. **표지** (1장)
   - 강의 제목

   - Slide 4: [챕터 1 제목]
   - Slide 5: [핵심 개념]
   - Slide 6: [사례/스토리]
   - Slide 7: [실전 팁]
   - ...

4. **본론 2 (15분, 5-7장)**
   - ...

5. **본론 3 (15분, 5-7장)**
   - ...

6. **워크숍/Q&A (10분, 2-3장)**
   - Slide XX: [실습 문제]
   - Slide XX: [질문 시간]

7. **마무리 (5분, 2-3장)**
   - Slide XX: 핵심 요약 3가지
   - Slide XX: 오늘부터 실천할 1가지
   - Slide XX: 연락처 + 책 정보

**총 [00]장**

[중요]
- 슬라이드당 1분 원칙
- 텍스트는 최소, 이미지는 최대
- 3장마다 청중 참여 활동 1개
```

## 💡 사용 팁

### 1. 타겟별 맞춤 전략
- **기업**: ROI, 생산성, 문제 해결 강조
- **학교**: 재미, 교육적 가치, 학생 참여
- **도서관**: 독서 연계, 지역 사회 기여
- **공공기관**: 사회적 가치, 공익성

### 2. 강의료 협상 팁
- 첫 제안은 높게 (협상 여지)
- 패키지 할인 제시 (3회 이상)
- 교통비/숙박비 별도 명시
- 책 판매 연계 (현장 판매 50% 할인)

### 3. 성공률 높이는 방법
- 타겟 기관 리서치 필수
- 담당자 이름 확인 (00님 호칭)
- 2주 후 팔로우업 메일
- 거절당해도 1년 후 재제안
