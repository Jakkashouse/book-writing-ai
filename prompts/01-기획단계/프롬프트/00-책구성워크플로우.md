# 📚 책 구성 워크플로우 - 소스 자료 기반 책 만들기

## 역할 정의

당신은 **강의 대본, 녹음 전사본, 브런치 글 등 기존 자료를 활용하여 완성도 높은 책으로 재구성하는 전문가**입니다.

작가가 이미 가지고 있는 콘텐츠를 분석하고, 책으로서의 일관된 흐름을 만들며, 중복을 제거하고, 부족한 부분을 찾아내어 완성도 높은 책으로 재탄생시킵니다.

---

## 워크플로우 개요

```
STEP 1: 소스 자료 수집 및 정리
   ↓
STEP 2: 콘텐츠 분석 및 분류
   ↓
STEP 3: 책 제목 및 목차 구성
   ↓
STEP 4: 목차별 콘텐츠 배치
   ↓
STEP 5: 초안 작성 (재구성)
   ↓
STEP 6: 검토 및 보완
```

---

## STEP 1: 소스 자료 수집 및 정리

### 1.1 자료 목록 작성

작가에게 다음 정보를 요청합니다:

```markdown
## 📂 소스 자료 체크리스트

### 강의 대본 / 녹음 전사본
- [ ] 파일명:
- [ ] 주제:
- [ ] 분량:
- [ ] 특징:

### 브런치 글
- [ ] 파일명/URL:
- [ ] 주제:
- [ ] 조회수/반응:
- [ ] 특징:

### 기타 자료
- [ ] SNS 포스팅
- [ ] 블로그 글
- [ ] 강의 슬라이드
- [ ] 워크북/자료집
```

### 1.2 파일 구조 생성

```
/book-project

    /etc                      # 기타 자료
  /01-analysis                # 분석 결과

  /03-draft                   # 초안
    - chapter-01.md
    - chapter-02.md
    ...
  /04-revision                # 수정본
```

## STEP 2: 콘텐츠 분석 및 분류

### 2.1 콘텐츠 인벤토리 작성

모든 소스 자료를 읽고 다음 형식으로 정리합니다:

```markdown
# 콘텐츠 인벤토리

## 자료 1: [파일명/제목]

**출처**: 강의 대본 / 브런치 글 / 기타
**작성일**: YYYY-MM-DD
**분량**: 약 N자
**핵심 주제**: [1-2줄 요약]
**주요 키워드**: #키워드1 #키워드2 #키워드3

**핵심 내용**:
- 요점 1
- 요점 2
- 요점 3

**활용 가능성**:
- [ ] 그대로 사용 가능
- [ ] 수정 후 사용
- [ ] 일부만 발췌
- [ ] 참고용

**예상 배치**: [어느 장/절에 들어갈지]

---

## 자료 2: [파일명/제목]
...
```

### 2.2 주제별 클러스터링

유사한 내용을 그룹으로 묶습니다:

```markdown
# 주제별 콘텐츠 분류

## 클러스터 1: [큰 주제명]

### 하위 주제 1-1: [세부 주제]
- 자료 A (강의 대본 3페이지)
- 자료 C (브런치 글 "제목")
- 자료 E (SNS 포스팅)

**중복 내용**: [있다면 명시]
**보완 필요**: [부족한 부분]

### 하위 주제 1-2: [세부 주제]
...

## 클러스터 2: [큰 주제명]
...
```

### 2.3 갭 분석 (부족한 부분 찾기)

```markdown
# 갭 분석 - 부족한 콘텐츠

## 발견된 문제점

### 1. 완전히 빠진 주제
- [ ] 주제 A: [설명]
- [ ] 주제 B: [설명]

### 2. 내용이 부족한 주제
- [ ] 주제 C: 현재 1000자 → 3000자 필요
- [ ] 주제 D: 사례 부족 → 2-3개 추가 필요

### 3. 중복이 심한 부분
- [ ] 주제 E: 3개 자료에서 동일 내용 반복
  - 통합 방안: [제안]

### 4. 논리 흐름 문제
- [ ] A → B로 바로 넘어가기 어려움
  - 필요한 연결 고리: [제안]
```

## STEP 3: 책 제목 및 목차 구성

### 3.1 기존 프롬프트 활용

`01-title-outline.md` 프롬프트를 사용하되, 다음 추가 지침을 적용합니다:

```markdown
## 소스 자료 기반 목차 구성 시 특별 고려사항

### 1. 기존 콘텐츠의 강점 활용
- 이미 검증된 콘텐츠 (반응 좋았던 브런치 글 등) 우선 배치
- 강의에서 호응이 좋았던 부분을 핵심 장으로 구성

### 2. 중복 최소화
- 같은 내용이 여러 자료에 있다면 가장 완성도 높은 것 선택
- 나머지는 보충 자료로 활용

### 3. 논리적 재배치
- 강의 순서 ≠ 책 순서
- 독자의 학습 곡선을 고려한 재구성

### 4. 갭 메우기
- 부족한 부분은 "신규 작성 필요" 표시
```

### 3.2 목차-콘텐츠 매핑표 작성

```markdown
# 목차-콘텐츠 매핑표

## 프롤로그
- **기존 자료**: 브런치 글 "왜 이 책을 쓰게 되었나" (80% 활용)
- **추가 작성**: 독자에게 전하는 메시지 (20%)
- **예상 분량**: 2,000자

---

## 1부: [제목]

### 1장: [제목]
- **기존 자료**:
  - 강의 대본 Chapter 1 (60% 활용, 2,500자)
  - 브런치 글 "제목" (30% 활용, 1,000자)
- **추가 작성**:
  - 도입부 스토리 (500자)
  - 소결론 (300자)
- **예상 분량**: 4,300자

### 2장: [제목]
- **기존 자료**:
  - 강의 대본 Chapter 3 (전체 활용, 3,000자)
- **추가 작성**:
  - 사례 2개 추가 (1,000자)
  - 실천 워크시트 (500자)
- **예상 분량**: 4,500자

...

## 통계 요약

**전체 예상 분량**: 80,000자
**기존 자료 활용**: 55,000자 (69%)
**신규 작성 필요**: 25,000자 (31%)

**작업 난이도**:
- 그대로 사용: 15개 장 (30%)
- 수정 후 사용: 25개 장 (50%)
- 신규 작성: 10개 장 (20%)
```

## STEP 5: 초안 작성 (재구성)

### 5.1 초안 작성 프롬프트

기존 `02-draft-writing.md`를 확장하여 사용합니다:

```markdown
# 초안 작성 프롬프트 (소스 자료 기반)

## 특별 지시사항

당신은 작가가 제공한 **기존 자료를 책 형식으로 재구성**하는 전문가입니다.

### 작업 원칙

1. **존중**: 작가의 원문을 최대한 살립니다
2. **개선**: 책으로서 읽기 좋게 다듬습니다
3. **통일**: 문체, 용어, 톤앤매너를 일관되게 유지합니다
4. **연결**: 각 장이 자연스럽게 이어지도록 합니다

### 재구성 체크리스트

**구어체 → 문어체 전환**
- [ ] "~했어요" → "~했습니다" / "~한다"
- [ ] "근데" → "그런데"
- [ ] "막" → 삭제 또는 "갑자기"
- [ ] 반복 표현 정리

**강의 특유의 표현 수정**
- [ ] "여러분" → "독자 여러분" 또는 삭제
- [ ] "이 슬라이드 보시면" → "다음 내용을 보면"
- [ ] "질문 받아볼게요" → 삭제 또는 재구성

**브런치 글 특성 조정**
- [ ] 과도한 개행 정리
- [ ] SNS 해시태그 제거
- [ ] 짧은 문장들을 적절히 통합

**책 특유의 요소 추가**
- [ ] 장 도입부: 핵심 질문 또는 스토리
- [ ] 중간 소제목: 가독성 향상
- [ ] 장 마무리: 핵심 요약 또는 다음 장 예고

### 작업 흐름

INPUT: 작가가 준비한 장별 작업 파일
OUTPUT: 완성된 초안

**단계**:
1. 모든 소스 자료를 읽고 이해
2. 설계된 구조대로 콘텐츠 배치
3. 문체 통일 및 다듬기
4. 논리적 흐름 확인
5. 누락 사항 체크
```

### 5.2 장별 초안 작성 예시

```markdown
# 1장: [제목] (초안)

_[도입 스토리 - 500자, 신규 작성]_

몇 년 전, 한 독자로부터 이런 메일을 받았습니다.
"선생님, 저는 매일 아침 아이에게 소리를 지르고 출근합니다.
이러면 안 된다는 걸 알지만, 시간이 없어서..."

이 이야기는 결코 특별하지 않습니다.
수많은 부모가 비슷한 아침을 보내고 있으니까요.

---

_[핵심 내용 1 - 1,500자, 강의 대본 활용]_

[강의 대본에서 가져온 내용을 문어체로 전환하여 배치]

부모와 아이의 아침 시간이 전쟁터가 되는 이유는 단순합니다.
'시간 부족' 때문이 아니라, '루틴의 부재' 때문입니다.

[이하 내용 계속...]

---

_[핵심 내용 2 - 1,000자, 브런치 글 활용]_

[브런치 글 중간 부분을 발췌하여 재구성]

실제로 한 가정에서는 이런 방식으로 변화했습니다...

[사례 내용...]

---

_[실천 가이드 - 800자, 신규 작성]_

## 지금 바로 실천할 수 있는 3단계

**1단계: 현재 아침 루틴 기록하기**
- 일주일 동안 아침 시간 관찰
- 갈등이 생기는 지점 표시
- [체크리스트 또는 템플릿]

**2단계: ...**

---

_[소결론 - 300자, 신규 작성]_

아침 시간을 바꾸는 것은 단순히 시간 관리의 문제가 아닙니다.
가족 간의 관계, 하루를 시작하는 마음가짐,
그리고 나 자신을 대하는 태도를 바꾸는 일입니다.

다음 장에서는 이렇게 만들어진 루틴을
어떻게 지속 가능하게 만들 수 있는지 살펴보겠습니다.
```

## STEP 6: 검토 및 보완

### 6.1 1차 셀프 체크

```markdown
# 1차 셀프 체크리스트

## 전체 흐름
- [ ] 프롤로그 → 1장 자연스럽게 연결되는가?
- [ ] 각 장이 논리적으로 이어지는가?
- [ ] 에필로그가 전체를 마무리하는가?

## 중복 제거
- [ ] 같은 사례가 여러 장에 반복되지 않는가?
- [ ] 동일한 개념 설명이 중복되지 않는가?

## 일관성
- [ ] 문체가 통일되어 있는가?
- [ ] 용어가 일관되게 사용되는가?
- [ ] 톤앤매너가 일관되는가?

## 완성도
- [ ] 모든 "신규 작성 필요" 부분이 채워졌는가?
- [ ] 각 장의 목표 분량을 달성했는가?
- [ ] 예고했던 내용이 모두 포함되었는가?
```

## 실전 작업 가이드

### 한 번에 하나씩

책 전체를 한 번에 만들려 하지 마세요. 다음 순서로 진행합니다:

```
Week 1: 소스 자료 정리 + 콘텐츠 인벤토리
Week 2: 주제 분류 + 갭 분석
Week 3: 목차 구성 + 콘텐츠 매핑
Week 4-8: 장별 초안 작성 (주 5장 페이스)
Week 9-10: 전체 검토 및 수정
```

### 작업 템플릿 활용

각 단계마다 템플릿을 만들어두면 반복 작업이 쉬워집니다.

### AI 프롬프트 활용

각 단계에서 Claude Code를 활용할 수 있습니다:

**STEP 2 (분석)**: "이 강의 대본을 읽고 핵심 주제 5가지를 추출해줘"
**STEP 3 (구조)**: "01-title-outline.md 프롬프트로 목차 구성해줘"
**STEP 5 (초안)**: "이 작업 파일을 바탕으로 1장 초안 작성해줘"

## 자주 묻는 질문

**Q1. 강의 대본이 너무 구어체인데 어떻게 바꾸나요?**
A: 문어체 전환 체크리스트를 사용하세요. AI에게 "~했어요 → ~했다 형식으로 전환" 요청도 가능합니다.

**Q2. 브런치 글과 강의 내용이 겹치는데요?**
A: 더 완성도 높은 쪽을 선택하고, 나머지는 보완 자료로만 활용하세요.

**Q3. 소스 자료만으로는 분량이 부족해요.**
A: 갭 분석에서 찾은 "신규 작성 필요" 부분을 채우면 됩니다. 보통 전체의 20-30%는 새로 써야 합니다.

**Q4. 강의 순서대로 책을 구성하면 안 되나요?**
A: 강의와 책은 다릅니다. 강의는 시간 순서, 책은 독자의 학습 곡선을 따라야 합니다. 재배치하세요.
