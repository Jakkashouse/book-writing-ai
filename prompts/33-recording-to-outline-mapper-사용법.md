# 녹음본 → 목차 자동 배열 AI 사용법 (초보자용)

## 🎯 이 도구가 하는 일

여러분이 **강의, 인터뷰, 강연을 녹음**하고 **문자로 변환**한 텍스트(6-8시간 분량)를 가지고 있을 때,

이 AI가 **책의 목차에 맞춰서 자동으로 내용을 분류하고 정리**해줍니다.

### 예를 들면

**Before (녹음본 그대로):**
```
"제가 처음 아이를 낳았을 때... 그리고 직장 복귀는...
아, 맞다 시간 관리 얘기하려고 했는데...
다시 육아 얘기로 돌아가면..."
```
→ 내용이 뒤죽박죽, 어디서부터 책을 써야 할지 막막함

**After (AI가 정리한 후):**
```
1장. 육아의 시작
  → "제가 처음 아이를 낳았을 때..." (녹음본 배치됨)

2장. 직장맘의 하루
  → "직장 복귀는..." (녹음본 배치됨)

3장. 시간 관리
  → "시간 관리 얘기하려고 했는데..." (녹음본 배치됨)
```
→ 목차에 맞춰 깔끔하게 정리됨

---

## 📋 준비물 (3가지만 있으면 됩니다)

### 1️⃣ 책 제목
```
예: "워킹맘의 하루, 나를 찾는 30분"
```

### 2️⃣ 목차 (간단하게 작성)
```
1장. 워킹맘이 된 날
  1-1. 복직 결정
  1-2. 첫 출근

2장. 시간과의 전쟁
  2-1. 아침 루틴
  2-2. 퇴근 후 3시간

3장. 나를 위한 30분
  3-1. 30분의 발견
  3-2. 30분 활용법
```

### 3️⃣ 녹음본 텍스트
- 강의 녹음을 **문자로 변환한 파일** (6-8시간 분량)
- 보통 `.txt` 또는 `.docx` 파일
- 녹음 → 텍스트 변환은 다음 도구 사용:
  - **네이버 클로바노트** (무료, 한국어 최고)
  - **Otter.ai** (영어)
  - **유튜브 자동 자막** (유튜브에 업로드 후 자막 다운)

## 🚀 사용 방법 (3단계)

### STEP 1: AI에게 프롬프트 복사 붙여넣기

1. **ChatGPT** 또는 **Claude**를 엽니다
   - ChatGPT: https://chat.openai.com
   - Claude: https://claude.ai

2. **새 대화**를 시작합니다

3. `33-recording-to-outline-mapper.md` 파일을 엽니다

4. **전체 내용을 복사**해서 AI 채팅창에 붙여넣습니다

5. **엔터**를 누릅니다

6. AI가 "알겠습니다" 라고 답하면 준비 완료!

---

### STEP 2: 책 정보와 녹음본 제공

이제 AI에게 다음과 같이 입력합니다:

```
**책 제목:**
워킹맘의 하루, 나를 찾는 30분

**목차:**
1장. 워킹맘이 된 날
  1-1. 복직 결정
  1-2. 첫 출근

2장. 시간과의 전쟁
  2-1. 아침 루틴
  2-2. 퇴근 후 3시간

3장. 나를 위한 30분
  3-1. 30분의 발견
  3-2. 30분 활용법

**녹음본 텍스트:**
[여기에 녹음본 전체를 붙여넣기]

저는 아이가 12개월 됐을 때 복직했어요.
정말 고민이 많았죠. 아이를 맡기고 가는 게...
그런데 첫 출근 날, 회사 문을 열고 들어가는데
묘하게 설레더라고요...

[녹음본 계속...]
```

### ⚠️ 주의사항

**녹음본이 너무 길 경우:**

ChatGPT/Claude는 한 번에 입력할 수 있는 글자 수 제한이 있습니다.

**해결 방법:**
1. 녹음본을 2-3개로 나눠서 입력
   ```
   "녹음본 1부를 먼저 드릴게요"
   [1-3시간 분량 붙여넣기]

   "녹음본 2부입니다"
   [3-6시간 분량 붙여넣기]
   ```

2. 또는 텍스트 파일로 만들어서 업로드
   - ChatGPT Plus / Claude Pro는 파일 업로드 가능
   - "녹음본.txt" 파일을 드래그 앤 드롭

---

### STEP 3: 결과 받기

AI가 5-10분 정도 분석한 후, 다음과 같은 결과를 줍니다:

```markdown
# 📚 워킹맘의 하루, 나를 찾는 30분 - 배열 결과

## 📊 작업 요약
- 녹음본 총 분량: 약 6.5시간
- 배치 완료율: 92%
- 미배치 섹션: 3개

## 📖 1장. 워킹맘이 된 날

### 1-1. 복직 결정
[녹음본에서 관련 내용 자동 배치]
"저는 아이가 12개월 됐을 때 복직했어요..."

### 1-2. 첫 출근
[녹음본에서 관련 내용 자동 배치]
"첫 출근 날, 회사 문을 열고..."

## 📖 2장. 시간과의 전쟁
...

## ⚠️ 추가 작업 필요
- 3장에 내용이 부족합니다 (67%)
  → 추가 녹음 권장
```

## 🔧 자주 묻는 질문 (FAQ)

### Q1. AI를 한 번도 안 써봤는데 어렵나요?
**A:** 전혀 어렵지 않습니다!
- **복사 + 붙여넣기**만 할 수 있으면 됩니다
- 채팅하듯이 편하게 입력하면 끝

---

### Q2. ChatGPT와 Claude 중 뭘 써야 하나요?
**A:** 둘 다 좋지만 추천은:
- **Claude (추천)**: 긴 글 처리에 강함, 한국어 자연스러움
- **ChatGPT**: 익숙하면 이것도 OK

무료 버전으로 시작해보세요!

---

### Q3. 녹음본이 10시간이 넘으면 어떡하나요?
**A:** 두 가지 방법:
1. **나눠서 입력**: 5시간씩 2번에 걸쳐 처리
   ```
   "1부(0-5시간) 먼저 처리해주세요"
   → 결과 받음

   "2부(5-10시간) 처리해주세요"
   → 결과 받음
   ```

2. **유료 버전 사용** (ChatGPT Plus $20/월, Claude Pro $20/월)
   → 한 번에 처리 가능

---

**A:** 추천 도구:

**3) Otter.ai (영어)**

### Q5. 목차를 어떻게 만들어야 하나요?
**A:** 간단하게!

**나쁜 예 (너무 복잡):**
```
제1장. 육아의 시작과 엄마로서의 정체성 확립 과정
  제1절. 복직 결정의 심리적 배경과 사회경제적 요인
```

**좋은 예 (간단명료):**
```
1장. 엄마가 된 날
  1-1. 복직을 결심하다
```

**팁:**
- 장 제목: 3-7글자
- 소제목: 5-10글자
- 전체 3-5장이면 충분

---

### Q6. 녹음본이 횡설수설인데 괜찮나요?
**A:** 완전히 괜찮습니다!

실제 녹음본 예시:
```
"아, 그게 뭐였더라... 음... 맞다!
제가 말하고 싶은 건... 아 잠깐,
그 전에 이것도 말해야 하고..."
```

→ AI가 알아서 의미 있는 부분만 추출합니다
→ "음...", "아..." 같은 건 자동으로 제외
