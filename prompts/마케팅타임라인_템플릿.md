## 💡 엑셀 수식 활용 팁

### 1. 날짜 자동 계산
```excel
// A1 셀에 출간일 입력
출간일: 2024-03-15

// D-90일 자동 계산
=A1-90

// D+30일 자동 계산
=A1+30
```

### 2. 진행률 계산
```excel
// 완료된 항목 수 / 전체 항목 수
=COUNTIF(F:F,"✓")/COUNTA(F:F)

// 백분율로 표시
=TEXT(진행률,"0%")
```

### 3. 조건부 서식
```excel
// D-Day가 오늘이면 빨간색
=A2=TODAY()

// 완료 체크 시 회색
=F2="✓"

// 마감일 7일 전이면 노란색
=A2-TODAY()<=7
```

### 4. 알림 설정
```excel
// D-30, D-7, D-Day에 이메일 알림
구글 스프레드시트 → 도구 → 알림 규칙
```
