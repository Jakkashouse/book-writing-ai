# 기획출판 릴스 스크립트

## 투고자 실제 대화 기반 콘텐츠

---

## 버전 1: 대화 재현형 (30초)

텍스트 애니메이션으로만 제작 가능 (Canva/CapCut)

```
[0-3초]
화면: 검은 배경 + 흰 텍스트
자막: "어제 있었던 일"
음악: 잔잔한 피아노 시작

[3-7초]
화면: 카톡 말풍선 애니메이션
자막: "계약 한다고 하셨는데..."
      "제가 얼마 내면 되나요?"
효과음: 카톡 알림음

[7-10초]
화면: 출판사 답장 말풍선
자막: "돈을 왜 내세요?"
효과음: 카톡 알림음

[10-14초]
화면: 투고자 말풍선
자막: "다른 출판사는 그렇게 하던데요..."

[14-18초]
화면: 출판사 답장 말풍선
자막: "저희는 기획출판이라"
      "오히려 돈 받으셔야죠"
음악: 밝아지는 전환

[18-23초]
화면: 흰 배경 + 큰 텍스트
자막: "기획출판은"
      "작가가 돈을 내는 게 아니라"
      "돈을 받는 겁니다"

[23-27초]
화면: 체크리스트 등장
자막: ✓ 출판 비용 0원
      ✓ 정식 인세 지급
      ✓ 편집·디자인·마케팅 지원

[27-30초]
화면: CTA
자막: "원고 있으시면 보내주세요"
      📩 프로필 링크
음악: 마무리
```

## 버전 2: 나레이션형 (30초)

직접 얼굴 나오며 말하는 버전

```
[0-3초]
화면: 얼굴 클로즈업 or 책상 위 원고
나레이션: "어제 투고하신 분이 저한테 이렇게 물어보셨어요"

[3-7초]
화면: 텍스트 오버레이
나레이션: "계약 한다고 하셨는데, 제가 얼마 내면 되나요?"
자막: (동일)

[7-12초]
화면: 놀란 표정 or 손사래
나레이션: "돈을 왜 내세요? 다른 데서 그러셨어요?"
         "저희는 기획출판이라 작가님이 오히려 돈 받으셔야죠"

[12-18초]
화면: 진지한 표정
나레이션: "자비출판이랑 기획출판은 완전히 달라요"
         "기획출판은 출판사가 투자하는 거예요"

[18-25초]
화면: 텍스트 강조
나레이션: "출판 비용 저희가 내고"
         "인세는 작가님이 받고"
         "편집 디자인 마케팅 다 저희가 해요"
자막: ✓ 비용 0원 ✓ 인세 지급 ✓ 전폭 지원

[25-30초]
화면: 카메라 보며
나레이션: "원고 있으시면 보내주세요. 프로필에 링크 있어요"
자막: 📩 원고 투고 문의
```

```
      📩 원고 투고는 프로필 링크
```

## 촬영 & 편집 팁

### 버전 1 (텍스트만)
- Canva 또는 CapCut으로 제작
- 말풍선 템플릿 활용
- 텍스트 애니메이션: 타이핑 효과 or 페이드인

### 버전 2 (나레이션)
- 스마트폰 셀카 모드
- 자연광 (창가 추천)
- 심플한 배경 (흰 벽, 책장)
- CapCut 자막 자동 생성 → 폰트만 수정

### 공통
- 세로 비율: 9:16 (1080 x 1920px)
- 첫 1초가 중요 (훅 강조)
- 자막 크기 크게 (모바일 가독성)
- 영상 끝에 "팔로우" 유도 문구
