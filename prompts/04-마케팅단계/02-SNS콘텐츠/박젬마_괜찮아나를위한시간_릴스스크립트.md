# 『괜찮아, 나를 위한 시간』 릴스/숏폼 스크립트

## 원고 내용

- **도서명:** 괜찮아, 나를 위한 시간
- **부제:** 유쾌하고 슬기로운 갱년기 사용법
- **저자:** 박젬마
- **출판사:** 작가의 집
- **출간일:** 2025년 1월 14일
- **키메시지:** 갱년기를 맞으면서 겪었던 증상과 그것을 받아들이는 과정에서의 고군분투기
- **성과:** 출간 직후 교보문고 시·에세이 부문 100위권 진입

## Vrew 사용법

### 1단계: 프로젝트 생성
- vrew.ai 접속 → 로그인
- "새로 만들기" → "텍스트로 비디오 만들기" 선택

### 2단계: 스크립트 입력
아래 텍스트를 복사해서 붙여넣기:

```
어느 날, 내 몸이 낯설어졌습니다

갑자기 찾아온 열감, 식은땀, 불면...

아무에게도 말 못 하고 혼자 버텼어요

그런데 알게 됐어요

이 시간도 나를 알아가는 과정이라는 걸

괜찮아, 나를 위한 시간

박젬마 지음

지금 서점에서 만나보세요
```

### 3단계: 설정
- 영상 비율: 9:16 (릴스/숏폼용)
- 길이: 30초
- 스타일: 따뜻함/위로

### 4단계: 이미지 교체
- 생성된 영상에서 배경 이미지를 표지로 교체
- 표지 파일 위치: `박젬마 괜찮아나를위한시간 앞표지.jpg`

### 5단계: BGM 추가
- Vrew 내장 음악 또는 저작권 무료 음원 선택
- 추천: "Soft Piano", "Hopeful", "Warm Acoustic"

### 6단계: 내보내기
- 형식: MP4
- 해상도: 1080x1920 (세로)
- 인스타그램 릴스에 업로드
