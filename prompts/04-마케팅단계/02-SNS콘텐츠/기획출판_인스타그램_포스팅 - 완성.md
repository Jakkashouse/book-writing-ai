### 릴스 캡션

```
"제가 얼마 내면 되나요?"

어제 투고하신 분의 질문이었어요.

다른 출판사에서 돈을 내셨다고 해서
당연히 그런 줄 아셨더라고요.

기획출판 = 작가가 돈 받는 거
자비출판 = 작가가 돈 내는 거

저희는 기획출판만 합니다.

원고 있으시면 보내주세요 📩

#기획출판 #원고투고 #출판사 #작가되기
#자비출판 #책출간 #신인작가 #릴스
```

### 추천 음악

- 잔잔한 분위기: "Aesthetic" / "Soft Piano"
- 반전 느낌: "Oh No" (전반부) → 밝은 음악 (후반부)
- 트렌디: "original sound" 트렌드 음원

### 촬영 팁

- **버전 1**: Canva/CapCut으로 텍스트 애니메이션만으로 제작 가능
- **버전 2**: 스마트폰 셀카 모드, 자연광, 심플한 배경
- **편집**: CapCut에서 자막 자동 생성 → 폰트만 수정
