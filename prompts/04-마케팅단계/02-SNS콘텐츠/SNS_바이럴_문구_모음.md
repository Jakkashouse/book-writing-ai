## 🔥 바이럴 성공 법칙

### 1. 첫 문장이 승부
```
❌ "이번에 신간이 나왔습니다"
✅ "서울 5억 아파트를 1.25억에?"
```

### 2. 숫자 활용
```
❌ "많은 분들이 사랑해주셨습니다"
✅ "전작 만 권 판매"
```

### 3. 감정 자극
```
❌ "주일학교 교사를 위한 책"
✅ "교사 그만두려던 제가 다시 섬기게 된 이유"
```

### 4. 긴급성

## 📊 채널별 최적 문구 길이

### 인스타그램
- 피드: 150-300자 (더 길어도 OK, 하지만 핵심은 앞에)
- 릴스: 100자 이내
- 스토리: 20-30자 (이미지로 보완)

### 트위터/X
- 280자 제한
- 핵심만 간결하게

### 페이스북
- 100-250자가 가장 높은 참여율

### 카카오톡
- 100자 이내 (너무 길면 읽지 않음)
