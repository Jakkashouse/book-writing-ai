## NotebookLM 팟캐스트 생성용 프롬프트

### 프롬프트 1: 기본 소개 팟캐스트 (10-15분용)

```
이 책 『여성의 시선으로 읽는 룻기』에 대한 팟캐스트를 만들어주세요.

다음 내용을 중심으로 두 명의 진행자가 대화하는 형식으로 구성해주세요:

1. 책의 핵심 질문: "나오미는 정말 괜찮았을까?", "룻은 두렵지 않았을까?"

2. 기존 룻기 해석의 한계:
   - 율법(기업 무를 자) 해설 중심
   - 예수 그리스도의 예표로만 해석
   - 다윗의 족보로서의 의미만 강조
   - 여성들의 감정과 목소리는 무시됨

3. 이 책의 새로운 시선:
   - 상실 → 생존 → 연대 → 회복의 흐름
   - 여성들의 감정선을 따라가는 해석
   - 약자에서 주체로의 변화
   - 연대의 신앙적 의미

4. 독자에게 주는 메시지:
   - 상실 앞에 선 분들에게 위로
   - 새로운 시작 앞에 선 분들에게 용기
   - 성경을 새롭게 읽고 싶은 분들에게 통찰

톤은 따뜻하고 진지하되 무겁지 않게,
일반 독자도 쉽게 이해할 수 있는 언어로 대화해주세요.
```

### 프롬프트 2: 심층 토론 팟캐스트 (20-30분용)

```
『여성의 시선으로 읽는 룻기』에 대한 깊이 있는 팟캐스트를 만들어주세요.

두 진행자가 다음 주제들을 토론하는 형식으로 구성해주세요:

[파트 1: 문제 제기]
- 왜 룻기를 "여성의 시선"으로 읽어야 하는가?
- 기존 해석에서 놓친 것은 무엇인가?
- 서양 신학에서는 이미 활발한 연구가 있는데, 왜 한국에서는 드물었는가?

[파트 2: 인물 분석]
- 나오미: "마라(쓴맛)"라 불린 여인의 분노와 절망
  - "전능자가 나를 심히 괴롭게 하셨다"는 고백의 의미
  - 하나님께 분노하는 것이 허용되는가?

- 룻: 이방인 여성의 결단
  - 고향, 가족, 신을 버리고 시어머니를 따른 이유
  - "기다리지 않고 스스로 움직인" 주체적 신앙

[파트 3: 핵심 메시지]
- 연대는 가장 강력한 신앙 실천이다
- 약자도 주체가 될 수 있다
- 감정도 신앙의 언어다
- 남성 독자와 리더들에게 주는 도전

[파트 4: 현대적 적용]
- 오늘날 상실을 경험하는 이들에게
- 교회 공동체에서 약자의 목소리를 듣는다는 것
- 소그룹 교재로 활용하는 방법

대화는 학술적이지 않고 일상적인 언어로,
하지만 깊이 있는 통찰을 담아주세요.
한 진행자가 질문하고 다른 진행자가 답하는 형식도 좋습니다.
```

### 프롬프트 3: 저자 인터뷰 스타일 (15-20분용)

```
『여성의 시선으로 읽는 룻기』 저자 추성은 목사를 인터뷰하는 형식의 팟캐스트를 만들어주세요.

인터뷰어와 저자(또는 저자를 대변하는 진행자)가 대화하는 형식으로 구성해주세요.

[질문 리스트]

Q1. 왜 룻기를 "여성의 시선"으로 읽게 되셨나요?
- 학부 시절 『제인 에어』와의 만남
- 12년간 청장년 사역에서 받은 질문들
- 서양 신학의 여성주의적 성경 해석 연구

Q2. 이 책은 페미니즘 책인가요?
- "여성주의"라는 틀에 머무르지 않음
- 본문 자체가 보여주는 여성상을 따라감
- 전통적 신학의 틀을 존중하면서 놓친 목소리 회복

Q3. 나오미의 분노를 어떻게 해석하셨나요?
- "전능자가 나를 심히 괴롭게 하셨다"
- 감정도 신앙의 언어라는 관점
- 욥과 시편 기자들의 선례

Q4. 룻의 결단이 오늘날 우리에게 주는 도전은?
- 약자이지만 기다리지 않고 움직임
- 연대의 결단
- 두려움 너머의 신앙

Q5. 남성 독자들에게는 어떤 메시지를 전하고 싶으신가요?
- 여성의 시선으로 읽는 것이 남성에게도 필요한 이유
- 보아스의 역할과 남성 리더십
- 약자 앞에서의 책임감

Q6. 이 책을 어떻게 활용하면 좋을까요?
- 개인 묵상
- 소그룹 교재 (한눈에 정리 & 생각해보기 활용)
- 설교 자료

대화는 자연스럽고 따뜻하게,
저자의 진정성이 느껴지도록 구성해주세요.
```

### 프롬프트 4: 핵심 메시지 요약 (5-10분용)

```
『여성의 시선으로 읽는 룻기』의 핵심 메시지를 소개하는 짧은 팟캐스트를 만들어주세요.

두 진행자가 가볍게 대화하면서 다음 5가지 핵심 메시지를 전달해주세요:

1. 상실은 끝이 아니다
   - 나오미는 모든 것을 잃었지만 거기서 멈추지 않았다

2. 연대는 가장 강력한 신앙 실천이다
   - 혼자였다면 살아남지 못했을 여성들이 서로를 붙잡았다

3. 약자도 주체가 될 수 있다
   - 과부, 이방인, 가난한 자였던 룻이 역사의 주인공이 되었다

4. 감정도 신앙의 언어다
   - 나오미의 분노와 절망도 하나님과의 관계 안에서 터져 나온 것

5. 다양한 목소리에 귀 기울이는 것이 믿음의 본질이다
   - 여성의 시선으로 읽는 것은 모든 공동체에 의미 있는 도전

톤은 밝고 에너지 있게,
책에 관심을 갖게 만드는 티저 형식으로 구성해주세요.
"이 책 읽어봐야겠다"는 생각이 들도록요.
```

### 프롬프트 5: 인물 중심 에피소드 (나오미 편, 10분용)

```
『여성의 시선으로 읽는 룻기』에서 나오미에 대한 내용을 중심으로 팟캐스트를 만들어주세요.

제목: "나오미, 쓴맛의 여인"

두 진행자가 나오미라는 인물에 대해 깊이 대화해주세요:

1. 나오미가 잃은 것들
   - 남편 엘리멜렉
   - 첫째 아들 말론, 둘째 아들 기룐
   - 고향, 미래, 희망
   - 남은 것은 이방인 며느리 둘뿐

2. 나오미의 감정
   - "나를 마라(쓴맛)라 부르라"
   - "전능자가 나를 심히 괴롭게 하셨다"
   - 하나님께 분노하는 것의 의미
   - 성경이 이 감정을 숨기지 않은 이유

3. 나오미의 회복
   - 며느리 룻과의 연대
   - 베들레헴으로의 귀환
   - 오벳을 품은 순간
   - "마라"에서 다시 "나오미"로

4. 오늘 우리에게 주는 메시지
   - 상실 앞에서 솔직해도 된다
   - 하나님께 분노해도 관계는 끊어지지 않는다
   - 회복은 혼자가 아닌 연대 속에서 일어난다

감정적으로 공감할 수 있도록,
나오미의 이야기를 생생하게 전달해주세요.
```

### 프롬프트 6: 인물 중심 에피소드 (룻 편, 10분용)

```
『여성의 시선으로 읽는 룻기』에서 룻에 대한 내용을 중심으로 팟캐스트를 만들어주세요.

제목: "룻, 이방인의 결단"

두 진행자가 룻이라는 인물에 대해 깊이 대화해주세요:

1. 룻의 정체성
   - 모압 여인 (이방인)
   - 남편을 잃은 젊은 과부
   - 사회의 가장 낮은 자리에 있던 사람

2. 룻의 결단
   - "어머니의 백성이 나의 백성이 되고, 어머니의 하나님이 나의 하나님이 되리라"
   - 고향을 버리고, 가족을 버리고, 신까지 바꾼 결단
   - 왜 시어머니를 따랐을까?
   - 연대의 결단, 두려움 너머의 신앙

3. 룻의 주체성
   - "내가 가서 이삭을 줍겠습니다" - 기다리지 않고 움직임
   - 타작마당에서 보아스에게 다가간 용기
   - 약자이지만 수동적이지 않았던 여성
   - 약자에서 주체로의 변화

4. 오늘 우리에게 주는 메시지
   - 낯선 곳에서 새로운 시작을 하는 이들에게
   - 두려움 속에서도 결단해야 할 때
   - 연약함이 이끄는 용기

룻의 용기와 결단이 느껴지도록,
도전적이고 영감을 주는 톤으로 구성해주세요.
```

## NotebookLM 사용 가이드

### 1단계: 소스 자료 업로드
- 이 프롬프트 파일을 NotebookLM에 업로드
- 책의 목차, 서문, 핵심 챕터가 있다면 함께 업로드
- 저자 소개 및 출간계획서 업로드

### 2단계: Audio Overview 생성
1. NotebookLM에서 "Audio Overview" 클릭
2. "Customize" 버튼 클릭
3. 위 프롬프트 중 원하는 것을 붙여넣기
4. "Generate" 클릭

### 3단계: 팟캐스트 활용
- 유튜브 업로드 (배경 이미지와 함께)
- 팟캐스트 플랫폼 배포 (애플 팟캐스트, 스포티파이 등)
- SNS 클립 제작 (1분 하이라이트)
