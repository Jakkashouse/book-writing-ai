## 작성 가이드라인

**블로그 글:**
- 문장은 짧고 읽기 쉽게 (한 문장 40자 이내)
- 줄바꿈 자주 사용
- 핵심 키워드 자연스럽게 3-5회 반복
- 독자에게 말 걸듯 친근한 톤

**이미지 프롬프트:**
- 사진이 아닌 일러스트/그래픽 스타일 권장 (저작권 안전)
- 한국인/아시아인 등장 시 명시
- 밝고 따뜻한 색감 위주
- 텍스트 없는 깔끔한 이미지
- 정사각형(1:1) 또는 가로형(16:9) 비율 명시

## 추가 팁

### Midjourney 사용 시
- 프롬프트 끝에 `--ar 1:1` (정사각형) 또는 `--ar 16:9` (가로형) 추가
- `--style raw` 추가하면 더 자연스러운 결과

### DALL-E 사용 시
- 프롬프트 그대로 사용
- "illustration style" 대신 "digital illustration" 또는 "watercolor style"로 변경 가능

### Canva 사용 시
- AI 이미지 생성 기능에 한글 설명 그대로 입력
- 또는 위 영문 프롬프트 번역해서 사용
