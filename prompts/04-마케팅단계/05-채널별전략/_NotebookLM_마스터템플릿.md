# NotebookLM 책 분해 마스터 템플릿 (작가의집 표준 v1.0)

> **사용법**: 아래 `[[ ]]` 슬롯만 책 정보로 교체 → notebooklm.google.com 에 책 원고/목차/저자소개 업로드 → Audio Overview 메뉴에서 "Customize" 클릭 → 시나리오별 프롬프트 붙여넣기 → mp3 다운로드.

[[핵심_질문_3]]: 
[[기존_관점의_한계_1]]: 
[[기존_관점의_한계_2]]: 
[[기존_관점의_한계_3]]: 
[[책의_새로운_시선_1]]: 
[[책의_새로운_시선_2]]: 
[[책의_새로운_시선_3]]:

## 🎙️ 시나리오 1 · 기본 소개 팟캐스트 (10-15분)

**용도**: 인스타 릴스 음성 / 스포티파이 첫 에피소드 / 첫 만남 독자

```
이 책 『[[책_제목]] — [[부제]]』에 대한 입문 팟캐스트를 만들어주세요.

두 명의 진행자(친근한 호스트 A + 책에 푹 빠진 게스트 B)가
편안하게 대화하는 형식으로 구성해주세요.

[다룰 내용]
1. 책의 핵심 질문 3가지:
   - [[핵심_질문_1]]
   - [[핵심_질문_2]]
   - [[핵심_질문_3]]

2. 기존 관점의 한계:
   - [[기존_관점의_한계_1]]
   - [[기존_관점의_한계_2]]

3. 이 책의 새로운 시선:
   - [[책의_새로운_시선_1]]
   - [[책의_새로운_시선_2]]
   - [[책의_새로운_시선_3]]

4. 어떤 독자에게 이 책이 가닿는지:
   - [[독자_페르소나_A]]
   - [[독자_페르소나_B]]

[톤]
- 따뜻하고 진지하되 무겁지 않게
- 일반 독자가 "어? 이거 내 얘기네" 하고 멈출 만한 한 문장씩 자연스럽게 배치
- "그 부분 정말 좋았어요"처럼 진짜 대화체
- 학술 용어 최소화

[금지]
- 책을 안 읽은 사람은 알 수 없는 인용
- 정답을 강요하는 결론
- 저자 미화
```

## 🎙️ 시나리오 2 · 심층 토론 팟캐스트 (20-30분)

**용도**: 유튜브 음성 / 블로그 임베드 / 충성 독자용

```
『[[책_제목]]』에 대한 깊이 있는 토론 팟캐스트를 만들어주세요.

두 진행자 모두 책을 정독한 상태로 가정하고,
서로 동의하는 부분과 의문 가는 부분을 교차로 나누는 형식으로 구성해주세요.

[파트 1 · 문제 제기 (5분)]
- 왜 지금 [[책_제목]] 같은 이야기가 필요한가?
- 우리가 평소 [[분야]]에서 놓쳐온 것은 무엇인가?
- 이 책이 '뻔한 [[분야]] 책'과 다른 한 가지

[파트 2 · 핵심 챕터 3개 분석 (10분)]
- [[챕터_핵심_3개]] 각각에서 가장 인상 깊은 한 장면씩
- 그 장면이 왜 독자의 마음을 움직이는지 분석
- 한 진행자는 "이 부분이 와닿았다", 다른 진행자는 "그런데 이런 의문도 있다"

[파트 3 · 책 너머의 메시지 (8분)]
- [[저자가_절대_놓치고_싶지_않은_메시지]]
- 책이 던지지만 답하지 않는 질문들
- 독자가 책을 덮고 무엇을 해보면 좋을지

[파트 4 · 누가 이 책을 읽으면 좋은가 (3분)]
- [[독자_페르소나_A]] / [[독자_페르소나_B]] / [[독자_페르소나_C]]
- 추천 vs 비추천 케이스 솔직하게

[톤]
- 일상 대화 + 깊이 있는 통찰
- 한 사람이 일방적으로 강의하지 않음
- "그 의견에는 살짝 다른 생각도 있어요"가 자연스러움
```

## 🎙️ 시나리오 3 · 저자 인터뷰 스타일 (15-20분)

**용도**: 출간 직후 홍보 / 저자 채널 업로드 / 강연 사전자료

```
『[[책_제목]]』 저자 [[저자]]를 인터뷰하는 형식의 팟캐스트를 만들어주세요.

인터뷰어 1명 + 저자(또는 저자를 대변하는 진행자)가
질문-답변 형식으로 대화하되, 답변이 단답이 아니라 이야기로 풀리도록 해주세요.

[질문 리스트]

Q1. 이 책은 어떻게 시작됐나요?
- [[책_뒤에_숨은_저자_이야기]]
- 처음 글을 쓰기 시작한 순간

Q2. 책에서 가장 쓰기 어려웠던 챕터는 무엇이었나요?
- 왜 어려웠는지
- 그 챕터를 끝낸 후 무엇이 달라졌는지

Q3. [[핵심_질문_1]]에 대한 저자의 답은 무엇인가요?

Q4. 이 책을 통해 독자가 가져갔으면 하는 한 가지는 무엇인가요?
- [[저자가_절대_놓치고_싶지_않은_메시지]]

Q5. [[저자]]님이 다음에 쓰고 싶은 책은 무엇인가요?
(작가의집 시리즈 확장 가능성 — 대답은 자연스럽게 열어두기)

[톤]
- 인터뷰어는 질문 후 충분히 듣는 사람
- 저자(역할)는 자기 자랑 X, 진솔한 회고체
- 침묵·여백·"그건 잘 모르겠어요"도 허용
```

## 🎙️ 시나리오 4 · 두 비평가 대담 (20분)

**용도**: 지적 독자층 / 북클럽 사전자료 / 서평 블로거 공유

```
『[[책_제목]]』을 두 명의 진지한 독자(서평가/연구자 톤)가 대담하는 형식으로 만들어주세요.

[설정]
- A: 책에 매우 호의적, 강점을 짚어내는 사람
- B: 비판적 거리를 두고 의문을 제기하는 사람
- 둘 다 책을 정독했고 서로 존중함

[다룰 주제]
1. 이 책이 [[분야]]에서 차지하는 위치
2. 강점:
   - [[책의_새로운_시선_1]]
   - [[책의_새로운_시선_2]]
3. 의문이 가는 지점:
   - 책이 답하지 않은 질문은 무엇인가
   - 독자가 동의하기 어려울 수 있는 주장은 무엇인가
4. 저자의 다음 책에서 보고 싶은 것

[톤]
- 학술적이지 않으나 사고의 깊이 있음
- 서로의 의견을 깎아내리지 않음
- 결론을 강요하지 않고 독자에게 판단 위임
```

## 🎙️ 시나리오 5 · 독자 Q&A (10분)

**용도**: 출간 1주 후 / 댓글·문의 응답 / 인스타 스토리 음성

```
『[[책_제목]]』을 읽은 가상의 독자들이 보내온 질문에 진행자 두 명이 답하는 형식으로 만들어주세요.

[가상 질문 5개]

Q1. "이 책의 [[챕터_핵심_3개]] 첫 번째 챕터에서 [[핵심_질문_1]]이 나오는데, 저는 동의가 안 됐어요. 어떻게 받아들여야 할까요?"
→ 두 진행자가 다른 각도로 답변

Q2. "[[독자_페르소나_A]]에 해당하는데, 책 어디부터 읽으면 좋을까요?"
→ 추천 챕터 + 이유

Q3. "저자가 책 끝에서 [[저자가_절대_놓치고_싶지_않은_메시지]]를 강조하는데, 이걸 일상에서 어떻게 적용하나요?"
→ 구체적 실천 3가지 제안

Q4. "이 책 다 읽고 다음에 뭘 읽으면 좋을까요?"
→ 비슷한 결의 책 2-3권 추천 (저자 다른 작품 포함)

Q5. "저자에게 직접 한마디 묻고 싶다면 뭘 묻겠어요?"
→ 두 진행자가 각자의 질문과 그 이유

[톤]
- 진행자가 독자 편에 서서 답함
- "맞아요, 그 부분 저도 멈췄어요" 같은 공감 포함
- 정답이 아니라 함께 생각하는 톤
```

## 🎙️ 시나리오 6 · 핵심 5분 요약 (릴스 원천)

**용도**: 인스타 릴스 음성 더빙 / 유튜브 쇼츠 / 30초~1분 컷 원천

```
『[[책_제목]]』의 핵심을 정확히 5분 안에 두 진행자가 빠르게 풀어주는 팟캐스트를 만들어주세요.

[구조]
- 0:00-0:30 | 후크 한 문장: "[[핵심_질문_1]]에 대해 들어본 적 있나요?"
- 0:30-1:30 | 책의 핵심 주장 1줄로
- 1:30-3:00 | 그 주장을 뒷받침하는 가장 강력한 챕터 1개 ([[챕터_핵심_3개]] 중 하나)
- 3:00-4:00 | 독자가 가져갈 수 있는 한 가지 행동
- 4:00-5:00 | 마지막 한 문장 + 책 추천

[톤]
- 빠르되 가볍지 않게
- 한 문장이 1초 안에 끝나는 짧은 호흡
- 마지막 한 문장은 인스타 캡션으로 그대로 따올 만큼 강력하게

[중요]
- 5분 절대 초과 금지
- 챕터 한 개에 집중, 책 전체 요약 X
- "이 책이 답을 줄 수도 있다" 정도의 권유 (확언 X)
```

## 🛠️ NotebookLM 사용 가이드 (직원용)

### 1단계 · 자료 업로드
1. notebooklm.google.com 접속 → "+ New notebook"
2. 다음 파일을 소스로 업로드 (최대 50개):
   - 책 원고 PDF 또는 docx
   - 목차 / 서문 / 가장 강력한 챕터 3개
   - 저자 소개서
   - 출간계획서
   - 위에서 작성한 슬롯 정보 (위 ▶ "📌 슬롯 정보" 부분만 따로 .txt로 저장해서 업로드)

### 2단계 · Audio Overview 생성
1. 우측 패널 "Audio Overview" → "Generate"가 아니라 **"Customize"** 먼저 클릭
2. 위 시나리오 1~6 중 하나의 프롬프트 전체 복사 → 붙여넣기
3. "Generate" 클릭 → 5~10분 대기
4. 생성 완료 후 ⋮ 메뉴 → "Download" → mp3 저장

### 3단계 · 검수 + 업로드
- mp3 듣고 사실 오류·발음 오류 체크
- 좋으면 → 직원에게 전달:
  - **인스타 릴스 음성**: 시나리오 6의 mp3 + 책 표지 정지 영상
  - **스포티파이/유튜브 음성**: 시나리오 1, 2, 3
  - **블로그 임베드**: 시나리오 2, 5
  - **북클럽 사전자료**: 시나리오 4

### 4단계 · 마인드맵 (보너스)
1. NotebookLM 좌측 "Mind Map" 클릭
2. 책 전체 구조가 자동 생성됨
3. 우클릭 → 이미지 저장 → 인스타 캐러셀 1장으로 활용
