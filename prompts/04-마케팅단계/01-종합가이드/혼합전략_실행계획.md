## 💡 혼합 전략 성공 팁

### 1. 시너지 극대화

```
씨스타일 리뷰 → 직접 섭외 인플루언서에게 공유
"이런 리뷰들이 올라오고 있어요! 선생님도 자유롭게~"

→ 동기 부여 + 레퍼런스 제공
```

### 2. 교차 활용

```
직접 섭외에서 반응 좋은 계정
→ 다음 캠페인 때 씨스타일에서 유료로 재협업

씨스타일에서 만난 우수 인플루언서
→ 개인 연락처 받아서 직접 관계 구축
```

### 3. 콘텐츠 재활용

```
인플루언서 리뷰
→ 자사 인스타 리포스트
→ 블로그 콘텐츠로 재가공
→ 온라인 서점 상세페이지 리뷰 섹션에 추가
→ 다음 마케팅 자료로 활용
```

### 4. 데이터 기반 의사결정

```
4주 후 비교:
"씨스타일이 ROI 600%, 직접 섭외가 800%"
→ 다음엔 직접 섭외 비중 높이기

"씨스타일 콘텐츠 퀄리티가 압도적"
→ 주요 신간은 씨스타일, 일반 신간은 직접
```
