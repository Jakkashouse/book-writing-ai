## 1. 사용 설명서

### 이 가이드의 특징
- **20일 집중**: 출간 전 10일 + 출간 후 10일 핵심 액션
- **복사-붙여넣기**: 모든 콘텐츠 템플릿 즉시 사용 가능
- **하루 30분-1시간**: 바쁜 작가도 실행 가능
- **무료 마케팅**: 예산 0원으로 최대 효과

### 활용법
1. 아래 양식에 책 정보 입력
2. 20일 캘린더 순서대로 실행
3. 각 날짜의 템플릿 복사-수정-발행
4. 체크리스트로 진행 상황 관리

### 책 정보 입력 (필수)
```
책 제목: [                    ]
저자명: [                    ]
출간일: [YYYY-MM-DD]
장르: [                    ]
타겟 독자: [                    ]
핵심 메시지 (1문장): [                    ]
구매 링크: [                    ]
작가 인스타그램: @[                    ]
```

