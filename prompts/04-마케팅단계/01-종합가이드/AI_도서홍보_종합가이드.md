## 3. 11일 마케팅 캘린더

### 출간 전 11일 홍보 일정표

| Day | 제목 | 내용 | 채널 | 비고 |
|-----|------|------|------|------|
| 1일차 | 티저 이미지 업로드 | 내지 시안 완성 후, 원고 기반 이미지 생성 + 타이틀 썸네일 형식 | 인스타, 네이버 블로그, 유튜브 게시판 | |
| 2일차 | 카드뉴스 미리보기 (Gamma) | Gamma로 제작한 카드뉴스 중 발췌해서 업로드 | 인스타, 네이버 블로그 | 텍스트 카피 중심, 빠른 초안용 |
| 3일차 | NotebookLM 카드뉴스 | NotebookLM으로 생성한 비주얼 카드뉴스 전체 업로드 (10~13장) | 인스타, 네이버 블로그 | 고퀄리티 비주얼, 원고 PDF 입력 |
| 4일차 | 블로그 챕터 미리보기 | 서평 내용 중 발췌, 본문속으로 등 핵심 챕터 미리보기 | 네이버 블로그 | |
| 5일차 | 블로그 서평 | 서평 형식대로 작성 (레퍼런스 신규 제작) | 네이버 블로그 | 신규 레퍼런스 제작 필요 (본문속으로 핵심챕터 소개란 포함) |
| 6일차 | NotebookLM 팟캐스트 | NotebookLM 오디오 오버뷰로 생성한 AI 팟캐스트 업로드 | 유튜브, 팟캐스트 플랫폼 | 원고 PDF 동일 소스 활용 |
| 7일차 | 쇼츠-1 | 핵심 내용-문제제기 부분 (신규 or 북트레일러 발췌) / 에세이는 갈등 | 인스타 릴스, 유튜브 쇼츠 | |
| 8일차 | 쇼츠-2 | 핵심 내용-해결방안 부분 (신규 or 북트레일러 발췌) / 에세이는 결말 | 인스타 릴스, 유튜브 쇼츠 | |
| 9일차 | 북트레일러 | 기존 보도자료 작업 중 북트레일러 업로드 | 유튜브 | 표지 디자인 및 저자 컨펌 필요 |
| 10일차 | 북트립 뉴스 기사 | 기존 보도자료 작업 중 뉴스기사 | 북트립 사이트 | |
| 11일차 | 책 목업 이미지 | 제목-저자-간단한 내용 소개 + 인터넷 서점 링크 | 인스타, 네이버 블로그, 유튜브 게시판 | 서점 판매 시작일에 따라 변동 |

### 일자별 상세 가이드

**1일차: 티저 이미지**
- 내지 시안이 완성되면 원고 분위기에 맞는 이미지 생성
- 책 제목을 타이틀로 넣어 썸네일 형식으로 제작
- "곧 만나요" 등 기대감을 주는 문구 추가

**2일차: 카드뉴스 미리보기 (Gamma)**
- Gamma로 제작한 텍스트 중심 카드뉴스 중 핵심 2-3장 발췌
- "전체 내용이 궁금하시다면?" CTA 포함
- 빠른 초안 제작, 텍스트 카피라이팅 강점 활용

**3일차: NotebookLM 비주얼 카드뉴스**
- NotebookLM에 원고 PDF 업로드 → 카드뉴스 생성
- 10~13장 구성 (표지 + 핵심 내용 + 인용문 카드 + 프로필)
- Gamma 카드뉴스와 차별화: 고퀄리티 비주얼, 다양한 레이아웃
- 텍스처/무드 배경, 인용문 강조 카드 포함
- 인스타그램 저장률 극대화 목적

**4일차: 블로그 챕터 미리보기**
- 가장 흥미로운 챕터 1개 선정
- "본문 속으로" 코너로 핵심 내용 소개

**5일차: 블로그 서평**
- 서평 레퍼런스 포맷 활용
- 핵심 챕터 소개란 포함

**6일차: NotebookLM AI 팟캐스트**
- NotebookLM 오디오 오버뷰 기능으로 AI 팟캐스트 생성
- 원고 PDF 동일 소스 활용 (3일차 카드뉴스와 같은 소스)
- 유튜브 + 팟캐스트 플랫폼(스포티파이, 애플팟캐스트 등) 동시 배포
- 1개 소스 → 카드뉴스 + 팟캐스트 2개 콘텐츠 확보

**7일차: 쇼츠-1 (문제제기/갈등)**
- 실용서: 독자의 문제 상황 제시
- 에세이: 갈등 장면 하이라이트
- 15-30초 분량

**8일차: 쇼츠-2 (해결/결말)**
- 실용서: 책이 제시하는 해결책
- 에세이: 결말 또는 깨달음
- "자세한 내용은 책에서" CTA

**9일차: 북트레일러**
- 1분 내외 영상
- 유튜브 메인 업로드

**10일차: 뉴스 기사**
- 북트립 등 도서 전문 사이트 게재
- 공식 보도자료 형식

**11일차: 목업 이미지 + 서점 링크**
- 책 목업 이미지로 실물감 연출
- 교보/예스24/알라딘 구매 링크 첨부
- 서점 판매 시작일에 맞춰 조정

### 4-1. [1일차] 티저 이미지 카피

```
역할: 당신은 베스트셀러 광고 카피라이터입니다.

[책 정보]
- 제목: {책 제목}
- 저자: {저자명}
- 타겟 독자: {타겟 독자}
- 핵심 메시지: {한 문장 소개}
- 출간 예정일: {출간일}

작업: 티저 이미지용 카피 3종 작성
- 내지 시안 분위기에 맞는 썸네일 형식
- 기대감을 주는 문구

[유형별 카피]

1. 감성형 (공감 자극)
- 헤드라인: (15자 이내)
- 서브 헤드라인: (25자 이내)
- 비주얼 제안:

2. 도발형 (호기심 유발)
- 헤드라인: (15자 이내)
- 서브 헤드라인: (25자 이내)
- 비주얼 제안:

3. 정보형 (구체적 혜택)
- 헤드라인: (15자 이내)
- 서브 헤드라인: (25자 이내)
- 비주얼 제안:

[출력 형식]
각 유형별로:
- 인스타그램 캡션 (100자)
- 블로그 소개글 (200자)
- 해시태그 10개
```

### 4-2. [2일차] 카드뉴스 미리보기 캡션

```
역할: 당신은 인스타그램 북스타그램 마케터입니다.

책 정보:
- 제목: {책 제목}
- 저자: {저자명}
- 타겟: {타겟 독자}
- 핵심 메시지: {한 문장 소개}

작업: 카드뉴스 미리보기용 SNS 캡션 작성
- 전체 카드뉴스 중 핵심 2-3장 발췌 시 사용
- 전체 내용이 궁금하게 만드는 훅

[인스타그램용]
- 본문: 150-200자 (줄바꿈 활용)
- 첫 문장: 강력한 훅
- 마지막: CTA ("전체 내용이 궁금하다면?")
- 해시태그: 15개

[블로그용]
- 제목: 30자 이내 (SEO 키워드 포함)
- 본문: 300-500자
- 마지막: "곧 공개될 책에서 더 자세히 만나보세요"
```

### 4-3. [3일차] 블로그 챕터 미리보기

```
역할: 당신은 네이버 블로그 SEO 전문가입니다.

책 정보:
- 제목: {책 제목}
- 저자: {저자명}
- 타겟: {타겟 독자}
- 미리보기 챕터: {챕터 제목}
- 챕터 핵심 내용: {200-300자 요약}

작업: "본문 속으로" 코너용 블로그 포스트 작성

[요구사항]
1. 제목: "본문 속으로 | {책 제목} - {챕터 제목}" (30자 이내)
2. 분량: 800-1,200자
3. 챕터 내용 일부 발췌 + 해설

[구조]
- 도입: 이 챕터를 선택한 이유 (50자)
- 발췌: 본문 인용 (따옴표 처리, 200-300자)
- 해설: 이 내용이 독자에게 주는 의미 (200자)
- 마무리: "더 많은 이야기는 책에서" CTA

[SEO 키워드 제안]
메인 키워드: (1개)
서브 키워드: (3개)
```

```
- 교보문고 / 예스24 / 알라딘

[분량] 1,500-2,000자
```

### 4-6. [6일차] 쇼츠-1 스크립트 (문제제기/갈등)

```
역할: 당신은 1000만 조회수 숏폼 전문 크리에이터입니다.

책 정보:
- 제목: {책 제목}
- 장르: {실용서 / 에세이 / 소설}
- 타겟: {타겟 독자}
- 타겟의 Pain Point: {고민 1가지}

작업: 15-30초 쇼츠 스크립트 (문제제기 버전)

[장르별 방향]
- 실용서: 독자의 문제 상황 제시 → "이런 고민 있으시죠?"
- 에세이: 갈등 장면 하이라이트 → 감정 자극
- 소설: 클라이맥스 전 긴장감 → 궁금증 유발

[스크립트 구조]
[0-3초] 훅: 강력한 공감 또는 충격적 질문
[3-20초] 본론: 문제 상황 구체화 (공감 극대화)
[20-30초] CTA: "해결책이 궁금하다면?" + 프로필 링크
```

## 부록: 자주 묻는 질문 (FAQ)

**Q1. AI 무료 버전으로도 충분한가요?**
A. 네, 충분합니다. ChatGPT 무료 + Canva 무료 + CapCut 무료만으로도 모든 홍보물을 만들 수 있습니다. 유료는 효율성을 높여줄 뿐입니다.

**Q2. 하루에 얼마나 시간을 투자해야 하나요?**
A. 출간 전 10일간 하루 30분-1시간이면 충분합니다. 보도자료가 미리 준비되어 있으면 시간을 더 줄일 수 있습니다.

**Q3. SNS 계정이 없는데 어떻게 해야 하나요?**
A. 인스타그램 하나만 집중하세요. 가장 도서 홍보에 효과적입니다. 팔로워가 적어도 꾸준히 하면 독자를 만날 수 있습니다.

**Q4. 직접 얼굴을 드러내야 하나요?**
A. 아니요. 책 표지, 명문장 카드, 책 관련 이미지만으로도 충분히 효과적인 홍보가 가능합니다.

**Q5. 광고비 없이도 효과가 있나요?**
A. 네. 이 가이드는 광고비 0원을 전제로 합니다. 유료 광고는 선택 사항이며, 유기적 홍보만으로도 충분한 효과를 볼 수 있습니다.
