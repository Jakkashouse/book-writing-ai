# 마음이 자라는 책방 - 출판사 마케팅 전략

## 목표
- 일일 판매 15-20권 달성
- 주간 베스트셀러 진입
- 장기 스테디셀러 기반 구축

---

## 역할 분담

### 출판사가 할 일
- 온라인 서점 MD 협상 및 광고
- 언론 홍보 (보도자료, 매체 섭외)
- 유료 광고 집행 (메타, 네이버)
- 대형 인플루언서 유료 협찬
- 오프라인 행사 기획 및 장소 섭외
- B2B 납품 및 대량 구매 제안
- 전문 콘텐츠 제작 (영상, 디자인)

### 작가가 할 일
- 개인 SNS (인스타그램) 운영
- 소규모 인플루언서 무료 협업
- 독자 커뮤니티 소통
- 강연/북토크 진행
- 콘텐츠 제작 협조

---

## 1단계: 즉시 실행 (1-3일차)

### 1일차 - 서점 협상 및 광고 준비

#### 온라인 서점 MD 제안
- [ ] **예스24 MD 컨택**
  - 신간 코너 배치 요청
  - 편집자 추천 제안
  - "육아 베스트" 기획전 참여 제안
  - 담당자: 육아/자녀교육 MD
  - 연락처: 예스24 출판사 담당 MD

- [ ] **알라딘 MD 컨택**
  - 신간 전시 요청
  - 알라딘 추천 도서 제안
  - 메인 배너 광고 비용 협의

- [ ] **교보문고 MD 컨택**
  - 신간 코너 배치
  - 교보문고 추천 도서 제안

#### 상세페이지 개선
- [ ] 미리보기 콘텐츠 확대
  - 목차 전체 공개
  - 본문 20-30페이지 미리보기
  - 저자 서문 전체 공개

- [ ] 독자 타겟 문구 명확화
  - "떼쓰기로 힘든 3-7세 부모를 위한 실전 가이드"
  - "하루 10분, 아이의 마음을 읽는 법"

- [ ] 추천사 확보 및 배치
  - 육아 전문가 추천사 3개
  - 소아정신과 의사 추천
  - 베타 독자 후기 5개

### 2일차 - 언론 홍보 시작

#### 보도자료 작성 및 배포
- [ ] **보도자료 작성**
  - 제목: "떼쓰기 아이, 어떻게 대할까? 실전 육아서 '마음이 자라는 책방' 출간"
  - 핵심 메시지: 감정 코칭, 실전 솔루션, 부모의 마음 성장
  - 저자 약력, 책 특징, 목차, 구매처

- [ ] **육아 전문 매체 배포** (우선순위)
  1. 베이비뉴스 (www.ibabynews.com)
  2. 맘앤앙팡 (www.momandangpang.co.kr)
  3. 키즈맘 (www.kidsmom.com)
  4. 육아정책연구소
  5. 교육플러스

- [ ] **일반 매체 배포**
  - 조선일보 가정섹션
  - 중앙일보 육아섹션
  - 한겨레 교육섹션
  - 여성신문

#### 저자 인터뷰 섭외
- [ ] **팟캐스트 출연 제안**
  - "요즘 육아 금쪽같은 내새끼"
  - "슬기로운 육아생활"
  - "육아멘탈 충전소"

- [ ] **유튜브 채널 섭외**
  - 육아 전문 채널 (구독자 10만+ 우선)
  - 북튜버 (책 소개 채널)

- [ ] **온라인 매거진 기고**
  - 브런치 기고
  - 육아 커뮤니티 칼럼

### 3일차 - 온라인 광고 및 서평단 준비

#### 메타 광고 (페이스북/인스타그램) 세팅
- [ ] **광고 계정 설정**
  - 메타 비즈니스 매니저 설정
  - 픽셀 설치 (구매 링크 추적)

- [ ] **광고 소재 제작**
  - 크리에이티브 A: 책 표지 + 핵심 문구
    - "아이가 떼쓸 때, 당신은 어떻게 하시나요?"
    - "3-7세 부모 필독서"
  - 크리에이티브 B: 독자 후기 캡처
  - 크리에이티브 C: 책 내용 미리보기

- [ ] **타겟팅 설정**
  - 연령: 25-42세
  - 성별: 여성 (주타겟), 남성 (부타겟)
  - 관심사: 육아, 자녀교육, 부모, 어린이집, 유치원
  - 행동: 육아 관련 페이지 좋아요, 육아 콘텐츠 소비

- [ ] **예산 설정**
  - 일일 예산: 3-5만원
  - 초기 테스트 기간: 3일
  - 성과 좋으면 일 5-10만원으로 증액

- [ ] **광고 목표**
  - 전환 목표: 링크 클릭 → 구매
  - KPI: CPC 500원 이하, CTR 2% 이상

#### 네이버 서평단 모집
- [ ] **서평단 카페 컨택**
  - 책먹는여우
  - 서평단닷컴
  - 리딩투데이
  - 네이버 책 카페

- [ ] **서평단 100명 모집**
  - 무료 증정 (출판사 부담)
  - 조건: 블로그/SNS 솔직 후기 필수
  - 기간: 2주 내 후기 작성
  - 신청 방법: 구글폼 or 카페 댓글

- [ ] **서평단 발송 준비**
  - 책 100권 확보
  - 발송 일정: 신청 마감 후 3일 내
  - 함께 발송: 감사 편지, 후기 가이드

## 2단계: 성장 가속화 (4-10일차)

### 4일차 - 네이버 광고 시작

#### 네이버 파워링크
- [ ] **키워드 선정**
  - 핵심 키워드: "육아서 추천", "자녀교육서", "떼쓰기 대처법"
  - 롱테일 키워드: "3세 육아 책", "유아 감정 코칭", "육아 베스트셀러"

- [ ] **광고 문구 작성**
  - 제목: "떼쓰기 아이, 5분이면 진정 | 실전 육아서"
  - 설명: "3-7세 부모 필독, 감정 코칭 완벽 가이드"
  - URL: 예스24 상세페이지

- [ ] **예산 책정**
  - 일일 예산: 2-3만원
  - CPC: 300-500원 목표

#### 네이버 블로그 체험단
- [ ] **블로그 인플루언서 섭외**
  - 육아 블로거 (이웃 1천+ 우선)
  - 책 무료 증정 + 솔직 후기
  - 30명 모집

### 5일차 - 대형 인플루언서 협업

#### 인플루언서 선정
- [ ] **인스타그램 육아 인플루언서**
  - 팔로워 5만-50만
  - 참여율 3% 이상
  - 진솔한 콘텐츠 스타일
  - 타겟: 10명

- [ ] **유튜브 육아 크리에이터**
  - 구독자 10만+
  - 책 소개 영상 제작 요청
  - 타겟: 5명

#### 협업 제안
- [ ] **유료 협찬 제안서 작성**
  - 협찬비: 50-300만원 (팔로워 규모별)
  - 제공 내용: 책 + 협찬비
  - 요청 사항: 피드 1개 + 스토리 3개 이상
  - 해시태그: #마음이자라는책방 #육아서추천 #협찬

- [ ] **계약서 작성**
  - 콘텐츠 가이드라인
  - 게시 기간 (최소 1개월 유지)
  - 성과 측정 (조회수, 참여율)

### 6일차 - 서평단 책 발송

- [ ] 서평단 100명 최종 선정
- [ ] 책 포장 및 발송
- [ ] 발송 완료 공지 (카페/DM)
- [ ] 후기 독려 메시지 (1주 후)

### 7일차 - 서점 프로모션 기획

#### 출간 기념 할인 이벤트
- [ ] **예스24 단독 특가**
  - 20% 할인 (1주일 한정)
  - 메인 배너 광고 협의
  - "출간 기념 특가" 표시

- [ ] **알라딘 중고 유입 방지**
  - 초기 가격 경쟁력 확보
  - 굿즈 증정으로 차별화

#### 굿즈 제작
- [ ] **육아 플래너 제작**
  - 디자인: A5 사이즈, 30일 육아 기록지
  - 제작 수량: 500부
  - 비용: 부당 1,000-2,000원

- [ ] **스티커/북마크**
  - 책 명언 스티커 세트
  - 북마크 (책 디자인 활용)

- [ ] **증정 방식**
  - "지금 구매 시 육아 플래너 증정 (선착순 500명)"

### 8-9일차 - B2B 마케팅

#### 기관 납품 제안
- [ ] **육아종합지원센터**
  - 전국 육아종합지원센터 리스트 확보
  - 납품 제안서 발송
  - 목표: 센터당 10-20권

- [ ] **도서관 납품**
  - 공공 도서관
  - 어린이 도서관
  - 목표: 도서관당 3-5권

- [ ] **유치원/어린이집**
  - 교사 연수 자료로 제안
  - 학부모 교육 자료
  - 목표: 기관당 5-10권

#### 대량 구매 제안
- [ ] **지자체 육아 프로그램**
  - 부모 교육 교재로 제안
  - 목표: 100-500권 단위

- [ ] **기업 복지몰**
  - 임직원 복지 포인트몰 입점
  - 출산/육아 선물 카테고리

### 10일차 - 콘텐츠 마케팅 준비

#### 유튜브 콘텐츠 제작
- [ ] **영상 제작 외주**
  - 영상 제작사 섭외
  - 책 핵심 내용 10개 쇼츠/릴스
  - 각 15-30초 분량

- [ ] **콘텐츠 주제**
  1. "아이 떼쓰기 대처법 3단계"
  2. "자존감 높이는 말 vs 낮추는 말"
  3. "출근 전 5분 애착 대화법"
  4. "아이 감정 읽는 3가지 신호"
  5. "훈육 vs 처벌, 차이점"
  6. "형제 싸움 중재법"
  7. "아이 거짓말, 어떻게 대응?"
  8. "스마트폰 떼기 작전"
  9. "공공장소 떼쓰기 솔루션"
  10. "엄마 화낼 때 아이 마음"

- [ ] **채널 업로드**
  - 출판사 공식 유튜브
  - 인스타그램 릴스
  - 네이버 TV

## 3단계: 바이럴 확산 (11-20일차)

### 11-12일차 - 서평단 후기 수집

- [ ] 서평단 후기 모니터링
- [ ] 우수 후기 선별 (10개)
- [ ] 서점 상세페이지에 후기 추가 요청
- [ ] SNS 리포스팅 (출판사 계정)

### 13일차 - 오프라인 행사 기획

#### 저자 북토크 준비
- [ ] **대형 서점 섭외**
  - 교보문고 광화문점
  - 영풍문고 종로점
  - 알라딘 홍대점

- [ ] **일정 및 주제**
  - 주제: "아이 마음을 읽는 부모되기"
  - 시간: 주말 오후 2-4시
  - 참석 인원: 30-50명

- [ ] **홍보**
  - 서점 공식 채널
  - 출판사 SNS
  - 작가 SNS
  - 육아 커뮤니티

- [ ] **혜택**
  - 참석자 사인본 증정
  - 현장 구매 시 10% 추가 할인

### 14일차 - 언론 기사 후속 조치

- [ ] 보도자료 반응 확인
- [ ] 기사화된 매체 리스트 작성
- [ ] 추가 인터뷰 요청 매체 대응
- [ ] 기사 링크 모음 (서점 상세페이지 활용)

### 15일차 - 네이버 시리즈/브런치 연재

#### 브런치 연재 시작
- [ ] **연재 기획**
  - 제목: "마음이 자라는 육아 이야기"
  - 주제: 책 일부 + 추가 육아 팁
  - 주기: 주 2-3회, 총 10회

- [ ] **첫 회 발행**
  - "떼쓰는 아이, 사실은 이렇게 말하고 싶었다"
  - 마지막에 책 소개 및 구매 링크

- [ ] **브런치북 제작**
  - 연재 완료 후 브런치북 출간
  - 무료 배포로 홍보 효과

### 16일차 - 2차 광고 최적화

#### 광고 성과 분석
- [ ] 메타 광고 데이터 분석
  - 가장 효과적인 크리에이티브 선별
  - 타겟 세분화 (연령, 지역, 관심사)
  - 예산 재배분

- [ ] 네이버 광고 데이터 분석
  - 전환율 높은 키워드 집중
  - 낮은 키워드 제외

- [ ] 예산 증액
  - 효과 좋은 채널에 예산 2배 증액
  - 총 일일 예산: 10-15만원

### 17일차 - 커뮤니티 마케팅

#### 육아 커뮤니티 활동
- [ ] **맘카페 활동**
  - 네이버 카페 (예: 82쿡, 맘스홀릭)
  - 자연스럽게 책 언급 (과도한 홍보 X)
  - 육아 고민 답변하며 신뢰 구축

- [ ] **페이스북 그룹**
  - 육아 그룹 참여
  - 가치 제공 후 책 소개

### 18일차 - 타 출판사 협업

#### 육아서 큐레이션
- [ ] **육아서 묶음 프로모션**
  - 비슷한 시기 출간된 육아서 3-5권
  - 함께 구매 시 할인
  - 크로스 홍보

### 19일차 - 이벤트 마무리

#### 성과 집계
- [ ] 판매량 집계 (서점별)
- [ ] 광고 성과 분석 (ROAS)
- [ ] 리뷰 수 집계
- [ ] SNS 팔로워 증가 분석

#### 감사 이벤트
- [ ] "출간 20일 감사 이벤트"
  - 리뷰 작성자 중 10명 추첨
  - 스타벅스 기프티콘 증정

### 20일차 - 장기 전략 수립

- [ ] 지난 20일 복기
- [ ] 효과적인 채널 파악
- [ ] 향후 3개월 마케팅 플랜
- [ ] 시즌별 이벤트 기획 (어린이날, 방학 등)

## 예산 계획

### 광고비 (20일 기준)
- 메타 광고: 5만원 × 20일 = 100만원
- 네이버 파워링크: 3만원 × 15일 = 45만원
- 서점 배너 광고: 50-100만원 (협의)
