# 작가 감사 편지 템플릿

> ✉️ 서평단/서포터즈에게 책과 함께 동봉하는 감사 편지

---

## 📝 버전 1: 정중한 버전

```
안녕하세요, ○○○입니다.

먼저 『엄마 사모 아내 선교사』를
손에 들어주셔서 감사합니다.

이 책은 오랜 시간 마음에 품고 있던
이야기들을 담았습니다.

엄마로, 사모로, 아내로, 선교사로
하루에도 수십 번 역할을 바꿔가며
묵묵히 자리를 지키는 분들.

그분들의 이야기를 쓰고 싶었습니다.

혹시 이 책을 읽으시다가
"아, 나도 그랬는데"라는 생각이 드신다면
그것만으로도 이 책을 쓴 보람이 있습니다.

솔직한 리뷰 부탁드립니다.
칭찬보다 진심 어린 피드백이
다음 책을 더 좋게 만듭니다.

감사합니다.

○○○ 드림
```

고민을 많이 했거든요.

그런데 이렇게 책을 기다려주시는 분들이 계시니

편하게 읽어주세요.
그리고 솔직하게 느낀 점 나눠주시면

좋은 점도, 아쉬운 점도
모두 다음 책의 밑거름이 됩니다.

다시 한번 감사드려요! 💕

○○○ 올림

## 🎨 디자인 & 인쇄 가이드

### 권장 사양

| 항목 | 권장 |
|------|------|
| 사이즈 | 엽서 (100x148mm) 또는 A6 (105x148mm) |
| 용지 | 모조지 120g 또는 아트지 200g |
| 인쇄 | 단면 컬러 또는 흑백 |
| 수량 | 서평단 인원 + 여유분 10부 |

### 손글씨 요소 추가 팁

1. **서명만 손글씨** - 인쇄 후 서명만 직접 작성
2. **이름 손글씨** - "○○○님께" 부분만 손글씨
3. **전체 손글씨** - 시간 여유 있으면 전체 손글씨 (감동 UP)

### 예상 비용

| 방식 | 100부 기준 |
|------|-----------|
| 온라인 인쇄소 | 1~2만원 |
| 동네 인쇄소 | 2~3만원 |
| 손글씨 (직접) | 0원 (시간 투자) |
