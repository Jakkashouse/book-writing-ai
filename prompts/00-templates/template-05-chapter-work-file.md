## ✍️ 추가 작성 필요 부분

### 1. 도입 스토리 (500자)

**목적**: 독자의 공감을 이끌어내고 몰입도를 높임

**내용 방향**:
- 독자가 겪을 법한 상황 묘사
- 실제 경험담 또는 가상 시나리오
- 이 장의 주제와 연결

**톤앤매너**: 공감형 / 경험담 / 스토리텔링

**참고 자료**:
- 브런치 댓글에서 독자 사연 활용
- 강의 중 질문 활용
- 개인 경험

**작성 체크리스트**:
- [ ] 독자가 "나 이야기네!"라고 느낄 수 있는가?
- [ ] 자연스럽게 본문으로 연결되는가?
- [ ] 너무 길지 않은가? (500자 내외)

---

### 2. 실천 가이드 (800자)

**목적**: 독자가 바로 실천할 수 있는 구체적 방법 제시

**형식**:
- [ ] 단계별 가이드 (3-5단계)
- [ ] 체크리스트
- [ ] Q&A 형식
- [ ] 사례 기반 설명

**내용 구성**:
1. **1단계**: [제목]
   - 설명: [구체적 방법]
   - 예시: [실제 예시]
   - 주의점: [주의할 점]

2. **2단계**: [제목]
   ...

3. **3단계**: [제목]
   ...

**작성 체크리스트**:
- [ ] 구체적이고 실행 가능한가?
- [ ] 독자가 바로 따라 할 수 있는가?
- [ ] 너무 어렵거나 복잡하지 않은가?

---

### 3. 보완 사례 (700자)

**목적**: 이론을 실제 사례로 뒷받침

**사례 출처**:
- [ ] 개인 경험
- [ ] 코칭 사례 (익명 처리)
- [ ] 공개된 사례 (출처 명시)
- [ ] 연구 결과

**사례 내용**:
- 배경: [어떤 상황이었나]
- 문제: [어떤 어려움이 있었나]
- 해결: [어떻게 해결했나]
- 결과: [어떤 변화가 있었나]
- 교훈: [독자가 배울 점]

**작성 체크리스트**:
- [ ] 사례가 본문 내용과 직접 연결되는가?
- [ ] 너무 길거나 지루하지 않은가?
- [ ] 개인정보 보호는 충분한가?

---

### 4. 소결론 (300자)

**목적**: 이 장의 핵심을 정리하고 다음 장으로 연결

**내용 구성**:
1. 핵심 메시지 반복 (100자)
2. 독자 행동 촉구 (100자)
3. 다음 장 예고 (100자)

**톤**: 격려형 / 동기부여형

**작성 체크리스트**:
- [ ] 이 장의 핵심이 명확히 요약되었는가?
- [ ] 독자가 행동하고 싶어지는가?
- [ ] 다음 장으로 자연스럽게 이어지는가?

## ⚠️ 주의사항 및 체크리스트

### 중복 방지
- [ ] 다른 장에서 이미 설명한 개념은 간단히만 언급
- [ ] 같은 사례가 여러 장에 반복되지 않도록 확인
- [ ] 용어 정의는 처음 나온 곳에서만 자세히

### 용어 통일
- [ ] 전문 용어는 용어집 참조
- [ ] "OO" → "XX" 일관되게 사용
- [ ] 독자 호칭 통일 ("당신", "여러분", "우리" 등)

### 문체 일관성
- [ ] 문장 종결형 통일 (입니다체 / 이다체)
- [ ] 톤앤매너 유지
- [ ] 문장 길이 적절 (한 문장 2-3줄 이내)

### 품질 체크
- [ ] 핵심 메시지가 명확한가?
- [ ] 독자에게 실질적 가치를 제공하는가?
- [ ] 읽기 쉽고 이해하기 쉬운가?
- [ ] 실천 가능한 내용이 포함되었는가?
