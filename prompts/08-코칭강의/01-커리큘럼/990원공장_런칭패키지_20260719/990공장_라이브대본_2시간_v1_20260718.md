## 1. 오프닝·약속 (0:00~0:08)

```
안녕하세요, 작가의집 황준연입니다. 오늘 이 자리에 와주셔서 진심으로 반갑습니다.

먼저 약속 하나 드릴게요.
오늘 두 시간이 끝나면, 여러분 손에 '언젠가 쓰고 싶다'가 아니라
'내 책의 목차 초안'이 남습니다. 막연한 생각이 아니라, 눈에 보이는 뼈대요.

그래서 오늘은 강의만 듣는 자리가 아니에요.
채팅창에 여러분의 '쓰고 싶은 책 주제 한 줄'을 지금 적어주세요.
그중 몇 분은 오늘 제가 직접, 실시간으로 목차를 잡아드릴 겁니다.
```
연출: 채팅 주제 수집 시작(5번 첨삭 재료). 참석자 수·환영 멘션.

## 2. 재정의 후킹 (0:08~0:20)

```
많은 분이 이렇게 말씀하세요. "저는 쓸 이야기가 없어요." "글재주가 없어서요."

그런데 제가 200명 넘게 코칭하면서 확인한 진실은 정반대였습니다.
이야기가 없는 게 아니라, '쓰는 순서'를 몰랐을 뿐이에요.

대부분 이렇게 시작해요. 빈 화면 열고, 멋진 첫 문장부터 쓰려다가, 3줄 쓰고 덮습니다.
순서가 거꾸로예요. 첫 문장이 아니라 목차(뼈대)가 먼저입니다.
뼈대가 서면, 그 다음부턴 칸을 채우는 일만 남아요. 그건 누구나 합니다.
```
핵심: 결핍(능력)을 → 해결 가능한 문제(순서)로 재정의.

## 3. 왜 지금인가 (0:20~0:32)

```
그리고 왜 하필 지금이냐. 세 가지가 겹쳤습니다.

하나, 콘텐츠 시장이 양극화 초입입니다. '내 이름'이 곧 자산이 되는 시대.
둘, 예전엔 '말솜씨·글솜씨'가 진입장벽이었는데, 이제 그 변환을 AI가 도와줍니다.
   경험을 말로 풀면, 그걸 원고로 바꾸는 건 도구가 합니다.
셋, 그래서 남는 건 딱 하나 — '무엇을, 어떤 순서로'. 그게 오늘의 주제예요.
```

## 4. 순서 3단계 강의 (0:32~0:57)

```
순서는 딱 세 단계입니다.

[1단계] 주제 한 줄 — "내가 가장 하고 싶은 이야기"를 한 문장으로.
   완벽하지 않아도 됩니다. "육아하며 배운 것" 이 정도면 충분해요.

[2단계] 목차(뼈대) — 그 한 줄을 5~7개 질문으로 쪼갭니다.
   질문이 곧 챕터가 됩니다. 오늘 이걸 여러분 것으로 직접 해볼 거예요.

[3단계] 하루 1시간 — 목차 한 칸씩, 하루 하나. 30일이면 원고의 시작이 섭니다.
   중요한 건 '완벽'이 아니라 '완성'입니다. 완성한 사람만 고칠 수 있어요.
```
연출: 각 단계마다 화면에 예시 1개. 참가자에게 "지금 1단계 한 줄 채팅에 적어보세요" 미니 참여.

## 5. 실시간 완성 aha (0:57~1:27) ★심장

```
자, 이제 오늘의 핵심입니다. 채팅에 올려주신 주제 몇 개를 제가 직접 목차로 만들어 볼게요.

(참가자 A 주제 선택)
"[A의 주제]" — 좋습니다. 이걸 질문으로 쪼개볼게요.
① 왜 이걸 시작했나 → ② 가장 힘들었던 순간 → ③ 그때 뭘 배웠나 →
④ 지금은 어떻게 다른가 → ⑤ 같은 고민을 하는 사람에게 한마디.
보이세요? 방금 [A님] 책의 1~5장이 생겼습니다.

(2~3명 반복)
```
연출: 실시간으로 목차가 화면에 채워지는 걸 '보여준다'. 이 순간이 "내 책이 진짜 되네"의 aha.
운영: 미리 990방에서 받은 '주제 한 줄'을 백업 재료로 확보(채팅이 적을 때 대비).

```
지금 몇 분 것만 했지만, 여기 계신 모든 분이 각자 이걸 할 수 있습니다.
방금 보신 게 바로 '순서'예요. 재능이 아니라.
```

## 6. 증거·사례 (1:27~1:37)

```
제가 이걸 어떻게 확신하냐면 —
출간 코칭 200명 이상, 제가 직접 만든 책이 120권이 넘습니다.
그 과정에서 '평범한 하루'가 책이 되는 걸 수백 번 봤어요.

한 분은 오랜 간병의 시간을 담아 『그동안 애쓰셨습니다』를 냈고,
또 한 분은 아이의 안전을 지키는 마음을 『당신의 아이는 안전합니까』로 엮었습니다.
특별한 작가여서가 아니라, 순서대로 30일을 걸었기 때문입니다.
```
가드레일: 소득·수익 숫자 언급 금지. 권위=코칭수/제작수, 사례=책 2권만.

3일 뒤, 여러분은 '기획안 + 목차 + 첫 꼭지'를 손에 쥐고 나가요.
