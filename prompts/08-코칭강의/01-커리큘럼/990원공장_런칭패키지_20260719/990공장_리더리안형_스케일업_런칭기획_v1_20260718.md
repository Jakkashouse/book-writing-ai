## 핵심 7가지 (먼저 읽으세요)

1. **기존 실행초안을 10배로 키운다.** 앞단 100명(광고비 30~50만) → **방 1,000명 · 라이브 300~400명**. 리더리안 최근 실적(990원 800명 → 라이브 200명 → 결제 20명)을 그대로 벤치마크.
2. **배선은 그대로, 규모만.** 메타광고 → **990원 결제방** → **온라인 라이브(웨비나)** → **3일과정 1기 230만**(위로 770/1200 업셀).
3. **라이브 = 7/30(목) 저녁.** 목표창 7/29(수)~7/31(금) 중 목요일 저녁 권장. 참석률이 매출의 선행지표.
4. **광고비 = 테스트 30만 → 실측 후 200만 내.** 30만으로 CPA·앵글 검증 후 이긴 앵글에 몰아 스케일. 예산은 리스크가 아니라 지렛대.
5. **표준 시나리오만 나와도 5,000만+.** 방 700~800 → 라이브 250~300 → 결제 25~30명 × 230만 = **5,750~6,900만**. 낙관은 8,000만대.
6. **임계경로 = 카카오 알림톡 승인(영업일 3~5일).** 7/20(월) 제출해야 7/30 리마인드 가능. 지연 시 방 공지로 대체.
7. **가드레일 절대 준수.** 소득숫자·가상후기 금지, 실사례 2편만, "990원 1회 결제"·"1기 한정" 정확 표기.

## 2. 스케일업 경제성 (200만 상한 · 정직 추정)

**모객 = 신규 990 결제 + 기존 400방 재활성 합산**

| 구간 | 보수 | 표준 | 낙관 |
|---|---|---|---|
| 신규 990 결제(200만 / CPA 3,000~5,000) | 400명 | 500명 | 650명 |
| 기존 400방 재활성 실참여 | 100명 | 200명 | 350명 |
| **방 총원** | **500** | **700~800** | **1,000+** |
| 방 → 라이브 참석(25~35%) | 200 | 250~300 | 350~400 |
| 라이브 → 230만 결제(7~10%) | 20 | 25~30 | 35~40 |
| **매출(230만 기준)** | **4,600만** | **5,750~6,900만** | **8,000~9,200만** |

- 990 결제 수입 자체가 광고비 일부 상쇄(예: 500명 × 990 ≈ 49만).
- ROAS: 광고비 200만 대비 매출 4,600~9,200만 = **약 23~46배**.
- **정직 프레이밍**: "정확히 1,000명"은 스트레치 목표. 표준(방 700~800 / 라이브 250~300 / 결제 25~30)은 리더리안과 동밴드다. 표준만 나와도 목표 달성. CPA가 좋으면 200만 안에서 "인원 더 많아도 OK" 여력으로 밀어붙인다.

## 4. Phase별 상세

### Phase A — 셋업 (7/18~7/22)
- **990 랜딩 확정**: 기존 랜딩 2종 재활용(A 전문가형 / B 자서전형). CTA "오늘 시작하기" 와이드·풀블리드, "990원(총 1회 결제)" 표시광고 문구 정확화. 990 단일 오퍼로 정리.
- **결제→방초대 자동화**: 990 결제 웹훅 → 오픈채팅/단톡 초대 링크 자동 발송(Make). 대표 확인 필요(웹훅·방링크·사업자정보).
- **메타 광고 4앵글 소재**: 이미지 + 카피(6장 §참조). 프로스펙팅/리타기팅 세트 분리.
- **기존 400방 재활성 시퀀스**: 안부 → 가치 1편 → 990방·웨비나 초대(3스텝, 평문 복붙용).
- **웨비나 2시간 대본**: 기존 60분 대본 확장 — 90분 완성 aha + 30분 오퍼.
- **선물 밸류스택 14종 허브**: 완성된 문서선물 8종을 드라이브/Notion 링크 1개로 묶기.

### Phase B — 모객 (7/20~7/29)
- **메타 3층 배분**: 프로스펙팅(콜드) 70% / 리타기팅(랜딩 미결제) 20% / 오가닉 증폭(릴스·캐러셀, 0원) 10%.
- **Phase0 테스트 30만 / 3~5일**: 4앵글 동시 A/B → 실 CPA·랜딩 CTR·앵글 성능 측정 → 이긴 앵글에 몰아 **총 200만 내** 스케일. 30만 넘겨 바로 태우지 않음(실측 게이트).
- **990방 운영**: 매일 가치 콘텐츠 1편 + 웨비나 예고. 방 자체가 무료·100% 도달 리마인드 채널.

### Phase C — 참석률 극대화 (7/28~7/30)
- 방 → 라이브 참석 25~35%가 매출 선행지표. **알림톡(채널추가자 90% 오픈) + 방공지 이원.**
- D-2 / D-1 / 당일 오전 / 시작 1시간 전 4연타 리마인드. 예약 버튼 + "선물 14종은 라이브 참석자에게만" 노쇼 방지 프레임.

### Phase D — 라이브 (7/30 목 저녁)
- **앞 90분**: 참가자 기획안/원고 실시간 피드백 → "내 책이 진짜 되네" aha(파는 게 아니라 터뜨리기).
- **뒤 30분**: 감정 최고점에서 3일과정 230만 오퍼. 밸류스택 14종에 "근거 1줄 + 자기 억제" 문법. 실시간 결제 링크.
- **희소성 = 사실형만**: "1기 정원 · 다음 일정 미정"(선착순 조작문구 금지).

### Phase E — 팔로업 (7/30~8/1)
- 미결제자: 라이브 후 24h/48h 2연타(녹화본 + 마감 리마인드, 캘린들리 무료상담 서브 CTA).
- 결제자: 3일과정 온보딩 자동 진입(Day1~2 녹화 인증 → Day3 라이브).

## 5. 메타 광고 4앵글 (990방 유입 · 소득숫자 금지)

광고는 **990 체험 + 무료 라이브**를 판다(230만은 라이브에서만).

| 앵글 | 후킹 | 근거 |
|---|---|---|
| **A1 · 990 심리** | "커피값도 안 되는 990원으로, 30일 뒤 내 책의 뼈대" | 초저가 앵커 문법 |
| **A2 · 재정의** | "쓸 게 없는 게 아니라, 쓰는 '순서'를 몰랐을 뿐" | 리더리안 VSL 골격 |
| **A3 · 권위 증거** | 황준연 — 출간코칭 200+ · 직접제작 120권+ (소득 아님=안전) | 소셜프루프 축 |
| **A4 · 결과 페이싱** | "30일 뒤 아침, 저장만 된 파일 vs 내 이름의 책" | 미래 페이싱 |

## 7. 가드레일 (작가의집 표준)

- **소득숫자·가상후기 금지.** 리더리안의 660만→8,000만식 소득 계산은 이식 금지 — 이식하는 건 *구조*(디코이·밸류스택 근거문법·순서전환 VSL·사실형 희소성)이지 *숫자*가 아님.
- **표시광고**: "990원(총 1회 결제)" 명확 표기. 230만은 정가 330·할인가·"1기 한정" 정확 표기.
- **실사례 2편만**: 이은정 『그동안 애쓰셨습니다』 · 『당신의 아이는 안전합니까』.
- **복붙 톡문안 = 평문**(blockquote 금지).
- **수익화 과정 작가 성과**(2주~1달 내 기대)는 실현 전까지 랜딩·광고·라이브 어디에도 미사용.

## 8. 검증 (실측 게이트)

1. **Phase0 실측**: 30만 집행 후 실 CPA·랜딩 CTR·앵글 성능 기록 → 추정(CPA 3,000~5,000)과 대조. 벗어나면 랜딩·소재부터 개선 후 스케일.
2. **모객 중간점검(7/26경)**: 방 총원 실측 → 500 미만이면 재활성·리타기팅 강화, 초과면 여력 집행.
3. **참석률 검증(라이브 당일)**: 방 대비 라이브 참석률 집계. 25% 미만이면 리마인드 시퀀스 원인 분석.
4. **최종 정산(라이브 후)**: 결제수 × 230만 vs 광고비 → 실 ROAS.
5. 모든 광고 수치는 **우리 실데이터로만** 이후 마케팅에 사용(외부 벤치마크는 설계 근거로만).
