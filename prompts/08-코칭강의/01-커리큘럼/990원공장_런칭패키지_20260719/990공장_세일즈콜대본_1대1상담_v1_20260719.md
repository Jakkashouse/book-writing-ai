# 990원 공장 · 1:1 무료상담 세일즈콜 대본 v1

> 작성 2026-07-19 · 대상: 라이브 후 캘린들리로 **1:1 무료상담 신청한 사람** · 30분 통화/줌
> 원칙: 듣기 70% / 말하기 30%. 파는 게 아니라 "이 사람 주제가 책이 될지" 같이 보는 자리.
> 목표: 3일과정 230(메인) · 다운셀 100(대안) · 상위 770/1200(상황 맞으면)
> 가드레일: 소득보장 금지. 실사례 2편만. 압박·마감조작 금지.

---

## 통화 구조 (30분)

| 구간 | 시간 | 목적 |
|---|---|---|
| 1. 라포·상황 | 0~7분 | 긴장 풀기 + 왜 신청했나 |
| 2. 주제 진단 | 7~17분 | 그의 주제를 실제로 목차로(작은 aha) |
| 3. 장애물·목표 | 17~23분 | 무엇이 막고 있나 / 어디까지 가고 싶나 |
| 4. 제안 | 23~28분 | 상황에 맞는 계단 1개 |
| 5. 다음 스텝 | 28~30분 | 결정 or 숙려 |

---

## 1. 라포·상황 (0~7분)

```
안녕하세요, 황준연입니다. 시간 내주셔서 고마워요. 편하게 얘기 나눠요.
오늘은 뭘 파는 자리 아니고요, ○○님 주제가 진짜 책이 될지 저랑 같이 보는 자리예요.

먼저 여쭤볼게요. 라이브는 어떻게 보셨어요? 어느 부분이 제일 와닿으셨어요?
(경청) 그리고 오늘 이 상담은 어떤 마음으로 신청하셨어요?
```
[핵심] 여기서 그의 '진짜 동기'가 나온다. 메모.

---

## 2. 주제 진단 — 작은 aha (7~17분)

```
자, 그럼 ○○님 이야기를 직접 봐요. 쓰고 싶은 주제, 한 줄로 말씀해 주시겠어요?
(듣고) 좋아요. 이걸 제가 질문 몇 개로 쪼개볼게요.
① 왜 이 이야기를 하고 싶으세요? ② 가장 기억에 남는 순간은요?
③ 거기서 뭘 배우셨어요? ④ 지금은 어떻게 다르세요? ⑤ 같은 사람에게 한마디 하면?

들으면서 정리해 볼게요 — 방금 ○○님이 하신 말이 그대로 1장, 2장, 3장이에요.
보세요. ○○님 책, 벌써 목차가 나왔어요.
```
[핵심] 전화로도 '내 책이 되네'를 체감시킨다. 이게 클로징의 8할.

---

## 3. 장애물·목표 (17~23분)

```
그럼 이거 하나 여쭤볼게요. 이렇게 될 것 같은데, 지금까지 왜 못 쓰셨을까요?
(경청 — 시간/방법/자신감 중 뭐가 진짜 벽인지)

그리고 반대로, 이 책 다 쓰고 나면 ○○님한테 뭐가 달라질 것 같아요?
그냥 소장하고 싶으세요, 아니면 이걸로 뭔가 이어가고 싶으세요?
```
> 답으로 계단 결정:
> - "시간·방법이 벽" + "완주가 목표" → **230 3일과정**
> - "지금 230은 부담" → **100 다운셀**
> - "이걸로 사업/강연 하고 싶다" → **770/1200** 언급(단, 무리하게 X)

---

## 4. 제안 — 상황에 맞는 계단 1개 (23~28분)

```
(230 케이스)
말씀 들어보니, ○○님한텐 '혼자 30일'보다 '같이 30일'이 맞겠어요.
그게 3일과정이에요. Day1~2 순서 익히고, Day3에 오늘처럼 제가 직접 첫 꼭지까지 완성 도와드려요.
1기라 지금 230으로 여는데, 다음 기수는 아직 안 정했어요.

(100 다운셀 케이스)
230이 지금 부담이시면, 한 계단 낮춰 [다운셀상품명]도 있어요.
전부는 아니어도 '제대로 시작'은 확실히 하는 자리예요.
```
[가드레일] **한 번에 하나만 제안.** 여러 개 늘어놓으면 결정 마비.

---

## 5. 다음 스텝 (28~30분)

```
오늘 결정 꼭 안 하셔도 돼요. 다만 두 가지만 정리해 드릴게요.
하나, 지금 ○○님 주제는 충분히 책이 됩니다. 이건 확실해요.
둘, 1기 자리는 정원이 있고 다음 일정은 미정이에요.

마음이 서시면 오늘 시작하시고, 며칠 생각이 필요하시면 편하게 알려주세요.
어느 쪽이든, 오늘 ○○님 목차 나온 건 진짜예요. 그거 하나는 챙겨 가세요.
```

## 반론 대응 (전화용)

| 반론 | 답변 |
|---|---|
| "생각해 볼게요" | 좋아요. 뭐가 제일 걸리세요? (진짜 이유 파악) |
| "가족이랑 상의" | 당연하죠. 상의하실 때 이 한 줄 보여주세요 — '내 주제로 이미 목차가 나왔다' |
| "돈이…" | 이해해요. 그래서 계단이 있어요(100/230). 목표에 맞는 걸로 |
| "혼자 해볼게요" | 응원해요. 오늘 순서로 시작하시고, 막히면 오세요 |
