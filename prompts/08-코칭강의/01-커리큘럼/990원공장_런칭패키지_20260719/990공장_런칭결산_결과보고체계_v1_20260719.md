## 핵심 5가지

1. **퍼널을 '워터폴'로 본다.** 노출→클릭→990결제→방→라이브신청→참석→L2결제. 각 마디의 이탈률이 어디서 새는지 한눈에.
2. **보고는 3주기.** ① 모객 중 일일 미니(3줄) ② 라이브 전후 집중 ③ 결산 리포트(2기 예산 근거).
3. **코호트를 쪼갠다.** 990신규 vs 400방재활성 / 광고앵글별 / 층별 — 뭉뚱그리면 뭘 끌지 모른다.
4. **숫자마다 의사결정 룰을 건다.** "CPA 5천 초과 → 스케일 중단" 처럼, 보고서가 곧 행동 지시.
5. **1차/생애 매출을 분리 보고.** 라이브 48h 1차 매출로 성패 판정, 후속(L3/L4)은 별도 트래킹.

## 1. 퍼널 워터폴 (핵심 보고 프레임)

| # | 마디 | 목표 전환 | 실측 | 이탈률 | 판정 |
|---|---|---|---|---|---|
| 1 | 광고 노출 → 랜딩 클릭 | CTR 1.5% | | | |
| 2 | 랜딩 클릭 → 990 결제 | 8~15% | | | |
| 3 | 990 결제 → 방 입장 | 95%+ | | | |
| 4 | 방 → 라이브 신청 | 60%+ | | | |
| 5 | 라이브 신청 → **참석** | 50%+ | | | ★핵심 |
| 6 | 참석 → L2 230 결제 | 8~10% | | | ★핵심 |
| 7 | L2 거절 → L1 100 다운셀 | 3~5% | | | |

> **가장 큰 누수 마디를 찾는 게 목적.** 5번(신청→참석)·6번(참석→결제)이 무너지면 앞단(광고)을 아무리 키워도 소용없다.

## 2. 보고 주기별 양식

### 2-A. 모객 중 일일 미니 보고 (3줄, 매일 밤)
```
[MM/DD] 990공장 데일리
· 광고: 지출 O원 / 990결제 O명(누적 O) / 실CPA O원 [양호·경고]
· 방: 총원 O명(신규 O + 재활성 O) / 목표대비 O%
· 오늘 판단: (예) A2앵글 승, A3 중단 / CPA 4.2천 양호 → 내일 증액
```

### 2-B. 라이브 D-1 점검 보고
```
· 방 총원 확정: O명
· 라이브 신청: O명 (방 대비 O%)
· 리마인드 발송: 알림톡 D-2/D-1 완료 O건
· 예상 참석: O명 (신청 × 55%)
· 리스크: (예) 신청 저조 → 당일 오전 리마인드 강화
```

### 2-C. 라이브 직후 속보 (당일 밤)
```
· 참석: O명 (방 대비 O% / 목표 25~35%)
· L2 230 결제: O명 → O원
· L1 100 다운셀: O명 → O원
· 1차 매출: O원 / 광고비 대비 ROAS O배
· 즉시 액션: 미결제 참석자 O명 → 24h 팔로업 발송
```

## 3. 런칭 결산 리포트 템플릿 (라이브 +3일)

### 3-1. 요약 (한 페이지)
- 총 투입 광고비 · 방 총원 · 라이브 참석 · L2/L1 결제 · **1차 매출 · ROAS · LTV/CAC**
- 표준 시나리오 대비 달성률(%)

### 3-2. 퍼널 워터폴 실측 (위 §1 표 채움)

### 3-3. 코호트 분석
| 코호트 | 인원 | 라이브 참석률 | L2 전환율 | 비고 |
|---|---|---|---|---|
| 990 신규(광고) | | | | |
| 400방 재활성 | | | | 어느 풀이 더 결제하나 |
| 앵글 A1/A2/A3/A4 | | | | 승자 앵글 |

### 3-4. 무엇이 통했나 / 안 통했나 (정성 3+3)
- 통한 것 3: (예) A2 재정의 앵글 CPA 최저 / 실시간 aha 후 결제 집중 / …
- 안 통한 것 3: (예) 신청→참석 42%로 목표 미달 / 다운셀 안내 늦음 / …

### 3-5. 2기·에버그린 반영 (금액모델 연동)
- 실측 LTV/CAC → **2기 광고 예산 상한** 재산정
- 실측 참석률·전환율 → 금액모델 v2 표 교체
- 승자 앵글·랜딩 → 에버그린 웨비나 고정 소재
