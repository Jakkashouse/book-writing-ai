# 메타광고 실행전략 · 인스턴트 양식 리드형

**이사라 대표 「페이스북 메타광고 4회차」 강의안 전면 적용판**

작성 2026-07-23(목) · 집행 시작 7/24(금) · 1차 목적지 **7/30(목) 라이브** · 2차 8월 1~2주차 연장

---

## 핵심 7가지

1. **랜딩을 쓰지 않습니다.** 페이스북 안에서 폼(인스턴트 양식)으로 전화번호를 받고, 완료화면에서 곧바로 단톡방으로 보냅니다. 지금 랜딩(SC933R0D)의 가격 ₩0 문제와 픽셀 미설치 문제를 **통째로 우회**합니다.
2. 대신 얻는 것은 **전화번호**입니다. 단톡방에 안 들어온 사람도 문자로 다시 부를 수 있습니다. 도달이 두 겹이 됩니다.
3. **오늘 밤에 세팅해야 내일 시작됩니다.** 광고 검수에 2~3일 걸립니다(PPT p.145). 내일 켠다 = 실제 노출은 7/26~27부터입니다.
4. 예산 **일 3만 × 6일 = 18만**. 리드 단가 2,000~3,000원 가정 시 **리드 60~90명**입니다. 라이브 신청 500명 목표에는 한참 못 미칩니다 — 이 6일은 **어느 앵글이 먹히는지 알아내는 테스트**로 쓰고, 승자가 나오면 8월에 증액하는 구조입니다.
5. 소재는 **오늘 아침에 만든 12장을 그대로 씁니다**(A1 자격 / A2 속도 / A3 명함 / A4 오퍼). 새로 만들 것 없습니다. 문구만 리드형 CTA로 바꿨습니다.
6. 운영 규칙은 딱 하나 — **리드 단가 3,000원을 넘으면 그 소재를 끄고 다음 소재로 교체**(PPT p.248). 매일 밤 10분이면 됩니다.
7. **가격은 광고에 쓰지 않습니다.** 500/700/990은 라이브와 상담에서만 공개하는 원칙 그대로입니다.

## 1. 왜 방식을 바꾸는가

7/18에 만든 SOP는 **랜딩 전환형**(판매 캠페인 → 랜딩 → 990원 결제 → 픽셀 최적화)이었습니다. 좋은 구조지만 지금 두 가지가 막혀 있습니다.

| 막힌 것 | 랜딩 전환형 | 인스턴트 양식 리드형 |
|---|---|---|
| 랜딩 가격 ₩0 표시 | 치명적 (돈 내는 화면이 깨져 있음) | **무관** — 랜딩을 안 거침 |
| 메타 픽셀 미설치 | 최적화 자체가 안 돎 = 광고비 증발 | **무관** — 메타 안에서 전환이 끝남 |
| 신규 광고계정 학습 | 결제 전환은 희소해서 학습이 느림 | 리드는 흔해서 **하루 만에 학습** |
| 이탈 | 광고→랜딩→폼→결제 4단계 | 광고→폼(자동입력)→완료 **2단계** |
| 남는 자산 | 이메일(설문 응답) | **전화번호** = 문자 재유입 가능 |

리드형의 유일한 약점은 **무료 유입이라 리드 질이 낮다**는 점입니다. "1,000원이라도 결제하게 해서 걸러낸다"는 대표님 원칙과 어긋납니다.

**그래서 필터를 뒤로 옮깁니다.**

```
메타광고 → 인스턴트 양식(전화·이메일)
            ↓ 완료화면
          단톡방 입장  ← 여기까지 무료
            ↓ (동시에 솔라피 문자 발송)
          1,000원 챌린지 신청 링크  ← 여기가 유료 필터
            ↓
          7/30(목) 라이브 2시간 → 상담 → 500 / 700 / 990
```

무료로 넓게 받되, 단톡방 안에서 1,000원으로 거릅니다. 광고비는 싸지고 필터는 유지됩니다.

## 7. 매일 밤 10분 운영 (PPT 8단계)

앱스토어에서 **META 광고 관리자** 앱을 깔면 폰에서 켜고 끌 수 있습니다 (PPT p.246).

| 지표 | 양호 | 조치 |
|---|---|---|
| 리드 단가(CPL) | **≤ 2,000원** | 유지 |
| CPL 2,000~3,000원 | 관찰 | 하루 더 지켜봄 |
| **CPL > 3,000원** | 경고 | **그 광고를 끄고 다음 소재로 교체** (PPT p.248) |
| 4개 다 3,000원 초과 | 심각 | 소재가 아니라 **앵글**을 바꿉니다 |
| 노출은 도는데 리드 0 | 폼 문제 | 폼 미리보기에서 직접 제출해 봅니다 |
| "처리 중" / "예약됨" | 정상 | 검수 대기 (2~3일) |
| 광고가 안 돌아감 | 스위치 꺼짐 | 상단 토글 활성화 (PPT p.234, 236) |

초반에는 단가가 낮게 나오다가 시간이 지나면 올라갑니다(PPT p.248). **오르기 시작하면 그때가 소재 교체 시점**입니다.

## 9. 숫자 — 정직한 계산

| 항목 | 6일 (일 3만) |
|---|---|
| 광고비 | 180,000원 |
| CPL 2,000원 가정 | **리드 90명** |
| CPL 3,000원 가정 | 리드 60명 |
| 단톡방 입장률 55% | 33~50명 |
| 라이브 참석률 40% | **13~20명** |
| 상담 전환 20% | 3~4건 |

**1억 목표(라이브 신청 500명)와는 자릿수가 다릅니다.** 500명을 CPL 2,000원으로 모으려면 광고비 100만원이 필요합니다.

그래서 이 6일의 목적은 **모객이 아니라 단가 확인**입니다.

- CPL이 2,000원 아래로 나오면 → 8월에 100만원을 태울 근거가 생깁니다
- CPL이 3,000원을 넘으면 → 100만원을 태워도 결과는 같습니다. 태우기 전에 알아낸 게 이득입니다

18만원은 **100만원을 쓸지 말지 알아내는 값**입니다.
