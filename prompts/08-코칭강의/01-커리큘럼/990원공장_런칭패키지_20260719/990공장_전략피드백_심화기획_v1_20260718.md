# 990원 공장 런칭 · 전략 피드백 & 심화 기획 (v1)

> 작성 2026-07-18(토) · 목적: 현재 기획의 **구멍을 먼저 찾고**, 2기·에버그린까지 내다보는 심화 설계
> 톤: 칭찬 최소화, 리스크·개선 중심. "될 이유"보다 "깨질 지점"을 먼저 본다.

---

## 핵심 5가지 (먼저 읽으세요)

1. **이 런칭의 단일 최대 리스크는 광고가 아니라 '참석률'이다.** 방 1,000명을 모아도 라이브에 200명이 안 오면 매출은 반토막. 예산보다 리마인드·참석 인센티브에 더 신경 써야 한다.
2. **990 결제 → 라이브 사이의 '빈 며칠'이 진짜 사망 구간.** 결제만 받고 방을 방치하면 라이브 참석률이 무너진다. 990방 데일리는 옵션이 아니라 **필수 인프라**.
3. **오퍼가 라이브 단 1회에 몰빵돼 있다.** 라이브를 놓친 사람 = 전환 기회 0. 리플레이(재시청 마감)와 48h 팔로업이 매출의 20~30%를 좌우한다.
4. **230만 '첫 노출 충격'을 밸류스택으로 흡수해야 한다.** 라이브 30분 오퍼에서 230만이 처음 등장하면 저항이 크다. 정가 330 + 선물 1,610만 앵커링이 "230만이 싸 보이게" 만드는 장치.
5. **1기는 '자산 만드는 회차'로 봐라.** 1기 매출보다 중요한 건 대본·랜딩·실측 CPA·후기. 성공하면 **에버그린 웨비나**로 전환해 상시 매출로 굴린다.

## 1. 강점 (짧게)

- 배선·자산·가드레일이 이미 정리돼 있어 **실행 리스크가 낮다**(신규 툴 도입 0).
- 리더리안 실측을 벤치마크로 삼아 **숫자가 공상이 아니다**(동밴드 근거).
- 230만 실수강자 존재로 "판매 자체 부재" 리스크는 해소됨.

## 2. 리스크 진단 Top 6 (깨질 지점)

| # | 리스크 | 왜 위험한가 | 대응 |
|---|---|---|---|
| **R1** | **참석률 붕괴** | 방→라이브 25~35%는 낙관치. 20%면 매출 −40% | 리마인드 4연타 + **라이브限 혜택**(녹화본을 미끼로 쓰지 말 것) + 참석 체크인 이벤트 |
| **R2** | **990→라이브 이탈** | 결제 후 며칠 방치 시 관계 소멸(벤치 '첫 10일 47% 이탈') | **990방 데일리 7편**(별도 산출물)로 매일 접점 |
| **R3** | **오퍼 1회 몰빵** | 라이브 놓치면 전환 0 | 리플레이(48h 마감) + 팔로업 2연타 + 미참석자 재초대 |
| **R4** | **CPA 초과** | 990 CPA 5천 초과 시 200만으로 방 400명뿐 | 기존 400방 재활성이 안전판. 재활성 성과가 CPA 보완 |
| **R5** | **230만 첫 노출 저항** | 라이브 전 가격 미노출 → 30분 오퍼에서 충격 | 밸류스택 14종 '근거 1줄' 앵커링(별도 산출물) |
| **R6** | **알림톡 반려** | 홍보성 문구는 반려. 7/20 제출도 재제출 시 지연 | 정보성 톤 작성 + 방 공지 백업(이미 확보) |

> **한 줄 결론**: R1(참석률)·R2(이탈)이 매출의 70%를 결정한다. 광고 최적화(R4)는 그 다음이다. **모객보다 '데워서 라이브까지 끌고 오는 것'에 자원을 더 써라.**

## 3. 현재 기획의 구멍 (놓친 것)

1. **결제 완료 직후(OTO) 설계가 비어 있다.** 벤치마크는 990 결제 직후 OTO에서 업셀 25~40%가 난다고 본다. 다만 우리는 230만을 라이브에서 판다 → **하드 OTO는 라이브 힘을 뺏으니 금지**, 대신 **소프트 OTO**(무료: "라이브 VIP 우선 질문권 + 선물 조기 언락, 지금 예약 확정")로 라이브 참석 약속을 잠근다. = 참석률(R1) 보험.
2. **오가닉 층(10%)이 카피팩에 없다.** 광고 4앵글만으로는 K-factor가 안 생긴다. 캐러셀·릴스·990방 데일리로 자연 확산(별도 산출물로 보강).
3. **참석 인증/체크인 이벤트가 없다.** 라이브 초반 이탈 방지 장치(출석 이벤트, 실시간 주제 첨삭 당첨) 필요.
4. **결제자 온보딩 Day1~3 상세가 없다.** 230만 낸 사람의 첫 경험이 부실하면 환불·불만. Day별 인증·라이브 배선 명시 필요.
5. **후속 사다리(770/1200) 업셀 타이밍 미설계.** 최적 시점 = 3일과정 Day3 감정 최고점. "완주자에게만 다음 문" 프레임.

## 4. 심화 기획 — 3개월 로드맵

### Phase 1 · 1기 런칭 (7월 말) = **자산 검증 회차**
- 목표: 매출 5,000만+ **그리고** 실측 CPA·참석률·전환율·후기 3편 확보.
- 성공 기준: 라이브 참석률 ≥25%, 참석→결제 ≥8%. 미달 시 원인(리마인드/오퍼/랜딩) 분해.

### Phase 2 · 에버그린 전환 (8월)
- 1기 라이브 녹화 → **에버그린 웨비나**(기존 에버그린 자산 재활용). 990 유입이 상시 자동으로 웨비나→230만.
- 라이브의 "실시간 aha"는 에버그린에서 약해지므로 → **월 1회 라이브 재개최**를 앵커로 병행(에버그린 + 월간 라이브 하이브리드).

### Phase 3 · 사다리 완성 (8~9월)
- 230만 결제자 → 770(출간확정)/1200(자동화·브랜딩수익화) 업셀. 타이밍=Day3 감정 최고점 + 3일과정 종료 후 1:1 무료상담.
- 밀레스톤 리퍼럴(원가0 인정형): 990방 참석/완주자 3명 초대 → 부트캠프 크레딧, 10명 → 황작가 1:1 30분.

## 5. 우선순위 권고 (자원 배분)

```
매출 영향도 순:
1위  참석률 부스터 (R1)   ← 리마인드·소프트OTO·체크인   [지금 가장 저평가된 지렛대]
2위  990방 데일리 (R2)    ← 매일 접점, 라이브까지 데우기
3위  라이브 오퍼 완성도    ← 밸류스택 앵커링·클로징·반론
4위  리플레이/팔로업 (R3)  ← 놓친 20~30% 회수
5위  광고 최적화 (R4)      ← CPA는 실측 후 조정 (가장 나중)
```

> **핵심 메시지**: "1,000명 모으기"에 꽂히면 R1·R2를 놓친다. 방 700명 + 참석률 35% > 방 1,000명 + 참석률 20%. **모객량보다 참석 전환에 자원을 몰아라.**
