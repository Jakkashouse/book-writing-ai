# 990원 공장 · 메타 광고 집행 SOP (v1)

> 작성 2026-07-18(토) · Ads Manager 직접 집행(권장) · Phase0 30만 → 실측 → 200만 내 스케일
> 대상: 대표/직원이 이 순서대로 따라 하면 집행 완료 · 채울 곳: [광고계정] · [990랜딩URL] · [픽셀ID]

---

## 핵심 6줄

1. **바로 200만 태우지 않는다.** Phase0 30만으로 4앵글 A/B → 이긴 앵글에만 스케일.
2. **3층 배분**: 프로스펙팅 70% / 리타기팅 20% / 오가닉 10%(0원).
3. **목표는 '전환' 캠페인**(990 결제 이벤트), 트래픽 아님.
4. **픽셀·전환 API 먼저** 심어야 최적화가 돈다(랜딩에 픽셀 설치 필수).
5. **판단 지표는 990 CPA** — 5천 이하면 스케일, 초과면 랜딩·소재부터.
6. **UTM 필수** — 앵글·층별 성과를 트래커로 자동 집계.

---

## STEP 1 · 사전 셋업 (집행 전날까지)

- [ ] Meta 픽셀을 [990랜딩URL]에 설치 (결제 완료 = Purchase 이벤트)
- [ ] 도메인 인증 + 전환 API(가능하면) 연결
- [ ] 광고 계정 결제수단·예산한도 확인
- [ ] 소재 준비: 이미지 4앵글(브리프 참조) + 카피 4앵글(카피팩 A) + UTM 링크

---

## STEP 2 · Phase0 테스트 캠페인 (30만 / 3~5일)

**캠페인 1개 = 목적 '판매(전환:Purchase)'**

| 요소 | 설정 |
|---|---|
| 캠페인 목적 | 판매(Sales) · 전환 이벤트 = Purchase(990 결제) |
| 예산 | CBO(캠페인 예산) 일 6만 × 5일 = 30만 |
| 광고세트 | **1개**(프로스펙팅) · Advantage+ 또는 관심사(자기계발/글쓰기/책/1인창업) |
| 타깃 | 한국 · 30~59세 · 관심사 broad(초기엔 넓게, 알고리즘이 찾게) |
| 노출위치 | Advantage+ 자동(피드·릴스·스토리) |
| 광고(크리에이티브) | **4개 = A1·A2·A3·A4** 각 1개(동일 세트 안에서 A/B) |
| 링크 | [990랜딩URL] + UTM(utm_content=A1_990심리 등) |

> 초기엔 앵글을 **한 광고세트 안에서** 경쟁시켜 알고리즘이 이긴 앵글에 노출을 몰게 한다(세트 쪼개면 학습 지연).

---

## STEP 3 · 실측 판독 (D+3~D+5)

트래커(990공장_UTM_ROAS_트래커)에 매일 입력 → 판단:

| 지표 | 양호 | 경고 → 조치 |
|---|---|---|
| 랜딩 CTR | ≥1.5% | <1% → 소재/헤드 교체 |
| 990 CPA | ≤5,000원 | >5,000 → 랜딩·소재 개선 후 재테스트(예산 확대 금지) |
| 앵글 편차 | 승자 1~2개 뚜렷 | 전부 비슷·저조 → 앵글 재작성 |

> **게이트: CPA ≤5천 확인 전에는 절대 스케일하지 않는다.** 나쁜 CPA에 200만 태우면 방만 커지고 손실.

---

## STEP 4 · 스케일 (총 200만 내)

- 이긴 앵글 1~2개만 남기고 **예산 증액은 하루 20~30%씩**(급증 시 학습 리셋).
- **리타기팅 세트 추가**(20%): 랜딩 방문·미결제(픽셀 커스텀 오디언스) → A2/A4 재노출.
- 룩얼라이크(선택): 990 결제자 1~3% LAL로 프로스펙팅 확장.
- 오가닉(0원): 캐러셀·릴스 유기 발행(오가닉 팩) → 잘 되는 릴스는 소액 부스팅.

**층별 예산 예시(총 170만 스케일 시)**

| 층 | 비중 | 금액 |
|---|---|---|
| 프로스펙팅 | 70% | 119만 |
| 리타기팅 | 20% | 34만 |
| 룩얼라이크 | 10% | 17만 |
| 오가닉 | 0원 | 0 |

(Phase0 30만 + 스케일 170만 = 총 200만 상한)

---

## STEP 5 · 모객 마감·라이브 연결

- 라이브 D-2에 광고 **신규 유입 중단**(그 뒤 유입은 라이브 참석 못 함) → 예산을 리타기팅·리마인드로.
- 990 결제자는 자동으로 방 초대 → 990방 데일리 + 알림톡 리마인드로 라이브까지 연결.

## 자주 나는 문제 (트러블슈팅)

| 증상 | 원인·조치 |
|---|---|
| 노출은 많은데 결제 0 | 랜딩 문제(픽셀 미설치/랜딩 설득력) → 랜딩 CVR부터 |
| CPA만 비쌈 | 앵글/타깃 미스매치 → 승자 앵글에 집중, 타깃 broad화 |
| 학습 이탈(Learning Limited) | 세트 너무 잘게 쪼갬 → 통합, 예산 안정화 |
| 반려(광고 검수) | "990원 1회 결제" 정확 표기, 과장·소득약속 제거 |

## 집행 방식 메모

- **권장 = Ads Manager 직접**(안전·즉시, 현재 세션 메타 광고 MCP 미연결).
