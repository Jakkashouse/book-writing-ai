## A. Day3 라이브 마무리 — "다음 문" 심기 (약 8~10분)

```
자, 3일 동안 정말 고생 많으셨어요. 지금 손에 뭐가 있죠?
기획안, 목차, 그리고 첫 꼭지. 3일 전엔 없던 거예요. 스스로 대단하신 거예요.

여기서 두 갈래 길이 있어요.
하나는, 오늘 배운 순서로 남은 원고를 혼자 완성해서 세상에 내놓는 길.
충분히 하실 수 있어요. 진심입니다.

또 하나는, '완성'을 넘어서 '출간'까지, 그리고 그 책을 '내 사업의 엔진'으로 만드는 길이에요.
이건 모두에게 권하진 않아요. 원고를 넘어 더 멀리 가고 싶은 분께만 열어요.
```

### 770 — 출간확정 (한 줄 소개)
```
첫 번째 문은 '출간확정'이에요.
원고를 끝까지 함께 다듬어서, POD든 정식 출간이든 '실제로 나온 책'까지 책임지고 갑니다.
'언젠가 내야지'가 아니라, 'ISBN 박힌 내 책'으로 끝을 보는 과정이에요.
```

### 1,200 — 자동화·브랜딩수익화 (한 줄 소개)
```
두 번째 문은 한 걸음 더 나가요. '브랜딩수익화 과정'이에요.
책을 낸 다음이 진짜예요. 그 책으로 강연, 코칭, 나만의 상품까지 —
'책 한 권'을 '내 이름의 사업'으로 잇는 자동화 시스템을 함께 세웁니다.
제가 지금 여러분께 이 라이브를 여는 방식, 그 구조 자체를 여러분 것으로 이식하는 거예요.
```

```
오늘은 여기까지만 말씀드릴게요. 지금 결정하실 필요 전혀 없어요.
관심 있으신 분은, 제가 3일과정 마친 분들께 1:1 상담 자리를 따로 열어요.
거기서 여러분 상황 놓고, 어느 길이 맞는지 같이 봐요.
자, 오늘 완성한 첫 꼭지에 스스로 박수 한 번. 정말 고생하셨습니다.
```

## B. 1:1 상담 — 실제 업셀 클로징 (구조)

### B-1. 여는 질문 (상황 파악, 듣기 70%)
```
3일과정 하시면서 어떠셨어요? 어느 순간이 제일 좋으셨어요?
지금 이 책, 다 쓰고 나면 뭘 하고 싶으세요? 그냥 소장용이에요, 아니면 뭔가 이어가고 싶으세요?
```
> 답에서 갈림: "그냥 내 책 갖고 싶다" → 770(출간). "이걸로 뭔가 하고 싶다" → 1,200(수익화).

### B-2. 770 제안 (출간이 목표인 분)
```
말씀 들어보니, '완성'보다 '실제 책'이 목표시네요.
그럼 혼자 조판·표지·유통까지 가는 건 생각보다 벽이 많아요. 거기서 대부분 멈춰요.
'출간확정'은 그 끝을 제가 책임지고 같이 넘는 과정이에요.
[상위과정링크] · 결정은 편하게, 궁금한 것부터 물어보세요.
```

### B-3. 1,200 제안 (사업이 목표인 분)
```
'책으로 뭔가 하고 싶다'고 하셨죠. 그게 핵심이에요.
책은 끝이 아니라 시작이에요. 문제는 그다음을 혼자 설계하기 어렵다는 거예요.
'브랜딩수익화 과정'은 책을 강연·코칭·상품으로 잇는 구조를 함께 세워요.
다만 분명히 말씀드려요. 이건 '얼마 번다'를 약속하는 과정이 아니에요.
'내 이름의 사업 구조를 세운다'는 과정이에요. 실행은 여전히 본인 몫이고요.
```
[가드레일] 절대 "월 O천 보장" 류 금지. "구조를 세운다"로만.

### B-4. 반론·클로징
| 반론 | 답변 |
|---|---|
| "지금 책도 안 끝났는데요" | 그래서 지금이에요. 끝까지 갈 레일을 지금 깔아두는 것 |
| "돈이 부담돼요" | 오늘 결정 아니어도 됩니다. 다음 기수 일정은 미정이라, 지금 여신 분만 이번 기수 |
| "혼자 해볼게요" | 좋아요. 하다 벽 만나면 그때 오세요. 문은 열려 있어요 |

```
결정을 재촉하진 않을게요. 다만 이 자리는 3일과정 마친 분께만 여는 거고,
다음 기수는 아직 안 정했어요. 오늘 마음이 서시면 시작하시고,
더 생각이 필요하면 며칠 안에 편하게 알려주세요.
```
