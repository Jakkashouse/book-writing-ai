# 990공장 카카오 알림톡 — 심사 제출용 템플릿 5종

**작성 2026-07-20(월) · 제출 마감: 오늘(D-10, 990 라이브 7/30 목) · 심사 3~5영업일**

## 핵심 5가지 (먼저 읽기)

1. **알림톡은 "정보성"만 통과, "광고성"은 반려.** 신청완료·예약·접속·다시보기·상담접수 = 정보성(안전). 할인·선물·이벤트·마감임박·최저가 = 광고성(반려).
2. **5종을 서로 다른 목적으로 분리** — 전부 '리마인드'면 중복으로 반려된다. (완료→D-1→당일→종료후→상담)
3. **광고성(선물 14종·1기 230 할인·마감)은 알림톡에서 전부 뺐다** → 그건 **친구톡/채널 메시지**로 발송(심사 불필요, 광고성 허용).
4. **변수는 `#{변수명}` 형식.** 변수만으로 된 줄 금지, 변수 비중 과다 반려. 아래 변수는 최소화했다.
5. **오늘 할 일**: 카카오 비즈니스 채널 → 알림톡 → 템플릿 등록 5개 → '채널 추가형' 신청 → 심사 제출. 사업자정보·채널 개설 선행.

## T1. 신청 완료 안내 ⭐(가장 안전, 100% 통과)

- **템플릿명**: `[특강] 신청완료 안내`
- **카테고리**: 서비스이용 > 이용안내/예약
- **유형**: 강조표기형 (상단 강조 타이틀)
- **강조 타이틀**: `신청이 완료되었습니다`
- **버튼**: ① 채널 추가 ② 신청내역 확인(웹링크 `#{신청링크}`)

```
#{이름}님, 신청이 정상 접수되었습니다.

▶ 프로그램: 온라인 라이브 특강
▶ 일시: #{라이브일시}
▶ 참여 방식: 온라인 (접속 링크는 시작 전 안내)

접속 링크와 준비 안내는 시작 전에 순차로 보내드립니다.
문의는 채널로 남겨 주세요.
```

> 심사 포인트: 예약/신청 완료 안내 = 순수 정보성. 반려 사유 없음. 여기서 채널 추가를 유도해 이후 친구톡(광고성) 발송 기반 확보.

---

## T2. 라이브 하루 전 리마인드

- **템플릿명**: `[특강] D-1 리마인드`
- **카테고리**: 서비스이용 > 이용안내
- **유형**: 기본형
- **버튼**: 일정 확인(웹링크 `#{일정링크}`)

```
#{이름}님, 신청하신 라이브가 내일 진행됩니다.

▶ 일시: #{라이브일시}
▶ 접속 링크는 시작 전 별도로 안내드립니다.

일정을 미리 확인해 주세요.
```

> 심사 포인트: 예약 리마인드 = 정보성. '선물·혜택' 문구 삭제(원래 초안엔 있었음 → 반려 소지라 제거).

## T3. 당일 시작 임박 + 접속 링크

- **템플릿명**: `[특강] 당일 시작안내`
- **카테고리**: 서비스이용 > 이용안내
- **유형**: 강조표기형
- **강조 타이틀**: `오늘 라이브가 시작됩니다`
- **버튼**: 접속하기(웹링크 `#{접속링크}`)

```
#{이름}님, 오늘 #{라이브시각} 라이브가 시작됩니다.

▶ 접속 링크: #{접속링크}

시작 시간에 맞춰 입장해 주세요.
접속이 안 되시면 채널로 알려 주세요.
```

> 심사 포인트: 이용 안내(접속 링크 제공) = 정보성. 가장 열람률 높은 핵심 터치. 링크 버튼 필수.

## T4. 종료 후 다시보기·자료 안내

- **템플릿명**: `[특강] 종료후 다시보기 안내`
- **카테고리**: 서비스이용 > 이용안내
- **유형**: 기본형
- **버튼**: 다시보기(웹링크 `#{다시보기링크}`)

```
#{이름}님, 오늘 라이브에 참여해 주셔서 감사합니다.

▶ 다시보기: #{다시보기링크}
▶ 다시보기 열람 기한: #{만료일}까지

안내 자료는 채널에서 확인하실 수 있습니다.
```

> 심사 포인트: 이용 후 안내 = 정보성. '판매·마감·할인' 문구 없음. 세일즈는 이 알림톡이 아니라 뒤이은 친구톡/무료상담에서.

## ⚠️ 광고성은 친구톡으로 (알림톡 반려분 분리)

기존 카피팩(E-1/E-2)의 "1기 230 할인·마감 안내·선물 14종"은 **알림톡으로 내면 반려**된다. 이건 **친구톡(광고성 허용)** 또는 채널 메시지로 발송:
- 친구톡 대상 = T1에서 채널 추가한 사람
- 친구톡 문안은 기존 카피팩 E-1/E-2/팔로업3종 그대로 사용 가능(평문)
- 즉 **정보성=알림톡(자동·전체), 광고성=친구톡(채널추가자)** 2트랙으로 분리 운영
