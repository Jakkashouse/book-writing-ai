## A. 메타 광고 4앵글 (990 결제방 유입)

각 앵글 = 1차 카피(피드) + 헤드라인(단문) + 본문. 광고 목적지 = [990랜딩URL]. **230만은 광고에 노출 금지**(라이브에서만).

### A1 · 990 심리 (초저가 앵커)

```
커피 한 잔의 5분의 1, 990원.

'언젠가 내 책 한 권'을 30일 뒤 '목차와 첫 꼭지'로 바꾸는
가장 작은 시작을 990원에 열었습니다.

말솜씨도, 글재주도 아닙니다. 순서만 알면 됩니다.
30일 뒤, 당신 이름이 박힌 책의 뼈대를 손에 쥐게 됩니다.

지금 990원으로 시작 → [990랜딩URL]
(990원 1회 결제 · 무료 온라인 라이브 초대 포함)
```
헤드라인: **990원으로 시작하는 30일, 내 책 한 권**

### A2 · 재정의 (순서 전환)

```
"저는 쓸 이야기가 없어요."

아닙니다. 이야기가 없는 게 아니라,
'쓰는 순서'를 몰랐을 뿐입니다.

먼저 목차를 세우고, 하루 1시간씩 채우면
30일 뒤엔 원고가 됩니다. 순서를 바꾸면 누구나 됩니다.

그 순서를 990원에 직접 경험해 보세요 → [990랜딩URL]
```
헤드라인: **문제는 재능이 아니라 순서였습니다**

### A3 · 권위 증거 (소셜프루프)

```
출간 코칭 200명 이상, 직접 만든 책 120권 이상.

작가의집 황준연이 실제로 사람들을 '저자'로 만들어 온 방식,
그 핵심을 30일 과정으로 압축했습니다.

첫 시작은 990원. 무료 온라인 라이브에서 직접 보여드립니다.
→ [990랜딩URL]
```
헤드라인: **200명을 저자로 만든 방식, 990원에 열다**

### A4 · 결과 페이싱 (미래)

```
30일 뒤 아침, 당신 앞엔 둘 중 하나가 놓입니다.

여전히 '언젠가'로 미뤄둔 빈 파일.
아니면, 목차가 잡히고 첫 꼭지가 쓰인 '내 책'의 시작.

무엇이 놓일지는 오늘 990원에서 갈립니다.
→ [990랜딩URL]
```
헤드라인: **30일 뒤, 빈 파일 vs 내 이름의 책**

> **운영 메모**: Phase0 30만으로 A1~A4 동시 A/B(3~5일) → 실 CPA·CTR 측정 → 이긴 1~2앵글에 몰아 200만 내 스케일. 프로스펙팅 70% / 리타기팅 20%(랜딩 방문·미결제) / 오가닉 10%(릴스·캐러셀 0원).

## B. 기존 400방 재활성 3스텝 (평문 복붙)

기존 단톡방은 응답률이 낮으므로 판매부터 꺼내지 않는다. **안부 → 가치 → 초대** 순서로 온기부터.

### B-1. 안부 (Day 1)

```
안녕하세요, 오랜만에 인사드립니다. 황준연입니다 ^^

그동안 잘 지내셨는지요. 방을 오래 비워 두어 죄송한 마음입니다.
요즘 '내 이름으로 된 책'을 훨씬 쉽게 시작하는 방법을 정리하고 있어서,
곧 여기 계신 분들께 가장 먼저 나누려고 합니다.

무더운 여름, 건강 잘 챙기세요. 다시 자주 인사드릴게요.
```

### B-2. 가치 1편 (Day 2~3)

```
'책은 재능 있는 사람이 쓰는 것'이라는 오해부터 풀고 싶습니다.

제가 200명 넘게 코칭하며 확인한 건 딱 하나였습니다.
글솜씨가 아니라 '순서'였어요.
① 쓰고 싶은 주제 한 줄 → ② 목차(뼈대) → ③ 하루 1시간씩 채우기.
이 순서면 30일 뒤엔 원고가 시작됩니다.

며칠 뒤, 이 순서를 직접 경험하는 무료 온라인 라이브 자리를 엽니다.
여기 계신 분들을 가장 먼저 모실게요.
```

### B-3. 초대 (Day 4~5)

```
약속드린 자리를 엽니다 — 무료 온라인 라이브 특강.

[라이브일시] · 온라인 · 약 2시간 (녹화본 제공)
'막연한 주제'를 '내 책의 목차와 첫 꼭지'로 바꾸는 과정을
제가 직접, 실시간으로 함께 잡아 드립니다.

참석 신청은 아래에서 성함/연락처와
'쓰고 싶은 책 주제 한 줄'만 남겨주세요. 그 한 줄을 라이브에서 함께 다듬어요.
→ [예약링크]
```

## D. 웨비나 리마인드 (카카오 알림톡 — 승인 제출용 5종)

> 7/20(월) 제출(임계경로). 채널추가형(오픈율 90%)로 신청. [ ] 안은 알림톡 변수.

### D-1. 신청 완료 (예약 직후)

```

■ 일시: [라이브일시]
■ 방식: 온라인 (링크는 당일 발송)
■ 준비물: '쓰고 싶은 책 주제 한 줄'

라이브 참석자에게만 드리는 선물 14종도 준비돼 있어요. 그날 뵙겠습니다!
```

### D-2. D-2 리마인드

```
[#{이름}]님, 이틀 뒤 [라이브일시] 무료 라이브에서 뵙습니다.

'내 책 목차'를 실시간으로 함께 잡는 2시간이에요.
주제 한 줄만 미리 떠올려 오시면 충분합니다. 잊지 말고 캘린더에 표시해 두세요!
```

### D-3. D-1 리마인드

```
[#{이름}]님, 내일이에요! [라이브일시] 무료 라이브.

참석하신 분께만 열리는 자리와 선물 14종이 준비돼 있습니다.
접속 링크는 내일 시작 전에 보내드릴게요. 편한 자리에서 만나요 :)
```

### D-4. 당일 오전

```
[#{이름}]님, 오늘 저녁 [라이브일시] 라이브 날입니다.

접속 링크: [예약링크]
시작 시간에 맞춰 들어오시면 처음부터 함께하실 수 있어요. 오늘 뵙겠습니다!
```

### D-5. 시작 1시간 전

```
[#{이름}]님, 1시간 뒤 시작합니다.

지금 링크를 미리 열어 접속을 확인해 두세요 → [예약링크]
'주제 한 줄'을 손에 들고 오시면, 오늘 당신의 목차가 완성됩니다.
```

어제 라이브에서 '되겠다'는 느낌을 받으셨다면, 그 느낌이 살아있을 때가 시작하기 가장 좋은 때입니다.
