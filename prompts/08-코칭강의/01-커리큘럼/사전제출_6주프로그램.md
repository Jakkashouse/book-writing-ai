# 📍 1주차
## 🎯 **"3년째 미루던 책, 단 하루 만에 제목과 목차 완성"**

Part.1 이론+노하우
- 책쓰기 실패의 진짜 원인은 재능이 아니라 '제목과 목차'입니다
	- 99%가 모르는 진실: 제목과 목차가 80%다
- 출판사가 숨기는 비밀: 제목 하나로 운명이 갈립니다
	- 제목 공식 10가지 상세 설명
- 목차가 없으면 3개월 후 거절됩니다
	- 5부 구조 시스템 (Why-What-How-Do-Future)
- 29년 실패한 사람도 목차 시스템으로 3주 만에 초고 완성
	- 박○○님 사례: 27년째 책쓰기 포기 → 2달 만에 출간

- 글쓰기 5+5 시스템: 말하듯 쓰면 됩니다
	- 70대도 30분 만에 주제 3개 찾은 비밀
- 초고 완성률 87%의 비밀
	- 작가의 집 수강생 초고 완성률 87% vs 일반인 5% (17배 차이)

Part.1 이론+노하우

	- 원고만 제출 → 답장률 5%, 기획서 제출 → 답장률 85% (17배 차이)
- 계약률 100%의 비밀: 5분 기획서 템플릿
	- 7가지 구성 요소 (제목, 타겟 독자, 시장 분석, 목차, 저자 소개, 마케팅 계획, 예상 판매 부수)
- 계약서 함정: 이것 모르면 500만원 손해
	- 인세율, 선인세, 저작권, 2차 저작물 권리 체크리스트
- 출판사 100곳 명단 공개
	- 장르별 / 타겟별 출판사 분류
	- 동시 제안 전략 (3~5곳)

Part.2 실습

# 📍 4주차
## 🎯 **"출간일 하루만에 베스트셀러 만들고 강의료 30만원 받기"**
### 💰 획득 가치: 출간일 판매 4배 증가 (30부→120부), 책 200권 판매 = 강의 1회 수익

Part.1 이론+노하우
- 출간 후 홍보하면 이미 늦습니다
	- 출간 후 홍보 시작 → 평균 30부, 출간 전 30일 마케팅 → 평균 120부 (4배 차이)
	- 출간일 100부만 팔아도 = 베스트셀러 (예스24 기준)
- 출간 전 30일 마케팅 타임라인
	- D-30: 출간 예고 SNS 포스팅
	- D-15: 지인 50명 동원
	- D-Day: 100부 판매 → 베스트셀러 달성
- 책은 명함입니다. 진짜 수익은 강의와 컨설팅입니다
	- 책 200권 × 1,700원 = 34만원 = 강의 1회 수익
- 책→강의→컨설팅 파이프라인 설계
	- 90일 플랜: 출간 → 강의 10건 → 컨설팅 5건

Part.2 실습
**🎯 출간일 100부 판매로 베스트셀러 만들기**
**🎯 책→강의→컨설팅 파이프라인 (연 1,920만원)**

# 📍 5주차
## 🎯 **"웨비나 1회로 3,000만원 벌고 매달 1,000만원씩 자동 수익 만들기"**
### 💰 획득 가치: 첫 웨비나 3,000만원 (10명 전환), 이후 매달 1,000만원 자동 수익 (월 3명 전환), 연 1억 2천만원 수익 구조

Part.1 이론+노하우
- 책 1권 = 콘텐츠 100개
	- 책 → 강의 → 웨비나 → 코칭 → 유튜브 → 블로그 → 전자책
	- 같은 콘텐츠로 7번 돈 버는 법
- **실제 사례: 2025년 1월 첫 웨비나로 3,000만원 (10명 전환)**
	- 웨비나 수익 구조: 참석 100명 → 전환 10명 × 상품가 300만원 = 3,000만원
	- 이후 매달 3명씩 전환 → 월 1,000만원 자동 수익
	- 연간 수익: 첫 달 3,000만원 + 11개월 × 1,000만원 = 1억 4,000만원
- 현재 상품가 700만원 기준, 1억 수익도 가능
	- 참석 100명 × 전환율 15% × 상품가 700만원 = 1억 500만원
- 웨비나 시스템 전체 공개 (복붙 가능)
	- 90분 웨비나 스크립트 (복붙 가능)
	- PPT 62페이지 (복붙 가능)
- 책쓰기 코치 상품 설계 (월 230만원)
	- 1:1 코칭 vs 그룹 코칭 vs 디지털 상품

Part.2 실습
**🎯 웨비나 시스템 전체 확보 (스크립트+PPT 62페이지 복붙 가능)**
**🎯 책쓰기 코치 상품 설계로 월 1,000만원 수익 구조**

# 📍 6주차
## 🎯 **"1인 출판사로 6개월 만에 7,000만원 매출 만들기"**
### 💰 획득 가치: 인세 수익 6배 증가 (1,500원→9,000원), 6개월 매출 7,000만원 달성 (실제 강사 사례), 지원금 4,500만원 확보

Part.1 이론+노하우
- 출판사 계약하면 인세 10%. 1인 출판사 하면 100%
	- 출판사: 15,000원 × 인세 10% = 1,500원
	- 1인 출판사: 15,000원 × 순수익 60% = 9,000원 (6배 차이)
- 실제 사례 4가지 (작가의 집 수강생)
	- 사례 1: 6개월 만에 600부 판매 → 순수익 500만원
	- 사례 2: 내 책 1,100부 판매 → 총 수익 3,950만원
	- 사례 3: 1년 만에 350부 판매 → 손해 안 봄
	- 사례 4: 코칭비 모델 → 손해 가능성 0%
	- **강사 실제 사례: 1인 출판사 6개월 운영 → 7,000만원 매출**
- 예비창업패키지 (실제 수혜 사례)
	- 내가 받은 지원금: 4,500만원
	- 어떻게 받았나? (신청 방법 상세)
- 6주 총정리: 당신은 이제 '작가'입니다
	- 제목 → 목차 → 초고 → 기획서 → 마케팅 → 수익화 전체 프로세스

Part.2 실습
**🎯 1인 출판사로 수익 6배 상승**
**🎯 예비창업패키지 4,500만원 지원금 신청 방법**
