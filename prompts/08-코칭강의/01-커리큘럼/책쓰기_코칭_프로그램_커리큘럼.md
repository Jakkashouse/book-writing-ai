# 책쓰기 코칭 프로그램 커리큘럼

---

## 프로그램 개요

### 목표
- 예비 저자가 **아이디어 → 완성 원고**까지 도달하도록 체계적 지원
- 출간 가능한 수준의 원고 완성
- 저자로서의 정체성과 브랜드 구축

### 대상
- 책을 쓰고 싶지만 시작을 못 하는 분
- 원고를 쓰다 중단한 분
- 블로그/브런치 글을 책으로 엮고 싶은 분
- 전문 분야를 책으로 정리하고 싶은 전문가

### 기간
- **기본 과정**: 12주 (주 1회 세션)
- **집중 과정**: 8주 (주 1회 + 중간 체크인)
- **장기 과정**: 24주 (격주 세션, 천천히 진행)

|------|------|
| 0-15분 | 인사 및 프로그램 소개 |

### 워크시트 질문

2. 이 책이 나오면 누가 가장 기뻐할까?
3. 10년 후에도 이 주제로 이야기하고 싶은가?
4. 이 책이 없으면 세상에 어떤 손해가 있을까?
5. 나만이 쓸 수 있는 이유는?

- [ ] 주제 후보 3가지 선정 및 각각 200자 설명 작성
- [ ] 비슷한 주제의 기존 책 3권 조사

### 책 구조 유형

**1. 순차형 (How-to)**
```

2장: 기본 개념
3장: 실전 방법 1
4장: 실전 방법 2
5장: 실전 방법 3
6장: 심화/응용
7장: 마무리/다음 단계
```

**2. 에세이형 (주제 모음)**
```
프롤로그
Part 1: 대주제 A
  - 에세이 1, 2, 3, 4
Part 2: 대주제 B
  - 에세이 5, 6, 7, 8
Part 3: 대주제 C
  - 에세이 9, 10, 11, 12
에필로그
```

**3. 스토리형 (서사 중심)**
```
1장: 시작점 (before)
2장: 계기/사건
3장: 시행착오
4장: 전환점
5장: 변화/성장
6장: 현재 (after)
7장: 독자에게 전하는 말
```

**4. 문제해결형**
```
1장: 문제 정의
2장: 원인 분석
3장: 해결책 1
4장: 해결책 2
5장: 해결책 3
6장: 실행 가이드
7장: 성공 사례
```

## 5주차: 첫 챕터 집필 & 글쓰기 루틴

### 세션 목표
- 첫 챕터 초고 완성
- 개인 글쓰기 루틴 설계
- 글쓰기 막힘 대처법 학습

### 세션 내용 (90분)

| 시간 | 내용 |
|------|------|
| 0-20분 | 과제 리뷰: 첫 챕터 초고 피드백 |
| 20-40분 | 강의: 효과적인 글쓰기 루틴 |
| 40-60분 | 개인 루틴 설계 워크숍 |
| 60-80분 | 글쓰기 막힘 해결법 |
| 80-90분 | 다음 주 집필 계획 수립 |

### 글쓰기 루틴 설계

**시간 확보 전략**
- 아침형: 기상 후 1-2시간
- 저녁형: 퇴근 후 1-2시간
- 주말형: 토/일 집중 3-4시간
- 틈새형: 점심시간, 출퇴근 시간 활용

**환경 설정**
- 고정된 장소 (책상, 카페, 도서관)
- 방해 요소 차단 (휴대폰, SNS)
- 글쓰기 전용 도구/앱

**목표 설정 방식**
- 시간 기반: "매일 1시간 쓴다"
- 분량 기반: "매일 1,000자 쓴다"
- 세션 기반: "주 3회, 회당 2,000자"

### 글쓰기 막힘 해결법

| 증상 | 해결법 |
|------|--------|
| 시작을 못 하겠다 | 아무 문장이나 일단 쓴다, 중간부터 쓴다 |
| 완벽주의 | "초고는 쓰레기여도 된다" 주문 |
| 집중이 안 된다 | 뽀모도로 기법 (25분 집중 + 5분 휴식) |
| 뭘 써야 할지 모르겠다 | 챕터 설계 워크시트 다시 보기 |
| 지루하다 | 순서 바꿔서 쓰기, 대화체로 써보기 |

### 과제
- [ ] 2번째 챕터 초고 완성
- [ ] 글쓰기 루틴 1주일 실천 및 기록

### 세션 목표

### 세션 내용 (90분)

| 시간 | 내용 |
|------|------|

| 30-50분 | 사례 작성 워크숍 |
| 50-70분 | 본인 원고에 적용 실습 |
| 70-90분 | 피드백 및 과제 안내 |

### 스토리텔링 기본 구조

**STAR 기법**
- **S**ituation (상황): 언제, 어디서, 누가
- **T**ask (과제): 무엇을 해야 했는가
- **A**ction (행동): 무엇을 했는가
- **R**esult (결과): 어떻게 되었는가

**감정 곡선**
```
     /\
    /  \      /\
   /    \    /  \
  /      \  /    \___
 /        \/
시작  갈등  전환  해결  여운
```

### 사례 유형별 활용법

| 유형 | 용도 | 주의점 |
|------|------|--------|
| 본인 경험 | 신뢰감, 공감 | 자랑으로 느껴지지 않게 |
| 타인 사례 | 객관성, 다양성 | 허락/익명 처리 |
| 가상 사례 | 설명 용이 | "가령~" 명시 |
| 유명인 사례 | 흥미 유발 | 출처 명확히 |
| 데이터/연구 | 신뢰도 | 최신 자료, 출처 표기 |

### 과제
- [ ] 기존 챕터에 사례/스토리 1개씩 추가
- [ ] 5-6번째 챕터 초고 완성
- [ ] 사례 수집 목록 업데이트

### 세션 목표
- 전체 원고 흐름 점검
- 챕터 간 연결 강화
- 부족한 부분 파악

### 세션 내용 (90분)

| 시간 | 내용 |
|------|------|
| 0-20분 | 진행 상황 점검 |
| 20-50분 | 전체 원고 흐름 리뷰 |
| 50-75분 | 챕터 간 연결 작업 |
| 75-90분 | 남은 집필 계획 조정 |

### 전체 흐름 체크

**구조 점검**
- [ ] 도입부가 독자를 끌어당기는가
- [ ] 각 챕터의 순서가 논리적인가
- [ ] 난이도 배분이 적절한가 (쉬운 것 → 어려운 것)
- [ ] 중복되는 내용이 없는가
- [ ] 빠진 내용이 없는가

**연결 점검**
- [ ] 챕터 마무리 → 다음 챕터 연결이 자연스러운가
- [ ] 전체를 관통하는 핵심 메시지가 일관되는가
- [ ] 앞에서 언급한 내용을 뒤에서 회수하는가

## 9주차: 도입부 & 마무리 작성

### 세션 목표
- 프롤로그/서문 작성
- 에필로그/맺음말 작성
- 책의 첫인상과 여운 설계

### 세션 내용 (90분)

| 시간 | 내용 |
|------|------|
| 0-20분 | 강의: 효과적인 도입부/마무리 |
| 20-45분 | 프롤로그 작성 실습 |
| 45-70분 | 에필로그 작성 실습 |
| 70-90분 | 피드백 및 수정 |

### 프롤로그 작성 가이드

**포함 요소**
1. 훅 (첫 문장/단락으로 끌어당기기)
2. 이 책을 쓰게 된 계기
3. 이 책이 다루는 내용
4. 독자가 얻을 것
5. 읽는 방법 안내 (선택)

**프롤로그 유형**
- **스토리형**: 개인 경험으로 시작
- **질문형**: 독자에게 질문 던지기
- **선언형**: 책의 핵심 메시지 선포
- **현장형**: 생생한 장면 묘사로 시작

### 에필로그 작성 가이드

**포함 요소**
1. 핵심 메시지 재확인
2. 독자에게 전하는 마지막 말
3. 행동 촉구 (다음 스텝)
4. 감사 인사

### 과제
- [ ] 프롤로그 완성
- [ ] 에필로그 완성

**1단계: 구조 퇴고**

- [ ] 불필요한 부분이 없는가
- [ ] 더 필요한 내용이 없는가
- [ ] 챕터 순서가 적절한가

**2단계: 내용 퇴고**
- [ ] 핵심 메시지가 명확한가
- [ ] 근거/예시가 충분한가
- [ ] 독자 눈높이에 맞는가
- [ ] 중복 내용이 없는가

**3단계: 문장 퇴고**
- [ ] 문장이 간결한가
- [ ] 어색한 표현이 없는가
- [ ] 맞춤법/띄어쓰기 확인
- [ ] 톤앤매너가 일관되는가

### 퇴고 팁
- 시간을 두고 읽기 (최소 1-2일 후)
- 소리 내어 읽기
- 프린트해서 읽기
- 다른 사람에게 읽어달라고 하기

### 과제
- [ ] 전체 원고 1차 퇴고 완료
- [ ] 수정 사항 표시
- [ ] 베타리더용 원고 준비

## 11주차: 베타리딩 & 피드백 반영

### 세션 목표
- 베타리더 피드백 분석
- 피드백 반영 우선순위 결정
- 2차 수정 진행

### 세션 내용 (90분)

| 시간 | 내용 |
|------|------|
| 0-30분 | 베타리더 피드백 공유 |
| 30-60분 | 피드백 분석 및 우선순위 |
| 60-85분 | 수정 방향 논의 |
| 85-90분 | 마지막 주 안내 |

### 베타리더 선정 가이드

**이상적인 베타리더 구성**
- 타겟 독자층 2-3명
- 글을 잘 아는 사람 1명 (작가, 편집자 등)
- 해당 분야 전문가 1명 (해당 시)

**베타리더에게 요청할 질문**
1. 읽는 동안 지루했던 부분은?
2. 이해가 안 되거나 어려웠던 부분은?
3. 더 알고 싶었던 내용은?
4. 가장 인상 깊었던 부분은?
5. 이 책을 추천한다면/안 한다면 이유는?

### 피드백 반영 매트릭스

| 피드백 내용 | 빈도 | 중요도 | 수정 난이도 | 우선순위 |
|-------------|------|--------|-------------|----------|
| | 높/중/낮 | 높/중/낮 | 높/중/낮 | A/B/C |

### 과제
- [ ] 피드백 반영하여 2차 수정
- [ ] 최종 퇴고
- [ ] 제목/부제 최종 확정

## 12주차: 최종 마무리 & 출간 준비

### 세션 목표
- 최종 원고 완성
- 출간 프로세스 안내
- 저자로서의 다음 스텝 설계

### 세션 내용 (90분)

| 시간 | 내용 |
|------|------|
| 0-20분 | 최종 원고 점검 |
| 20-40분 | 제목/부제/저자 소개 확정 |
| 40-60분 | 출간 프로세스 안내 |
| 60-80분 | 저자 브랜딩 & 마케팅 계획 |
| 80-90분 | 수료 및 마무리 |

### 최종 제출 체크리스트

**원고**
- [ ] 본문 최종 완성
- [ ] 프롤로그/에필로그 완성
- [ ] 목차 최종 확정
- [ ] 맞춤법/오탈자 최종 점검

**부가 요소**
- [ ] 책 제목 확정
- [ ] 부제 확정
- [ ] 저자 소개 (200자 내외)
- [ ] 저자 사진 (선택)
- [ ] 참고문헌/출처 정리 (해당 시)

### 출간 후 저자 활동 안내

**온라인**
- SNS 계정 정비
- 브런치/블로그 연재
- 뉴스레터 시작

**오프라인**
- 북콘서트/출간 기념회
- 강연/특강
- 인터뷰/팟캐스트
