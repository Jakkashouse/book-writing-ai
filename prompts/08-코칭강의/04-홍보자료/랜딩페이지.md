- 섹션별 배경 색상 교차 (흰색 ↔ 연한 회색)
- CTA 버튼: 고정 크기, 눈에 띄는 색상 (#FF6B35)
- 여백: 넉넉하게 (가독성 최우선)

## 이미지
- 히어로: 수강생 책 표지 모음 (격자 형태)
- 증거: 실제 데이터 인포그래픽
- 후기: 수강생 사진 + 인용문
- 강사: 프로필 사진 + 실적 아이콘

## 애니메이션
- 스크롤 시 숫자 카운트 업 효과
- CTA 버튼 호버 시 확대 효과
- 섹션별 페이드 인 효과

## 전환율 최적화 요소
- [x] 명확한 헤드라인 (3초 안에 이해 가능)
- [x] 구체적인 숫자 (출간률 99%, 초고 완성률 87%)
- [x] 사회적 증거 (52명, 후기, 데이터)
- [x] 긴급성 (선착순 100명)
- [x] 손실 회피 (30일 환불 보장)
- [x] 명확한 CTA (5개 이상 배치)
- [x] FAQ (6가지 핵심 질문)
- [x] 보너스 (750만원 가치)
- [x] 가격 앵커링 (실제 가치 vs 특가)
- [x] 모바일 최적화

## A/B 테스트 포인트
1. 헤드라인: "3년째 미루던 책" vs "단 6주 만에 작가 되기"
2. CTA 버튼 문구: "지금 바로 시작하기" vs "무료 웨비나 신청하기"
3. 가격 제시: 앵커링 vs 단순 가격
4. 후기 배치: 섹션별 vs 한곳에 모음
