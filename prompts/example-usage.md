# 사용 예시 및 가이드

## 전체 워크플로우

```
1. book-input-template.md 복사
   ↓
2. 책 정보 간단히 입력 (3-5분)
   ↓
3. 27-book-video-script-generator.md 프롬프트에 제공
   ↓
4. AI가 90초 영상 스크립트 생성
   ↓
5. 영상 촬영 및 편집
```

## 실전 사용 예시

### STEP 1: 입력 양식 작성

```markdown
### 책 기본 정보
- 책 제목: 가르치며 배우는 신앙: 52주 교사 가이드
- 저자: 권오희 목사
- 장르: 신앙

### 핵심 정보
- 핵심 메시지: 교사의 영성을 52주 동안 체계적으로 세우는 올인원 가이드
- 대상 독자: 주일학교 교사, 소그룹 리더
- 가장 강력한 차별점: 20년 현장 노하우 + 말씀/나눔/기도/실천 올인원 구성

### 가격 및 혜택
- 정가: 17,000원
- 특별가: 10,000원
- 특별 혜택: 한정 1,000부
```

### STEP 2: AI에게 요청

```
[27-book-video-script-generator.md 프롬프트]와 함께

"위 정보를 바탕으로 90초 영상 스크립트를 생성해주세요"
```

### STEP 3: 생성된 스크립트 활용

AI가 생성한 스크립트를 바탕으로:
- 촬영 콘티 작성
- 나레이션 녹음
- 영상 편집
- 자막 삽입

## 45권 책을 위한 효율적 작업 방법

### 📊 추천 작업 계획

#### 1일차: 정보 수집 (2-3시간)
- 45권 책 리스트 정리
- 기본 정보 수집 (제목, 저자, 가격)
- 장르별 분류

#### 2일차: 입력 양식 작성 (2-4시간)
- 장르별로 묶어서 작성
- 신앙서 → 자기계발 → 전문서 순
- 1권당 3-5분 투자

#### 3일차: AI 스크립트 생성 (2-3시간)
- 10권씩 묶어서 AI에게 요청
- 생성된 스크립트 검토
- 필요시 수정 요청

#### 4-5일차: 스크립트 정리 및 우선순위 (2시간)
- 45개 스크립트 정리
- 촬영 우선순위 결정
- 비슷한 콘셉트끼리 묶기

## 장르별 활용 전략

### 📖 신앙서적 (예: 20권)

**공통 전략:**
- 영적 필요 강조
- 성경적 근거
- 공동체 변화

**차별화 포인트:**
- 각 책의 타겟 독자 (교사/부모/청년/리더)
- 핵심 주제 (기도/예배/성경공부/관계)

### 💼 자기계발서 (예: 15권)

**공통 전략:**
- Before/After 강조
- 구체적 변화
- 실용적 솔루션

**차별화 포인트:**
- 분야 (공부/커리어/습관/관계)
- 타겟 연령대
- 적용 기간

### 📚 전문/실용서 (예: 10권)

**공통 전략:**
- 전문성 강조
- 즉시 활용
- ROI 강조

**차별화 포인트:**
- 직무별 (마케팅/디자인/개발/경영)
- 난이도 (입문/중급/고급)
- 실습 자료 유무

## 촬영 효율화 팁

### 🎬 배치 촬영 (Batch Shooting)

#### 방법 1: 장르별 묶어 촬영
```
Day 1: 신앙서 20권 (의상/배경 동일)
Day 2: 자기계발 15권 (다른 콘셉트)
Day 3: 전문서 10권 (전문가 느낌)
```

#### 방법 2: 구조별 묶어 촬영
```
Session 1: 모든 책의 "후킹" 부분만 45개 촬영
Session 2: 모든 책의 "문제 공감" 부분만 45개 촬영
Session 3: 모든 책의 "솔루션" 부분만 45개 촬영
Session 4: 모든 책의 "CTA" 부분만 45개 촬영
```

**장점:**
- 같은 세팅/조명 활용
- 촬영 흐름 유지
- 시간 절약

### 🎨 템플릿 활용

#### 영상 템플릿 3-4개 제작
```
템플릿 A: 신앙서용 (따뜻한 톤)
템플릿 B: 자기계발용 (에너제틱한 톤)
템플릿 C: 전문서용 (전문적인 톤)
```

**템플릿 구성:**
- 인트로 애니메이션
- 섹션 전환 효과
- 자막 스타일
- 아웃트로 CTA

## FAQ

### Q1: 45권을 모두 한 번에 해야 하나요?

**A:** 아니요! 우선순위 높은 10-15권부터 시작하세요.
- 테스트 run으로 프로세스 검증
- 피드백 받고 개선
- 나머지 30권 진행

### Q2: 입력 정보가 부족하면 어떻게 하나요?

**A:** 최소한의 정보만 있어도 됩니다.
- 책 제목 + 저자 필수
- 나머지는 온라인 서점 정보로 보충
- AI가 일반적 패턴으로 채워줌

### Q3: 모든 영상이 비슷해 보이면?

**A:** 후킹 부분을 다르게 만드세요.
- 각 책의 핵심 차별점 강조
- 타겟 독자별 다른 문제 제기
- 시각적 요소 다양화

### Q4: 촬영 없이 스크립트만 활용할 수 있나요?

**A:** 물론입니다!
- 텍스트 기반 릴스/쇼츠 제작
- 슬라이드 + 나레이션
- AI 이미지 생성 + 스크립트
