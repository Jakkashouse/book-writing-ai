## 1. 포스팅 단계별 프로세스

| 단계 | 담당자 | 소요시간 | 체크포인트 | 산출물 |
|------|--------|----------|------------|--------|
| 1. 아이디어 확정 | 팀장 | 5분 | 프롬프트 파일 선택 완료 | 프롬프트.txt |
| 2. AI 콘텐츠 생성 | 직원 | 10분 | 프롬프트 실행 및 결과 확인 | 초안 텍스트 |

| 평가 항목 | 우수 (90점+) | 보통 (70-89점) | 개선 필요 (70점 미만) |

## 6. 체크리스트

### ✅ STEP 1: 콘텐츠 생성 전 (5분)

```
□ 프롬프트 파일 위치 확인 (경로: C:\Users\JUN\my-first-project\book-writing-ai\prompts)
□ 이번 주 포스팅 일정 확인 (위 주간 계획표 참조)
□ 타겟 고객 페르소나 상기 (예: 3040 여성, 자기계발 관심)
□ 최근 반응 좋았던 포스팅 1개 참고
```

---

### ✅ STEP 2: AI 생성 후 검토 (15분)

```
□ 맞춤법 검사 완료 (네이버 맞춤법 검사기 사용)
□ 브랜드 금지어 미사용 확인 (예: 저렴한, 싼, 할인)
□ 브랜드 선호어 포함 확인 (예: 프리미엄, 가치, 성장)
□ 문단 길이 적절 (3-5줄 이내)
□ 이모지 2-4개 포함 (과도하지 않게)
□ 타겟 고객 공감 포인트 1개 이상 포함
```

**브랜드 톤 자가진단**:
- [ ] 이 글이 우리 브랜드가 쓴 게 맞다고 느껴진다
- [ ] 경쟁사와 차별화되는 메시지가 있다
- [ ] 고객이 읽고 행동을 취할 만하다

---

### ✅ STEP 3: 이미지 준비 (20분)

```
□ 이미지 해상도 확인 (최소 1080x1080 픽셀)
□ 파일 크기 적정 (3MB 이하)
□ 브랜드 컬러 포함 여부 (메인 컬러 또는 보조 컬러)
□ 텍스트 삽입 시 가독성 확인 (폰트 크기, 대비)
□ 저작권 이슈 없는 이미지 사용 (자체 제작 또는 무료 이미지)
□ 필터 적용 시 브랜드 일관성 유지
```

**이미지 품질 자가진단**:
- [ ] 3초 안에 메시지가 전달된다
- [ ] 피드에서 스크롤을 멈추게 만든다
- [ ] 브랜드 이미지와 어울린다

---

### ✅ STEP 4: 해시태그 선정 (10분)

```
□ 해시태그 개수 15-20개
□ 브랜드 고유 해시태그 포함 (예: #우리브랜드명)
□ 인기 해시태그 3-5개 (10만+ 게시물)
□ 중간 해시태그 5-7개 (1만-10만 게시물)
□ 니치 해시태그 5-7개 (1천-1만 게시물)
□ 한글/영문 해시태그 적절히 혼합
□ 띄어쓰기 없이 작성 (예: #자기계발 ✅, #자기 계발 ❌)
```

**해시태그 예시**:
```
#자기계발 #동기부여 #성장 #책스타그램 #독서
#3040여성 #워킹맘 #커리어우먼 #자기관리
#브랜드명 #프리미엄라이프 #가치있는하루
#booklover #selfimprovement #motivation
```

---

### ✅ STEP 5: 업로드 전 최종 확인 (5분)

```
□ 캡션 첫 줄에 핵심 메시지 배치 (첫 1-2줄이 피드에 노출)
□ CTA(행동유도) 문구 포함 (예: "공감되면 저장 🔖")
□ 게시 시간 확인 (권장: 평일 19-21시, 주말 10-12시)
□ 위치 태그 추가 여부 결정
□ 협업 태그 필요 시 확인
□ 첫 댓글 준비 (추가 정보 또는 링크)
```

---

### ✅ STEP 6: 게시 후 (5분)

```
□ 노션 포스팅 데이터베이스에 기록
  - 게시 일시
  - 주제/카테고리
  - 사용한 프롬프트
  - 이미지 파일명
□ 슬랙/메신저로 완료 보고
□ 게시 후 30분 이내 댓글 모니터링
□ 오타 발견 시 즉시 수정
□ 24시간 후 인사이트 확인 예약
```

## 7. 자주 묻는 질문 (FAQ)

### Q1. 프롬프트 결과가 마음에 안 들 때는?
**A**:
1. 프롬프트 3회 재실행 (AI는 매번 다른 결과 생성)
2. 가장 나은 결과 선택 후 수동 수정
3. 그래도 안 되면 팀장에게 프롬프트 수정 요청

### Q2. 게시 시간을 꼭 지켜야 하나?
**A**:
- 권장 시간: 평일 19-21시 (퇴근 후 SNS 확인 시간대)
- ±1시간 조정 가능 (예: 급한 일정)
- 2시간 이상 차이 나면 팀장과 상의

### Q3. 댓글에 부정적 반응이 올 때는?
**A**:
1. 즉시 팀장에게 보고 (1시간 이내)
2. 절대 삭제하지 말 것
3. 답변은 팀장 검토 후 작성

### Q4. 이미지를 직접 만들어야 하나?
**A**:
- 기본: Canva 템플릿 활용 (브랜드 컬러 적용)
- 무료 이미지: Unsplash, Pexels
- 자체 제작 가능하면 더 좋음
