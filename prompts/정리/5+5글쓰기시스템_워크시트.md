# 📝 글쓰기 5+5 시스템: 말하듯 쓰면 전문가처럼 보이는 마법

> **"'육아는 힘들다'(3줄) → '밤 9시 퇴근해서 잠든 아이만 보시나요?'(1,500자) - 92%가 한 달 내 초고 완성한 비결"**

---

## 🎯 왜 5+5 시스템인가?

### 일반적인 글쓰기의 문제점
- ❌ "글을 완벽하게 써야 해" → 3년째 한 글자도 못 씀
- ❌ "좋은 문장을 써야 해" → 한 문단에 3시간
- ❌ "전문가처럼 써야 해" → 어렵게 쓰다가 포기

### 5+5 시스템의 해결책
- ✅ 질문 → 경험 → 비유 → 팁 → 체크리스트 = **1꼭지 1,500자 자동**
- ✅ 말하듯 쓰면 됩니다 → 전문가처럼 보입니다
- ✅ 5단계 공식 = 누구나 따라할 수 있습니다

## 📚 5+5 시스템 구조

### 전반부 5단계: 문제 인식 + 공감
1. **질문** (100자): 독자의 고민을 질문으로
2. **공감** (200자): "나도 그랬어요"
3. **경험** (300자): 내 실패/성공 스토리
4. **깨달음** (200자): "그때 알았습니다"
5. **전환** (100자): "이제부터 달라집니다"

### 후반부 5단계: 해결책 + 실행
6. **원리** (200자): 왜 이게 효과적인가?
7. **방법** (300자): 구체적으로 어떻게?
8. **사례** (100자): 실제 적용 사례
9. **팁** (200자): 실전 노하우
10. **체크리스트** (100자): 즉시 실행 가능한 리스트

**= 총 1,800자 (1꼭지 완성)**

- [ ] 독자가 바로 실행할 수 있나?
- [ ] 말하듯 자연스러운가?
- [ ] 질문 → 공감 → 해결 흐름이 자연스러운가?

**✅ 7개 모두 체크 = 완벽!**
**✅ 5~6개 = 좋음 (약간 보완)**
**✅ 4개 이하 = 다시 작성 권장**

## 💬 자주 묻는 질문

**Q: 5+5 순서를 꼭 지켜야 하나요?**
A: 처음엔 지키세요. 익숙해지면 자유롭게 변형 가능합니다.

**Q: 1,500자보다 짧아도 되나요?**
A: 최소 1,200자 이상 권장. 너무 짧으면 내용이 부실합니다.

**Q: AI로 전부 쓰면 안 되나요?**
A: AI는 초안용. 내 경험/스토리는 반드시 직접 써야 합니다.

**Q: 5+5로 안 써지는 주제도 있나요?**
A: 거의 없습니다. 자기계발, 비즈니스, 육아, 건강 등 모든 분야 적용 가능.

- 후반부: 해결책 8단계 (길게)

- 전반부: 문제 4단계 (길게)
- 후반부: 해결책 6단계 (짧게)
