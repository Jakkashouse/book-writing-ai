# 📄 출판 계약서 체크리스트 + 계약 전 질문 7가지

> **"전자책 권리 몰랐음. 3년간 500만원 못 받음 - 5분 체크가 평생 지킵니다"**

---

## 🎯 왜 계약서가 중요한가?

### 실제 피해 사례

**사례 1: 전자책 권리**
> "전자책 권리를 출판사에 넘겼는지 몰랐습니다.
> 3년간 전자책으로 500만원 이상 수익 발생했는데,
> 저는 한 푼도 못 받았습니다."
> - 익명 작가 (2023)

**사례 2: 유통 범위**
> "유통 범위를 확인 안 했습니다.
> 온라인 서점만 유통되고,
> 오프라인 대형 서점에는 입점도 안 됐습니다."
> - 익명 작가 (2023)

**사례 3: 인세율**
> "인세율 10%로 계약했는데,
> 나중에 알고 보니 15%도 가능했습니다.
> 1,000부 팔아서 200만원 손해 봤습니다."
> - 신인 작가 A씨

---

## ⚠️ 계약서의 진실

### 출판사는 알려주지 않는 것들
- ❌ "계약서는 다 똑같아요" → 거짓. 출판사마다 다릅니다
- ❌ "인세율은 정해져 있어요" → 거짓. 협상 가능합니다
- ❌ "여기 서명만 하세요" → 위험. 반드시 꼼꼼히 읽으세요

### 5분 체크의 힘
- 인세율 10% vs 15% = **수백만원 차이**
- 전자책 권리 = **500만원 손해 방지**
- 재출간 조건 = **평생 수익 보호**
- 유통 범위 = **판매량 2배 차이**

## ✅ 출판 계약서 5분 체크리스트

### 1단계: 기본 정보 확인 (1분)

#### 계약 당사자
- [ ] 출판사 법인명이 정확한가?
- [ ] 출판사 사업자등록번호가 있는가?
- [ ] 대표자 이름이 정확한가?
- [ ] 내 이름/주민번호가 정확한가?

#### 책 정보
- [ ] 책 제목이 정확한가?
- [ ] 분량(페이지/원고지 매수)이 명시되어 있나?
- [ ] 출간 예정일이 명시되어 있나?
- [ ] 정가가 명시되어 있나? (또는 협의 예정?)

---

### 2단계: 인세 조건 확인 (1분)

#### 인세율
- [ ] 인세율이 몇 %인가? _____%
- [ ] 정가 기준인가? 실판매가 기준인가?
- [ ] 중쇄(2쇄) 시 인세율 변동이 있나?

**업계 평균:**
| 구분 | 평균 인세율 (종이책) | 전자책 |
|------|-----------|---------|
| 신인 작가 | 5-10% | 20-25% |
| 경력 작가 | 10-15% | 20-25% |
| 베스트셀러 작가 | 15-20% | 25-30% |

**협상 팁:**
- ✅ "15%는 안 되나요?"라고 물어보세요
- ✅ "2쇄부터 12%로 올릴 수 있나요?"
- ✅ "전자책은 별도로 20%는 안 되나요?"

#### 인세 정산
- [ ] 정산 주기가 명시되어 있나? (월/분기/반기/연)
- [ ] 정산일이 명시되어 있나?
- [ ] 지급 방법이 명시되어 있나?
- [ ] 원천징수 여부가 명시되어 있나?

**주의:**
- ❌ "정산은 나중에..." → 반드시 계약서에 명시
- ❌ "팔리는 대로 드릴게요" → 정산 주기 없음 = 위험

---

### 3단계: 권리 관계 확인 (1분)

#### 저작권
- [ ] 저작권은 작가에게 있나?
- [ ] 출판권만 출판사에 주는 것인가?
- [ ] 저작권 양도가 아닌가? (절대 ❌)

**중요:**
```
✅ 출판권 설정 계약 = 좋음 (작가가 저작권 보유)
❌ 저작권 양도 계약 = 나쁨 (작가가 저작권 상실)
```

#### 전자책 권리
- [ ] 전자책(e-book) 출판권도 포함되는가?
- [ ] 전자책 인세율은 별도인가? _____%
- [ ] 전자책만 따로 계약 가능한가?

**협상 팁:**
- 종이책: 10% / 전자책: 20~25% 별도 협상 권장
- 전자책 제작비가 거의 없으므로 인세율 높게 받을 수 있음

#### 2차 저작권
- [ ] 해외 판권은 누구에게 있나?
- [ ] 영상화 권리는 누구에게 있나?
- [ ] 강연/교육 활용은 자유로운가?
- [ ] 오디오북 권리는 누구에게 있나?

**중요:**
```
✅ 2차 저작권은 작가 보유 or 수익 배분 명시
❌ 출판사에 일괄 양도 = 위험
```

---

### 4단계: 출판사 의무 확인 (1분)

#### 제작
- [ ] 출간 예정일이 명시되어 있나?
- [ ] 편집/디자인 품질 기준이 있나?
- [ ] 제작 비용은 누가 부담하나? (보통 출판사)
- [ ] 표지/내지 디자인 결정권은 누구에게 있나?

#### 유통
- [ ] 유통 범위가 명시되어 있나?
  - [ ] 온라인 서점 (예스24, 알라딘, 교보 등)
  - [ ] 오프라인 대형 서점
  - [ ] 독립 서점
  - [ ] 도서관
- [ ] 최소 유통 기간이 있나?
- [ ] 절판 조건이 명시되어 있나?

**주의:**
- ❌ "유통은 알아서 할게요" → 범위 명시 필수
- ✅ "온라인+오프라인 전국 유통" 명시

#### 마케팅
- [ ] 마케팅 지원 내용이 있나?
- [ ] SNS/블로그 홍보 지원이 있나?
- [ ] 서점 이벤트 지원이 있나?
- [ ] 마케팅 비용은 누가 부담하나?

**현실:**
- 대부분 출판사는 마케팅을 거의 안 해줌
- 작가가 직접 홍보해야 팔림
- 마케팅 지원 약속은 서면으로 받으세요

---

### 5단계: 계약 종료 조건 확인 (1분)

#### 계약 기간
- [ ] 계약 기간이 명시되어 있나? (보통 **5년**)
- [ ] 자동 연장 조항이 있나?
- [ ] 재계약 조건이 명시되어 있나?

**주의:**
- ❌ "계약 기간 없음" = 평생 묶임 = 위험
- ✅ **5년 계약** + 재협상 = 안전 (3년 협상 가능하지만 출판사는 꺼려함)

#### 중도 해지
- [ ] 중도 해지 조건이 명시되어 있나?
- [ ] 해지 위약금이 있나?
- [ ] 출판사 의무 불이행 시 해지 가능한가?

**가능한 해지 조건 예시:**
- 출간 예정일 6개월 초과 시
- 정산 3회 이상 지연 시
- 유통 의무 불이행 시

#### 절판 및 재출간
- [ ] 절판 기준이 명시되어 있나?
- [ ] 절판 시 저작권 반환 조항이 있나?
- [ ] 재출간 권리가 작가에게 있나?
- [ ] 재고 처리 방법이 명시되어 있나?

**중요:**
```
✅ 절판 시 저작권 즉시 반환
✅ 재출간 권리 작가 보유
❌ 재출간도 출판사 독점 = 위험
```

## 🗣️ 계약 전 질문 7가지 (협상력 확보)

### 질문 1: "유통 범위는 어디까지인가요?"

**왜 중요한가?**
- 온라인만 vs 온라인+오프라인 = 판매량 2배 차이
- 서울만 vs 전국 = 판매량 5배 차이

**물어볼 것:**
- "온라인 서점은 어디까지 입점되나요?" (예스24, 알라딘, 교보, 인터파크, 쿠팡 등)
- "오프라인 서점 입점도 되나요?" (교보문고, 영풍문고, 알라딘 매장 등)
- "지방 서점도 유통되나요?"
- "도서관 납품도 하시나요?"

**좋은 답변:**
- "온라인 5대 서점 + 오프라인 대형 서점 전국 유통됩니다"
- "도서관 납품도 진행합니다"

**나쁜 답변:**
- "온라인 위주로 유통됩니다" → 오프라인 없음
- "알아서 해드릴게요" → 범위 불명확

---

### 질문 2: "마케팅 지원은 어떻게 되나요?"

**왜 중요한가?**
- 출판사 마케팅 있음 vs 없음 = 판매량 3배 차이
- 대부분 출판사는 마케팅을 안 해줌

**물어볼 것:**
- "출간 전 마케팅 계획이 있나요?"
- "SNS/블로그 홍보 지원 가능한가요?"
- "서점 MD 추천/이벤트 지원이 있나요?"
- "마케팅 비용은 누가 부담하나요?"

**좋은 답변:**
- "출간 1개월 전부터 SNS 홍보 시작합니다"
- "서점 MD 추천 요청해드립니다"
- "블로그 리뷰어 30명 연결해드립니다"

**나쁜 답변:**
- "작가님이 직접 홍보하셔야 합니다" → 지원 없음
- "출간 후에 상황 봐서..." → 계획 없음

**현실:**
- 90% 출판사는 마케팅 안 해줌
- 작가가 직접 SNS/블로그 홍보해야 팔림
- 기대하지 말고, 직접 준비하세요

---

### 질문 3: "재고는 어떻게 처리되나요?"

**왜 중요한가?**
- 재고 = 창고비 = 작가 부담 가능성
- 폐기 vs 작가 인수 = 수백만원 차이

**물어볼 것:**
- "초판 부수는 몇 부인가요?"
- "재고가 남으면 어떻게 되나요?"
- "재고 보관 기간은 얼마나 되나요?"
- "재고 폐기 시 작가에게 비용 청구되나요?"
- "재고를 작가가 인수할 수 있나요? 가격은?"

**좋은 답변:**
- "재고는 출판사가 1년간 무료 보관합니다"
- "작가님 원하시면 원가에 인수 가능합니다"
- "폐기 시 비용 청구 없습니다"

**나쁜 답변:**
- "재고 창고비는 작가님 부담입니다" → 위험
- "폐기 시 비용 청구될 수 있습니다" → 위험

---

### 질문 4: "절판 기준은 무엇인가요?"

**왜 중요한가?**
- 절판 = 더 이상 팔리지 않음
- 절판 후 저작권 회수 가능 여부 = 재출간 기회

**물어볼 것:**
- "어떤 경우에 절판되나요?"
- "절판 기준이 있나요?" (판매량, 기간 등)
- "절판 시 작가에게 미리 알려주나요?"
- "절판 후 저작권이 작가에게 돌아오나요?"
- "절판 후 재출간 권리는 누구에게 있나요?"

**좋은 답변:**
- "월 판매 10부 이하 3개월 지속 시 절판 협의합니다"
- "절판 3개월 전 미리 알려드립니다"
- "절판 시 저작권 즉시 반환됩니다"
- "재출간 권리는 작가님께 있습니다"

**나쁜 답변:**
- "절판 기준 없습니다" → 언제든 절판 가능
- "재출간도 출판사 독점입니다" → 위험

---

### 질문 5: "2쇄(중쇄) 조건은 어떻게 되나요?"

**왜 중요한가?**
- 초판 완판 = 성공
- 2쇄 = 진짜 성공
- 2쇄 인세율 협상 가능

**물어볼 것:**
- "초판 부수는 몇 부인가요?"
- "초판 완판 시 2쇄 결정 기준은?"
- "2쇄부터 인세율 변동이 있나요?"
- "2쇄 결정은 누가 하나요?"

**좋은 답변:**
- "초판 **500~1,000부**, 70% 판매 시 2쇄 진행합니다" (신인 작가 기준)
- "중견 출판사는 1,000~2,000부 찍습니다"
- "2쇄부터 인세율 12%로 상향 가능합니다"
- "2쇄 결정 시 작가님과 협의합니다"

**나쁜 답변:**
- "2쇄는 출판사가 알아서 결정합니다" → 투명성 없음
- "인세율 변동 없습니다" → 협상 불가

---

### 질문 6: "독점 계약인가요?"

**왜 중요한가?**
- 독점 = 다른 출판사와 계약 불가
- 비독점 = 전자책, 해외 판권 별도 계약 가능

**물어볼 것:**
- "이 계약은 독점 계약인가요?"
- "전자책도 독점인가요?"
- "해외 판권도 독점인가요?"
- "강의/교육 자료 활용은 자유로운가요?"
- "오디오북도 독점인가요?"

**좋은 답변:**
- "종이책만 독점, 전자책은 별도 계약 가능합니다"
- "해외 판권은 작가님께 있습니다"
- "강의/교육 자료 활용은 자유롭습니다"

**나쁜 답변:**
- "모든 권리 독점 계약입니다" → 위험
- "다른 곳과 계약 불가합니다" → 자유 제한

---

### 질문 7: "계약 해지 조건은 무엇인가요?"

**왜 중요한가?**
- 출판사가 의무를 안 지킬 때 탈출구 필요
- 계약 해지 불가 = 평생 묶임

**물어볼 것:**
- "중도 해지가 가능한가요?"
- "어떤 경우에 해지할 수 있나요?"
- "해지 시 위약금이 있나요?"
- "출판사가 의무를 안 지키면 즉시 해지 가능한가요?"
- "해지 후 저작권은 누구에게 있나요?"

**좋은 답변:**
- "출간 6개월 지연 시 즉시 해지 가능합니다"
- "정산 3회 지연 시 해지 가능합니다"
- "해지 시 위약금 없습니다"
- "해지 후 저작권은 작가님께 반환됩니다"

**나쁜 답변:**
- "중도 해지 불가합니다" → 위험
- "위약금 500만원입니다" → 사실상 불가능
- "해지 후에도 출판권은 출판사에 있습니다" → 위험

## 📋 계약 전 협상 시나리오

### 시나리오 1: 인세율 협상

**출판사:** "인세는 10%입니다."

**작가(나쁜 답변):** "네, 알겠습니다."

**작가(좋은 답변):**
"다른 출판사에서 12~15% 제안받았는데,
여기선 15%는 어려울까요?
아니면 2쇄부터 12%로 상향 가능할까요?"

**결과:**
- 협상 시도 = 50% 확률로 인세율 ↑
- 협상 안 함 = 0% 확률

---

### 시나리오 2: 전자책 권리 협상

**출판사:** "전자책도 포함해서 계약합니다."

**작가(나쁜 답변):** "네, 알겠습니다."

**작가(좋은 답변):**
"전자책 인세율은 별도인가요?

## 🚨 절대 하면 안 되는 것

### 1. 저작권 양도 계약
```
❌ "저작권을 출판사에 양도한다"
✅ "출판권을 출판사에 설정한다"
```
- 저작권 양도 = 내 책이 아님
- 출판권 설정 = 내 책, 출판만 위임

### 2. 계약 기간 없음
```
❌ "계약 기간: 명시 없음"
✅ "계약 기간: 5년 (재협상 가능)"
```
- 기간 없음 = 평생 묶임
- **5년** = 재협상 기회 (3년 협상 가능하지만 출판사는 꺼려함)

### 3. 중도 해지 불가
```
❌ "중도 해지 불가"
✅ "출판사 의무 불이행 시 즉시 해지 가능"
```

### 4. 구두 약속만 믿기
```
❌ "마케팅은 나중에 해드릴게요" (구두)
✅ 계약서에 명시 또는 이메일로 받기
```

### 5. 서명 전 변호사 검토 생략
```
⚠️ 중요한 계약은 변호사 검토 권장
💰 비용: 10~30만원 (1회)
```

## 💡 프로 팁

### Tip 1: 계약서는 2부 작성
- 출판사 1부 + 작가 1부
- 각자 직인/서명
- 평생 보관

### Tip 2: 모든 커뮤니케이션 기록
- 카카오톡, 이메일 보관
- 출판사 약속 = 서면으로 받기
- 나중에 증거 자료

### Tip 3: 비교하기
- 최소 3곳 이상 출판사 비교
- 조건 표로 정리
- 유리한 조건 선택

### Tip 4: 협상은 당당하게
- "다른 곳에서 더 좋은 조건 받았는데..."
- "이 조건은 어려울 것 같은데 조정 가능한가요?"
- 침묵 = 0% 확률 / 협상 = 50% 확률

### Tip 5: 급하게 서명하지 말기
- "오늘 서명해야 해요" → 의심
- 최소 3일 검토 후 서명
- 주변에 물어보기

A: 즉시 변호사 상담. 계약 무효/취소 가능 여부 확인.
