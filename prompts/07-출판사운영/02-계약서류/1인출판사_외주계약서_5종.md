# 📋 1인 출판사 외주 계약서 5종

> **법적 효력**: 본 계약서는 참고용이며, 실제 사용 시 법무사 검토 권장

## 1️⃣ 편집자 외주 계약서

```markdown
[ 출판 편집 외주 계약서 ]

계약일: 20__년 __월 __일

■ 발주자 (갑)
- 상호: ___________________
- 대표: ___________________
- 연락처: _________________

■ 수주자 (을)
- 성명: ___________________
- 연락처: _________________
- 계좌: ___________________

■ 계약 내용
1. 작업물: 「_____________」 편집 (총 ___페이지 예상)
2. 범위:
   □ 원고 교정/교열
   □ 레이아웃 조정
   □ 인디자인 작업
   □ 최종 PDF 제작
   □ 기타: ___________________

3. 일정:
   - 계약일: 20__년 __월 __일
   - 초고 납품: 20__년 __월 __일
   - 1차 수정: 20__년 __월 __일
   - 최종 납품: 20__년 __월 __일

4. 대금:
   - 총액: ________________원 (VAT 별도/포함)
   - 계약금 (30%): __________원 (계약 시)
   - 중도금 (40%): __________원 (초고 납품 시)
   - 잔금 (30%): ___________원 (최종 납품 시)

5. 수정:
   - 무상 수정: 2회
   - 3회차부터: 회당 ________원

6. 저작권:
   - 편집 결과물 저작권은 '갑'에게 귀속
   - '을'은 포트폴리오 목적으로만 사용 가능

7. 기밀유지:
   - '을'은 원고 내용을 제3자에게 공개 금지
   - 위반 시 손해배상 책임

8. 해지:
   - 일방 해지 시 7일 전 서면 통지
   - 기 지급 금액은 작업 진행률에 따라 정산

갑: _____________________ (인)
을: _____________________ (인)
```

## 2️⃣ 표지 디자이너 계약서

```markdown
[ 표지 디자인 외주 계약서 ]

계약일: 20__년 __월 __일

■ 발주자 (갑)
- 상호: ___________________
- 대표: ___________________
- 연락처: _________________

■ 디자이너 (을)
- 성명: ___________________
- 연락처: _________________
- 계좌: ___________________

■ 계약 내용
1. 작업물: 「_____________」 표지 디자인
   - 크기: 국판 / 신국판 / 기타 (_________)
   - 페이지: 앞표지 + 뒤표지 + 날개 + 띠지

2. 시안:
   - 초안 제출: ___개 (컨셉 다르게)
   - 제출일: 20__년 __월 __일
   - 선택 후 수정: 2회 무상

3. 일정:
   - 초안 제출: 20__년 __월 __일
   - 최종 확정: 20__년 __월 __일
   - 인쇄용 파일: 20__년 __월 __일

4. 대금:
   - 총액: ________________원 (VAT 별도/포함)
   - 계약금 (50%): __________원 (계약 시)
   - 잔금 (50%): ___________원 (최종 파일 납품 시)

5. 납품 형식:
   - AI 파일 (편집 가능)
   - PDF (인쇄용, 300dpi)
   - JPG (미리보기용)

6. 저작권:
   - 최종 결과물 저작권은 '갑'에게 양도
   - '을'은 포트폴리오 사용 가능 (출판 후)

7. 수정:
   - 2회 무상 수정 (초안 선택 후)
   - 3회차부터: 회당 _______원
   - 컨셉 전면 변경 시: 추가 _______원

8. 책임:
   - 저작권 침해 소지 있는 이미지 사용 금지
   - 위반 시 '을'이 전적으로 책임

갑: _____________________ (인)
을: _____________________ (인)
```

## 3️⃣ 인쇄소 계약서

```markdown
[ 도서 인쇄 계약서 ]

계약일: 20__년 __월 __일

■ 발주자 (갑)
- 상호: ___________________
- 대표: ___________________
- 연락처: _________________

■ 인쇄소 (을)
- 상호: ___________________
- 대표: ___________________
- 사업자번호: _____________
- 주소: ___________________

■ 인쇄 사양
1. 도서명: 「_____________」
2. 판형: 국판 / 신국판 / 기타 (_______)
3. 페이지: 본문 ____p + 표지 4p
4. 수량: ______부
5. 종이:
   - 본문: 백상지 80g / 미색 80g / 기타 (_______)
   - 표지: 아트지 250g / 스노우지 / 기타 (_______)
6. 인쇄:
   - 본문: 1도(흑백) / 4도(컬러)
   - 표지: 4도(컬러) + 코팅 (유광/무광/양면)
7. 제본: 무선제본 / 양장 / 기타 (_______)

■ 일정 및 비용
1. 인쇄 일정:
   - 파일 입고: 20__년 __월 __일
   - 초도 확인: 20__년 __월 __일
   - 납품 완료: 20__년 __월 __일

2. 비용:
   - 총액: ________________원 (VAT 포함)
   - 부당: ______원
   - 계약금 (50%): _________원 (계약 시)
   - 잔금 (50%): __________원 (납품 시)

3. 납품:
   - 장소: ___________________
   - 배송비: 갑 부담 / 을 부담

■ 하자 및 책임
1. 초도 확인 후 발견된 인쇄 오류는 '을'이 책임
2. 원고 오류는 '갑'이 책임
3. 초도 통과 후 수정 시 추가 비용 '갑' 부담

■ 기타
- ISBN 바코드 인쇄 포함
- 불량률 3% 이내 허용
- 추가 인쇄 시 부당 ______원 (____부 이상)

갑: _____________________ (인)
을: _____________________ (인)
```

## 4️⃣ 작가 계약서 (출판사 ↔ 작가)

```markdown
[ 출판 계약서 ]

계약일: 20__년 __월 __일

■ 출판사 (갑)
- 상호: ___________________
- 대표: ___________________
- 주소: ___________________
- 사업자번호: _____________

■ 저작자 (을)
- 성명: ___________________
- 주소: ___________________
- 연락처: _________________
- 계좌: ___________________

■ 저작물 정보
- 도서명: 「_____________」
- 분량: 약 _____매 (200자 원고지 기준)
- 예상 페이지: _____p
- 예상 정가: _____원

■ 계약 내용
1. 출판권:
   - '을'은 본 저작물의 출판권을 '갑'에게 부여
   - 기간: 계약일로부터 __년 (자동 연장 ○/×)
   - 범위:
     □ 종이책 (국내)
     □ 전자책 (국내)
     □ 해외 판권
     □ 오디오북
     □ 2차 저작물 (강의, 영상 등)

2. 원고:
   - 납품일: 20__년 __월 __일
   - 형식: 한글(HWP) / 워드(DOCX)
   - '을'은 표절 없는 독창적 저작물임을 보증

3. 인세:
   - 종이책: 정가 기준 __% (보통 10-15%)
   - 전자책: 정가 기준 __% (보통 15-20%)
   - 정산: 연 2회 (6월 말 / 12월 말)
   - 지급: 정산 후 30일 이내

4. 출판 부수:
   - 초판: _____부
   - 증쇄 조건: 재고 __부 이하 시

5. 저작자 제공 부수:
   - 무상: ___부
   - 저자 구매 시: 정가의 __%

6. 편집 및 제작:
   - '갑'이 편집/디자인 전권
   - 단, 내용 수정 시 '을'의 동의 필요

7. 홍보 및 마케팅:
   - '갑'이 주관
   - '을'은 합리적 범위 내 협조

8. 절판:
   - 조건: 연간 판매 __부 미만 시
   - '을'은 출판권 회수 가능

9. 계약 해지:
   - 상호 합의 시 가능
   - 일방 해지 시 __개월 전 서면 통지
   - '을'의 원고 미납 또는 표절 시 '갑'의 즉시 해지 가능

10. 기타:
    - 저작권 등록: '을' 명의
    - 분쟁 발생 시: __지방법원 관할

본 계약의 성실한 이행을 위해 계약서 2부를 작성하여
각각 1부씩 보관합니다.

갑: _____________________ (인)
을: _____________________ (인)
```

## 5️⃣ 서평단/베타리더 계약서

```markdown
[ 베타리더 협약서 ]

협약일: 20__년 __월 __일

■ 출판사 (갑)
- 상호: ___________________
- 연락처: _________________

■ 베타리더 (을)
- 성명: ___________________
- 연락처: _________________

■ 협약 내용
1. 대상 도서: 「_____________」 (출간 예정)

2. '을'의 역할:
   □ 원고 검토 (오탈자, 문맥, 가독성)
   □ 피드백 제출 (설문지 작성)
   □ 서평 작성 (출간 후 온라인 게시)
   □ SNS 홍보 협조

3. 일정:
   - 원고 제공: 20__년 __월 __일
   - 피드백 제출: 20__년 __월 __일 (__ 주 이내)
   - 서평 게시: 출간 후 __ 주 이내

4. 제공 사항:
   - 출간 전 원고 (PDF/출력물)
   - 출간 후 정식 책 __부 무료 제공

5. 기밀유지:
   - '을'은 원고 내용을 제3자에게 공개 금지
   - SNS 언급 시 '갑'의 사전 승인 필요
   - 출간 전까지 내용 누설 절대 금지

6. 서평 가이드:
   - 긍정적 리뷰 강요 없음 (솔직한 의견 환영)
   - 최소 분량: ___자 이상
   - 게시 플랫폼: 예스24/알라딘/교보문고 중 1곳 이상

7. 책임:
   - '을'의 기밀 누설 시 손해배상 청구 가능
   - '을'의 서평 미이행 시 제공된 책 반환 또는 정가 지불

8. 해지:
   - 상호 합의 시 가능
   - '을'의 일방적 중단 시 책 반환

본 협약서는 신뢰를 바탕으로 하며,
양측의 합의 하에 작성되었습니다.

갑: _____________________ (인)
을: _____________________ (인)
```

## ⚠️ 사용 전 체크리스트

### 1. 법적 검토
- [ ] 금액이 큰 계약(500만원 이상)은 법무사 검토 권장
- [ ] 세금계산서 발행 여부 확인 (VAT 포함/별도)

### 2. 필수 수정 사항
- [ ] 회사명, 대표자명 정확히 기입
- [ ] 금액, 날짜, 수량 빠짐없이 작성
- [ ] 양측 서명/날인 확인

### 3. 보관
- [ ] 원본 2부 작성 (각 1부씩 보관)
- [ ] PDF 스캔 후 클라우드 백업
- [ ] 세금계산서, 입금 증빙 함께 보관

## 💡 실전 팁

### 계약서 작성 실수 방지
1. **금액은 숫자+한글 병기**
   - 예: 1,500,000원 (일백오십만원)

2. **날짜는 구체적으로**
   - ❌ "2주 이내"
   - ✅ "2024년 1월 15일까지"

3. **애매한 표현 금지**
   - ❌ "적절한 수준"
   - ✅ "2회 무상, 3회차부터 회당 10만원"

4. **증빙 남기기**
   - 카카오톡 대화 캡처
   - 이메일 계약 내용 정리 후 발송
   - 입금 시 거래 내역 보관
