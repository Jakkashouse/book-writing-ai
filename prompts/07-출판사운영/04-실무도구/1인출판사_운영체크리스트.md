## 1. 출판사 설립 (10단계)

### ✅ 사전 준비 (1-3)
- [ ] 1. 출판사 이름 정하기
  - 중복 확인: [국립중앙도서관 ISBN](https://seoji.nl.go.kr)
  - 도메인 확인: [후이즈](https://whois.co.kr)
  - SNS 계정명 확인: 인스타/유튜브

- [ ] 2. 사업자 등록
  - 개인사업자 or 법인?
  - 세무서 방문 or 홈택스
  - 준비물: 신분증, 사무실 주소 (자택 가능)
  - 비용: 무료 (단, 법인은 약 50-100만원)

- [ ] 3. 사업자 통장 개설
  - 은행 선택 (카카오뱅크 추천: 온라인 가능)
  - 사업자등록증 필요

### ✅ 출판사 신고 (4-6)
- [ ] 4. 출판사 신고
  - 신고 기관: 관할 교육청 (서울시교육청 등)
  - 온라인: 정부24
  - 준비물: 사업자등록증 사본
  - 비용: 무료
  - 처리 기간: 즉시 (온라인) / 3일 (방문)

- [ ] 5. ISBN 발급 기관 등록
  - 사이트: [국립중앙도서관 ISBN](https://seoji.nl.go.kr)
  - 준비물: 출판사 신고증, 사업자등록증
  - 비용: 무료
  - 발급: 즉시 (온라인)

- [ ] 6. CIP 신청 (선택)
  - CIP = 출판예정도서목록
  - 국립중앙도서관에서 무료 발급
  - 책 출간 전에 신청 → ISBN과 함께 발급

### ✅ 시스템 구축 (7-10)
- [ ] 7. 협력사 확보
  - 편집자 1-2명 (네트워크)
  - 디자이너 1-2명 (포트폴리오 확인)
  - 인쇄소 2-3곳 (견적 비교)

- [ ] 8. AI 프롬프트 세팅
  - ChatGPT Plus or Claude Pro 가입
  - 프롬프트 27종 설치
  - 템플릿 폴더 정리 (구글 드라이브/노션)

- [ ] 9. 홈페이지 or 랜딩페이지
  - 간단한 1페이지 사이트
  - 필수 항목: 출판사 소개, 대표 도서, 연락처
  - 툴 추천: Wix, Notion, Carrd (무료 가능)

- [ ] 10. SNS 계정 개설
  - 인스타그램 (필수)
  - 유튜브 (선택)
  - 블로그 (네이버 or 티스토리)

## 2. 책 1권 출간 (30단계)

### 📝 기획 단계 (1-5일)
- [ ] 1. 저자 확보
  - 직접 집필 or 외부 저자
  - 계약서 작성 (외부 저자일 경우)

- [ ] 2. 주제/타겟 확정
  - 독자: 누구?
  - 문제: 무엇?
  - 해결: 어떻게?

- [ ] 3. 경쟁 도서 분석
  - 예스24/알라딘 베스트셀러 10권 리서치
  - 차별점 3가지 도출

- [ ] 4. 제목 10개 뽑기
  - AI 프롬프트 활용
  - 지인 10명에게 투표

- [ ] 5. 목차 40꼭지 완성
  - Why-What-How-Do-Future 5부 구조
  - 1꼭지 = 1,500자 기준

### ✍️ 집필 단계 (30일)
- [ ] 6. 집필 시작
  - 하루 1-2꼭지씩
  - 주 5일 → 8주 완성

- [ ] 7. AI 활용 (80% 자동화)
  - 도입부 후킹
  - 스토리텔링
  - 비유/사례
  - 체크리스트

- [ ] 8. 베타리더 모집
  - 5-10명
  - 협약서 작성
  - 피드백 수집 (2주)

- [ ] 9. 1차 수정
  - 베타리더 의견 반영
  - 오탈자 수정
  - 가독성 개선

### 🎨 편집/디자인 단계 (15일)
- [ ] 10. 편집자 섭외
  - 계약서 작성
  - 원고 전달
  - 일정 확정 (보통 2주)

- [ ] 11. 편집 진행
  - 교정/교열
  - 레이아웃 조정
  - 인디자인 작업

- [ ] 12. 표지 디자이너 섭외
  - 포트폴리오 확인
  - 컨셉 브리핑
  - 계약서 작성

- [ ] 13. 표지 시안 확인
  - 초안 3개 중 선택
  - 2회 수정
  - 최종 확정

- [ ] 14. ISBN 발급
  - 국립중앙도서관 사이트
  - 도서명, 저자명, 정가, 페이지 입력
  - 발급 (즉시)

- [ ] 15. 바코드 제작
  - ISBN 13자리 → 바코드 생성기
  - 표지 디자이너에게 전달

### 🖨️ 인쇄 단계 (7일)
- [ ] 16. 인쇄소 견적 비교
  - 최소 3곳 비교
  - 사양: 페이지, 판형, 종이, 수량

- [ ] 17. 인쇄소 선정 및 계약
  - 계약서 작성
  - 계약금 입금 (보통 50%)

- [ ] 18. 인쇄 파일 전달
  - 표지: AI + PDF (300dpi)
  - 본문: PDF (인쇄용)

- [ ] 19. 초도 확인
  - 인쇄소 방문 or 사진 확인
  - 색상, 오탈자 최종 점검

- [ ] 20. 인쇄 진행
  - 보통 3-7일 소요
  - 잔금 입금 (납품 시)

### 📦 유통 단계 (10일)
- [ ] 21. 납품 받기
  - 배송지 확인
  - 수량/품질 확인

- [ ] 22. 서점 유통 신청
  - 대형: 교보문고, 영풍문고, 예스24, 알라딘
  - 온라인: 쿠팡, 11번가
  - 신청 방법: 각 사이트 '출판사 입점' 메뉴

- [ ] 23. 국립중앙도서관 납본
  - 의무: 2부 무료 납본
  - 주소: 서울 서초구 반포대로 201
  - 납본증 발급 → 정부지원금 신청 시 필요

- [ ] 24. 온라인 서점 등록 완료 확인
  - 예스24/알라딘 검색 확인
  - 책 소개, 저자 소개 수정

### 📢 마케팅 단계 (30일)
- [ ] 25. 출간 30일 전: SNS 티저
  - "새 책 준비 중입니다"
  - 표지 일부 공개

- [ ] 26. 출간 15일 전: 예약판매
  - 지인 50명에게 연락
  - "출간 전 특가" 이벤트

- [ ] 27. 출간 7일 전: 서평단 모집
  - SNS/블로그 공지
  - 무료 제공 (대신 서평 필수)

- [ ] 28. 출간일: 대대적 공지
  - SNS 전체 공개
  - 이벤트 (댓글 추첨 등)

- [ ] 29. 출간 후 1주: 리뷰 요청
  - 구매자에게 리뷰 부탁 메시지
  - 긍정 리뷰 → SNS 공유

- [ ] 30. 출간 후 1개월: 강의 제안
  - 기업/기관 10곳에 메일
  - 강의 제안서 첨부

## 3. 월별 운영 체크리스트

### 📅 매월 1일
- [ ] 전월 매출 정산
  - 온라인 서점 판매 수량 확인 (예스24 관리자 페이지)
  - 오프라인 서점 정산서 확인
  - 엑셀 기록

- [ ] 재고 확인
  - 남은 재고 파악
  - 증쇄 필요 여부 판단 (재고 20부 이하 시)

- [ ] SNS 콘텐츠 계획
  - 이번 달 주제 선정
  - 주 2회 포스팅 계획

### 📅 매월 15일
- [ ] 신규 저자 발굴
  - 네트워킹 (독서모임, 온라인 커뮤니티)
  - 기획서 받은 것 검토

- [ ] 협력사 관리
  - 편집자/디자이너에게 안부 메시지
  - 다음 프로젝트 일정 공유

### 📅 매월 말일
- [ ] 세금계산서 발행
  - 판매 대금에 대한 세금계산서
  - 외주 비용 받은 세금계산서 정리

- [ ] 다음 달 목표 설정
  - 신간 기획 진행 상황
  - 강의/컨설팅 일정

## 4. 수익화 체크리스트

### 💰 책 판매 수익
- [ ] 온라인 서점 판매 (인세 35-40%)
- [ ] 오프라인 서점 판매 (인세 30-35%)
- [ ] 직접 판매 (100% 수익)
  - 강의 현장에서 판매
  - SNS 직거래

### 💰 강의 수익
- [ ] 강의 제안서 작성
- [ ] 기업/기관 10곳에 메일 발송 (매월)
- [ ] 강의 후 후기 수집 → 다음 제안 시 활용

### 💰 컨설팅 수익
- [ ] 책 주제 관련 1:1 컨설팅 상품 기획
- [ ] 가격 책정 (시간당 10-30만원)
- [ ] 랜딩페이지 or SNS에 안내

### 💰 온라인 강의
- [ ] 책 내용 → 온라인 강의 (40개 영상)
- [ ] 플랫폼: 클래스101, 탈잉, 자체 사이트
- [ ] 가격: 5-30만원

### 💰 1인 출판사 확장
- [ ] 다른 저자 책 출간 (연 4-12권)
- [ ] 출판사 수수료 (보통 인세의 50%)

## 5. 위기 대응 체크리스트

### 🚨 책이 안 팔려요 (월 10부 이하)
- [ ] 원인 분석
  - 표지가 안 예쁜가?
  - 제목이 안 끌리나?
  - 타겟이 명확하지 않나?

- [ ] 즉시 대응
  - 표지 리뉴얼 (2쇄부터)
  - SNS 마케팅 강화 (주 3회 → 매일)
  - 무료 나눔 이벤트 (30부)

- [ ] 중장기 대응
  - 강의/컨설팅으로 전환
  - 책 = 명함으로 활용

### 🚨 편집자/디자이너가 잠수탔어요
- [ ] 즉시 연락 (전화, 문자, 이메일)
- [ ] 3일 연락 두절 시:
  - 계약서 확인 (위약 조항)
  - 대체 인력 섭외 시작

- [ ] 예방
  - 중요 프로젝트는 중도금 지급 후 진행
  - 중간 결과물 수시로 확인

### 🚨 인쇄 오류 (오탈자, 색상 이상)
- [ ] 초도 확인 미스 → 인쇄소와 협의
  - 재인쇄 요구 (인쇄소 과실 시)
  - 비용 분담 협의

- [ ] 원고 오류 → 본인 책임
  - 스티커로 정오표 부착
  - 2쇄에서 수정

### 🚨 저자와 갈등 (인세, 마케팅 불만 등)
- [ ] 계약서 재확인
- [ ] 중재 노력
  - 현재 판매 수량 투명 공개
  - 추가 마케팅 방안 제시

- [ ] 최악의 경우
  - 계약 해지 조항 확인
  - 법률 자문 (변호사, 법무사)

### 🚨 현금 흐름 문제
- [ ] 단기 대응
  - 외주 일정 조정 (결제 늦추기)
  - 직접 판매 강화 (즉시 현금화)

- [ ] 중장기 대응
  - 정부지원금 신청 (예비창업패키지)
  - 대출 (신용대출, 사업자대출)

## ✅ 마지막 체크: "이것만은 꼭!"

### 출판사 운영 3대 원칙
1. **계약서 필수**
   - 모든 거래는 계약서로
   - 구두 약속 절대 금지

2. **증빙 자료 보관**
   - 세금계산서, 입금 내역, 이메일
   - 최소 5년 보관 (세무 대비)

3. **현금 흐름 관리**
   - 수입/지출 엑셀 기록
   - 통장 분리 (개인/사업자)
