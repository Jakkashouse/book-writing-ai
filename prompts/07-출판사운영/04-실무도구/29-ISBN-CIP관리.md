## 3. 발급 체크리스트

### ISBN 발급 전
- [ ] 국립중앙도서관 ISBN 센터 로그인
- [ ] 출판사 정보 확인 (신고번호, 대표자)
- [ ] 기존 발급 ISBN 번호 확인 (중복 방지)

### ISBN 신청
- [ ] 도서 기본정보 입력
- [ ] 분류정보 입력
- [ ] ISBN 번호 발급 (즉시)
- [ ] 바코드 생성 (ISBN 13자리)

### CIP 신청 (선택)
- [ ] CIP 신청서 작성
- [ ] 표지 시안 첨부
- [ ] 목차 파일 첨부
- [ ] 승인 대기 (3-5일)

### 발급 후
- [ ] ISBN을 표지 디자이너에게 전달
- [ ] 바코드를 뒤표지에 배치 확인
- [ ] CIP 정보를 판권페이지에 삽입

## 활용 팁

1. **ISBN 번호 관리**: 엑셀로 발급 번호 기록 (책별로 정리)
2. **CIP 필수 여부**: 선택이지만, 공신력 + 도서관 납품 시 유리
3. **전자책 ISBN**: 종이책과 별도 발급 필요
