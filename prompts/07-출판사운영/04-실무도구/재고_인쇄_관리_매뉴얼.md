## 2. 재고 기준표

### 적정 재고 기준

| 구분 | 기준 | 비고 |
|------|------|------|
| **최소 재고** | 월 판매량 × 1개월 | 이 이하면 인쇄 검토 |
| **적정 재고** | 월 판매량 × 2~3개월 | 유지 목표 |
| **과다 재고** | 월 판매량 × 6개월 이상 | 주의 필요 |

### 재고 상태 분류

| 상태 | 기준 | 조치 |
|------|------|------|
| 🔴 긴급 | 2주 이내 소진 예상 | 즉시 인쇄 발주 |
| 🟡 주의 | 1개월 이내 소진 예상 | 인쇄 검토, 대표 보고 |
| 🟢 정상 | 1개월 이상 재고 | 현행 유지 |
| ⚪ 과다 | 6개월 이상 재고 | 판촉 검토 |

## 4. 대량 인쇄 (오프셋)

### 발주 기준
- 인쇄 부수: ___부 이상
- 예상 판매 기간: ___개월 이상 분량
- 권당 단가가 소량 대비 ___% 이상 저렴할 때

### 발주 프로세스

```
1. 재고 부족 확인
      ↓
2. 인쇄 부수 산정 (아래 계산법 참고)
      ↓
3. 대표에게 승인 요청
   - 도서명
   - 현재고
   - 월 평균 판매량
   - 요청 부수
   - 예상 비용
      ↓
4. 승인 후 인쇄소에 발주
      ↓
5. 인쇄 파일 전달 (기존 파일 확인)
      ↓
6. 샘플 확인 (필요시)
      ↓
7. 인쇄 완료 → 총판 입고
      ↓
8. 입고 확인 및 기록
```

### 인쇄 부수 산정법

```
권장 인쇄 부수 = 월 평균 판매량 × ___개월

예시:
- 월 평균 판매: 100부
- 기준: 6개월분
- 인쇄 부수: 600부
```

## 5. 소량 인쇄 (POD/디지털)

### 발주 기준
- 인쇄 부수: ___부 이하
- 긴급 재고 보충 필요시
- 판매량 적어 대량 인쇄 부담될 때

### 발주 프로세스

```
1. 재고 부족 확인
      ↓
2. 소량 인쇄 적합 여부 판단
   - 긴급성
   - 예상 판매량
   - 단가 비교
      ↓
3. 인쇄소에 직접 발주
      ↓
4. 발주 내역 기록
      ↓
5. 인쇄 완료 → 입고
      ↓
6. 대표에게 사후 보고
```

### 직접 발주 가능 범위

| 조건 | 기준 |
|------|------|
| 부수 | ___부 이하 |
| 비용 | ___원 이하 |
| 도서 | 기존 인쇄 이력 있는 책 |

### 발주 시 체크리스트

- [ ] 인쇄 파일 최신 버전 확인
- [ ] 정가 변동 없는지 확인
- [ ] ISBN 바코드 확인
- [ ] 납품 주소 확인

## 10. 문제 상황 대응

### 인쇄 품질 불량

```
1. 불량 내용 사진 촬영
2. 인쇄소에 즉시 연락
3. 대표에게 보고
4. 불량 부수 확인
5. 재인쇄/보상 협의
```

### 납기 지연

```
1. 인쇄소에 사유 확인
2. 예상 납품일 확인
3. 재고 소진 예상일과 비교
4. 대표에게 보고
5. 필요시 소량 인쇄로 긴급 대응
```

### 파일 오류

```
1. 오류 내용 확인
2. 원본 파일 점검
3. 디자이너에게 수정 요청 (필요시)
4. 수정 파일 재전달
5. 일정 영향 확인
```

### 입고 후 체크리스트

- [ ] 수량 맞는가?
- [ ] 인쇄 품질 이상 없는가?
- [ ] 제본 상태 양호한가?
- [ ] 재고 시스템에 반영했는가?
- [ ] 발주 기록 업데이트했는가?

## 부록: 용어 정리

| 용어 | 설명 |
|------|------|
| **오프셋 인쇄** | 대량 인쇄에 적합한 전통 인쇄 방식 |
| **POD** | Print On Demand, 주문형 소량 인쇄 |
| **디지털 인쇄** | 소량에 적합한 인쇄 방식 |
| **총판** | 서점에 책을 유통하는 도매업체 |
| **배본** | 서점에 책을 배송하는 것 |
| **리드타임** | 발주~납품까지 걸리는 시간 |
| **도련** | 재단 시 잘릴 여유 영역 |
