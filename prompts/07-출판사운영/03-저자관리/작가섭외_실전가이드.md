## 1. 브런치 작가 섭외

### 브런치란?
- 카카오에서 운영하는 **글쓰기 플랫폼**
- 현재 **7만여 명의 작가** 활동 중
- 책 출간을 꿈꾸는 작가 지망생이 많음
- 브런치북 출판 프로젝트로 실제 출간 사례 다수

### 브런치 출신 베스트셀러
| 작가 | 책 제목 |
|------|--------|
| 정문정 | 『무례한 사람에게 웃으며 대처하는 법』 |
| 보름 | 『어서 오세요, 휴남동 서점입니다』 |
| 정지음 | 『젊은 ADHD의 슬픔』 |

---

### 따뜻한 글 작가 찾는 방법

**Step 1: 브런치 접속**
- PC: https://brunch.co.kr
- 앱: 브런치스토리 (iOS/Android)

**Step 2: 키워드 검색**
```
추천 검색어:
- "위로"
- "따뜻한 하루"
- "일상 에세이"
- "혼자 사는 이야기"
- "시골 생활"
- "퇴근 후"
- "부모님"
- "작은 행복"
```

**Step 3: 작가 선별 기준**
- 구독자 수: 100~5,000명 (너무 유명하지 않은)
- 글 발행 주기: 꾸준히 쓰는 분
- 댓글 소통: 독자와 교류하는 분
- 프로필에 이메일/연락처 공개 여부

**Step 4: 연락하기**
- 브런치 내 **메시지 기능** 활용
- 프로필에 이메일 있으면 **이메일 발송**
- 응원하기(후원) 댓글로 **정중히 제안**

## 2. KBS 인간극장 제작진 연락

### 프로그램 정보
- **방송**: KBS1 평일 오전 7:50~8:25
- **성격**: 휴먼 다큐멘터리 (2000년 시작, 25년 역사)
- **특징**: 일반인의 감동적인 삶을 5일간 밀착 취재

### 연락 방법

**방법 1: KBS 시청자센터**
```
전화: 1588-1801
- 인간극장 제작팀 연결 요청
- "과거 출연자 중 책 출간 협조 가능한 분 문의" 설명
```

**방법 2: KBS 홈페이지 게시판**
```
1. program.kbs.co.kr 접속
2. 인간극장 프로그램 페이지 찾기
3. 시청자 게시판에 문의글 작성
```

**방법 3: KBS 시사교양본부 직접 연락**
```
KBS 본사: 02-781-1000
→ 시사교양본부 → 인간극장 담당 PD 연결 요청
```

## 3. 실행 체크리스트

### 이번 주 할 일
- [ ] 브런치 앱 설치 및 가입
- [ ] 키워드로 작가 10명 이상 탐색
- [ ] 마음에 드는 작가 3명 선정
- [ ] 각 작가에게 맞춤 메시지 발송
- [ ] KBS 시청자센터 전화 (1588-1801)

### 메시지 발송 팁
1. **구체적으로** - "글이 좋아요" (X) → "○○ 글에서 ○○ 부분이 인상 깊었어요" (O)
2. **짧게** - 첫 메시지는 5줄 이내
3. **부담 없이** - "관심 있으시면 연락주세요" 정도로 마무리
4. **여러 명에게** - 1명에게만 보내지 말고 5~10명에게 동시 발송
