# 작가 커뮤니티 운영 가이드

> 60명 규모 카카오톡 기반 커뮤니티 운영 방안

---

## 📋 전체 구조

### 커뮤니티 구성
- **VIP 초고 과정**: 10명 내외, 별도 밀착 코칭
- **메인 커뮤니티**: 50-60명, 카카오톡 1개 방
- **월간 집중 코칭**: 희망자 10-15명 순환 운영

### 참여 자격
- 코칭 중인 작가
- 투고로 출간한 작가
- 코칭으로 출간한 작가
- **모든 작가가 처음부터 끝까지 함께**

---

## 💬 카카오톡 운영 (1개 방)

### 기본 원칙
✅ **단톡방 1개로 모든 소통**
✅ 형식과 타이밍으로 중요도 구분
✅ 자유로운 분위기 + 체계적 관리

### 메시지 형식 구분

**중요 공지**
```
[공지] 제목 🎉
[필독] 제목 📅
```

**일상 소통**
```
자유롭게 작성
서로 격려하고 질문 답변
```

### 카톡 기능 활용
- 📌 **공지 고정**: 가장 중요한 것 1개만
- 👍 **반응 기능**: 중요 메시지에 리액션 유도
- 💬 **답장 기능**: 스레드 정리

---

## 📅 운영 루틴

### 주간 루틴

**월요일 오전 9시**
```
[필독] 이번 주 시작 메시지
- 격려 한마디
- 주요 일정
- 특별 공지
```

**금요일 저녁**
```
이번 주 얼마나 썼어요? 인증 타임!
- 자발적 참여
- 서로 격려
```

### 월간 루틴

**매월 1일**
- 이번 달 목표 설정 독려
- 월간 집중 코칭 신청 받기 (5-10명 선착순)

**매월 15일**
- 중간 체크인
- "어디까지 왔나요?" 진행 상황 공유

**매월 말일**
- 이번 달 성과 인증
- 출간 소식 공유
- 다음 달 집중방 모집

### 분기별

**3개월마다**
- 온라인 줌 모임 (저녁 8시)
- 출간 노하우 공유
- 선배 작가 경험담
- Q&A 시간

---

## ⏰ 시간 관리 (내 에너지 보호)

### 답변 시간 정하기
```
질문 답변: 매일 오후 9시 일괄 답변
→ "평일 저녁 9시에 답변드립니다" 공지
→ 긴급 아닌 건 서로 답변 유도
```

### 시간 절약 팁
- 자주 묻는 질문 → 답변 템플릿 만들기
- 기출간 작가 2-3명 부운영자 위촉
- @전체 멘션 최소화 (월 1-2회만)

---

## 🎯 핵심 운영 원칙

### 1. 느슨한 연결
- 강제 참여 없음
- 원하는 만큼만
- 알림도 각자 자유

### 2. 선택적 집중
- 월간 집중 코칭 (희망자만)
- 줌 모임 (선택 참여)
- 자발적 동기부여

### 3. 공동체 문화
- 서로 돕는 분위기
- 출간 소식은 다같이 축하
- 선배 작가가 후배 도움

### 4. 지속가능성
- 내 시간 보호
- 시스템으로 돌아가게
- 번아웃 방지

---

## 📌 월간 집중 코칭

### 운영 방식
- 매월 초 신청 받기 (5-10명 선착순)
- 별도 소그룹 톡방 (한 달만 운영)
- 집중 피드백 및 밀착 관리
- 한 달 후 해체 → 새로 모집

### 효과
- 동기부여 UP
- 실제 진도 나감
- 메인 방은 여유롭게 유지
- 참여 원하는 사람만 집중 투입

---

## 💡 성공 포인트

### 알림 피로 줄이기
- 중요 공지 형식 통일
- 고정 타이밍 (월요일 9시, 금요일 저녁)
- 자유 수다는 각자 알림 설정

### 정보 축적
- 월간 성과 기록
- 출간 소식 아카이브
- 노하우 공유 정리

### 동기부여 유지
- 정기적 성공 사례 공유
- 작은 성취도 축하
- 함께 가는 느낌
