## 옵션 1: 직접 제작 (무료/저비용)

### 1-1. 무료 제작 프로그램

#### Sigil (시길) - EPUB 전문 편집기
- **다운로드**: [sigil-ebook.com](https://sigil-ebook.com)
- **특징**:
  - 구글이 개발한 무료 오픈소스 프로그램
  - Windows, Mac, Linux 모두 지원
  - WYSIWYG 편집 + HTML 직접 편집 가능
  - 메모장이나 아래한글 수준이면 배울 수 있음
- **적합한 경우**: 텍스트 위주 책, 표나 복잡한 서식 없는 원고
- **참고**: [내맘대로의 EPUB 제작 가이드](https://www.epubguide.net)

#### Calibre (칼리브레) - 변환 + 관리 도구
- **다운로드**: [calibre-ebook.com](https://calibre-ebook.com)
- **특징**:
  - Word, PDF, TXT → EPUB 자동 변환
  - 전자책 라이브러리 관리
  - 내장 뷰어로 결과물 확인
  - MOBI(킨들용) 변환도 가능
- **적합한 경우**: 기존 Word 원고를 빠르게 EPUB으로 변환

#### 추천 워크플로우
```
[Word/한글로 원고 작성]
    ↓
[스타일 적용 (제목1, 제목2, 본문)]
    ↓
[Calibre로 EPUB 변환]
    ↓
[Sigil로 세부 편집/수정]
    ↓
[Calibre 뷰어로 확인]
```

### 1-2. 표지 직접 제작

#### Canva (캔바)
- **사이트**: [canva.com](https://www.canva.com/create/ebook-covers/)
- **특징**: 무료 템플릿 다수, 10분 만에 전문가급 표지 완성 가능
- **비용**: 무료 (프로 버전 월 $12.99)

- **사이트**: [miricanvas.com](https://www.miricanvas.com)

  - 한국형 디자인 템플릿 풍부
  - 저작권 걱정 없는 일러스트/사진 제공
  - 누적 가입자 250만 명
- **비용**: 무료 (프로 월 14,900원)

#### Adobe Express
- **사이트**: [adobe.com/express](https://www.adobe.com/kr/express/create/cover/book)
- **특징**: 전문적인 품질, 데스크톱/모바일 모두 사용 가능
- **비용**: 무료

#### 표지 권장 사양
| 항목 | 권장값 |
|------|--------|
| 해상도 | 1400 x 2100px 이상 |
| 비율 | 2:3 (가로:세로) |
| 파일형식 | JPG, PNG |
| 용량 | 5MB 이하 |

## 옵션 4: 정부 지원 사업 활용

### 한국출판문화산업진흥원 (KPIPA) 전자책 제작 지원

- **공식 사이트**: [kpipa.or.kr](https://www.kpipa.or.kr)
- **지원 대상**: 출간 도서 및 미출간 원고를 전자책으로 제작·유통하려는 출판사
- **지원 내용**:
  | 형식 | 지원금 |
  |------|--------|
  | EPUB 2.0 | 50만원 |
  | EPUB 3.0 | 최대 350만원 |
- **추가 지원**: 전자책 제작 교육 및 컨설팅
- **신청**: 온라인 접수 (전자책바로센터)
- **2025년 일정**: 연 4회 (3월, 4월, 6월, 8월 공고)
- **필수 조건**: 출판유통통합전산망 가입 ([bnk.kpipa.or.kr](https://bnk.kpipa.or.kr))

### 신청 시 주의사항
- 종이책 메타데이터 등록 권고
- 출판사 등록 필요 (개인 불가)
- 파일 이상 시 승인 보류/반려 (리뷰 기간 3일 내외)

- **제한**: 전자책은 출판사(개인/법인 사업자)만 직접 계약 가능

## 2. 전자책 구독 서비스 입점

### 밀리의서재
- **문의**: contents@millie.town
- **입점 절차**:
  1. 이메일로 입점 문의
  2. 서비스 소개서 수령
  3. 사업자등록증 + 통장사본 제출
  4. 전자 계약서 체결
  5. 파트너센터 가입 → 도서 정보 입력 → EPUB 업로드
- **승인 소요**: 약 3일
- **필수**: ISBN 발급된 전자책
- **정산**: 25회 다운로드 = 정가의 80% 지급
- **준비물**: 도서 소개, 목차, 출판사 서평, 작가 소개, 책 속으로

### 리디북스
- **특징**:
  - 리디셀렉트 (구독형) + 개별 판매 병행
  - 독점 연재작/자체출판 브랜드 별도 운영
- **입점 방법**:
  - 교보문고 퍼플 등록 시 자동 등록됨
  - 또는 리디 공식 출판사 등록 페이지에서 별도 문의
- **필수**: 전자책용 ISBN

## 3. 해외 유통: 아마존 KDP

### 기본 정보
- **사이트**: [kdp.amazon.com](https://kdp.amazon.com)
- **중요**: **한국어 책은 출판 불가** (40여개 외국어만 지원)

### 출판 과정
```

4. 메타데이터 입력 (제목, 저자, 설명)
5. 원고 파일 업로드 (.doc, .docx, .pdf, .kpf)
6. 표지 업로드
7. 가격 설정
8. 출판
```

### 로열티 구조
| 옵션 | 로열티 | 가격 범위 |
|------|--------|----------|
| 70% 옵션 | 70% | $2.99 ~ $9.99 |
| 35% 옵션 | 35% | 제한 없음 |

### 정산
- **주의**: 한국 계좌 직접 수령 불가

# PART 3. ISBN 발급 가이드

---

## 1. ISBN이란?
- International Standard Book Number (국제표준도서번호)
- 전 세계 도서에 부여되는 고유번호
- **중요**: 종이책과 전자책 ISBN은 별도 발급 필요

## 2. 직접 발급 (무료)

### 국립중앙도서관 한국문헌번호센터
- **사이트**: [nl.go.kr/seoji](https://www.nl.go.kr/seoji/)
- **비용**: 무료
- **조건**: 출판사 등록 필요

### 발급 절차
```
1. 출판사 신고/사업자 등록
2. 발행자번호 신청 (2~3일)
   - 필요서류: 신청서, 연간출판예정목록, 출판사신고확인증
3. ISBN 교육 이수
4. 도서번호 신청 (2~3일)
5. 바코드 발급
```
- **총 소요기간**: 약 1주일
- **문의**: 02-590-0700 (내선 1번)

## 3. 대행 발급

### 출판 플랫폼 이용
| 플랫폼 | 비용 | 소요기간 |
|--------|------|----------|
| 유페이퍼 | 1,000원 | 7일 |
| 이퍼플 | **무료** | - |
| 기타 대행 출판사 | 3~10만원 | 1~2주 |

### 주의사항
- 대행 발급 시 발행처(출판사명)는 해당 플랫폼으로 표기
- 자체 출판사명 원하면 직접 발급 필요

## 4. 납본 의무
- **근거**: 도서관법 제20조
- **기한**: 발행 후 30일 이내
- **대상**: ISBN 발급받은 전자책 포함 (2016년 8월~)
- **방법**: 국립중앙도서관 온라인 납본
