## 📋 AI 영상 제작 체크리스트

### 준비물
- [ ] 책 표지 이미지 (고해상도)
- [ ] 책 내부 페이지 몇 장 (핵심 문장)
- [ ] 브루 AI 계정 준비
- [ ] 나레이션 음성 선택 (여성, 중년, 따뜻한 톤)

### AI 이미지 생성 프롬프트 (총 8-10개)
1. "50대 아시아 여성, 무릎 통증, 걱정스러운 표정, 집 안 거실"
2. "50대 아시아 여성, 손가락 관절 통증, 자연광"
3. "약병 여러 개, 탁자 위, 걱정스러운 분위기"
4. "책 표지: 90세가 되어도 내 집에서 살고 싶다"
5. "건강한 50대 아시아 여성, 요가 매트, 스트레칭, 밝은 햇살"
6. "건강한 음식, 신선한 채소와 과일, 따뜻한 주방"
7. "책 내부 페이지, 손글씨, 깔끔한 레이아웃"
8. "책 표지 + 가격 정보, 깨끗한 배경"

### 자막 스타일 가이드
- **폰트**: 고딕체 (깔끔하고 읽기 쉬운)
- **색상**: 흰색 텍스트 + 검은색 아웃라인
- **위치**: 화면 중앙 하단
- **크기**: 큼 (모바일에서도 읽기 쉽게)
- **애니메이션**: 페이드 인 효과

### 배경음악 추천
- **분위기**: 따뜻하고 희망적
- **장르**: 어쿠스틱, 피아노
- **템포**: 중간 (80-100 BPM)
- **볼륨**: 나레이션의 30% 정도 (배경으로만)

## 🎨 브루 AI 제작 워크플로우

### Step 1: 스크립트 입력
```
위의 나레이션 전체를 브루 AI에 복사 붙여넣기
```

### Step 2: 장면별 이미지 프롬프트 입력
```
각 섹션(후킹/문제/솔루션/CTA)마다
위의 "화면 프롬프트"를 그대로 입력
```

### Step 3: 나레이션 설정
```
- 성별: 여성
- 나이: 중년 (40-50대 톤)
- 톤: 따뜻하고 공감적
- 속도: 보통 (너무 빠르지 않게)
```

### Step 4: 자막 설정
```
- 위의 "자막 텍스트" 그대로 입력
- 핵심 키워드만 강조
- 전체 나레이션 자막 ON
```

### Step 5: 배경음악 선택
```
브루 AI 내장 음악 중:
- "Hopeful Piano" 또는
- "Warm Acoustic" 스타일
```

### Step 6: 미리보기 및 수정
```
- 나레이션 속도 조정
- 이미지 전환 타이밍 조정
- 자막 위치/크기 조정
```

## 💡 제작 팁

### 이미지 선택 전략
✅ **실사 느낌보다는 일러스트/그래픽**
- AI 생성 이미지가 더 자연스러움
- 저작권 문제 없음

✅ **감정 표현 명확하게**
- "걱정스러운", "희망적인", "건강한" 등 감정 키워드 추가

✅ **배경은 단순하게**
- 복잡한 배경보다 깔끔한 배경
- 주제에 집중

### 자막 전략
✅ **이중 자막**
- 전체 나레이션 자막 (작게, 하단)
- 핵심 키워드만 자막 (크게, 중앙)

✅ **숫자는 크게**
- "9년", "17,000원", "90세" 등

### 음악 전략
✅ **섹션별 다른 음악 고려**
- 후킹/문제: 조금 긴장감 있는
- 솔루션/CTA: 밝고 희망적인
