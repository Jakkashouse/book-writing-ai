## 1. 사전 준비 (10단계)

### ✅ 1. 제목이 후킹하는가?
- [ ] 3초 안에 관심을 끄는가?
- [ ] 숫자가 들어가는가? (예: "3가지", "7일 만에")
- [ ] 타겟이 명확한가? (예: "30대 직장인을 위한")
- [ ] 문제 해결이 보이는가? (예: "~~하는 법")
- [ ] 15자 이내인가? (온라인 서점 노출 최적화)

**테스트:**
- 지인 10명에게 제목 3개 보여주고 투표
- 가장 많이 선택된 것 선택

**예시:**
- ❌ "나의 육아 이야기" → 관심도 0%
- ✅ "밤 9시 퇴근 엄마의 하루 30분 육아법" → 클릭 유도

---

### ✅ 2. 표지가 서점에서 눈에 띄는가?
- [ ] 썸네일로 봐도 제목이 읽히는가?
- [ ] 색상이 경쟁 도서와 다른가?
- [ ] 메인 카피가 3초 안에 읽히는가?
- [ ] 모바일에서 봐도 예쁜가?

**테스트:**
- 표지를 스마트폰 썸네일 크기로 축소
- 1미터 거리에서 제목이 보이는가?

**베스트셀러 표지 공식:**
- 강렬한 색상 (빨강/노랑/파랑)
- 큰 글씨 (제목 60pt 이상)
- 여백 충분 (답답하지 않게)

---

### ✅ 3. 타겟 독자 100명 리스트 확보
- [ ] 지인 (친구/가족) 50명
- [ ] 동료/동문 30명
- [ ] SNS 팔로워 중 관심 있을 사람 20명

**리스트 작성 방법:**
- 엑셀에 이름, 연락처, 관계 기록
- "책 나오면 알려드릴까요?" 사전 동의
- 출간 D-30부터 단계적 접근

---

### ✅ 4. 서평단 30명 모집
- [ ] 블로그/인스타/카페에 모집 공지
- [ ] 신청서 작성 (이름, 연락처, SNS, 지원 동기)
- [ ] 30명 선정 (리뷰 성실히 쓸 사람 우선)
- [ ] 협약서 작성 (책 무료 제공 → 리뷰 필수)

**서평단 혜택:**
- 출간 전 원고 무료 제공
- 출간 후 정식 책 1부
- 저자 사인 or 감사 편지

**서평단 의무:**
- 출간일 전후 1주일 내 온라인 서점 리뷰
- 최소 300자 이상
- SNS 공유 (선택)

---

### ✅ 5. SNS 채널 3개 이상 확보
- [ ] 인스타그램 (필수)
- [ ] 블로그 (네이버 or 티스토리)
- [ ] 유튜브 or 페이스북

**팔로워 목표:**
- 출간 전 최소 100명
- 출간 후 3개월 500명

**콘텐츠 계획:**
- 주 2회 이상 포스팅
- 출간 D-30부터 매일 포스팅

---

### ✅ 6. 책 소개글 3종 작성
- [ ] **짧은 버전 (100자):** 검색 결과용
- [ ] **중간 버전 (500자):** 온라인 서점 상세페이지
- [ ] **긴 버전 (1,500자):** 블로그/보도자료

**짧은 버전 예시:**
> "밤 9시 퇴근 엄마가 하루 30분으로 아이와 깊은 유대감을 만든 육아법. 바쁜 워킹맘을 위한 실전 가이드."

**중간 버전 구성:**
1. 후킹 (1줄)
2. 문제 제기 (3줄)
3. 이 책의 솔루션 (5줄)
4. 독자 추천 대상 (3줄)

---

### ✅ 7. 경쟁 도서 10권 분석

- [ ] 공통점 3가지 도출
- [ ] 우리 책의 차별점 3가지 도출

**분석 템플릿:**

## 🎯 베스트셀러 공식

### 출간일 100부 = 베스트셀러
- 예약 판매: 50부
- 지인 구매: 30부
- 서평단 공유 효과: 20부
- **= 출간일 100부 달성!**

### 출간일 100부 → 주간 베스트셀러 가능
- 분야별 순위는 주간 판매량 기준
- 소분야(육아, 자기계발 등)는 100부면 10-50위
- **→ "베스트셀러" 배지 획득!**

### 베스트셀러 배지 → 추가 판매 자동 발생
- 온라인 서점 "베스트" 코너 노출
- 추천 알고리즘 작동
- "이 책 괜찮나?" → "베스트네, 사야지"
- **→ 선순환 시작**
