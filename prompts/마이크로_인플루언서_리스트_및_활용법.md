# 마이크로 인플루언서 리스트 및 활용법

## 🎯 마이크로 인플루언서 전략의 장점

### 대형 vs 마이크로 비교

```
┌─────────────┬──────────────┬──────────────┐
│             │   대형 (10만+) │ 마이크로 (1-10만)│
├─────────────┼──────────────┼──────────────┤
│ 참여율      │  1-3%        │  5-10%       │
│ 신뢰도      │  낮음        │  높음        │
│ 비용        │  100-500만원 │  무료-50만원 │
│ 전환율      │  0.5-1%      │  3-5%        │
│ 협상 가능성 │  어려움      │  쉬움        │
└─────────────┴──────────────┴──────────────┘
```

**마이크로 인플루언서가 유리한 이유:**
- ✅ 팔로워와의 진정성 있는 소통
- ✅ 틈새 타겟 정확히 공략
- ✅ 적은 비용으로 여러 명 접촉
- ✅ 책 협찬으로 협업 가능
- ✅ 장기 관계 구축 용이

## 📱 인스타그램 마이크로 인플루언서 찾는 법

### 방법 1: 해시태그 검색

**추천 해시태그:**
```
#주일학교교사
#주일학교
#교회학교
#기독교육아
#크리스챤맘
#기독교엄마
#주일학교선생님
#교회교사
#성경공부
#어린이성경
```

**검색 프로세스:**
1. 인스타그램에서 해시태그 검색
2. "최근 게시물" 탭 확인
3. 팔로워 1,000~50,000 범위 필터링
4. 참여율 확인 (좋아요/댓글 수)
5. 프로필 메모장에 정리

---

### 방법 2: 계정 추천 기능

**시드 계정에서 시작:**
1. 주일학교 관련 인기 계정 팔로우
2. "비슷한 계정" 추천 확인
3. 팔로워 수 적당한 계정 선별
4. DM으로 협업 제안

---

### 방법 3: 위치 기반 검색

**타겟 지역:**
- 대형 교회 인근
- 기독교 서점 주변
- 기독교 카페/서점

**방법:**
1. 인스타그램 "장소" 검색
2. 해당 위치 게시물 확인
3. 주일학교/기독교 관련 계정 선별

## 📊 인플루언서 선정 기준

### 체크리스트

```
✅ 필수 조건:
- [ ] 팔로워 1,000~50,000명
- [ ] 주일학교 교사 or 기독교 육아 중
- [ ] 최근 1주일 내 게시물 있음
- [ ] 게시물당 좋아요 50개 이상
- [ ] 댓글 5개 이상 (참여율 높음)

✅ 가산점:
- [ ] 책 리뷰 경험 있음
- [ ] 스토리 활발히 사용
- [ ] 릴스 제작 경험
- [ ] 팔로워와 소통 활발
- [ ] 프로필에 협업 오픈 명시
```

### 참여율 계산법

```
참여율 = (좋아요 + 댓글) / 팔로워 수 × 100

예시:
팔로워 5,000명
평균 좋아요 300개
평균 댓글 20개
→ (300+20) / 5,000 × 100 = 6.4%

✅ 5% 이상: 우수
✅ 3-5%: 양호
❌ 3% 미만: 재검토
```

## 🤖 인플루언서 마케팅 자동화 플랫폼

### 1. 씨스타일 (Cstyle)

**특징:**
- 국내 최대 인플루언서 마케팅 플랫폼
- 카테고리별 인플루언서 검색
- 캠페인 자동 매칭
- 결제 대행 시스템

**가격:**
- 최소 캠페인: 30만원부터 가능
- 마이크로 인플루언서 패키지 활용

**활용법:**
```
1. 씨스타일 가입 (광고주 계정)
2. 캠페인 등록
   - 상품: 가르치며 배우는 신앙
   - 카테고리: 육아/교육/라이프스타일
   - 예산: 50만원
   - 인플루언서 조건: 팔로워 3천~3만
3. 인플루언서 지원 대기
4. 선정 및 샘플 발송
5. 콘텐츠 업로드 확인
6. 정산
```

**웹사이트:** https://www.cstyle.me/

---

### 2. 애드픽 (Adpick)

**특징:**
- 마이크로 인플루언서 특화
- 팔로워 1천~10만 중심
- 비용 효율적
- 셀프 서비스 가능

**가격:**
- 인플루언서당 5만~30만원
- 수수료 15%

**활용법:**
```
1. 애드픽 광고주 가입
2. 상품 등록
3. 희망 인플루언서 조건 설정
4. 자동 매칭 or 직접 섭외
5. 콘텐츠 검수
6. 성과 리포트 확인
```

**웹사이트:** https://www.adpick.co.kr/

### 3. 레뷰 (Revu)

**특징:**
- 서평단 특화 플랫폼
- 책 마케팅에 최적
- 블로그 + 인스타 동시 진행
- 리뷰어 풀 보유

**가격:**
- 서평단 20명: 60만~100만원 (책값 포함)
- 플랫폼 수수료 20%

**활용법:**
```
1. 레뷰 플랫폼 가입
2. 서평단 캠페인 생성
   - 모집 인원: 20명
   - 리뷰 채널: 블로그 + 인스타
   - 미션: 1,000자 이상 + 사진 3장
3. 리뷰어 신청 접수
4. 선정 및 책 발송
5. 리뷰 업로드 확인
6. 우수 리뷰 선정
```

**웹사이트:** https://www.revu.net/

## 💡 플랫폼 vs 직접 섭외 비교

└─────────────┴───────────────┴───────────────┘
```

## 🎯 추천 전략 (혼합 전략 - 가장 효과적!)

### ⭐ 최고의 선택: 직접 섭외 + 플랫폼 병행

```
■ 총 예산: 60만원
  - 씨스타일 캠페인: 30만원
  - 직접 섭외: 30만원 (책 20권)

■ 역할 분담:

【씨스타일 담당】
- 검증된 인플루언서 5~10명
- 확실한 업로드 보장 (계약)
- 빠른 집행 (1주일 내)
- 퀄리티 있는 콘텐츠
- 성과 리포트 자동 제공

【직접 섭외 담당】
- 타겟 정확한 니치 인플루언서 20명
- 비용 효율적
- 장기 관계 구축
- 진정성 있는 리뷰
- 다음 신간까지 연결

■ 예상 결과:
- 총 리뷰: 25~28개
  (플랫폼 10개 + 직접 15개)
- 총 노출: 150,000~300,000명
- 도달: 30,000~60,000명
- 판매 전환: 80~120권
- ROI: 200~400%

■ 장점:
✅ 플랫폼으로 빠르고 확실한 기본 성과 확보
✅ 직접 섭외로 비용 효율 + 장기 관계
✅ 리스크 분산
✅ 다양한 콘텐츠 스타일 확보
✅ 성과 비교 가능 (어떤 방식이 더 효과적인지)
```

### 옵션 1: 순수 직접 섭외 (예산 30만원)

```
■ 예산 배분:
- 책 20권 × 15,000원 = 30만원
- 플랫폼 비용: 0원

■ 진행 방법:
1. 인스타 해시태그로 20명 발굴
2. DM으로 무료 협찬 제안
3. 수락한 분들께 책 발송
4. 자유로운 리뷰 부탁
5. 우수 리뷰 10명에게 다음 신관 할인 쿠폰

■ 예상 결과:
- 리뷰 업로드: 15명 (75%)
- 총 노출: 60,000~150,000명
- 도달: 10,000~30,000명
- 판매 전환: 30~50권

■ 장단점:
