## 업무별 프롬프트 활용 가이드

### 책 출간 과정

```
1. 기획 (00-05번)
   └─ 주제 선정 → 목차 구성 → 타겟 분석

2. 집필 (06-12번)
   └─ 초안 작성 → 스토리텔링 → 체크리스트

3. 편집 (13-17번)
   └─ 진도 관리 → 피드백 → 베타리딩

4. 마케팅 (18-22번)
   └─ SNS → 이벤트 → 보도자료

5. 수익화 (23-28번)
   └─ 강의 → 코칭 → 수익 모델
```

### 출판사 운영

```
저자 관리
├─ 30번: 기획서 평가
├─ 31번: 계약서 검토
└─ 33번: 베타리더 관리

도서 관리
├─ 29번: ISBN 발급
├─ 32번: 원가 계산
└─ 35번: 판촉물 기획

유통/판매
├─ 34번: 서점 입점
└─ 36번: 월간 리포트
```

```
코칭 운영
├─ 37번: 세션 기록
└─ 39번: 작가 브랜딩

강의 사업
├─ 38번: 온라인 강의 기획
└─ 23번: 강연 제안서

심화 도구
├─ 25번: 필체 분석

└─ 44번: 녹음본 → 목차
```
