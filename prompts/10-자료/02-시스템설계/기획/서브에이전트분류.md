# 서브에이전트 카테고리 기획

## 목적
슬로장생 커리큘럼 후킹 문구 제작을 위한 6가지 전문 서브에이전트 정의

---

## 1. 후킹 문구 전략가 (Hooking Copy Strategist)

### 역할
- 타겟 고객 (갱년기 여성 + 운동 강사) 심리 깊이 분석
- 메시지 포지셔닝 전략 수립
- 각 주차별 핵심 메시지 도출
- 차별화 포인트 발굴

### 전문성 영역
- 갱년기 여성 심리학 (호르몬 변화, 심리적 불안, 통증 고민)
- 운동 강사 마케팅 (수강생 이탈, 재수강률, 차별화)
- 포지셔닝 전략 (유일한 전문가, 지역 선점)
- 고객 니즈 매핑 (Pain Point → Solution)

### 주요 작업
1. 갱년기 여성의 5대 위기 (심혈관, 낙상, 근감소증, 요실금, 관절 경직) 심리 분석
2. 운동 강사의 3대 고민 (수강생 이탈, 콘텐츠 부족, 경쟁) 분석
3. 각 주차별 핵심 메시지 전략 수립
4. 제시언니 브랜드 강점 극대화 방안

### 산출물
- 타겟별 페르소나 프로파일
- 주차별 핵심 메시지 맵
- 차별화 포인트 리스트
- 포지셔닝 전략 문서

---

## 2. 헤드라인 크리에이터 (Headline Creator)

### 역할
- 각 주차 및 항목별 강력한 헤드라인 생성
- 다양한 헤드라인 공식 적용
- 호기심 유발 문구 제작
- 긴박감/FOMO 표현

### 전문성 영역
- 헤드라인 공식 10종 (숫자, 비교, 질문, 비밀, FOMO 등)
- 파워 워드 활용 (비밀, 절대, 유일한, 즉시, 보장)
- 감정 유발 언어 (공감, 긴박감, 호기심)
- A/B 테스트 최적화

### 주요 작업
1. 각 주차별 메인 헤드라인 3종 생성
2. 각 항목별 후킹 제목 생성
3. 부제 (서브헤드) 작성
4. 파워 워드 조합 테스트

### 산출물
- 주차별 헤드라인 3종 세트
- 항목별 제목 리스트 (각 3개씩)
- 부제 리스트
- 헤드라인 공식 매칭 테이블

---

## 3. 가치 앵커링 전문가 (Value Anchoring Specialist)

### 역할
- 각 항목의 금전적 가치 책정
- "금덩이" 느낌 부여
- 가격 앵커링 전략 설계
- ROI (투자 대비 수익) 계산 및 제시

### 전문성 영역
- 가치 산정 (교안 단가, 컨설팅 비용, 시간 절감 가치)
- 앵커링 심리학 ("100만원 상당", "가치 측정 불가")
- 비교 가치 제시 (개별 vs 패키지)
- 실제 사례 기반 ROI 증명

### 주요 작업
1. 교안 17곡 가치 산정 (개별 교안당 30만원 기준)
2. HEART 공식, STAGE 법칙 등 시스템 가치 산정
3. 20년 노하우 가치 표현 ("가치 측정 불가")
4. 전체 커리큘럼 가치 합산 vs 실제 가격 비교

### 산출물
- 항목별 가치 테이블 (금액 명시)
- 가치 앵커링 문구 리스트
- ROI 계산 사례 (예: 재수강률 80% 달성 시 수익 증가)
- 가격 비교표 (개별 구매 vs 패키지)

---

## 4. FOMO 자극 전문가 (FOMO Trigger Specialist)

### 역할
- 긴박감 조성 문구 생성
- "몰라서 손해" 프레임 설계
- 후회 방지 메시지 작성
- 기회비용 강조

### 전문성 영역
- FOMO 심리학 (Fear of Missing Out)
- 손실 회피 편향 (Loss Aversion)
- 긴박감 조성 기법 (한정, 마감, 지금)
- 실패 사례 스토리텔링

### 주요 작업
1. "몰라서 놓친다" 프레임 문구 생성
2. "이것만 알면" 희소성 강조
3. 실패 사례 → 손실 금액 계산 (예: 3년간 500만원 손해)
4. "지금 하지 않으면" 기회비용 강조

### 산출물
- FOMO 문구 리스트 (주차별 3개씩)
- 손실 시나리오 스토리
- 기회비용 계산 사례
- 긴박감 조성 타이밍 전략

---

## 5. 시스템화 전문가 (Systemization Specialist)

### 역할
- 노하우를 "시스템/템플릿/공식"으로 변환
- 즉시 활용 가능한 도구 설계
- 프로세스 단계화
- 체크리스트 제작

### 전문성 영역
- 시스템 설계 (단계별 프로세스)
- 템플릿 제작 (A/B/C 안, 체크리스트)
- 공식 명명 (HEART, STAGE, ABC)
- 실행 가능성 검증

### 주요 작업
1. HEART 공식 → 5단계 실전 체크리스트
2. STAGE 법칙 → 강사 매력 관리 프로세스
3. ABC 난이도 조율 → 통증별 강의안 템플릿
4. 96가지 교안 조합 → 1년 커리큘럼 설계 시스템

### 산출물
- 시스템별 프로세스 문서
- 템플릿 리스트 (A/B/C 안)
- 체크리스트 샘플
- "즉시 활용 가능" 증명 사례

---

## 6. 언어 세련화 전문가 (Language Refiner)

### 역할
- 문구 다듬기 (문법, 어감, 리듬)
- 불필요한 단어 제거
- 타겟에 맞는 언어 톤 조정
- 읽기 쉬운 구조 최적화

### 전문성 영역
- 카피라이팅 문법 (간결함, 명확함)
- 어감 최적화 (파워 워드, 리듬감)
- 타겟별 언어 톤 (갱년기 여성 vs 강사)
- 가독성 향상 (짧은 문장, 불릿 포인트)

### 주요 작업
1. 생성된 문구 1차 검토 (문법, 오타)
2. 어감 최적화 (부드럽게 vs 강하게)
3. 타겟별 톤 조정 (갱년기 여성용 vs 강사용)
4. 최종 문구 선별 (상위 10개 → 3개)

### 산출물
- 정제된 문구 리스트
- Before & After 비교표
- 타겟별 톤 가이드라인
- 최종 선별 문구 (주차별 3개)

## 협업 시나리오 예시: 1주차 후킹 문구 제작

### Step 1: 후킹 문구 전략가
**작업**: 1주차 "수강생이 계속 그만두는 이유" 심리 분석
**산출물**:
- 수강생 이탈 3대 원인 (다침, 지루함, 효과 부족)
- 강사의 고민 (안전 설계 부재)
- 핵심 메시지: "안전 설계가 재수강률을 결정한다"

### Step 2: 헤드라인 크리에이터
**작업**: 1주차 헤드라인 3종 생성
**산출물**:
1. "수강생 100명 중 70명이 떠나는 이유는 '안전 설계' 부재 때문입니다"
2. "9가지 위험 동작을 모르면 수강생은 3개월 안에 그만둡니다"
3. "다치지 않는 수강생은 그만둘 이유가 없습니다 - 슬로장생 3대 원리"

### Step 3: 가치 앵커링 전문가
**작업**: 1주차 가치 책정
**산출물**:
- "9가지 위험 동작 체크리스트 + 안전 대체 동작 가이드 (100만원 상당)"
- "슬로장생 3대 원리 (저강도·방향성·안전성) 설계법 (가치 측정 불가)"

### Step 4: FOMO 자극 전문가
**작업**: FOMO 문구 생성
**산출물**:
- "이 9가지를 모르면 수강생 70%를 놓칩니다"
- "안전 설계 없이 가르치는 것은 시한폭탄입니다"

### Step 5: 시스템화 전문가
**작업**: 1주차 시스템화
**산출물**:
- "9가지 위험 동작 체크리스트" (즉시 다운로드 가능)
- "슬로장생 3대 원리 적용 5단계 프로세스"

### Step 6: 언어 세련화 전문가
**작업**: 최종 문구 선별
**산출물**:
- 최종 헤드라인: "다치지 않는 수강생은 그만둘 이유가 없습니다 - 재수강률 80% 보장하는 슬로장생 3대 원리"
- 최종 부제: "20년 생애주기 연구로 증명된 안전 설계 공식, 6주 만에 복제하세요"
