# 📚 책쓰기 코칭 완전 자동화 시스템 설계서

> **목표: 준현님의 케어 시간 80% 절감 + 수강생 만족도 유지**

---

## 🎯 핵심 철학

**"AI가 90%를 자동화하고, 준현님은 10%만 집중한다"**

- AI가 할 수 있는 것: 분석, 제안, 피드백, 관리, 독촉
- 준현님만 할 수 있는 것: 감성적 교감, 전문가 조언, 최종 의사결정

---

## 🚀 9대 자동화 시스템

### 1️⃣ 컨설팅지 자동 분석 시스템

#### 작동 방식
```
수강생 업로드 → AI 즉시 분석 (3분 내) → 분석 보고서 자동 발송
```

#### AI가 분석하는 것
1. **강점 3가지** 발견 및 구체적 칭찬
2. **약점 3가지** + 개선 방법
3. **차별화 포인트** 평가
4. **타겟 독자** 명확성 체크
5. **시장성 예측** (보수적 판매량 예상)

#### 출력 형식
```markdown
## 📋 컨설팅지 분석 보고서

### ✨ 강점
1. [구체적 강점 1]
2. [구체적 강점 2]
3. [구체적 강점 3]

### 🔧 개선이 필요한 부분
1. [문제점] → [해결 방법]
2. [문제점] → [해결 방법]

### 📊 시장성 평가
- 예상 판매량: 최소 [N]권 ~ 최대 [N]권
- 차별화 점수: [N]/10점
- 타겟 명확성: [N]/10점

### 💡 다음 단계
1. [즉시 할 일]
2. [1주일 내 할 일]
3. [2주 내 할 일]
```

#### 준현님의 역할
- AI 분석 결과 확인 (5분)
- 필요 시 추가 코멘트 (선택)
- 승인 버튼 클릭 → 수강생에게 자동 발송

---

### 2️⃣ 제목/목차 자동 제안 시스템

#### 작동 방식
```
컨설팅지 입력 → AI가 베스트셀러 패턴 분석 → 제목 10개 + 목차 생성
```

#### AI가 생성하는 것
1. **제목 10개** (다양한 스타일)
   - 문장형, 질문형, 숫자형, 감성형 등
   - 각 제목에 대한 평가 (호기심/감정/명확성 점수)
2. **최적 목차**
   - 장르에 맞는 구조 (육아서: 8부, 전문서: 5부 등)
   - 논리적 흐름 (MECE 원칙 적용)
   - 각 장의 핵심 메시지

#### 출력 형식
```markdown
## 📚 제목 제안 (10개)

### 최종 추천 (Top 3)
1. **[제목]** - 호기심 9/10, 감정 10/10, 명확성 8/10
   - 선정 이유: [설명]

2. **[제목]** - ...

### 추가 후보
4. [제목] - 장점: ... / 단점: ...
...

## 📖 목차 제안

### 전체 구조
- 총 [N]부, [N]장
- 구조 유형: [3막 구조 / 5부 구성 등]

### 상세 목차
**프롤로그**: [제목]

**제1부: [파트 제목]**
1장. [장 제목] - [핵심 내용 1줄]
2장. ...

...
```

#### 준현님의 역할
- AI 제안 확인 (5분)
- 더 나은 아이디어 있으면 추가 (선택)
- 승인 → 수강생에게 발송

---

### 3️⃣ 스마트 초안 작성 도우미

#### 작동 방식
```
수강생: 장 제목 + 키워드 입력 → AI: 1,500자 초안 생성 → 수강생: 수정/완성
```

#### AI가 작성하는 것
1. **구조화된 초안** (1,500자)
   - 오프닝 (10%)
   - 스토리/경험 (30%)
   - 통찰/발견 (20%)
   - 해결/방법 (30%)
   - 마무리 (10%)

2. **작가 스타일 반영**
   - 수강생의 샘플 텍스트 분석
   - 문체, 어미, 문장 길이 패턴 학습
   - AI 티 제거

#### 예시
```
입력:
- 장 제목: "아이와의 첫 갈등"
- 키워드: 떼쓰기, 마트, 죄책감
- 샘플 텍스트: (수강생이 작성한 짧은 글)

출력:
- 1,500자 초안 (스토리 중심, 감정 표현 풍부)
- 개선 제안 (디테일 추가, 5감 활용 등)
```

#### 준현님의 역할
- 없음 (수강생이 스스로 초안 받고 수정)

---

### 4️⃣ 자동 원고 진단 시스템

#### 작동 방식
```
수강생: 원고 업로드 → AI: 10분 내 진단 → 100점 만점 평가 + 개선안
```

#### AI가 진단하는 것
1. **완성도 평가** (100점 만점)
   - 구조와 흐름: 25점
   - 문장과 문체: 25점
   - 메시지와 내용: 25점
   - 독자 몰입도: 25점

2. **구체적 개선점**
   - 우선순위 1, 2, 3
   - Before → After 예시
   - 예상 효과

3. **시장성 분석**
   - 보수적 판매량 예측 (1년)
   - 손익분기 가능성
   - 출판 전략 제안

#### 출력 형식
```markdown
## 📋 원고 진단 보고서

**총점: [N]/100점**

### ✨ 강점 (먼저 칭찬!)
1. [구체적 강점 + 예시 인용]
2. ...

### 🔧 개선이 필요한 부분
**우선순위 1: [문제]**
- 현재 상황: [설명]
- 개선 방향: [Before → After]
- 예상 효과: [설명]

### 📈 시장성 분석
- 예상 판매량 (1년): 최소 [N]권 ~ 최대 [N]권
- 손익분기 가능성: [높음/중간/낮음]

### 🎯 다음 단계
1. [즉시 할 일]
2. [1주일 내]
3. [2주 내]
```

#### 준현님의 역할
- AI 진단 결과 확인 (10분)
- 중요한 부분만 추가 코멘트 (선택)
- 승인 → 수강생에게 발송

---

### 5️⃣ 진도 자동 추적 및 리마인더

#### 작동 방식
```
시스템이 매일 자동 체크 → 지연 발견 시 → 자동 알림 발송
```

#### AI가 관리하는 것
1. **진행 상황 자동 체크**
   - 컨설팅지 제출 여부
   - 제목/목차 확정 여부
   - 초안 작성 진도 (장별)
   - 원고 완성도

2. **자동 알림**
   - D+3일: "안녕하세요! 다음 단계 진행 어떠신가요?"
   - D+7일: "혹시 어려움이 있으신가요? 도움이 필요하시면 말씀해주세요."
   - D+14일: "준현님께 상황 공유 + 1:1 세션 제안"

3. **통계 대시보드**
   - 전체 수강생 진행률 (%)
   - 완주 예상 인원
   - 지연 위험 인원 (빨간불)

#### 준현님의 역할
- 대시보드 확인 (하루 5분)
- 빨간불 수강생만 직접 연락

---

### 6️⃣ AI 챗봇 Q&A 시스템

#### 작동 방식
```
수강생: 질문 입력 → AI: 27종 프롬프트 기반 즉시 답변 → 만족도 체크
```

#### AI가 답변하는 것
1. **일반적 질문**
   - "제목 어떻게 짓나요?" → 제목 공식 10가지 안내
   - "목차 구조 어떻게?" → 장르별 목차 템플릿 제공
   - "초안 막혀요" → 질문법으로 풀어주기

2. **기술적 질문**
   - "AI 티 어떻게 없애나요?" → 10가지 방법 안내
   - "스토리텔링 팁?" → Show, don't tell 예시

3. **감정적 지원**
   - "포기하고 싶어요" → 격려 메시지 + 작은 목표 제시

#### 만족도 체크
- 답변 후: "도움이 되셨나요? 👍 / 👎"
- 👎 클릭 시 → 준현님께 자동 알림

#### 준현님의 역할
- AI가 답변 못한 질문만 직접 답변
- 복잡한 질문만 개입

---

### 7️⃣ 1:1 코칭 세션 자동 요약

#### 작동 방식
```
코칭 중 녹음 → AI 자동 정리 → PDF 요약본 발송 (코칭 직후)
```

#### AI가 정리하는 것
1. **핵심 내용 요약**
   - 준현님이 한 조언 (3-5가지)
   - 수강생이 해야 할 일 (To-Do 리스트)
   - 다음 세션까지 목표

2. **감정적 하이라이트**
   - 준현님의 격려 문구
   - 수강생의 깨달음

#### 출력 형식
```markdown
## 📝 코칭 세션 요약 (2025-12-28)

### 💡 준현님의 조언
1. [조언 1]
2. [조언 2]
3. [조언 3]

### ✅ 다음 세션까지 할 일
- [ ] [할 일 1]
- [ ] [할 일 2]

### 💪 격려의 말
"[준현님이 한 격려 문구]"

### 🎯 다음 세션
- 날짜: [날짜]
- 주제: [주제]
```

#### 준현님의 역할
- 녹음 파일 업로드만 (30초)
- AI가 자동으로 정리 및 발송

### 8️⃣ 격려 메시지 자동 발송 시스템

#### 작동 방식
```
마일스톤 달성 감지 → AI가 맞춤형 격려 메시지 작성 → 자동 발송

#### 마일스톤
1. 컨설팅지 제출 완료
2. 제목/목차 확정
3. 첫 장 초안 완성
4. 10장 완성
5. 20장 완성
6. 전체 원고 1차 완성

#### 메시지 예시
```

화이팅! 💪

#### 준현님의 역할
- 없음 (완전 자동)
