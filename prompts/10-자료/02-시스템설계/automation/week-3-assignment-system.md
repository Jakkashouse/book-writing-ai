# 3주차: 40꼭지 초고 완성 & 중간 점검 - 과제 및 자동화 피드백 시스템

## 개요

**프로그램**: 6주 책쓰기 프로그램 (출간 과정)
**주차**: 3주차
**핵심 주제**: 전체 초고 완성 (40꼭지) & 중간 점검
**목표**: 전체 원고 80% 초안 완성 + 구조/흐름 점검

---

## 1. 주요 학습 목표

### 1.1 핵심 역량

1. **집필 속도 최적화**
   - 개인별 최적 집필 패턴 확립
   - 효율적인 시간 관리
   - 연속 집필 습관 정착

2. **전체 흐름 관리**
   - 파트 간 연결성 확보
   - 메시지 일관성 유지
   - 중복/누락 발견 및 수정

3. **중간 점검 능력**
   - 객관적 자가 평가
   - 피드백 반영 능력
   - 수정 우선순위 결정

### 1.2 주차 종료 시 기대 성과

- 40꼭지 전체 80% 초안 완성
- Part 1-5 흐름 연결 완료
- 자가 진단 보고서 작성
- 4-6주차 수정 계획 수립

### 과제 3-3: 전체 원고 중간 점검 보고서

#### 과제 목표
완성된 40꼭지 초안 전체를 점검하고, 4-6주차 수정 계획 수립

#### 과제 개요
- **난이도**: 중급
- **예상 소요시간**: 3-4시간
- **제출 형식**: 마크다운 또는 워드 문서

#### 상세 내용

**중간 점검 프로세스:**

**STEP 1: 전체 읽기 (2시간)**
- 프롤로그부터 에필로그까지 처음부터 끝까지
- 편집 모드 OFF, 독자 모드 ON
- 중간에 멈추지 말고 쭉 읽기
- 읽으면서 느낀 점 간단히 메모

**STEP 2: 체크리스트 작성 (30분)**

```markdown
## 전체 원고 점검 체크리스트

### 구조 점검
- [ ] 프롤로그가 독자를 끌어들이는가
- [ ] Part 간 연결이 자연스러운가
- [ ] 각 Part의 역할이 명확한가
- [ ] 에필로그가 여운을 남기는가
- [ ] 전체 흐름이 논리적인가

### 메시지 점검
- [ ] 핵심 메시지가 일관되는가
- [ ] 각 챕터가 전체 메시지에 기여하는가
- [ ] 메시지가 명확하게 전달되는가
- [ ] 독자가 얻어갈 것이 분명한가

### 콘텐츠 점검
- [ ] 에피소드/사례가 충분한가
- [ ] 5감 묘사가 활용되었는가
- [ ] 반복되는 내용이 없는가
- [ ] 빠진 내용이 없는가

### 가독성 점검
- [ ] 문장이 읽기 쉬운가
- [ ] 단락 구성이 적절한가
- [ ] 리듬감이 있는가
- [ ] AI 티가 없는가
```

- C (선택 수정): 미세 조정, 추가 에피소드

**STEP 4: 수정 계획 수립 (30분)**

- C 등급 문제 (시간 허용 시)
