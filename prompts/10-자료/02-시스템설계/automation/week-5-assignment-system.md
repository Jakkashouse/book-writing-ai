## 1. 주요 학습 목표

### 핵심 학습 목표 (마케팅/수익화 중심)

1. **출판사 투고 실전**
   - 출판사 10곳 선정 및 이메일 투고

   - 후속 관리 및 협상 기초

2. **온라인 판매 채널 구축**

## 2. 과제 3개

### 과제 1: 출판사 10곳 투고

**과제 설명**
4주차에 완성한 출판 기획서를 바탕으로 타겟 출판사 10곳에 투고 이메일을 발송합니다.

**제출 요건**
```
필수 제출물:
1. 투고한 출판사 리스트 (10곳)
   - 출판사명
   - 담당자/이메일
   - 투고일
   - 선정 이유 (50자 이내)

2. 투고 이메일 본문 (3가지 버전)
   - 대형 출판사용 (격식체)
   - 중소형 출판사용 (친근체)
   - 전문 출판사용 (전문성 강조)

3. 투고 증빙
   - 발송 완료 스크린샷 5개 이상
   - 또는 발송 확인 메일 캡처

4. 투고 추적표
   - 발송일 / 응답 예정일 / 현재 상태
```

**과제 목표**
- 실제 투고 경험 획득
- 거절에 대한 심리적 준비
- 협상 가능한 관계 구축

### 과제 2: 온라인 서점 상세페이지 완성

**과제 설명**
자가출판 또는 출판사 출간 시 사용할 온라인 서점 상세페이지를 완성합니다.

**제출 요건**
```
상세페이지 구성 (순서대로):
1. 메인 비주얼 + 헤드라인
2. 타겟 독자 메시지 ("이런 분들께 추천")
3. 책 소개 (500자)
4. 목차 요약 (5부 구조)
5. 저자 소개 (300자)
6. 독자 후기/추천사 (3개 이상)
7. 구매 CTA

제출 형식:
- Word/PDF (페이지 시뮬레이션)
- 또는 실제 플랫폼 미리보기 스크린샷
- Canva 등 디자인 툴 작업물도 가능

추가 제출:
- 표지 시안 (3가지 버전)
- 가격 설정 및 근거
```

**과제 목표**
- 실제 판매 가능한 상세페이지 완성
- 구매 전환율 3% 이상 목표
- A/B 테스트 가능한 요소 포함

### 과제 3: SNS 콘텐츠 1주차 실행

**과제 설명**
4주차에 작성한 30일 콘텐츠 캘린더의 1주차(Day 1-7)를 실제로 실행합니다.

**제출 요건**
```
필수 실행 항목:
- 7일간 매일 1개 이상 콘텐츠 발행
- 최소 3개 플랫폼 활용 (인스타/페북/블로그 등)

제출물:
1. 발행 콘텐츠 링크 또는 스크린샷 (7개)
2. 1주차 성과 리포트
   - 총 도달 수
   - 총 좋아요/댓글
   - 최고 성과 콘텐츠 분석
   - 개선점 도출

3. 2주차 수정 계획
   - 1주차 학습 기반 조정 사항
   - 새로운 콘텐츠 아이디어

형식: 자유 (표/텍스트)
```

**과제 목표**
- 콘텐츠 발행 습관 형성
- 데이터 기반 개선 학습
- 팔로워/독자 기반 구축 시작
