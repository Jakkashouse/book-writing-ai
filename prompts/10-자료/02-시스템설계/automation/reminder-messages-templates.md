# 카톡/이메일 메시지 템플릿 모음

## 개요

6주 책쓰기 프로그램의 자동화 메시지 시스템을 위한 완전한 템플릿 모음입니다.
모든 메시지는 즉시 사용 가능한 형태로 작성되었습니다.

**변수 표기법**: `{변수명}` 형식으로 표기
- `{이름}`: 수강생 이름
- `{진도}`: 현재 진도율 (%)
- `{주차}`: 현재 주차
- `{남은일}`: 마감까지 남은 일수
- `{목표}`: 이번 주 목표
- `{접속일}`: 미접속 일수
