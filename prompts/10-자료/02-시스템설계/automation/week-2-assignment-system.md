## 2. 과제 3개

### 과제 2-1: AI 프롬프트 실습 - 1개 챕터 완전 작성

#### 과제 목표
AI 프롬프트 7종을 활용하여 1개 챕터를 처음부터 끝까지 작성하고, AI 출력물을 자신의 스타일로 변환

#### 과제 개요
- **난이도**: 중급
- **예상 소요시간**: 3시간
- **제출 형식**: 워드 문서 (Before/After 포함)

#### 상세 내용

**STEP 1: 챕터 선택 (15분)**

1주차에 완성한 목차에서 가장 자신 있는 챕터 1개 선택
- 가장 많은 경험이 있는 주제
- 가장 쓰고 싶은 이야기
- 가장 에피소드가 풍부한 주제

**STEP 2: AI 프롬프트 7종 순차 적용 (2시간)**

다음 7가지 프롬프트를 순서대로 사용하여 챕터 작성:

**프롬프트 1: 아이디어 확장**
```
[주제: (선택한 챕터 주제)]에 대해 책의 한 챕터를 쓰려고 합니다.
이 주제로 다룰 수 있는 내용을 5가지 측면으로 나눠서 정리해주세요.
각 측면마다 구체적인 예시나 스토리 아이디어도 함께 제안해주세요.
```

**프롬프트 2: 도입부 작성**
```
[주제]로 챕터를 시작하려 합니다.
독자의 관심을 끄는 도입부를 3가지 버전으로 작성해주세요:
1) 질문으로 시작
2) 충격적 고백으로 시작
3) 구체적 장면으로 시작
각각 300자 내외로 작성해주세요.
```

**프롬프트 3: 본문 전개**
```
[주제]의 챕터 본문을 작성해주세요.
- 핵심 메시지: [핵심 메시지 1문장]
- 포함할 에피소드: [에피소드 간략 설명]
- 타겟 독자: [독자 설명]
- 톤: [따뜻한/전문적인/유머러스한 등]
약 1,500자로 작성해주세요.
```

**프롬프트 4: 예시/사례 추가**
```
[본문 내용]에 추가할 수 있는 구체적인 사례나 예시를 3개 작성해주세요.
각 사례는:
- 구체적인 상황 묘사
- 5감을 활용한 디테일
- 독자가 공감할 수 있는 감정
을 포함해주세요.
```

**프롬프트 5: 마무리 작성**
```
[본문 내용]의 마무리를 작성해주세요.
- 핵심 메시지를 다시 한번 강조
- 독자에게 행동이나 생각의 변화를 촉구
- 여운이 남는 문장으로 마무리
약 300자로 작성해주세요.
```

**프롬프트 6: 전체 흐름 점검**
```
다음 챕터 초안의 전체 흐름을 점검해주세요:
[전체 초안 붙여넣기]

1) 도입-본문-마무리 연결이 자연스러운가?
2) 중복되는 내용은 없는가?
3) 논리적 비약은 없는가?
4) 개선이 필요한 부분을 구체적으로 지적해주세요.
```

**프롬프트 7: AI 티 제거**
```
다음 글을 더 자연스럽고 인간적으로 수정해주세요:
[초안 붙여넣기]

수정 방향:
- 딱딱한 표현 → 구어체로
- 긴 문장 → 짧게 나누기
- 반복 표현 제거
- 작가의 개인적 경험이나 감정 추가할 여지 표시
```

**STEP 3: 작가 스타일 변환 (45분)**

AI 출력물을 바탕으로:
1. 나만의 경험/에피소드 추가
2. 어색한 표현 수정
3. 감정 표현 강화
4. 구어체로 전환
5. 최종 검토

#### 제출 형식

```markdown
## AI 프롬프트 실습 과제 제출

### 1. 기본 정보
- 선택한 챕터: [Part N - 챕터 제목]
- 챕터 핵심 메시지: [한 문장]
- 예상 분량: 약 [N]자
- 작성 소요시간: [N]시간

### 2. 프롬프트 사용 기록

**프롬프트 1: 아이디어 확장**
- 사용한 프롬프트: [전문]
- AI 출력 요약: [핵심 3줄]
- 채택/수정 여부: [채택/부분 수정/전면 수정]

[프롬프트 2-7 동일 형식]

### 3. Before & After

**Before (AI 원본):**
[AI가 출력한 첫 번째 단락 원본]

**After (작가 수정 후):**
[수정된 첫 번째 단락]

**수정 포인트:**
- [수정 1]: [이유]
- [수정 2]: [이유]
- [수정 3]: [이유]

### 4. 완성된 챕터 전문
[최종 완성본 전문 - 약 2,000-3,000자]

### 5. 자가 평가
- AI 활용 만족도: ⭐⭐⭐⭐⭐ (1-5)
- 가장 유용했던 프롬프트: [번호]
- 가장 많이 수정한 부분: [설명]
- 다음 챕터에 적용할 교훈: [설명]
```

### 과제 2-2: 5+5 시스템으로 3개 챕터 구조화

#### 과제 목표
5+5 시스템(5분 아이디어 + 5단계 작성)을 활용하여 3개 챕터의 구조를 잡고 아웃라인 완성

#### 과제 개요
- **난이도**: 중급
- **예상 소요시간**: 2시간
- **제출 형식**: 워드 문서

#### 상세 내용

**5+5 시스템 설명:**

**5분 아이디어 확장:**
1. 챕터 주제 적기 (30초)
2. 관련 키워드 10개 적기 (1분)
3. 에피소드 3개 떠올리기 (1분 30초)
4. 핵심 메시지 정하기 (1분)
5. 독자 질문 예상하기 (1분)

**5단계 작성 프로세스:**
1. **Hook**: 첫 문장/문단 - 독자 끌어들이기
2. **Story**: 에피소드/사례 - 공감 형성
3. **Point**: 핵심 메시지 - 배울 점 전달
4. **Action**: 실천 방법 - 독자가 할 수 있는 것
5. **Bridge**: 다음 챕터 연결 - 흐름 유지

**실습 과제:**

Part 1의 챕터 3개를 5+5 시스템으로 구조화하세요.

**각 챕터별 작성 내용:**

### 과제 2-3: 80% 완성 원칙 실습 - Part 1 초안 작성

#### 과제 목표
"완벽보다 완성" 원칙을 적용하여 Part 1 전체(8-10꼭지)를 80% 수준으로 초안 작성

#### 과제 개요
- **난이도**: 고급
- **예상 소요시간**: 8-10시간 (주중 분산)
- **제출 형식**: 워드 문서

#### 상세 내용

**80% 완성 원칙이란?**

- **100% 추구**: 1개 챕터에 10시간 → 번아웃 → 포기
- **80% 완성**: 10개 챕터에 10시간 → 완주 → 이후 다듬기

**80% 수준의 기준:**
- 핵심 메시지가 명확함
- 에피소드가 1개 이상 포함됨
- 도입-본문-마무리 구조가 있음
- 문장이 조금 어색해도 OK
- 완벽한 표현이 아니어도 OK

**실습 진행:**

**Day 1-2: 챕터 1-3 작성**
- 과제 2-1에서 작성한 1개 + 새로 2개
- 각 챕터 2,000-3,000자 목표
- 하루 1-2개 챕터씩

**Day 3-4: 챕터 4-6 작성**
- 5+5 시스템 적용
- AI 프롬프트 활용
- 하루 1-2개 챕터씩

**Day 5-6: 챕터 7-8(10) 작성**
- 남은 챕터 모두 완성
- Part 1 전체 흐름 확인

**Day 7: 검토 및 제출**
- 전체 읽어보기
- 큰 문제만 수정
- 80% 완성 상태로 제출

## 3. AI 자동 피드백 프롬프트

### 과제 2-1 피드백: AI 프롬프트 활용도 분석 보고서

```markdown
# AI 프롬프트 활용 분석 AI 피드백 프롬프트

## 역할 정의
당신은 AI 글쓰기 코칭 전문가입니다. 작가가 AI 프롬프트를 얼마나 효과적으로 활용했는지 분석하고, AI 출력물을 작가 스타일로 얼마나 잘 변환했는지 평가합니다.

## 분석 기준

### 1. AI 활용 효과성 (40점)
- 프롬프트 작성의 구체성 (15점)
- 프롬프트 순서 활용 적절성 (15점)
- AI 출력물 취사선택 판단력 (10점)

### 2. 작가 변환 품질 (40점)
- AI 티 제거 정도 (15점)
- 개인 경험/스타일 반영 (15점)
- 문장 자연스러움 (10점)

### 3. 최종 챕터 품질 (20점)
- 구조 완성도 (10점)
- 메시지 전달력 (10점)

## 출력 형식

---

## AI 프롬프트 활용 분석 보고서

**작가명**: [이름]
**분석 챕터**: [챕터 제목]
**제출일**: [날짜]

---

### 1. 종합 평가

**총점: [N]/100점**

| 평가 항목 | 점수 | 평가 |

**AI 코치 답변**

AI 글을 자연스럽게 만드는 5가지 방법입니다.

**1. 구어체로 전환**
- Before: "이것은 매우 중요한 사항입니다."
- After: "이건 정말 중요해요."

**2. 불완전한 문장 허용**
- Before: "그 일을 겪은 후 많이 변했습니다."
- After: "그 일 이후, 많이 변했어요. 정말 많이."

**3. 감정 표현 추가**
- Before: "성공했다."
- After: "드디어 성공했어요! 그때 정말 기뻤습니다."

**4. 개인 경험 삽입**
- Before: "많은 사람들이 어려움을 겪습니다."
- After: "저도 그랬어요. 2020년 3월, 그날..."

**5. 문장 길이 다양화**
- 짧은 문장: "변했다."
- 긴 문장: "그 경험을 통해 나는 완전히 다른 사람이 되었고..."

과제 2-1에서 프롬프트 7번(AI 티 제거)을 꼭 활용해보세요!
```

**Q2: AI 프롬프트를 더 효과적으로 쓰려면?**

```markdown
**AI 코치 답변**

효과적인 AI 프롬프트의 3가지 원칙입니다.

**1. 구체적으로 요청하기**
- Bad: "좋은 글 써줘"
- Good: "30대 워킹맘 대상, 따뜻한 톤, 1,500자, 육아 에피소드 포함해서 써줘"

**2. 역할 부여하기**
- Bad: "글 써줘"
- Good: "당신은 10년 경력의 육아 에세이 작가입니다. ..."

**3. 예시 제공하기**
- "다음 스타일로 써줘: [예시 문장]"
- "이런 톤은 피해줘: [피할 예시]"

**보너스 팁:**
"한 번에 다 요청하지 말고, 단계별로 나눠서 요청하세요."

과제에 제공된 7종 프롬프트를 그대로 사용해보시고,
익숙해지면 자신만의 프롬프트로 수정해보세요!
```

**Q3: AI가 쓴 부분과 내가 쓴 부분이 어색하게 이어져요**

```markdown
**AI 코치 답변**

AI 글과 내 글을 자연스럽게 연결하는 방법입니다.

**1. 연결 문장 추가**
- AI 문단 끝: "이처럼 습관의 힘은 강력합니다."
- 내 문단 시작: "저도 처음엔 믿지 않았어요. 하지만..."

**2. 톤 통일**
- AI가 "~입니다"체면 나도 "~입니다"체로
- AI가 "~해요"체면 나도 "~해요"체로

**3. 경험으로 연결**
- AI: [일반적 설명]
- 나: "제 경험으로는..."
- AI: [다시 일반적 설명으로 마무리]

**4. 전체 다시 읽기**
- 작성 후 처음부터 끝까지 소리 내어 읽기
- 어색한 부분 표시 → 수정

**팁:** 한 챕터를 완성한 후, 전체를 한 번 다시 쓴다고 생각하고 다듬으면 자연스러워집니다!
```

#### 질문 카테고리 2: 5+5 시스템 관련

**Q4: 5분 안에 아이디어가 안 떠올라요**

```markdown
**AI 코치 답변**

5분 아이디어 확장이 막힐 때 쓰는 비상 도구입니다.

**1. 키워드 연상법**
- 주제: "육아"
- 연상: 아이 → 울음 → 새벽 → 피곤 → 커피 → 위로 → 남편 → ...
- 10개가 될 때까지 자유롭게 연결

**2. 5W1H 질문법**
- Who: 누가 관련되어 있지?
- What: 정확히 뭐가 문제지?
- When: 언제 그랬지?
- Where: 어디서 일어났지?
- Why: 왜 그랬지?
- How: 어떻게 해결했지?

**3. 에피소드 떠올리기 질문**
- "이 주제로 가장 기억나는 순간은?"
- "이 주제로 가장 힘들었던 순간은?"
- "이 주제로 가장 뿌듯했던 순간은?"

**비상 팁:**
5분 안에 안 되면, 타이머 리셋하고 다시!
2-3번 하다 보면 갑자기 쏟아져 나옵니다.
```

**Q5: Hook(도입부)를 어떻게 시작해야 할지 모르겠어요**

```markdown
**AI 코치 답변**

막힐 때 쓰는 Hook 5가지 공식입니다.

**1. 질문 공식**
"당신도 [고민]한 적 있나요?"
예: "당신도 아이에게 소리 지른 뒤 자책한 적 있나요?"

**2. 고백 공식**
"솔직히 말하면, 나는 [충격적 고백]."
예: "솔직히 말하면, 나는 아이를 미워한 적이 있다."

**3. 장면 공식**
"[시간], [장소], 나는 [행동]하고 있었다."
예: "새벽 3시, 주방에서, 나는 혼자 울고 있었다."

**4. 통계 공식**
"[충격적 숫자/사실]이라는 걸 아시나요?"
예: "한국 엄마의 72%가 번아웃을 경험한다는 걸 아시나요?"

**5. 인용 공식**
"[누군가]가 말했다. '[인용문]'"
예: "아이가 말했다. '엄마, 왜 자꾸 화내?'"

**팁:**
하나만 고르지 말고, 3가지 버전을 다 써보세요!
그중 가장 끌리는 걸 선택하면 됩니다.
```

**Q6: Action(실천 방법)을 어떻게 구체화하나요?**

```markdown
**AI 코치 답변**

독자가 "오늘 당장" 할 수 있는 Action 작성법입니다.

**좋은 Action의 조건:**
1. 5분 안에 시작 가능
2. 도구나 비용이 거의 필요 없음
3. 혼자서도 할 수 있음

**나쁜 Action vs 좋은 Action:**

| 나쁜 Action | 좋은 Action |
|-------------|------------|
| "운동을 시작하세요" | "오늘 밤, 잠자기 전 스쿼트 10개만 하세요" |
| "감사일기를 쓰세요" | "지금 당장 폰 메모장에 감사한 것 3개 적으세요" |
| "아이와 대화하세요" | "오늘 저녁, '오늘 뭐가 재밌었어?'라고 한 번만 물어보세요" |

**Action 작성 공식:**
"[시간]에, [장소]에서, [구체적 행동]을 [횟수/분량]만큼 해보세요."

예: "오늘 밤 잠들기 전, 침대에서, 내일 할 가장 중요한 일 1개를 메모장에 적어보세요."
```

#### 질문 카테고리 3: 집필 습관 관련

**Q7: 매일 쓰는 게 너무 힘들어요**

```markdown
**AI 코치 답변**

매일 쓰기 어려울 때의 현실적 전략입니다.

**1. 최소 목표 설정**
- 매일 2,000자 → 매일 500자
- 막히면 200자라도 OK
- "0자"만 피하면 됨

**2. 시간 고정**
- 가장 방해받지 않는 시간 찾기
- 매일 같은 시간에 앉기 (내용 상관없이)
- 15분이라도 일정하게

**3. 환경 세팅**
- 글쓰기 전용 공간/의자
- 폰 다른 방에 두기
- 집필 전 루틴 만들기 (커피 한 잔 등)

**4. 보상 시스템**
- 500자 쓰면 [보상]
- 1,000자 쓰면 [보상]
- 일주일 연속 쓰면 [보상]

**오늘의 미션:**
"지금 당장 15분 타이머를 맞추고, 아무 챕터나 200자만 쓰세요."

완벽하지 않아도 됩니다. 일단 쓰면 이깁니다!
```

**Q8: 80% 완성이 뭔지 감이 안 와요**

```markdown
**AI 코치 답변**

80% 완성의 구체적 기준입니다.

**80% 완성 체크리스트:**
- [ ] 핵심 메시지가 적혀 있다
- [ ] 도입-본문-마무리 구조가 있다
- [ ] 에피소드/예시가 1개 이상 있다
- [ ] 처음부터 끝까지 읽을 수 있다

**100%가 아닌 것들 (OK인 것들):**
- 문장이 조금 어색해도 OK
- 맞춤법이 완벽하지 않아도 OK
- "나중에 이 부분 수정"이라고 표시해도 OK
- 에피소드가 부족해도 OK (나중에 추가)

**80% 예시:**

```
[80% 완성본]

아이가 처음 걸음마를 뗐을 때, 나는 울었다.
(이 부분에 그때 감정 더 구체적으로 추가할 것)

아이가 넘어졌다. 나도 넘어졌다.
(여기 5감 묘사 추가할 것: 거실 바닥 촉감, 아이 울음소리)

하지만 우리는 다시 일어났다.
(마무리 문장 더 강하게 수정할 것)
```

**80%면 충분합니다. 나머지 20%는 나중에!**
```
