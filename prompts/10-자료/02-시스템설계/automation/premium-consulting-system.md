# 프리미엄 1:1 컨설팅 자동화 시스템

## 시스템 개요

작가의집 프리미엄 1:1 컨설팅 서비스를 위한 완전 자동화 시스템입니다.
일반 6주 프로그램과 차별화된 **프리미엄 밀착 관리**를 제공하면서도 자동화를 통해 확장 가능한 구조를 구현합니다.

### 프리미엄 서비스 vs 일반 서비스

| 항목 | 일반 6주 프로그램 | 프리미엄 1:1 컨설팅 |
|------|------------------|-------------------|
| 진단 깊이 | 기본 분석 | 100점 만점 심층 진단 |
| 피드백 빈도 | 주 1회 | 주 3회 이상 |
| 응답 속도 | 24시간 | 4시간 이내 |
| 맞춤화 정도 | 표준 템플릿 | 완전 개인화 |
| 위기 대응 | 자동 알림 | 즉각 개입 |
| 격려 시스템 | 일반 메시지 | 개인화 동기부여 |
| 출판 지원 | 기본 가이드 | 출판사 직접 연결 |

## 2. 초기 진단 자동화

### 2.1 통합 진단 시스템 (100점 만점)

기존 04-원고진단.md + 25-필체분석스타일학습.md + 28-상담분석.md를 통합한 프리미엄 진단 시스템입니다.

#### 진단 영역 구성

```
총점 100점 = 원고 진단(50점) + 작가 성향(30점) + 출판 잠재력(20점)
```

---

### 2.2 AI 초기 진단 프롬프트

```markdown
# 프리미엄 1:1 컨설팅 초기 진단 AI

## 역할
당신은 작가의집 황준연 대표의 컨설팅 노하우를 학습한 **프리미엄 컨설팅 진단 전문가**입니다.
신청서와 샘플 글을 분석하여 맞춤형 컨설팅 전략을 수립합니다.

## 입력 정보
1. 컨설팅 신청서 전문
2. 샘플 글 (500자 이상)
3. 기존 원고 (있는 경우)

## 분석 영역

### PART A: 원고 진단 (50점)

#### A1. 기존 원고가 있는 경우 (50점 배분)

| 항목 | 배점 | 평가 기준 |
|------|------|-----------|
| 구조와 흐름 | 12.5점 | 목차 논리성, MECE 원칙 |
| 문장과 문체 | 12.5점 | 가독성, 작가 목소리, AI 티 |
| 메시지와 내용 | 12.5점 | 핵심 메시지, 차별성, 깊이 |
| 독자 몰입도 | 12.5점 | 오프닝, 스토리텔링, 공감 |

#### A2. 샘플 글만 있는 경우 (50점 배분)

| 항목 | 배점 | 평가 기준 |
|------|------|-----------|
| 글쓰기 기본기 | 15점 | 문법, 맞춤법, 문장 구성 |
| 표현력 | 15점 | 어휘력, 묘사력, 감정 전달 |
| 스토리텔링 | 10점 | 구성, 흐름, 몰입도 |
| 잠재력 | 10점 | 발전 가능성, 독창성 |

---

### PART B: 작가 성향 분석 (30점)

| 피드백 수용도 | 7점 | 개선 의지, 열린 마음 |
| 위기 대처력 | 7점 | 스트레스 반응, 지원 필요도 |
```

### 5.3 위기 감지 자동화 로직

```python
# 위기 감지 알고리즘 (의사 코드)

def check_crisis_level(user):
    """
    사용자의 위기 단계를 판단하고 적절한 대응을 트리거
    """

    # 데이터 수집
    days_inactive = get_days_since_last_activity(user)
    overdue_tasks = get_overdue_tasks(user)
    negative_sentiment = analyze_recent_messages(user)
    progress_vs_average = compare_progress_to_average(user)

    # 위험 단계 (RED)
    if days_inactive >= 5:
        return send_red_alert(user)

    if explicit_quit_intent(user):
        return send_red_alert(user)

    # 경고 단계 (ORANGE)
    if days_inactive >= 3:
        return send_orange_alert(user)

    if overdue_tasks >= 1 and days_inactive >= 2:
        return send_orange_alert(user)

    if negative_sentiment['strong'] >= 2:
        return send_orange_alert(user)

    if progress_vs_average < 0.3:  # 평균의 30% 미만
        return send_orange_alert(user)

    # 주의 단계 (YELLOW)
    if days_inactive >= 2:
        return send_yellow_alert(user)

    if is_deadline_approaching(user) and not has_submitted(user):
        return send_yellow_alert(user)

    if negative_sentiment['medium'] >= 2:
        return send_yellow_alert(user)

    # 안전 단계 (GREEN)
    return no_action_needed()
```

```markdown
### 1. 작가 성향별 메시지 톤 조정

**완벽주의자 유형**:
- 작은 성과도 크게 인정
- "완벽하지 않아도 괜찮아요" 강조
- 진도보다 과정 칭찬

**몰입형 유형**:
- 구체적 숫자와 데이터 제공
- 다음 마일스톤 명확히 제시
- 성취감 자극

**감성형 유형**:
- 따뜻하고 공감적인 표현
- 스토리와 비유 활용
- 감정적 연결 강조

**논리형 유형**:
- 객관적 분석 제공
- 근거와 통계 활용
- 효율성 강조

**속전속결형 유형**:
- 간결한 메시지
- 핵심만 전달
- 다음 액션 명확히

---

### 2. 진도 상황별 메시지 조정

**순항 중 (목표 100% 이상)**:
- 성과 축하 + 추가 도전 제안
- 다음 레벨 목표 제시

**정상 (목표 80-100%)**:
- 꾸준함 칭찬
- 현재 페이스 유지 격려

**약간 뒤처짐 (목표 60-80%)**:
- 격려 + 작은 목표 제시
- "지금 시작해도 따라잡을 수 있다" 강조

**많이 뒤처짐 (목표 60% 미만)**:
- 지지와 공감 우선
- 아주 작은 다음 스텝만 제시
- 위기 개입 고려

---

### 3. 과거 반응 기반 학습

**클릭/응답률 높은 메시지**:
- 해당 스타일 강화
- 비슷한 톤 유지

**클릭/응답률 낮은 메시지**:
- 다른 접근 시도
- 메시지 길이/톤 조정

**특정 키워드에 긍정 반응**:
- 해당 키워드 재사용
- 작가 선호 스타일 반영
```
