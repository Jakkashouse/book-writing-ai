# 6주 책쓰기 프로그램 자동화 시스템

> **목표**: 강사 시간 80% 절감 + 수강생 만족도 유지/향상
> **작성일**: 2026-01-10
> **버전**: 1.0.0

---

## 시스템 개요

이 폴더에는 6주 책쓰기 프로그램의 완전한 자동화 시스템이 포함되어 있습니다.

### 핵심 원칙

```
자동화 80% + 수동 개입 20% = 최고의 만족도
```

- **자동화**: 반복 작업, 데이터 분석, 표준화된 피드백
- **수동 개입**: 창의적 조언, 심리적 지원, 위기 상황

## 사용 방법

### 1. AI 피드백 프롬프트 사용

각 주차별 과제 시스템 파일(week-N-assignment-system.md)에서:

1. **과제 3개** 확인
2. **AI 자동 피드백 프롬프트** 복사
3. Claude/ChatGPT에 붙여넣기
4. 수강생 제출물 추가
5. 피드백 보고서 생성

### 2. 챗봇 시스템 적용

`chatbot-system.md` 파일의 시스템 프롬프트를:

1. API 챗봇에 적용
2. 또는 Claude Projects에 설정
3. FAQ는 `chatbot-faq-database.md` 참조

### 3. 백엔드 구현

1. `system-architecture-overview.md` 참조
2. `api-specification.md` 기반 API 개발
3. `database-schema.md` 기반 DB 설계

## 주의사항

### 자동화 vs 수동 판단 기준

**자동화 대상 (80%)**
- 반복적인 검토 (오탈자, 구조 검증)
- 데이터 기반 평가 (점수, 통계)
- 표준화된 피드백 (개선 방향)
- 진도 관리 & 리마인더
- FAQ 응답

**수동 개입 필요 (20%)**
- 창의적 조언
- 심리적 지원
- 위기 상황 개입
- 출판사 협상 조언
- 개인별 맞춤 전략
