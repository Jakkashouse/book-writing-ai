# AI 챗봇 FAQ 데이터베이스

## 개요

이 문서는 AI 챗봇의 **무제한 FAQ 자동 응답 시스템**에서 사용되는 FAQ 데이터베이스입니다.

### 특징
- **무제한 조회**: 질문 횟수에 포함되지 않음
- **즉시 응답**: 키워드 매칭으로 빠른 답변
- **우선 표시**: AI 코치 질문 전 FAQ 먼저 제안

## Category 1: 과제 제출 관련 (10개)

### FAQ-001: 과제는 어디서 제출하나요?

**키워드**: 과제, 제출, 어디서, 업로드

**답변**:
```
과제 제출은 수강생 대시보드에서 할 수 있어요!

[제출 방법]
1. 대시보드 접속 (로그인 필요)
2. 좌측 메뉴 > "과제 제출" 클릭
3. 해당 주차 선택
4. 파일 업로드 또는 텍스트 입력
5. "제출하기" 버튼 클릭

파일 형식: PDF, DOCX, HWP, TXT 가능
최대 용량: 50MB

문제가 있으면 기술 지원팀에 문의하세요!
```
