# 과제 피드백 보고서 자동 생성 시스템

## 시스템 개요

### 목적
수강생의 과제 제출 시 1회성으로 구조화된 피드백 보고서를 자동 생성하여:
- 수강생의 만족도와 성장 실감 극대화
- 강사의 피드백 시간 80% 절감
- 적절한 수준의 정보 제공 (강의 가치 유지)

### 핵심 원칙

#### 1. 긍정 우선 원칙 (Praise First)
- 강점을 먼저 발견하고 구체적으로 칭찬
- 개선점도 "더 좋아질 수 있는 방법"으로 포장
- 수강생이 피드백 후 "더 하고 싶다"고 느껴야 함

#### 2. 구체적 예시 원칙 (Show, Don't Tell)
- 추상적 평가 금지 ("좋아요", "아쉬워요" 등)
- 원고에서 실제 문장/내용 인용
- Before/After 예시 필수 포함

#### 3. 실행 가능한 조언 원칙 (Actionable Feedback)
- 다음 단계가 명확해야 함
- "오늘 당장 할 수 있는 것" 제시
- 예상 소요 시간 명시

#### 4. 적절한 수준 원칙 (Balanced Value)
- 너무 많이 주면 강의가 무의미해짐
- 너무 적으면 만족도 하락
- **핵심 3가지**에 집중 (강점 3개 + 개선점 3개)

| B. 초안 작성 과제 | 챕터 초안, 오프닝 작성 | 문장력, 스토리텔링 |
| C. 원고 완성 과제 | 전체 원고, 최종 수정 | 완성도, 일관성 |
| D. 마케팅 과제 | 저자 소개, 책 소개글 | 매력도, 차별화 |

## 시스템 운영 가이드

### 피드백 생성 프로세스

```
1. 수강생 과제 제출
   ↓
2. 과제 유형 자동 분류 (A/B/C/D)
   ↓
3. 해당 유형 AI 프롬프트 실행
   ↓
4. 상세 피드백 보고서 생성
   ↓
5. 요약 버전 자동 생성
   ↓
6. 카톡/이메일 자동 발송 (요약)
   ↓
7. 웹앱에서 상세 보고서 확인 가능
```

### 품질 보장 체크리스트

#### 모든 보고서에 필수 포함
- [ ] 100점 만점 점수 체계
- [ ] 강점 3가지 (구체적 인용 포함)
- [ ] 개선점 3가지 (Before/After 포함)
- [ ] 다음 단계 가이드 (시간 명시)
- [ ] 격려 메시지

#### 금지 사항
- [ ] 추상적 평가 ("좋아요", "아쉬워요" 등 단독 사용)
- [ ] 과도한 부정적 표현
- [ ] 실행 불가능한 조언
- [ ] 너무 많은 개선점 나열 (3개 초과)

### 수준별 피드백 조절

#### 초급 수강생
- 칭찬 비율 높이기 (70%)
- 개선점은 가장 시급한 1-2개만
- 구체적 예시 더 풍부하게
- 격려 메시지 강화

#### 중급 수강생
- 칭찬과 개선점 균형 (50:50)
- 3가지 개선점 모두 제시
- 다음 레벨 도약 방법 포함

#### 고급 수강생
- 미세한 부분까지 지적 가능
- 시장성, 차별화 분석 강화
- 출판 전략 조언 포함

## 피드백 품질 보장 원칙 (상세)

### 1. 긍정 우선 원칙

**반드시 지키기**:
- 아무리 미흡한 과제라도 강점 3가지 필수 발견
- 강점을 먼저 언급한 후 개선점 언급
- 작은 장점도 구체적으로 칭찬

**좋은 예시**:
```
"김OO님, 첫 번째 제목 '마흔, 새로운 시작'이 정말 마음에 듭니다!
'마흔'이라는 구체적 숫자가 타겟 독자를 명확히 보여주고,
'새로운 시작'이라는 희망적 메시지가 독자를 끌어당기네요.
이 제목 하나로 작가님의 센스가 느껴져요!"
```

**나쁜 예시**:
```
"제목이 전반적으로 평범해요. 다시 생각해보세요."
```

### 2. 구체적 예시 원칙

**반드시 지키기**:
- 수강생 제출물에서 실제 문장/내용 인용
- 추상적 평가 금지
- Before/After 예시 필수

**좋은 예시**:
```
**현재 문장**:
> "아이가 울었다. 나는 힘들었다."

**수정 제안**:
> "아이가 울었다. 새벽 3시, 어둠 속에서 아이 울음소리만 들렸다.
> 내 눈에서도 눈물이 흘러내렸다."

**변화 포인트**:
- "힘들었다" → 구체적 장면과 행동으로 표현
- 시간, 감각 묘사 추가
- 독자가 그 순간을 함께 느낄 수 있음
```

**나쁜 예시**:
```
"문장이 어색해요. 더 자연스럽게 써보세요."
```

### 3. 실행 가능한 조언 원칙

**반드시 지키기**:
- 다음 단계가 명확해야 함
- 예상 소요 시간 명시
- "오늘 당장 할 수 있는 것" 제시

**좋은 예시**:
```
## 오늘 할 일 (30분)

1. **"힘들다" 반복 수정** (15분)
   - 위치: 3문단, 5문단, 7문단
   - 방법: 각 "힘들다"를 구체적 장면으로 교체
   - 팁: "어디서, 언제, 무슨 행동을 했는지" 추가

2. **마지막 문장 보강** (15분)
   - 현재: "그날 나는 포기했다."
   - 추가: "대신 무엇을 얻었는지" 1문장 추가
```

**나쁜 예시**:
```
"전체적으로 다시 써보세요."
```

### 4. 동기부여 메시지 원칙

**반드시 지키기**:
- 피드백 후 "더 하고 싶다"고 느끼게
- 구체적인 성과 인정
- 다음 단계에 대한 희망 제시

**좋은 예시**:
```
## 격려 메시지

김OO님, 이 챕터를 읽으면서 저도 눈물이 났습니다.

**특히 좋았던 점**:
"새벽 3시, 나는 아이와 함께 울고 있었다"
이 첫 문장은 제가 본 육아 에세이 중 상위 5%입니다!

**앞으로가 기대되는 이유**:
이미 스토리텔링의 핵심을 알고 계세요.
조금만 다듬으면 독자들이 눈물 흘릴 베스트 챕터가 됩니다.

**다음 챕터가 벌써 기대돼요!**
오늘 30분만 투자하면 이 챕터는 완성입니다.
천천히, 하나씩 해나가면 됩니다. 작가님 화이팅!
```
