# 세상에서 제일 멋진 누나
## 그림책 시리즈 (전 10권)

**기획 의도**: 5살 누나가 갓 태어난 남동생과 함께 성장하는 이야기

**타겟 독자**: 3~6세 어린이 + 읽어주는 부모

---

## 1권. 동생을 처음 만난 날

**핵심 메시지**: 첫 만남의 설렘

| 페이지 | 글 | 그림 설명 |
|--------|-----|----------|
| 1-2 | 오늘 병원에 갔어요. | 엄마 손 잡고 병원 복도 걷는 누나 |
| 3-4 | 아기가 있었어요. 아주 작은 아기. | 신생아실 유리창 너머 아기 보는 누나 |
| 5-6 | "이게 네 동생이야." | 아빠가 누나 눈높이에 맞춰 설명 |
| 7-8 | 동생 손이 내 손가락을 잡았어요. | 아기 손이 누나 손가락 잡는 클로즈업 |
| 9-10 | 간지러웠어요. 그리고... 조금 따뜻했어요. | 살짝 미소 짓는 누나 |
| 11-12 | "안녕, 동생아." | 아기에게 인사하는 누나 |

---

## 2권. 삐진 날

**핵심 메시지**: 감정 표현과 위로

| 페이지 | 글 | 그림 설명 |
|--------|-----|----------|
| 1-2 | 오늘은 기분이 안 좋아요. | 뾰로통한 누나 |
| 3-4 | 엄마가 자꾸 동생만 봐요. | 동생 안은 엄마, 멀리 있는 누나 |
| 5-6 | 방에 들어가서 문을 닫았어요. | 방문 닫는 누나 |
| 7-8 | 똑똑. 엄마가 왔어요. | 문 두드리는 엄마 |
| 9-10 | "우리 딸, 속상했구나." | 누나 안아주는 엄마 |
| 11-12 | 울었어요. 그랬더니 마음이 풀렸어요. | 엄마 품에서 우는 누나 |

---

## 3권. 엄마는 나도 사랑해?

**핵심 메시지**: 변함없는 사랑 확인

| 페이지 | 글 | 그림 설명 |
|--------|-----|----------|
| 1-2 | 자기 전에 물었어요. | 이불 속 누나 |
| 3-4 | "엄마, 나도 사랑해?" | 걱정스러운 눈의 누나 |
| 5-6 | 엄마가 웃었어요. | 부드럽게 웃는 엄마 |
| 7-8 | "세상에서 제일 사랑해." | 누나 이마에 뽀뽀하는 엄마 |
| 9-10 | "동생도요?" "동생도." | 대화하는 둘 |
| 11-12 | 사랑은 둘 다 제일 할 수 있대요. | 행복하게 잠든 누나 |

---

## 4권. 사랑은 안 줄어요

**핵심 메시지**: 사랑의 의미

| 페이지 | 글 | 그림 설명 |
|--------|-----|----------|
| 1-2 | 피자를 나눠 먹으면 작아져요. | 피자 나누는 그림 |
| 3-4 | 케이크를 나눠 먹으면 작아져요. | 케이크 나누는 그림 |
| 5-6 | 그런데 사랑은요? | 생각하는 누나 |
| 7-8 | 엄마가 말했어요. "사랑은 나눠도 줄지 않아." | 엄마 설명 |
| 9-10 | 오히려 더 커진대요. | 하트가 커지는 상상 |
| 11-12 | 신기해요. 사랑은 마법이에요. | 양손에 하트 든 누나 |

## 5권. 동생이 울 때

| 페이지 | 글 | 그림 설명 |

| 1-2 | 으앙! 동생이 울어요. | 우는 아기 |
| 3-4 | 엄마가 없어요. 어떡하지? | 두리번거리는 누나 |
| 5-6 | 딸랑딸랑. 딸랑이를 흔들었어요. | 딸랑이 흔드는 누나 |
| 7-8 | 동생이 쳐다봤어요. | 딸랑이 보는 아기 |
| 9-10 | 울음을 멈췄어요! | 울음 그친 아기 |
| 11-12 | 내가 해냈어요! | 뿌듯한 누나 |

| 페이지 | 글 | 그림 설명 |
|--------|-----|----------|
| 1-2 | 동생이 심심해 보여요. | 멍한 표정의 아기 |

| 5-6 | 손으로 얼굴을 가렸어요. | 손으로 얼굴 가린 누나 |
| 7-8 | "까꿍!" | 손 치우며 웃는 누나 |
| 9-10 | 까르르르! 동생이 웃어요! | 깔깔 웃는 아기 |
| 11-12 | 까꿍 놀이는 최고예요. | 계속 까꿍하는 누나 |

## 8권. 동생이 "누나" 할 때까지

**핵심 메시지**: 기다림과 기대

| 페이지 | 글 | 그림 설명 |
|--------|-----|----------|
| 1-2 | 동생은 아직 말을 못 해요. | 옹알이하는 아기 |
| 3-4 | "누나. 누-나." | 가르치는 누나 |
| 5-6 | "아-바-바-바." | 옹알이하는 아기 |
| 7-8 | 아직이에요. 괜찮아요. | 기다리는 누나 |
| 9-10 | 언젠가 "누나!" 할 거예요. | 상상하는 누나 |
| 11-12 | 그날이 너무 기다려져요. | 설레는 표정 |

| 페이지 | 글 | 그림 설명 |
|--------|-----|----------|

| 7-8 | 처음 웃음, 처음 걸음. | 아기 때 사진들 |
| 9-10 | 다 나와 함께였대요. | 추억 사진들 |
| 11-12 | 나는 특별한 첫째예요. | 뿌듯한 누나 |
