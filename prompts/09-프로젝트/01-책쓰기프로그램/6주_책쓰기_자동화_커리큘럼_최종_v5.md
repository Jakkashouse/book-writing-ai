## 핵심 철학: "쉽다"의 정의

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   "AI가 80%, 나는 20%만"                                │
│   "빈칸만 채우면 끝"                                    │
│   "막히면 바로 답 온다"                                 │
│                                                         │
│   → 수강생이 느끼는 것: "이거 나도 되겠는데?"           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### "쉽다"를 만드는 3요소

| 요소 | 적용 방법 |
|------|-----------|
| **양이 적다** | 모든 미션 "핵심만" (과감히 축소) |
| **내가 할 게 없다** | AI가 초안 → 나는 선택/수정만 |
| **막혀도 바로 해결** | 챗봇 + 예시 + 템플릿 풍부 |

## 전체 구조

```
[0주차] 온보딩 - "준비 끝, 기대감 UP" (자동)
   ↓
[1주차] 제목+목차 - "뼈대 완성" (2시간)
   ↓
[2주차] 초고 전반 - "절반 썼다" (3시간)
   ↓
[3주차] 초고 완성+제안 - "출판사 발송!" (3시간)
   ↓
[4주차] 마케팅 플랜 - "베스트셀러 준비" (2시간)
   ↓
[5주차] 웨비나 설계 - "수익화 시스템" (3시간)
   ↓

   ↓
[수료 후] 출간 지원 3개월
```

**총 투자 시간: 6주 × 약 3시간 = 18시간**
(하루 30분 × 주 4일 페이스)

### 챗봇이 바로 답변하는 것 (짧은 조언)

```
✅ 즉시 답변 영역

1. 일정/링크 질문
   • VOD 어디서 봐요? → 링크 제공
   • 라이브 언제예요? → 일정 안내
   • 자료 어디 있어요? → 다운로드 링크

2. 도구 사용법
   • AI가 이상하게 답해요 → 프롬프트 수정 팁
   • 템플릿 어떻게 써요? → 간단 가이드

3. 간단한 프롬프트 수정 팁
   • "너무 길게 나와요" → "2000자 내외로" 추가하세요
   • "너무 딱딱해요" → "친근한 말투로" 추가하세요

4. 마인드셋 응원
   • "못할 것 같아요" → 응원 메시지 + 성공 사례
   • "늦은 것 같아요" → 괜찮다는 안심 + 복구 방법
```

```
   ├─ 서로 리뷰 교환 (출간 시 서로 서점 리뷰)
   ├─ 마케팅 협업 (공동 라이브, 콜라보)
   └─ 출판사/기회 정보 공유

2. 월 1회 수료생 모임 (온라인)
   ├─ 출간 성공 사례 발표
   ├─ 네트워킹 시간
   ├─ 신규 기회 공유 (강연, 출판, 협업)
   └─ 선배 저자 멘토링

3. 출간 축하 이벤트
   ├─ 출간 시 전체 공지 + 축하 메시지
   ├─ 수료생들 서점 리뷰 릴레이
   ├─ SNS 홍보 지원 (공식 계정에서 소개)
   └─ 출간 기념 라이브 인터뷰

4. 수료생 특별 혜택
   ├─ 신규 프로그램 50% 할인
   ├─ 후배 기수 추천 시 리워드
   └─ 협업 기회 우선 제공
```

## 5. 프리미엄 vs 일반

| 항목 | 일반 (700만) | 프리미엄 (1,200만) |
|------|-------------|-------------------|
| VOD + 라이브 6주 | ✅ | ✅ |
| 템플릿/프롬프트 | ✅ | ✅ |
| 자동 피드백 | 24시간 | **12시간** |
| 챗봇 | 일 10회 | **무제한** |
| 1:1 코칭 | 2회 | **6회 (매주)** |
| 피드백 깊이 | 핵심 3가지 | **전체 상세 분석** |
| 출판사 | 리스트 제공 | **직접 연결 + 협상 지원** |
| 수료 후 무료 | 3개월 | **6개월** |

**프리미엄 핵심 차별화:**
1. **속도** - 피드백 12시간
2. **깊이** - 상세 분석 + 매주 코칭
3. **연결** - 출판사 직접 소개

## 6. 프리미엄 1:1 코칭 주차별 어젠다

```
┌─────────────────────────────────────────────────────────┐
│ 프리미엄 1:1 코칭 시스템 (매주 30분)                      │
│ "1:1 케어로 실력을 끌어올리는 로직"                       │
└─────────────────────────────────────────────────────────┘
```

### 1주차 코칭 (30분): 제목/목차 확정

```
[어젠다]
├─ 00-05분: 이번 주 진행 상황 체크
├─ 05-15분: 제목 최종 확정
│   └─ AI 피드백 TOP 3 중 1개 선택 도움
│   └─ 타겟 독자 관점에서 검증
├─ 15-25분: 목차 심층 리뷰
│   └─ 5부 흐름 전체 점검
│   └─ 약한 부분 즉석 수정
└─ 25-30분: 다음 주 목표 설정 + 질문

[코칭 후 제공물]
• 확정된 제목 1개
• 수정된 목차 파일
• 2주차 초고 작성 가이드
```

### 2주차 코칭 (30분): 초고 돌파

```
[어젠다]
├─ 00-05분: 1-3부 진행 상황 체크
├─ 05-25분: 막히는 챕터 돌파
│   └─ 어떤 챕터가 막히는지 파악
│   └─ 함께 본인 경험 발굴 (질문으로 끌어내기)
│   └─ 막힌 챕터 즉석 완성 도움
└─ 25-30분: 남은 챕터 전략 + 질문

[코칭 후 제공물]
• 막힌 챕터 완성본
• 본인 경험 발굴 메모
• 남은 챕터 작성 순서 가이드
```

### 3주차 코칭 (30분): 기획서/출판사 전략

```
[어젠다]
├─ 00-05분: 4-5부 완성 여부 확인
├─ 05-15분: 기획서 최종 검토
│   └─ 출판사가 보는 관점에서 피드백
│   └─ 책 소개/저자 소개 즉석 수정
├─ 15-25분: 출판사 전략
│   └─ 30곳 중 우선순위 TOP 10 선정
│   └─ 각 출판사별 맞춤 어필 포인트
└─ 25-30분: 발송 전 최종 체크 + 질문

[코칭 후 제공물]
• 완성된 기획서
• 출판사 우선순위 리스트
• 맞춤 이메일 템플릿 3종
```

### 4주차 코칭 (30분): 마케팅/출판사 대응

```
[어젠다]
├─ 00-05분: 출판사 답변 상황 공유
├─ 05-15분: 마케팅 플랜 점검
│   └─ D-30 타임라인 실현 가능성 체크
│   └─ SNS 콘텐츠 차별화 전략
├─ 15-25분: 리뷰어 확보 전략
│   └─ 영향력 있는 리뷰어 섭외 방법
│   └─ 리뷰 요청 메시지 작성 도움
└─ 25-30분: 출판사 답변 대응 (있을 경우) + 질문

[코칭 후 제공물]
• 수정된 마케팅 타임라인
• 리뷰 요청 메시지 템플릿
• 출판사 협상 가이드 (답변 온 경우)
```

### 5주차 코칭 (30분): 웨비나 리허설

```
[어젠다]
├─ 00-05분: 스크립트 완성 여부 확인
├─ 05-25분: 웨비나 리허설
│   └─ 핵심 파트 직접 리딩 (오프닝, 전환, 클로징)
│   └─ 실시간 피드백 + 즉석 수정
│   └─ 전환율 높이는 말투/강조점 코칭
└─ 25-30분: 오퍼 가격 최종 조정 + 질문

[코칭 후 제공물]
• 수정된 스크립트
• 리허설 피드백 메모
• 웨비나 체크리스트
```

### 6주차 코칭 (30분): 로드맵/수료 후 설계

```
[어젠다]
├─ 00-05분: 6주간 성과 축하 + 회고
├─ 05-15분: 1년 로드맵 최종 점검
│   └─ 월별 목표 현실성 체크
│   └─ 우선순위 조정
├─ 15-25분: 수료 후 3개월 액션 플랜
│   └─ 출판사 계약 시 대응 전략
│   └─ 자가 출판 시 실행 계획
│   └─ 웨비나 런칭 일정
└─ 25-30분: 수료 후 지원 안내 + 마무리

[코칭 후 제공물]
• 확정된 1년 로드맵
• 3개월 액션 플랜
• 수료 후 지원 가이드
```
