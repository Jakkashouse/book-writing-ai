## 슬라이드별 상세 내용

### 슬라이드 1 (표지)
**제목:** 이 책이 청소년에게 주는 5가지

**부제:** 『열다섯 걸음, 울릉도 독도 이야기』

**배경:** 따뜻한 그라데이션 (주황-노랑 계열)

**이미지 키워드:** 책 표지, 학생들 단체 사진, 울릉도 풍경

---

### 슬라이드 2
**제목:** 1️⃣ 공감

**본문:**
```
또래가 쓴 글이기에
더 깊이 공감됩니다

15명의 솔직한 목소리가
같은 나이 친구들에게
더 와닿습니다

전문 작가가 아닌
진짜 10대의 이야기
```

**배경:** 파스텔 핑크

**이미지 키워드:** 학생들이 함께 책 읽는 모습, 하트 아이콘, 친구들

---

### 슬라이드 3
**제목:** 2️⃣ 용기

**본문:**
```
"나도 할 수 있다"는
자신감을 얻습니다

힘든 등산도, 글쓰기도
또래가 해냈다면
나도 할 수 있습니다
```

**배경:** 파스텔 블루

**이미지 키워드:** 산을 오르는 학생, 등산, 성취감, 도전

---

### 슬라이드 4
**제목:** 3️⃣ 호기심

**본문:**
```
울릉도·독도에 대한
관심이 생깁니다

"저도 독도 땅을 밟아보고 싶어요"
"나리분지 진짜 궁금해요!"

여행 욕구를 자극하는 생생함
```

**배경:** 파스텔 민트

**이미지 키워드:** 독도 풍경, 울릉도 절경, 나리분지, 바다

---

### 슬라이드 5
**제목:** 4️⃣ 글쓰기 영감

**본문:**
```
기행문 쓰기의
좋은 모델이 됩니다

✅ 솔직한 감정 표현법
✅ 여행 정보 담는 법
✅ 재미있는 제목 짓기
✅ 일기를 책으로 만드는 과정

국어 교사 추천 도서
```

**배경:** 파스텔 옐로우

**이미지 키워드:** 펜과 노트, 글쓰는 손, 일기장, 책

---

### 슬라이드 6
**제목:** 5️⃣ 역사 의식

**본문:**
```
독도 영토 의식을
자연스럽게 배웁니다

"나는 독도를 위해 뭘 했지?"

학생이 독도의용수비대 기념관에서
던진 질문.

진짜 교육은 이렇게 시작됩니다
```

**배경:** 파스텔 퍼플

**이미지 키워드:** 태극기, 독도 표지판, 기념관, 애국심

---

### 슬라이드 7
**제목:** 이 책의 활용 가능성

**본문:**
```

✅ 독서 모임 교재
   또래 친구들과 함께 읽기

✅ 기행문 쓰기 참고
   생생한 글쓰기 모델

✅ 독도 영토 교육 자료
   자연스러운 역사 학습
```

**배경:** 화이트 + 컬러 포인트

**이미지 키워드:** 체크리스트, 학교 건물, 도서관, 교실

### 3. 테마 선택
- **추천 테마:** "Modern", "Clean", "Educational", "Vibrant"
- **색상 팔레트:** 파스텔 톤 또는 따뜻한 톤

### 4. 폰트 설정
- **제목:** 굵은 고딕 (Bold Sans-serif)
- **본문:** 가독성 좋은 고딕 (Noto Sans KR 또는 Pretendard)
- **크기:** 제목 32-40pt, 본문 18-24pt

### 5. 이미지 추가 (옵션)
- 감마 AI가 자동으로 이미지 제안
- 또는 직접 업로드 (책 표지, 학생 사진 등)
- 무료 이미지 사이트: Unsplash, Pexels

### 6. 색상별 슬라이드 배경 추천
- 슬라이드 1: 주황-노랑 그라데이션 (#FF9A56 → #FFD766)
- 슬라이드 2: 파스텔 핑크 (#FFB3BA)
- 슬라이드 3: 파스텔 블루 (#BAE1FF)
- 슬라이드 4: 파스텔 민트 (#BFFCC6)
- 슬라이드 5: 파스텔 옐로우 (#FFFFBA)
- 슬라이드 6: 파스텔 퍼플 (#D4BAFF)
- 슬라이드 7: 화이트 (#FFFFFF)
- 슬라이드 8: 브랜드 컬러 그라데이션

### 7. 애니메이션 설정
- 슬라이드 전환: "Fade" 또는 "Slide"
- 속도: Medium (2-3초)

### 8. 내보내기
- **인스타그램용:** 1080x1080 (정사각형) 또는 1080x1920 (세로)
- **형식:** PNG 또는 PDF
- "Export" → "Images" 선택
