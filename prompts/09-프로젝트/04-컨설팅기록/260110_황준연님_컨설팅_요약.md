# 미팅 요약: 황준연님 컨설팅 (5-2회차)

**날짜**: 2026년 1월 10일
**참석자**: 화자 1 (황준연님), 화자 2 (컨설턴트)
**회차**: 5-2회차
**미팅 시간**: 약 58분

---

## 핵심 요약

책 출간 강의 프로그램을 3주(출간 과정) + 3주(마케팅/수익화 과정)으로 재구성하고, AI 자동화 시스템을 활용한 수강생 맞춤형 프로그램 개발 전략을 수립했습니다. Claude Code, Cursor 등 AI 개발 도구를 활용하여 웹앱 자동화 시스템을 구축하고, 2월 초 유료 강의 런칭을 목표로 세부 일정을 확정했습니다.

## 미팅 분위기

- **긍정적이고 열정적**: 황준연님이 Claude Code와 Cursor 활용에 큰 흥미를 보이며 적극적으로 학습 중
- **협업적**: 컨설턴트가 구체적인 피드백과 실행 가능한 제안을 제공하며 상호 신뢰 관계 유지
- **실용적**: 기술적 가능성보다는 실제 구현 가능성과 비즈니스 효율성에 집중

## 주요 의사결정

### 1. 강의 구조 재설계
- **결정사항**: 6주 프로그램을 3주 + 3주로 분리
  - **1~3주차**: 출간 과정 (제목/목차 → 초고 → 출판사 제출)
  - **4~6주차**: 마케팅 및 수익화 과정 (강의/웨비나/출판사 협업)
- **가격 전략**:
  - 1~3주차 단독 상품 (저가)
  - 1~6주차 통합 상품 (중가, 메인 상품)
  - 1대1 프리미엄 컨설팅 (고가, 최소화 전략)
- **근거**: 수강생이 필요한 과정만 선택 가능하고, 후반부 과정의 매력도를 높여 통합 상품 판매 유도

### 2. 강의 제목 및 메시지 개선
- **기존**: "단 하루 만에 제목과 목차 완성"
- **개선안**: "하루 만에 책 절반 완성"
  - 제목과 목차가 완성되면 책의 절반이 완성된 것으로 프레이밍
  - 나머지 작업은 상대적으로 쉽다는 메시지 전달

### 3. AI 자동화 시스템 구축 방향
- **핵심 결정**: 수강생 전용 웹앱 개발 (엑셀/GPT 링크가 아닌 독립 프로그램)
- **기술 스택**: Claude Code, Cursor, Antigravity (선택적)
- **개발 난이도**: 수강생 전용이므로 상용 서비스 수준의 보안/안정성 불필요
- **예상 개발 기간**: 1~2주 (핵심 기능 먼저 구현, 나머지는 점진적 추가)

### 4. 강의 일정 확정
- **광고 시작**: 2026년 1월 26일
- **무료 웨비나**: 2026년 2월 4일 (수요일)
- **판매 마감**: 2026년 2월 6일 (금요일)
- **유료 강의 시작**: 2026년 2월 7일 (토요일)
- **고려 사항**: 설날 연휴(1/28~2/1) 직전/직후 피하고, 광고 기간 약 10일 확보

### 5. 기술 도구 선택
- **우선순위 1**: Cursor + Claude Code (현재 황준연님이 학습 중)
- **우선순위 2**: Antigravity (이미지 생성 및 디자인 강점, Google Gemini 연동)
- **교육 자료**: 코드팩토리 강의 추천 (깔끔한 교육, 쓸데없는 설명 최소화)

## 의사결정 과정

### 강의 구조 분리 배경
1. **컨설턴트 제안**: 3주 단독 상품과 6주 통합 상품으로 분리
2. **황준연님 초기 의견**: 4주까지 출간, 5~6주가 수익화로 생각했으나 수정에 동의
3. **최종 합의**: 3주/3주 분리가 상품 전략상 유리 (후반부 매력도 증가 + 가격 차별화)

### AI 자동화 시스템의 중요성 강조
1. **컨설턴트 강조**: "건물의 뼈대를 설계하는 과정"
2. **시간 투자 필요성**: 최소 2~3일간 아이디어 20개 이상 도출 후 최선 선택
3. **Snowballing 효과**: 초기 설계가 잘못되면 나중에 수정 불가능 (시멘트로 철근 문제 해결 불가)
4. **핵심 가치**: 1대1 컨설팅 효과의 50% 이상을 자동화로 구현하여 수강생 만족도 ↑, 강사 시간 ↓

### 일정 조율 과정
1. **광고 기간**: 최소 10일 필요 (효율성 최대화)
2. **설날 회피**: 1/28~2/1 연휴 직전/직후 피함
3. **평일 vs 주말**: 황준연님 평일 선호 → 수요일 웨비나, 토요일 강의 시작으로 절충

## 논의된 주요 주제

### 1. AI 자동화 시스템 설계 철학
- **핵심 원칙**: "건물의 뼈대" - 초기 설계가 전체 효율성 결정
- **목표**: 1대1 컨설팅 효과의 50% 이상을 자동화로 달성
- **주요 기능**:
  - 주차별 과제 자동 제출 및 피드백 시스템 (보고서 형식)
  - 챗봇 Q&A (횟수 제한, 짧은 답변으로 구성)
  - 수강 종료 후 프로그램 지속 사용 여부 (무료 1년 vs 유료화)

### 2. 기술 도구 비교 및 선택
- **Claude Code**: 서브에이전트, 병렬 작업, 스킬 기능 강점
- **Cursor**: 랜딩 페이지 빠른 제작 (30분 내), 배포 용이
- **Antigravity**: 이미지 생성, 디자인 우수, 브라우저 컨트롤 강점 (Google Gemini 연동)
- **선택 기준**: 익숙한 도구 우선, 90점 vs 100점의 차이보다는 실행 속도 중시

### 3. 서브에이전트(Subagent) 개념
- **정의**: 특정 작업을 전문적으로 수행하는 AI 에이전트
- **장점**:
  - Context 오염 방지 (메인 에이전트는 관리만, 서브 에이전트는 실행)
  - 병렬 작업 가능 (터미널 여러 개 동시 작업)
  - 전문성 향상 (리서치, 기획, 문서 작성 등 각자 전문 분야)
- **활용 예시**:
  - 메인 에이전트가 15명의 서브 에이전트 호출
  - 리서치 전문가, 기획 문서 작성자, 검토 전문가 등 역할 분담
  - 각자 깨끗한 Context로 작업하여 품질 향상

### 4. 1대1 프리미엄 컨설팅 전략
- **가격 전략**: "아주 비싸게" 설정하여 강사 시간 투입 최소화
- **목적**:
  - 자동화 시스템으로 대부분 해결
  - 1대1은 극소수 고객만 선택하도록 유도
  - 강사는 시스템 개선 및 콘텐츠 확장에 집중

### 5. 경쟁 우위 확보 전략
- **차별화 요소**:
  - Prompt 공유가 아닌 "전용 프로그램" 제공
  - 수강생이 바로 사용 가능한 웹앱 형태
  - 실시간 데모로 "책이 정말 나온다"는 확신 제공
- **진입 장벽**:
  - 경쟁사가 유사 시스템 구축하는 데 최소 1년 소요 예상
  - 지속적인 업그레이드로 격차 유지

## 주의 신호

### 1. 알림톡 승인 불확실성
- **문제**: 카카오톡 검수 기준이 엄격해져 승인 거절 가능성 존재
- **대응**:
  - 고마워톡 개발자에게 최신 기준 확인
  - 승인 거절 대비 문자 발송 시스템 미리 준비
  - 웨비나 직전이 아닌 사전에 세팅 및 테스트

### 2. 자동화 시스템 개발 난이도
- **문제**: 수강생 전용 vs 상용 서비스의 난이도 차이 (10배)
- **대응**:
  - 수강생 전용으로 한정하여 보안/안정성 부담 최소화
  - 기능 작동 우선, 세련된 UX는 추후 개선
  - AI 도구 활용으로 개발 시간 단축

### 3. 일정 촉박함
- **문제**: 1월 26일 광고 시작까지 약 2주 남음
- **대응**:
  - 자동화 커리큘럼 기획에 집중 (다른 작업의 기초)
  - 웹앱 개발은 핵심 기능만 우선 완성
  - 병렬 작업 (랜딩 페이지, CRM, 웨비나 동시 진행)

### 4. 과도한 기능 제공 우려
- **문제**: 챗봇/자동화 기능이 너무 많으면 강의 완강률 하락 가능
- **대응**:
  - 과제 피드백은 보고서 형식 (횟수 제한)
  - 챗봇은 짧은 답변 (결과물 대신 가이드 제공)
  - 채팅 횟수 제한 고려
  - 수강 종료 후 프로그램 사용은 유료화 검토
