# 1. 구체적인 프롬프트 예시

## 📋 ChatGPT 프롬프트 템플릿

### A. 숏폼 영상 스크립트 생성

```
역할: 당신은 1000만 조회수 숏폼 전문 카피라이터입니다.

작업: 60초 숏폼 영상 스크립트 작성

책 정보:
- 제목: "재개발의 여왕, 100억 자산가 되다"
- 작가: 김성진
- 장르: 재테크 실용서 (소설 형식)
- 주인공: 30대 주부 김소정
- 스토리: 청약 5번 실패 → 재개발 투자 → 10년 후 100억 자산가

타겟 독자:
- 30대 여성, 주부
- 청약 실패 경험자
- 1억 이하 소액 투자자
- 재테크 관심 있지만 막막한 사람

영상 목적: 도파민 자극 → 공감 → 호기심 → 구매 욕구

스크립트 요구사항:
1. 총 60초 (4개 챕터 × 15초)
2. 훅(0-15초): 강력한 공감 또는 충격
3. 문제 제기(15-30초): "나만 힘든가?" 공감대 형성
4. 해결책(30-45초): 재개발 투자의 가능성
5. CTA(45-60초): 책 구매 유도

톤 앤 매너:
- 친근하고 공감 가는 말투
- "~요", "~ㅂ니다" 혼용
- 숫자/데이터 활용 (구체성)
- 희망적이지만 과장 금지

출력 형식:
각 챕터별로:
[타임코드] 챕터명
🎭 감정/분위기
📝 내레이션 (말 그대로 읽을 대본)
🎬 화면 설명 (어떤 영상/이미지가 나올지)

예시:
[0-15초] 훅
🎭 분위기: 좌절 → 반전
📝 "고딩 친구는 강남 아파트 2채인데, 나는 청약만 5번 떨어졌어요. 근데... 10년 뒤 제가 100억 자산가가 됐습니다."
🎬 화면: 청약 낙첨 문자 → 고급 아파트 → 책 표지

이제 위 정보를 바탕으로 영상 1탄 "강남 아파트 두 채 가진 고딩 친구의 비밀은?" 스크립트를 작성해주세요.
```

### B. 카드뉴스 스토리보드 생성

```
역할: 당신은 인스타그램 100만 저장 카드뉴스 기획자입니다.

작업: 8컷 카드뉴스 스토리보드 작성

책 정보: [위와 동일]

카드뉴스 콘셉트:
- 제목: "청약 5번 떨어진 주부가 100억 만든 비법"
- 형식: 스토리텔링 (감정선 있는 이야기)
- 톤: 웹툰 느낌, 공감형
- 목적: 저장하고 싶게 만들기

각 컷 구성 요소:
1. 컷 번호 (1/8, 2/8...)
2. 장면 제목
3. 감정/분위기
4. 메인 카피 (큰 텍스트, 10자 이내)
5. 서브 카피 (작은 텍스트, 1-2줄)
6. 비주얼 설명 (어떤 이미지/일러스트)
7. 색상 분위기 (컷마다 감정에 맞게)

출력 형식:
---
컷 1/8: [장면 제목]
🎭 감정: [감정]
📢 메인 카피: "[10자 이내 임팩트 문구]"
📝 서브 카피: "[1-2줄 설명]"
🎨 비주얼: [이미지 설명]
🌈 색상: [색상 톤]
---

예시:
---
컷 1/8: 오프닝
🎭 감정: 호기심 유발
📢 메인 카피: "또 떨어졌어..."
📝 서브 카피: "청약 5번째 실패. 이제 내 집 마련은 포기해야 하나?"
🎨 비주얼: 노트북 앞에서 고개 떨구고 있는 30대 여성, 화면에 '낙첨' 문자
🌈 색상: 회색 톤 (우울한 분위기)
---

이제 8컷 전체 스토리보드를 작성해주세요.
감정선이 자연스럽게 흐르도록:
컷 1-3: 좌절/문제
컷 4-5: 전환점/깨달음
컷 6-7: 성장/성공
컷 8: CTA/책 소개
```

6. 이번 홍보 과정 매뉴얼화 → 시스템 구축
